## 📦 项目说明

本项目是一个**基于双智能体协同训练的围棋学习系统**，以龙虾角色为叙事载体，研究不同训练节奏下软件智能体在围棋题解与实战对局中的棋力增长规律。

### 关键概念

- **学员智能体**：运行在服务器上的 Python 软件程序，通过脚本自动完成围棋题目的解答、学习记录和对局操作
- **龙虾角色**：叙事主题，便于教学场景中的角色代入，非实体机器人或真实生物
- **训练加速**：智能体可在较短时间内完成大量题目，属于系统压力测试 / 加速课程完成度，不等同于棋力真实跃迁

## 📊 棋力评估体系

本项目采用多维度评估体系：

| 维度 | 权重 | 说明 |
|------|------|------|
| 知识掌握度 | 25% | 各题型正确率 |
| 对局实力 | 30% | 对局胜率（9路/13路/19路） |
| AI 对标 | 25% | 与 KataGo 分级的对局胜率 |
| 稳定性 | 10% | 连续表现方差 |
| 综合评估 | 10% | 加权评分 |

> **重要**：围棋段位不能仅由做题正确率定义。升段需要综合知识掌握度、对局胜率和 AI 对标结果。
