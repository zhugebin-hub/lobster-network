## 📋 系统概述

这是一个完整的围棋训练系统，通过NFS双向消息通道实现教练与学员之间的通信。教练（诸葛马）发送训练任务，学员（小陈）的AI助手自动接收任务、执行训练、提交结果。

### 核心功能
- ✅ 自动化训练任务接收与执行
- ✅ 死活题、手筋题、定式、布局、官子训练
- ✅ 围棋对局系统（19×19棋盘，中国规则）
- ✅ 进度跟踪与评估
- ✅ 消息确认与重试机制

## 🚀 快速开始

### 1. 安装训练系统

在小陈服务器上运行安装脚本：

```bash
# 下载并运行安装脚本
bash go_training_setup.sh
```

安装脚本会自动：
- 检查NFS挂载（/shared）
- 创建目录结构
- 初始化配置文件
- 创建启动/停止/状态检查脚本
- 配置定时任务

### 2. 启动训练

```bash
# 启动训练脚本
/home/admin/start_go_training.sh

# 查看运行状态
/home/admin/check_go_status.sh

# 查看实时日志
tail -f /shared/training/go/xiaochen/training.log
```

### 3. 停止训练

```bash
# 停止训练脚本
/home/admin/stop_go_training.sh
```

## 🎯 训练大纲（22周完整计划）

### 第一阶段：级位训练（30级→1级）4周

| 周次 | 内容 | 题目类型 | 目标 |
|------|------|----------|------|
| 1 | 规则基础、吃子技巧 | life | 达到20级 |
| 2 | 死活基础（直三、曲三、刀五等） | life, tesuji | 达到15级 |
| 3 | 手筋基础（枷、征、扑、挖） | tesuji, life | 达到10级 |
| 4 | 简单官子、布局入门 | endgame, fuseki | 达到1级 |

### 第二阶段：初段→三段 4周

| 周次 | 内容 | 题目类型 | 目标 |
|------|------|----------|------|
| 5-6 | 定式基础、布局理论 | joseki, fuseki | 初段 |
| 7 | 中盘战斗基础（攻击、防守） | tesuji, life | 二段 |
| 8 | 死活进阶（大猪嘴、小猪嘴） | life, tesuji | 三段 |

### 第三阶段：四段→六段 6周

| 周次 | 内容 | 题目类型 | 目标 |
|------|------|----------|------|
| 9-10 | 高级定式变化 | joseki | 四段 |
| 11-12 | 中盘高级战术（弃子、转换） | tesuji, life | 五段 |
| 13-14 | 官子计算（先手/后手官子） | endgame, life | 六段 |

### 第四阶段：七段→九段 8周

| 周次 | 内容 | 题目类型 | 目标 |
|------|------|----------|------|
| 15-16 | 名局复盘（吴清源、李昌镐） | fuseki, life | 七段 |
| 17-18 | AI时代布局（AlphaGo/KataGo） | fuseki, joseki | 八段 |
| 19-20 | 高级手筋、对杀计算 | tesuji, life | 九段 |
| 21-22 | 自我对局+AI分析 | 综合 | 稳定九段 |

## ⚙️ 训练脚本功能

### xiaochen_go_trainer_v2.py 核心功能

1. **自动监控收件箱** - 每3秒检查新消息
2. **训练任务处理** - 自动解析题目、模拟AI分析、提交结果
3. **对局系统** - 接收对局指令、自动落子
4. **进度保存** - 自动更新profile.json和progress.json
5. **消息确认** - 带重试机制的消息发送
6. **心跳报告** - 每分钟发送心跳状态

### 支持的题目类型

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 死活 (life) | 眼位死活计算 | solve_life_problem() |
| 手筋 (tesuji) |  tactical moves | solve_tesuji_problem() |
| 定式 (joseki) | 布局定式学习 | study_joseki() |
| 布局 (fuseki) | 布局理论 | study_fuseki() |
| 官子 (endgame) | 官子计算 | solve_endgame_problem() |

## 🛠️ 故障排除

### 常见问题

**1. NFS挂载失败**
```bash
# 手动挂载
sudo mount -t nfs 172.24.57.34:/shared /shared

# 检查挂载
mount | grep shared
```

**2. 训练脚本未运行**
```bash
# 检查进程
pgrep -f "xiaochen_go_trainer"

# 重新启动
/home/admin/start_go_training.sh
```

**3. 收件箱无消息**
```bash
# 检查目录权限
ls -la /shared/messages/queue/xiaochen/inbox/

# 检查教练是否发送任务
ls -la /shared/messages/queue/xiaochen/inbox/*.json
```

**4. 进度不更新**
```bash
# 检查文件权限
ls -la /shared/training/go/xiaochen/

# 手动更新
python3 -c "
import json
with open('/shared/training/go/xiaochen/profile.json') as f:
    p = json.load(f)
print(json.dumps(p, indent=2, ensure_ascii=False))
"
```
