## 📖 使用说明

本手册为智能体棋艺提升训练的实操指南，包含每日训练内容、训练方法和评估标准。

> **说明**：所有学员均为运行在服务器上的 Python 软件程序，以龙虾角色为叙事主题。训练加速属于软件执行效率，不等同于棋力真实跃迁。

### 训练原则
1. **循序渐进**: 从基础到高级，逐步提升
2. **理论结合实战**: 每天理论学习+实战练习
3. **重视复盘**: 每局必复盘，从错误中学习
4. **持续跟踪**: 记录训练进度，定期评估
5. **多维度评估**: 棋力评估不只看做题正确率，需结合对局表现和 AI 对标

## ⚫ 围棋训练指导

### 第1周：死活基础训练

#### 训练内容
- **理论学习**: 直三、曲三、丁四、刀五、梅花五
- **专项训练**: 死活题10道/天
- **实战练习**: 9路棋盘对局，每天1局

#### 训练方法
```
1. 学习死活基本型（30分钟等效）
2. 完成死活题（30分钟等效）
3. 实战对局1局（30分钟/方）
4. 复盘分析（20分钟等效）
```

#### 评估标准
- [ ] 能独立完成基本死活题（正确率 ≥ 70%）
- [ ] 对局中能识别死活形状
- [ ] 复盘能指出关键着法
- [ ] 生成 SGF 棋谱文件

## 🎓 教练提示

### 训练建议
1. **每天坚持**: 棋艺如逆水行舟，不进则退
2. **重视基础**: 基础不牢，地动山摇
3. **善于总结**: 从每局棋中吸取经验教训
4. **勇于挑战**: 与高手过招才能快速进步
5. **保持兴趣**: 享受下棋乐趣，不要急于求成

### 常见错误
1. **贪吃子**: 不要只盯着吃子，要看全局
2. **无计划**: 走一步看一步，缺乏长远计划
3. **不复盘**: 下完就结束，不总结经验教训
4. **怕输棋**: 输棋是进步的机会，不要害怕
5. **不学习**: 只下棋不学习理论，进步缓慢

### 成功秘诀
1. **系统学习**: 建立完整的知识体系
2. **刻意练习**: 针对弱点专项训练
3. **深度复盘**: 每局必复盘，找出改进点
4. **持续跟踪**: 记录训练进度，定期评估
5. **保持耐心**: 棋艺提升需要时间，不要急于求成
