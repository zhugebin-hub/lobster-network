## 一、项目定位与核心概念

### 1.1 项目定义

本项目是一个**基于双智能体协同训练的围棋学习系统**，以龙虾角色为叙事载体，研究不同训练节奏下软件智能体在围棋题解与实战对局中的棋力增长规律。

### 1.2 关键概念澄清

| 术语 | 含义 |
|------|------|
| 龙虾 / 小龙虾 | **叙事主题**，非生物实体或仿生硬件。学员智能体以龙虾角色命名（小陈、诸葛虾），便于教学场景中的角色代入 |
| 学员 / 智能体 | 运行在服务器上的 **Python 软件程序**（software agent），通过脚本自动完成围棋题目的解答、学习记录和对局操作 |
| 教练（诸葛马 / Hermes） | 负责任务分发、难度调节、结果审阅的**调度智能体** |
| 九段目标 | **长期方向性目标**，不代表当前已达到的棋力水平。棋力评估需通过多维度指标（见 4.1 节）综合判定 |

### 1.3 研究对象说明

- **软件性质**：所有学员均为运行在 Linux 服务器上的 Python 脚本，通过读取题库 JSON 文件、调用围棋规则库进行题解，并将结果写入结构化日志文件
- **非实体性**：不涉及仿生硬件、真实生物或机器人物理感知
- **训练加速**：智能体可以在较短时间内完成大量题目练习（如 1 天完成约 4 周的人类学习量），但这属于**系统压力测试 / 加速课程完成度**，不等同于棋力的真实跃迁

## 三、训练大纲（从入门到高段）

### 第一阶段：级位训练（30级→1级）约4周

| 周次 | 内容 | 目标 |
|------|------|------|
| 第1周 | 规则基础、吃子技巧、气的概念 | 达到20级 |
| 第2周 | 死活基础（直三、曲三、刀五等） | 达到15级 |
| 第3周 | 手筋基础（枷、征、扑、挖） | 达到10级 |
| 第4周 | 简单官子、布局入门 | 达到1级 |

### 第二阶段：初段→三段 约4周

| 周次 | 内容 | 目标 |
|------|------|------|
| 第5周 | 定式基础（星位、小目） | 初段 |
| 第6周 | 布局理论（中国流、小林流） | 初段 |
| 第7周 | 中盘战斗基础（攻击、防守） | 二段 |
| 第8周 | 死活进阶（大猪嘴、小猪嘴） | 三段 |

### 第三阶段：四段→六段 约6周

| 周次 | 内容 | 目标 |
|------|------|------|
| 第9-10周 | 高级定式变化 | 四段 |
| 第11-12周 | 中盘高级战术（弃子、转换） | 五段 |
| 第13-14周 | 官子计算（先手/后手官子） | 六段 |

### 第四阶段：七段→九段 约8周

| 周次 | 内容 | 目标 |
|------|------|------|
| 第15-16周 | 名局复盘（吴清源、李昌镐） | 七段 |

## 四、棋力评估体系

### 4.1 多维度评估指标

> **重要说明**：围棋段位不能仅由做题正确率定义。本项目采用多维度评估体系，综合判定智能体的棋力水平。

| 评估维度 | 指标 | 数据来源 | 权重 |
|----------|------|----------|------|
| **知识掌握度** | 各题型正确率（死活/手筋/定式/官子/布局） | problem_history/ JSON 记录 | 25% |
| **对局实力** | 对局胜率（9路/13路/19路分别统计） | game_records/ SGF 文件 | 30% |
| **AI 对标** | 与 KataGo 分级的对局胜率 / 复盘误差 | KataGo 分析结果 | 25% |
| **稳定性** | 连续 N 局表现方差、弱点改善趋势 | progress.json 追踪 | 10% |
| **综合评估** | 知识掌握 + 对局实力的加权评分 | 计算得出 | 10% |

### 4.2 升段标准（综合判定）

| 段位 | 知识掌握度 | 对局胜率 | AI 对标 | 其他要求 |
|------|-----------|---------|---------|---------|
| 级位→初段 | ≥ 80% | 9路胜率 ≥ 50%（≥ 10局） | - | 掌握基本死活 |
| 初段→二段 | ≥ 85% | 9路胜率 ≥ 60%（≥ 15局） | KataGo 10k 级别胜率 ≥ 30% | 定式 10+ |
| 二段→三段 | ≥ 85% | 9路胜率 ≥ 65%（≥ 20局） | KataGo 5k 级别胜率 ≥ 30% | 中盘战术 |
| 三段→四段 | ≥ 88% | 13路胜率 ≥ 50%（≥ 10局） | KataGo 1k 级别胜率 ≥ 25% | 高级定式 |
| 四段→五段 | ≥ 90% | 13路胜率 ≥ 55% | KataGo 1d 级别胜率 ≥ 20% | 官子计算 |
| 五段→六段 | ≥ 90% | 13路胜率 ≥ 60% | KataGo 3d 级别胜率 ≥ 15% | 综合稳定 |
| 六段→七段 | ≥ 92% | 19路胜率 ≥ 40% | KataGo 5d 级别胜率 ≥ 10% | 名局复盘 |
| 七段→八段 | ≥ 93% | 19路胜率 ≥ 45% | KataGo 7d 级别胜率 ≥ 8% | AI布局 |
| 八段→九段 | ≥ 95% | 19路胜率 ≥ 50% | KataGo 9d 级别胜率 ≥ 5% | 综合稳定 |

### 4.3 当前状态

截至 2026-06-14：

| 维度 | 诸葛虾 | 评估 |
|------|--------|------|
| 知识掌握度 | 78.1%（311题，243正确） | 属于"继续当前训练"范围（70-89%） |
| 对局实力 | **尚未启动**（game_records 为空） | 缺少关键数据 |
| AI 对标 | **尚未对接** | 未接入 KataGo |
| 综合段位 | **级位阶段**（非初段） | 仅知识维度达标初段门槛，对局维度缺失 |

> **注**：此前报告中的"初段"为暂定级别，仅基于知识掌握度。在缺少对局数据的情况下，不应授予正式段位。待对局系统启动并积累足够棋谱后，重新综合评估。

## 六、对局系统

两个智能体互相下棋，教练裁判：

```
教练发送 → 对局指令 → 小陈执黑 / 诸葛虾执白
         ↓
    小陈落子 → 写入 go/move.json → 教练广播 → 诸葛虾收到
         ↓
    诸葛虾落子 → 写入 go/move.json → 教练广播 → 小陈收到
         ↓
    循环直到终局
         ↓
    终局结果 → 写入 SGF 文件 → KataGo 分析 → 更新评估
```

### 6.1 对局记录格式

每局对局生成 SGF（Smart Game Format）文件，记录完整棋谱，用于：
- 棋力评估（胜率、目差、关键着法分析）
- 复盘分析（错误着法识别、改进建议）
- AI 对标（KataGo 分析误差）

### 6.2 对局计划

| 阶段 | 棋盘大小 | 每局时间 | 最低局数要求 |
|------|---------|---------|-------------|
| 第1-4周（级位） | 9路 | 20分钟/方 | 5局 |
| 第5-8周（初段→三段） | 9路→13路 | 30分钟/方 | 15局 |
| 第9-14周（四段→六段） | 13路 | 30分钟/方 | 20局 |
| 第15-22周（七段→九段） | 19路 | 45分钟/方 | 30局 |

## 七、训练数据说明

### 7.1 数据来源

所有训练数据存储于 `/shared/training/go/` 目录，包括：

- **题库**：`problem_bank/` 下 5 个分类，共 309 个 JSON 文件
- **答题记录**：`zhuguxia/problem_history/` 和 `xiaochen/problem_history/` 下的每日 JSON 文件
- **进度汇总**：`progress.json` 和 `progress/` 目录下的统计文件
- **对局记录**：`game_records/` 目录下的 SGF 文件（**当前为空，待补充**）

### 7.2 数据一致性说明

> **注意**：在 v5.0 重构前，存在以下数据口径不一致问题，已在此版本中修正：
>
> - 分类加总数：311 题 / 243 正确 / 78.1%
> - 系统记录数：304 题 / 238 正确 / 78.3%
> - 差异原因：冲刺训练（2026-06-04）的 232 题中，部分题目同时出现在多个分类统计中，导致加总数偏高
>
> **统一口径**：以 `progress.json` 中的 `total_solved=304`、`total_correct=238`、`overall_accuracy=0.783` 为准。分类加总数据仅作为参考，不代表独立统计。

### 7.3 数据可追溯性

研究需要可追溯的原始数据，当前状态：

| 数据类型 | 状态 | 位置 |
|----------|------|------|
| 题库文件 | ✅ 完整 | `problem_bank/` 下 5 个分类 |
| 答题记录 | ✅ 存在 | `zhuguxia/problem_history/` 目录 |
| 错题记录 | ⚠️ 部分 | 答题记录中包含错误标记，但无独立错题集 |
| 对局棋谱 | ❌ 缺失 | `game_records/` 目录为空 |
| AI分析记录 | ❌ 缺失 | 未接入 KataGo |
| 评估脚本 | ⚠️ 部分 | 有基础统计脚本，缺综合分析 |
