## 排课原则

1. **教师不冲突**：同一教师同一时间只能在一个班级上课
2. **主科优先**：语文、数学、英语、科学优先安排上午
3. **均衡分布**：同一学科尽量隔天安排
4. **连堂处理**：科学、历史与社会可连堂 2 节
5. **体育分散**：同班级体育课不集中在同一天
