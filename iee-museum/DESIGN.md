# 🏛️ 信息与电子工程学院线上院史馆系统设计

> 访客扫码加入钉钉群 → 与小龙虾私聊 → 沉浸式了解学院历史与文化

---

## 一、用户旅程

```
[访客] 扫码加入钉钉群
  ↓
[系统] 自动发送欢迎消息 + 导航菜单
  ↓
[访客] 私聊小龙虾，输入数字或自然语言
  ↓
[小龙虾] 根据意图返回对应内容（文字+图片+链接）
  ↓
[访客] 继续对话探索 / 参与答题 / 贡献史料
```

---

## 二、核心功能模块

### 1. 🏠 欢迎页 & 导航菜单

访客首次私聊时自动发送：

```
🦞 欢迎来到信息与电子工程学院线上院史馆！

我是小龙虾，你的院史讲解员。请输入数字或告诉我你想了解的内容：

1️⃣ 学院简介
2️⃣ 历史沿革（时间轴）
3️⃣ 师资队伍
4️⃣ 学科专业
5️⃣ 科研成果
6️⃣ 知名校友
7️⃣ 校园风光（老照片）
8️⃣ 院史闯关答题
9️⃣ 贡献史料
0️⃣ 返回主菜单

💡 也可以直接问我问题，比如："学院有多少教授？" "谁是知名校友？"
```

### 2. 📜 历史沿革（时间轴）

**交互方式：**
- 访客输入 `2` 或说"历史沿革"
- 小龙虾按年代分段讲述，每段可追问详情

**时间轴结构：**
```
📅 建院初期（年份待补充）
   - 创办背景
   - 首批专业设置
   - 首任院长/书记

📅 发展壮大（年份待补充）
   - 专业扩展
   - 实验室建设
   - 师资增长

📅 新时代跨越（年份待补充）
   - 学科升级
   - 重大成果
   - 国际合作
```

**追问示例：**
- "详细介绍建院初期的故事"
- "那几年有什么重大事件？"
- "看看那时候的照片"

```
📊 总数：XX 人
🎓 教授：XX 人
🔬 副教授：XX 人
🌟 国家级人才：XX 人
🏆 省级人才：XX 人

📌 知名教授：
1. [姓名] - [职称] - [研究方向] - [简介]
2. ...

💡 输入教授名字可查看详情，或输入方向筛选：
   "人工智能方向" "通信方向" "产业教授"
```

### 4. 📚 学科专业

### 8. 🎮 院史闯关答题（新生教育）

**交互方式：**
- 访客输入 `8` 或说"院史答题"
- 小龙虾出题，逐题互动

**答题流程：**
```
🎮 院史闯关答题
━━━━━━━━━━━━━━━
第 1 关：入门级（共 5 题）

Q1: 信息与电子工程学院位于浙江工商大学的哪栋楼？
A. 信电楼  B. 实验楼  C. 教学楼

[访客回复答案]

✅ 回答正确！+10 分

━━━━━━━━━━━━━━━

```

**关卡设计：**
- 🟢 入门级（5题）：学院基本信息
- 🟡 进阶级（5题）：历史事件、人物
- 🔴 达人级（5题）：深度知识
- 🏆 通关后生成电子证书（图片）

## 三、对话交互设计

### 3.1 意图识别

| 用户输入 | 意图 | 响应 |
|---------|------|------|
| "1" / "简介" / "学院介绍" | 学院简介 | 发送简介内容 |
| "2" / "历史" / "沿革" | 历史沿革 | 发送时间轴 |
| "3" / "老师" / "教授" | 师资队伍 | 发送师资列表 |
| "4" / "专业" / "学科" | 学科专业 | 发送专业信息 |
| "5" / "科研" / "成果" | 科研成果 | 发送科研成果 |
| "6" / "校友" | 知名校友 | 发送校友名录 |
| "7" / "照片" / "老照片" | 历史照片 | 发送图片 |
| "8" / "答题" / "闯关" | 院史答题 | 开始答题 |
| "9" / "贡献" / "投稿" | 贡献史料 | 发送贡献指南 |
| "0" / "菜单" / "主菜单" | 返回主菜单 | 发送导航菜单 |
| "退出" / "再见" | 结束对话 | 发送告别语 |
| 自由提问 | 问答 | 基于知识库回答 |

### 3.2 上下文记忆

小龙虾需要记住：
- 用户当前所在模块（方便"返回""上一级"）
- 答题进度和得分
- 用户身份（新生/校友/访客）

### 3.3 多轮对话示例

```
访客: 我想了解学院历史
小龙虾: 📜 学院历史沿革...
       [时间轴内容]
       💡 输入年代编号可查看详情，或回复"0"返回主菜单

访客: 想看看建院初期的故事
小龙虾: 🏫 建院初期（年份）...
       [详细内容]
       [配图：老照片]

访客: 第一任院长是谁？
小龙虾: 🎓 第一任院长是 [姓名]...
       [详细介绍]
```

## 四、技术实现方案

### 4.1 架构

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  钉钉群聊    │────▶│  小龙虾 AI   │────▶│  院史知识库  │
│  (扫码加入)  │◀────│  (对话引擎)  │◀────│  (结构化数据)│
└─────────────┘     └──────────────┘     └─────────────┘
                           │
                    ┌──────┴──────┐
                    ▼             ▼
              ┌──────────┐  ┌──────────┐
              │ 答题系统  │  │ 图片库   │
              └──────────┘  └──────────┘
```

### 4.2 知识库结构

```
/home/admin/.openclaw/workspace/iee-museum/
├── DESIGN.md              # 本设计文档
├── KNOWLEDGE.md           # 学院知识（从官网采集）
├── TIMELINE.md            # 历史时间轴
├── FACULTY.md             # 师资队伍
├── ALUMNI.md              # 知名校友
├── RESEARCH.md            # 科研成果
├── PHOTOS/                # 历史照片
│   ├── old-campus.jpg
│   ├── first-lab.jpg
│   └── ...
├── QUIZ.md                # 题库
└── CONTRIBUTIONS/         # 校友贡献的史料
```

### 4.3 实现方式

**方案 A：基于现有小龙虾（推荐 MVP）**
- 利用 OpenClaw 的 DingTalk 集成
- 将知识库注入到 AI 的 System Prompt / 技能文件中
- 访客私聊时，AI 自动从知识库检索回答
- ✅ 快速上线，无需额外开发
- ⚠️ 依赖 AI 的理解能力

**方案 B：专用 Skill 插件**
- 开发 `iee-museum` skill
- 结构化知识库 + 意图路由
- 更精确的回复控制
- ✅ 更稳定可控
- ⚠️ 需要开发时间

**方案 C：独立服务**
- 独立的对话服务 + 知识库
- 支持更复杂的交互逻辑
- ✅ 功能最完整
- ⚠️ 开发成本高
