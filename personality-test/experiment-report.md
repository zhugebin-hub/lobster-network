## 三、实验内容

### 3.1 需求描述

通过与小龙虾对话，提出开发需求：
- 开发一个 MBTI 类型的性格测试 Web 应用
- 支持自定义性格维度
- 包含基础测试和结果报告功能
- 技术栈由 AI 助手推荐

### 3.2 开发过程

#### （1）项目初始化

小龙虾自动创建了完整的项目结构：
```
personality-test/
├── backend/           # 后端服务
│   ├── server.js      # Express API 服务器
│   ├── scripts/       # 数据库初始化脚本
│   └── data/          # 数据存储
├── frontend/          # 前端应用
│   ├── src/
│   │   ├── views/     # 页面组件
│   │   ├── stores/    # 状态管理
│   │   └── router/    # 路由配置
│   └── dist/          # 生产构建
└── README.md          # 项目文档
```

#### （2）性格模型设计

采用四维度八极性格模型（参考 MBTI）：

| 维度 | 两极 | 说明 |
|------|------|------|
| 能量来源 | E（外向）←→ I（内向） | 获取能量的方式 |
| 信息处理 | N（直觉）←→ S（感觉） | 处理信息的方式 |
| 决策方式 | T（理性）←→ F（感性） | 做决策的方式 |
| 生活态度 | J（计划）←→ P（灵活） | 组织生活的方式 |

共生成 16 种性格类型，每种包含：
- 类型名称（如"物流师 ISTJ"）
- 性格描述
- 优势特点
- 劣势注意
- 职业建议

#### （3）测试题目设计

每个维度设计 10 道题目，共 40 题：
- 采用 Likert 5 点量表（非常不同意→非常同意）
- 题目方向平衡（正向/反向）
- 实时计分逻辑

#### （4）功能实现

**前端功能：**
- 首页：测试介绍和维度说明
- 测试页：题目展示、进度条、答题交互
- 结果页：性格类型、维度得分可视化、详细分析

**后端功能：**
- GET /api/questions - 获取测试题目
- POST /api/submit - 提交测试结果
- GET /api/type/:code - 获取性格类型详情

### 3.3 部署与测试

1. 安装依赖：`npm install`
2. 初始化数据库：`npm run init-db`
3. 启动后端：`npm start`（端口 3000）
4. 启动前端：`npm run dev`（端口 5173）
5. 访问测试：http://localhost:5173

## 五、技术要点

### 5.1 前端技术

- **Vue 3 Composition API：** 使用 `<script setup>` 语法
- **Pinia 状态管理：** 统一管理测试状态和计分逻辑
- **Vue Router：** 页面路由导航
- **Tailwind CSS：** 快速构建响应式 UI

### 5.2 后端技术

- **Express.js：** 轻量级 API 服务器
- **RESTful API：** 标准化接口设计
- **JSON 存储：** 简化数据持久化

### 5.3 计分算法

```javascript
// 每个维度两个极性的得分计算
维度得分 = 正向题目得分 + (5 - 反向题目得分)
性格类型 = 各维度得分较高者的组合
```

### 6.1 对 AI 辅助开发的新认识

这次实验让我深刻体会到了 AI 助手在软件开发中的巨大潜力。以前我认为编程必须自己一行一行写代码，但通过与小龙虾的对话，我发现自然语言描述需求就能获得完整的应用框架。这大大降低了开发门槛，让我能够把精力集中在业务逻辑和用户体验上，而不是纠结于语法细节。

### 6.2 人机协作的工作流程

我总结出与 AI 协作开发的高效流程：

1. **清晰描述需求**：告诉 AI 你想要什么，包括功能、平台、技术偏好
2. **及时反馈调整**：遇到问题立刻告诉 AI，它会快速修复
3. **理解生成代码**：不要盲目复制，要理解 AI 生成的代码逻辑
4. **主动测试验证**：每完成一个功能就测试，确保符合预期

### 6.3 技术收获

通过本次实验，我掌握了：
- Vue 3 组件化开发的基本模式
- 前后端分离架构的设计思路

### 6.4 遇到的挑战与解决

**挑战 1：** 服务无法外部访问  
**解决：** AI 帮我诊断是防火墙问题，添加了 iptables 规则并指导我在云控制台开放安全组端口。

**挑战 2：** 前端构建失败  
**解决：** Vue 组件语法错误，AI 快速定位并修复了路由导入和组件模板问题。
