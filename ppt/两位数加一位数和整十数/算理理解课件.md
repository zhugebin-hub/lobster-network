### 23 + 5 = ?

## 方法一：摆小棒

```

     (2 个十)              (3 个一)

5：                          |||||
                            (5 个一)

相加：||  ||||  ||||  ||||   ||||||||
      (2 个十)              (8 个一)

结果：28
```

# 探究新知（一）
## 两位数加一位数（不进位）

### 方法二：数的组成

```
    23  +  5  =  28
   /  \      /
  20   3    8
   \   |   /
    \  |  /
     \ | /
    先算 3 + 5 = 8
    再算 20 + 8 = 28
```

### 算理：
**个位加个位，十位不变**

# 对比总结

## 两种加法的区别

| 类型 | 例子 | 计算方法 | 算理 |
|------|------|----------|------|
| 两位数加一位数 | 23 + 5 | 个位相加，十位不变 | 相同数位相加 |
| 两位数加整十数 | 23 + 40 | 十位相加，个位不变 | 相同数位相加 |

## 核心算理
> **相同数位上的数才能直接相加**
> - 个位 + 个位
> - 十位 + 十位

---

# 算理理解

## 为什么这样算？

### 数的组成原理

```
23 = 20 + 3  (2 个十和 3 个一)
5  = 0 + 5   (0 个十和 5 个一)
────────────────────────
23 + 5 = (20 + 0) + (3 + 5) = 20 + 8 = 28
```

```
23 = 20 + 3  (2 个十和 3 个一)
40 = 40 + 0  (4 个十和 0 个一)
────────────────────────
23 + 40 = (20 + 40) + (3 + 0) = 60 + 3 = 63
```

### 本质：
> **只有相同计数单位的数才能直接相加**

---

# 易错点提醒

## 常见错误

❌ **错误 1**：23 + 5 = 235（直接把 5 写在后面）
> 纠正：5 是个位，要和 3 相加，不是写在后面

❌ **错误 2**：23 + 40 = 27（把 4 和 3 相加）
> 纠正：40 是 4 个十，要和 20 相加，不是和 3 相加

❌ **错误 3**：23 + 40 = 60（忘记加个位的 3）
> 纠正：个位的 3 不变，要加到结果里

## 记住：
> **看清加的是什么位的数！**
