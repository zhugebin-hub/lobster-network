【知识文档】RAG（检索增强生成）技术详解
类别：网页 | 可信度：高 | 来源：技术博客
日期：2024-04-15

RAG（Retrieval-Augmented Generation）是将信息检索与文本生成相结合的技术框架。

一、RAG架构

┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   用户查询   │───→│  检索器     │───→│  生成器     │
└─────────────┘    │ (Retriever)  │    │ (Generator) │
                   └─────────────┘    └─────────────┘
                         ↑
                   ┌─────────────┐
                   │  知识库     │
                   │ (向量数据库) │
                   └─────────────┘

二、核心组件

1. 文档处理
   - 文档分割：按段落/语义切分为chunk
   - 文本清洗：去除无关格式、HTML标签
   - 元数据标注：来源、日期、类别

2. 向量化（Embedding）
   - 将文本转换为稠密向量
   - 常用模型：text-embedding-3、bge-large、m3e
   - 维度：512-4096维

3. 向量数据库
   - ChromaDB：轻量级，适合开发测试
   - Milvus：企业级，支持大规模
   - Pinecone：云端托管
   - FAISS：Facebook开源，高效相似度搜索

4. 检索策略
   - 稠密检索：向量相似度（余弦相似度、内积）
   - 稀疏检索：BM25关键词匹配
   - 混合检索：稠密+稀疏，兼顾语义和关键词

三、RAG的优势

- 减少幻觉：基于检索到的文档生成
- 知识可更新：无需重新训练，更新知识库即可
- 可追溯：引用来源，增强可信度
- 成本低：避免频繁微调大模型

四、应用场景

- 企业知识库问答
- 客服机器人
- 法律/医疗文档检索
- 学术研究辅助
