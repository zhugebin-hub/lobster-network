【知识文档】线性回归与逻辑回归
类别：课件 | 可信度：高 | 来源：浙江工商大学AI学院课件
日期：2024-03-15

一、线性回归（Linear Regression）

定义：用线性模型拟合输入特征与连续目标变量之间的关系。

模型形式：y = w^T * x + b
- w：权重向量
- b：偏置
- x：输入特征向量

损失函数：均方误差（MSE）
L = (1/n) * Σ(y_i - ŷ_i)²

求解方法：
1. 最小二乘法（解析解）：w = (X^T X)^(-1) X^T y
2. 梯度下降（迭代解）：
   w = w - α * ∇L
   α：学习率

正则化：
- Lasso（L1）：L + λ*|w|，可产生稀疏解
- Ridge（L2）：L + λ*w²，防止过拟合
- Elastic Net：L1 + L2 组合

二、逻辑回归（Logistic Regression）

定义：用线性模型解决二分类问题。

模型形式：P(y=1|x) = σ(w^T * x + b)
σ(z) = 1 / (1 + e^(-z))  # Sigmoid函数

损失函数：交叉熵损失
L = -(1/n) * Σ[y_i*log(ŷ_i) + (1-y_i)*log(1-ŷ_i)]

评估指标：
- 混淆矩阵：TP、FP、TN、FN
- 准确率 = (TP+TN) / 总样本
- 精确率 = TP / (TP+FP)
- 召回率 = TP / (TP+FN)
- F1 = 2 * 精确率 * 召回率 / (精确率 + 召回率)
