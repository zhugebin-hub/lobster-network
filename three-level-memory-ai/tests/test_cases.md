# 三级记忆 AI 助手 - 测试用例

## 测试环境
- 主题：人工智能基础与机器学习
- 知识库：15份文档，覆盖AI历史、机器学习、深度学习、NLP、CV、LLM等
- 测试日期：2026-05-14

---

## 第一组：基础题（验证感知记忆）

**测试目标：** 单轮对话是否记住上下文

### 测试1.1：连续追问
```
用户：什么是机器学习？
AI：[回答机器学习定义]
用户：它有哪些主要类型？
AI：[应基于上文"机器学习"继续回答监督学习、无监督学习、强化学习]
```
**预期：** AI能在同一对话中保持上下文连贯性

### 测试1.2：指代理解
```
用户：Transformer是什么？
AI：[介绍Transformer架构]
用户：它的核心组件有哪些？
AI：[应理解"它"指Transformer，回答自注意力、多头注意力等]
```
**预期：** AI能正确理解代词指代

### 测试1.3：上下文窗口限制
```
连续进行10轮对话后，最早的对话内容是否被遗忘
```
**预期：** 超出窗口（10轮）的内容不再保留

---

## 第二组：进阶题（验证短期记忆）

**测试目标：** 跨天对话是否保留历史

### 测试2.1：跨会话回忆
```
Day 1 对话：我想了解深度学习的应用领域
Day 2 对话：你昨天提到的深度学习应用，能详细说说医疗方面的吗？
```
**预期：** AI能回忆起前一天的对话内容

### 测试2.2：标签检索
```
用户：搜索关于"Transformer"的对话记录
```
**预期：** AI能按标签/关键词检索历史对话

### 测试2.3：记忆衰减
```
对话记录保留7天后，超过期限的内容是否自动清理
```
**预期：** 超过retention_days的内容被清理

---

## 第三组：综合题（验证长期记忆/RAG）

**测试目标：** 能否精准调取知识库答案

### 测试3.1：知识问答
```
用户：Transformer架构中的自注意力机制是什么？
```
**预期：** 从知识库中检索到Transformer相关内容，准确回答Q/K/V机制

### 测试3.2：对比分析
```
用户：GAN和扩散模型有什么区别？
```
**预期：** 检索到两种模型的描述，进行对比分析

### 测试3.3：跨领域综合
```
用户：AI在医疗和金融领域的应用有什么异同？
```
**预期：** 检索两个领域的知识，进行综合分析

### 测试3.4：知识边界
```
用户：量子计算在AI中的应用
```
**预期：** 知识库无相关内容时，明确告知无法回答，而非编造
