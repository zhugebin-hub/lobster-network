## 第二章 管理层培训模块

### 2.1 课程目标

学完本课程，管理者能够：
- 用通俗语言解释"智能体"是什么
- 知道智能体能为自己的部门做什么
- 掌握设定规则和审批权限的方法
- 看懂智能体生成的报告
- 知道何时介入、何时放权

### 2.2 课程内容

#### 单元 1：智能体入门（30 分钟）

**什么是智能体？**
> 智能体 = 会思考 + 能执行 + 可学习的数字员工

**与传统软件的区别：**
| 传统软件 | 智能体 |
|---------|--------|
| 你操作它 | 它主动工作 |
| 固定流程 | 自主决策 |
| 需要培训 | 越用越聪明 |
| 报错停机 | 降级运行 |

**举例说明：**
```
传统方式：
  供应链专员每天早上花 2 小时查看各仓库存，
  手动计算调拨计划，打电话安排物流。

智能体方式：
  SupplyAgent 自动监控库存，发现上海仓不足，
  自动从苏州仓调拨 3 吨，钉钉通知供应链总监：
  "已从苏州调拨 3 吨至上海，预计 2 小时到达，
   成本 2800 元，避免缺货损失约 3.2 万元。"
  总监回复"收到"即可。
```

#### 单元 2：五大智能体速览（30 分钟）

| 智能体 | 一句话介绍 | 它能帮你做什么 |
|--------|-----------|---------------|
| FarmAgent | 养殖预测专家 | 告诉您下周能出多少虾、什么时候捕捞最佳 |
| SupplyAgent | 物流调度高手 | 自动安排调拨、选择最优路线、控制损耗 |
| PriceMarketer | 定价营销达人 | 实时调价、精准投放、生成营销方案 |
| FinanceGuard | 财务风控卫士 | 7×24 监控资金、预警风险、生成财报 |
| ServiceOps | 客户服务管家 | 自动回复客诉、预测复购、维护口碑 |

#### 单元 3：管理要点（30 分钟）

**三大管理原则：**
1. **定规则，不微操** —— 设定边界，让智能体自主决策
2. **看异常，不盯日常** —— 关注偏差，而非每个决策
3. **持续优化，不一次定死** —— 每周复盘，调整策略

**审批权限速查表：**
| 决策类型 | 智能体自主 | 需您审批 |
|---------|-----------|---------|
| 调价 | ±10% 以内 | >±10% |
| 调拨 | <3 吨 | ≥3 吨 |
| 营销投放 | <5 万 | ≥5 万 |
| 客户补偿 | <200 元 | ≥200 元 |

#### 单元 4：看懂智能体报告（30 分钟）

**智能体晨报示例：**
```
📊 智能体晨报 | 2026-04-10

🎯 核心指标
  • 昨日营收：287 万元 ✅（目标 275 万，达成 104%）
  • 毛利率：35.1% 📈（环比 +1.2pp）
  • 客诉率：0.8% ✅（目标 <1%）

🤖 智能体运行
  • 自主决策：47 次
  • 人工干预：3 次
  • 异常：1 起（已处理）

⚠️ 需关注
  1. 南京店销量连续 3 天下滑，竞品新店开业
     → 建议：推出老客回馈券
  2. 湖北产区降雨预警，供应可能 -15%
     → 建议：启动安徽备选供应商

📅 今日重点
  1. 审批 5 月营销预算（80 万）
  2. 确认 Q3 供应商名单
```

**如何快速阅读：**
1. 先看 🎯 核心指标 —— 整体好不好
2. 再看 ⚠️ 需关注 —— 有没有异常
3. 最后看 📅 今日重点 —— 今天要做什么

### 3.2 系统操作

#### 3.2.1 登录系统

```
1. 打开钉钉 → 工作台 → "智能体经济"应用
2. 使用钉钉账号登录

#### 3.2.2 查看仪表盘

```
登录后默认进入仪表盘，包含：
┌─────────────────────────────────────┐
│  📊 实时指标    📈 趋势图    🤖 智能体状态  │
├─────────────────────────────────────┤
│  📋 待办审批    ⚠️ 异常预警    📅 今日任务  │
├─────────────────────────────────────┤
│  📝 操作日志    📖 知识库    ❓ 帮助中心    │
└─────────────────────────────────────┘

#### 3.2.3 处理审批

```
1. 点击"待办审批"
2. 查看审批详情（智能体已填充数据和建议）
3. 选择"批准"或"驳回"
4. 驳回需填写原因
5. 审批记录自动归档
```

#### 3.2.4 处理异常

```
1. 收到钉钉异常通知
2. 点击进入异常详情页
3. 查看智能体诊断和建议
4. 选择处理方式：
   - 采纳建议
   - 手动处理
   - 升级上报
5. 记录处理结果
```

### 3.3 业务场景实操

#### 场景 1：智能体推送调价建议

```
情境：PriceMarketer 检测到竞品降价 8%

智能体消息：
"检测到'虾先生'上海店小龙虾降价 8%，
建议同步调价 -5%，预计影响毛利 -1.2pp，
但可保住 85% 市场份额。是否执行？"

操作：
1. 查看竞品价格截图（附件）
2. 查看影响评估
3. 选择：
   - ✅ 执行（智能体自动调价）
   - ❌ 不执行（填写原因）
   - 📝 调整后执行（输入自定义幅度）
```

#### 场景 2：库存预警处理

```
情境：SupplyAgent 预警上海仓库存不足

智能体消息：
"上海仓当前库存 2.1 吨，安全线 3 吨，
预计 2 天后缺货。
建议从苏州仓调拨 3 吨，成本 2800 元。
是否执行？"

操作：
1. 确认库存数据
2. 确认调拨方案
3. 审批通过
4. 跟踪物流状态
```

### 4.3 部署操作

#### 4.3.1 环境检查

```bash
# 检查 Docker
docker --version

# 检查 Docker Compose
docker-compose --version

# 检查 Python
python3 --version

# 检查网络连通性
ping qwen-api.aliyun.com
ping openclaw-gateway:8080
```

#### 4.3.2 启动服务

```bash
# 克隆代码
git clone git@github.com:yefeng/xiaolongxia-agents.git
cd xiaolongxia-agents

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入实际配置

# 启动服务
docker-compose up -d

# 检查状态
docker-compose ps
openclaw status
```

#### 4.3.3 部署 Agent

```bash
# 部署 FarmAgent
openclaw agent deploy farm_agent.yaml

# 部署 SupplyAgent
openclaw agent deploy supply_agent.yaml

# 部署所有 Agent
openclaw agent deploy-all
```

### 4.4 故障排查

#### 常见问题清单

| 问题 | 检查命令 | 解决方案 |

## 第六章 常见问题与解答

### 6.1 通用问题

**Q1：智能体会取代我的工作吗？**
A：不会。智能体是工具，帮您从重复劳动中解放出来，聚焦更有价值的工作。

**Q2：智能体出错怎么办？**
A：系统有完善的降级和审批机制。重大决策需人工审批，出错可追溯。

**Q3：我不懂技术，能用智能体吗？**
A：可以。日常操作只需在钉钉上点几下，无需技术背景。

### 6.2 业务问题

**Q4：智能体定的价格比我定的准吗？**
A：智能体基于海量数据和实时竞争分析，通常更准。但您设定了上下限，不会离谱。

**Q5：智能体能处理突发情况吗？**
A：能识别异常并预警，但重大突发事件（如疫情）仍需人工决策。

### 6.3 技术问题

**Q6：系统宕机了怎么办？**
A：有主备双机，自动切换。极端情况降级到人工模式。

**Q7：数据安全如何保障？**
A：本地化部署、权限管控、操作审计、定期备份。
