### 3.1 FarmAgent（养殖预测智能体）

#### 配置文件 `agents/farm_agent.yaml`

```yaml
agent:

  description: 小龙虾养殖预测与优化智能体

  temperature: 0.3  # 预测任务需要确定性

      source: influxdb://iot-cluster:8086/xiaolongxia
      fields: [water_temp, dissolved_oxygen, ph, ammonia]
      interval: 5m
    
    - name: weather_forecast
      source: api://weather-service/forecast
      params:
        regions: [honghu, qiandaohu, chuzhou]
        days: 30
    
    - name: historical_yield
      source: postgresql://bi-db:5432/farm_data
      table: yield_history
      years: 3

  outputs:
    - name: forecast_report
      format: json
      destination: rabbitmq://forecast_queue
    
    - name: alert_notification
      format: text
      destination: dingtalk://webhook_url

  skills:
    - time_series_foreing
    - anomaly_detection
    - optimization_recommendation
```

#### 核心代码 `agents/farm_agent.py`

```python
from openclaw.agent import BaseAgent
from openclaw.triggers import CronTrigger, EventTrigger
from qwen import QwenClient
import influxdb_client
import pandas as pd

class FarmAgent(BaseAgent):
    def __init__(self, config):
        super().__init__(config)
        self.qwen = QwenClient(model="qwen3.6-plus")
        self.influx = influxdb_client.InfluxDBClient(
            url=config["influx_url"],
            token=config["influx_token"]
        )
    
    async def daily_forecast(self):
        """每日产量预测"""
        # 1. 获取 IoT 数据
        iot_data = self._query_iot_data(days=30)
        
        # 2. 获取气象预报
        weather = self._get_weather_forecast(days=30)
        
        # 3. 构建预测提示词
        prompt = self._build_forecast_prompt(iot_data, weather)
        
        # 4. 调用 Qwen3.6 Plus 生成预测
        forecast = await self.qwen.chat(prompt)
        
        # 5. 解析并存储结果
        result = self._parse_forecast(forecast)
        self._save_forecast(result)
        
        # 6. 发布到消息队列
        self.publish("forecast_queue", result)
        
        return result
    
    def _query_iot_data(self, days):
        """查询 IoT 传感器数据"""
        query = f'''
        from(bucket: "xiaolongxia")
        |> range(start: -{days}d)
        |> filter(fn: (r) => r._measurement == "farm_sensors")
        |> pivot(rowKey:["_time"], columnKey: ["_field"], valueColumn: "_value")
        '''
        result = self.influx.query_api().query(query)
        return self._to_dataframe(result)
    
    def _build_forecast_prompt(self, iot_data, weather):
        """构建预测提示词"""
        return f"""
        作为小龙虾养殖专家，请基于以下数据预测未来 30 天产量：
        
        当前养殖数据：
        - 水温：{iot_data['water_temp'].mean():.1f}°C
        - 溶氧：{iot_data['dissolved_oxygen'].mean():.2f}mg/L
        - PH 值：{iot_data['ph'].mean():.1f}
        - 氨氮：{iot_data['ammonia'].mean():.2f}mg/L
        
        气象预报：
        {weather.to_markdown()}
        
        历史同期产量：{self._get_historical_yield()}
        
        请输出：
        1. 未来 30 天每日预测产量（吨）
        2. 最佳捕捞窗口期
        3. 风险预警及建议
        4. 饲料投喂优化方案
        
        以 JSON 格式输出。
        """
```

## 5 OpenClaw 编排配置

### 5.1 Orchestrator 配置

```yaml
orchestrator:
  name: XiaolongxiaOrchestrator
  description: 小龙虾智能体编排中枢
  
  agents:
    - FarmAgent
    - SupplyAgent
    - PriceMarketer
    - FinanceGuard
    - ServiceOps
  
  workflows:
    - name: daily_operations
      schedule: "0 6 * * *"
      steps:
        - agent: FarmAgent
          action: daily_forecast
        - agent: SupplyAgent
          action: dispatch_plan
          wait_for: FarmAgent
        - agent: PriceMarketer
          action: price_update
          wait_for: SupplyAgent
        - agent: FinanceGuard
          action: daily_check
          wait_for: PriceMarketer
    
    - name: emergency_response
      trigger: "risk_level >= high"
      steps:
        - agent: FinanceGuard
          action: escalate
        - agent: SupplyAgent
          action: contingency_plan
        - agent: ServiceOps
          action: customer_notify
```

### 5.2 通信协议

```python
# Agent 间通信消息格式
class AgentMessage:
    def __init__(self, source, target, action, payload, priority="normal"):
        self.message_id = str(uuid.uuid4())
        self.timestamp = datetime.now()
        self.source = source  # 发送 Agent
        self.target = target  # 接收 Agent
        self.action = action  # 请求动作
        self.payload = payload  # 数据
        self.priority = priority  # low/normal/high/urgent
        self.status = "pending"  # pending/processing/completed/failed
```

## 7 故障排查

### 7.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| Agent 不响应 | 模型 API 超时 | 检查网络，切换备用模型 |
| 预测偏差大 | 数据质量差 | 检查数据源，重新训练 |
| 消息队列积压 | 消费速度慢 | 增加消费者实例 |
| 内存溢出 | 数据量过大 | 分页查询，增加内存 |

### 7.2 应急流程

```
故障发生
  ↓
监控告警（钉钉 + 邮件）
  ↓
值班人员响应（15 分钟内）
  ↓
初步诊断（30 分钟内）
  ↓
├─ 可自动恢复 → 执行恢复脚本
└─ 需人工干预 → 升级至技术负责人
  ↓
故障修复（2 小时内）
  ↓
复盘报告（24 小时内）
```
