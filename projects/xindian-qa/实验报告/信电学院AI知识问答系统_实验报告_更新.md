## 一、项目概述

### 1.1 项目背景

信电学院需要一套能够整合课程教材资源、提供智能问答服务的系统。传统教学方式中，学生遇到问题需要等待教师回复，效率低下。本项目基于阿里云百炼知识库 + OpenClaw 智能体 + 钉钉平台，打造"小龙虾数字员工"，实现 7×24 小时课程知识问答服务。

### 1.2 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                    应用交互层 (App Layer)                    │
│              钉钉机器人 + Webhook + HTTP Server              │
└─────────────────────────────┬───────────────────────────────┘
                              │
┌─────────────────────────────▼───────────────────────────────┐
│                    智能体层 (Agent Layer)                    │
│     百炼API Skill + 本地RAG + 三级记忆路由 + Prompt模板      │
└─────────────────────────────┬───────────────────────────────┘
                              │
┌─────────────────────────────▼───────────────────────────────┐
│                    知识库层 (Knowledge Base)                 │
│         6门课程教材 + SQLite向量数据库 + DashScope Embedding │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 核心功能

- **课程知识问答：** 基于教材原文的智能问答，支持电路分析、信号与系统、数字电子技术等6门课程
- **三级记忆系统：** L1工作记忆（会话上下文）+ L2知识记忆（RAG检索）+ L3长期记忆（用户画像、FAQ统计）
- **钉钉平台对接：** 通过钉钉机器人实现移动端问答，支持群聊和私聊
- **自动回退机制：** 百炼API失败时自动回退到本地RAG系统

#### 2.1.2 本地 RAG 系统

- **向量模型：** DashScope text-embedding-v3
- **存储：** SQLite 向量数据库（vector_db.sqlite）
- **检索：** 余弦相似度 Top-K 检索
- **生成：** DashScope qwen-plus 大模型
- **回退机制：** 百炼API失败时自动切换到本地RAG

#### 2.1.3 技术方案调整

**问题：** 百炼知识库 API 认证失败（错误码 100016）  
**解决方案：** 自建本地 RAG 系统，使用 DashScope Embedding + SQLite + 余弦相似度检索  
**效果：** 本地 RAG 检索准确率良好：
- 基尔霍夫定律相似度：0.590
- 傅里叶变换相似度：0.735
- 触发器相似度：0.732

### 2.2 智能体层

#### 2.2.1 系统架构

```python
class XindianQASystem:
    """信电学院 AI 知识问答系统"""
    
    def process_query(self, query, session_id, user_id):
        # 1. 意图识别
        intent = self._identify_intent(query)
        
        # 2. 根据意图路由
        if intent == 'course_knowledge':
            result = self._handle_course_knowledge(query, session_id, user_id)
        elif intent == 'system_operation':
            result = self._handle_system_operation(query)
        else:
            result = self._handle_casual_chat(query)
        
        # 3. 记忆沉淀
        self._memory_sediment(query, result, session_id, user_id)
        
        return result
```

#### 2.2.2 百炼 API Skill（带本地RAG回退）

- 优先使用百炼知识库 API 进行检索
- 失败时自动回退到本地 RAG 系统
- 支持搜索、上传、向量生成、答案生成等功能

#### 2.2.3 三级记忆路由系统

| 层级 | 名称 | 功能 | 存储方式 |
|-----|------|------|---------|
| L1 | 工作记忆 | 会话上下文、短期记忆 | 内存（字典） |
| L2 | 知识记忆 | 教材知识检索 | 百炼RAG / 本地RAG |
| L3 | 长期记忆 | 用户画像、FAQ统计、对话摘要 | JSON 文件 |

#### 2.2.4 Prompt 模板系统

- 系统 Prompt：定义助手角色和回答规则
- 问答 Prompt：基于知识片段生成答案
- 意图识别 Prompt：区分课程知识/系统操作/闲聊
- 摘要提取 Prompt：对话内容摘要
- 用户画像更新 Prompt：学习画像维护

### 2.3 应用交互层

#### 2.3.1 钉钉机器人

- 接收钉钉消息 → 调用 QA 系统 → 返回答案
- 支持文本消息类型
- 自动处理用户认证和会话管理
- 通过 Webhook 接收消息，HTTP 返回回复

#### 2.3.2 启动脚本

```bash
./start.sh server   # 启动服务
./start.sh test     # 运行测试
./start.sh status   # 查看状态
./start.sh stop     # 停止服务
```
