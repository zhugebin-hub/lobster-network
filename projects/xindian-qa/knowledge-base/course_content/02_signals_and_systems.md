# 信号与系统

## 第一章 信号与系统的基本概念

### 1.1 信号的定义与分类

**信号**是携带信息的物理量，通常表示为时间或空间的函数。

#### 连续时间信号与离散时间信号
- **连续时间信号**：在连续的时间范围内有定义的信号，记为 x(t)
- **离散时间信号**：仅在离散的时间点上有定义的信号，记为 x[n]

#### 确定性信号与随机信号
- **确定性信号**：可以用确定的时间函数表示的信号
- **随机信号**：不能用确定的时间函数表示，只能用统计特性描述的信号

#### 周期信号与非周期信号
- **周期信号**：存在 T > 0，使得 x(t+T) = x(t)，最小正周期 T 称为基本周期
- **非周期信号**：不满足周期条件的信号

#### 能量信号与功率信号
- **能量信号**：0 < E < ∞，其中 E = ∫|x(t)|²dt
- **功率信号**：0 < P < ∞，其中 P = lim(T→∞) (1/2T)∫_{-T}^{T} |x(t)|²dt

### 1.2 基本信号

#### 阶跃信号与冲激信号

**单位阶跃信号**：
$$u(t) = \begin{cases} 1, & t > 0 \\ 0, & t < 0 \end{cases}$$

**单位冲激信号（Dirac δ 函数）**：
$$\delta(t) = 0, \quad t \neq 0$$
$$\int_{-\infty}^{\infty} \delta(t)dt = 1$$

冲激信号的筛选性质：
$$\int_{-\infty}^{\infty} x(t)\delta(t-t_0)dt = x(t_0)$$

冲激信号的尺度性质：
$$\delta(at) = \frac{1}{|a|}\delta(t)$$

#### 复指数信号
$$x(t) = e^{st} = e^{(\sigma + j\omega)t} = e^{\sigma t}(\cos\omega t + j\sin\omega t)$$
其中 s = σ + jω 为复频率。

#### 正弦信号
$$x(t) = A\cos(\omega t + \varphi)$$
- A 为振幅
- ω 为角频率
- φ 为初相位

### 1.3 信号的基本运算

#### 平移（时移）
x(t - t₀)：t₀ > 0 右移，t₀ < 0 左移

#### 反折
x(-t)：以纵轴为对称轴反折

#### 尺度变换
x(at)：a > 1 压缩，0 < a < 1 扩展

#### 综合运算
x(at + b)：先平移后尺度，或先尺度后平移

## 第二章 线性时不变系统（LTI 系统）

### 2.1 系统的性质

#### 线性
若 x₁(t) → y₁(t)，x₂(t) → y₂(t)，则：
$$a x_1(t) + b x_2(t) \rightarrow a y_1(t) + b y_2(t)$$

#### 时不变性
若 x(t) → y(t)，则：
$$x(t - t_0) \rightarrow y(t - t_0)$$

#### 因果性
系统的输出只取决于当前和过去的输入，不取决于未来的输入。

#### 稳定性（BIBO 稳定）
有界输入产生有界输出。

### 2.2 LTI 系统的描述

#### 微分方程描述
连续时间 LTI 系统可用线性常系数微分方程描述：
$$\sum_{k=0}^{N} a_k \frac{d^k y(t)}{dt^k} = \sum_{k=0}^{M} b_k \frac{d^k x(t)}{dt^k}$$

#### 差分方程描述
离散时间 LTI 系统可用线性常系数差分方程描述：
$$\sum_{k=0}^{N} a_k y[n-k] = \sum_{k=0}^{M} b_k x[n-k]$$

### 2.3 LTI 系统的冲激响应与卷积

#### 冲激响应
LTI 系统对单位冲激信号 δ(t) 的零状态响应，记为 h(t)。

#### 卷积积分
连续时间 LTI 系统的零状态响应：
$$y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} x(\tau)h(t-\tau)d\tau$$

#### 卷积和
离散时间 LTI 系统的零状态响应：
$$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k]h[n-k]$$

#### 卷积的性质
- 交换律：x(t) * h(t) = h(t) * x(t)
- 分配律：x(t) * [h₁(t) + h₂(t)] = x(t) * h₁(t) + x(t) * h₂(t)
- 结合律：[x(t) * h₁(t)] * h₂(t) = x(t) * [h₁(t) * h₂(t)]
- 与冲激信号的卷积：x(t) * δ(t) = x(t)
- 时移性质：x(t) * δ(t - t₀) = x(t - t₀)

#### 因果性判据
连续时间 LTI 系统因果 ⇔ h(t) = 0, t < 0
离散时间 LTI 系统因果 ⇔ h[n] = 0, n < 0

#### 稳定性判据
连续时间 LTI 系统 BIBO 稳定 ⇔ ∫|h(t)|dt < ∞
离散时间 LTI 系统 BIBO 稳定 ⇔ Σ|h[n]| < ∞

## 第三章 傅里叶级数表示

### 3.1 周期信号的傅里叶级数

#### 三角形式
周期信号 x(t) 可展开为：
$$x(t) = a_0 + \sum_{n=1}^{\infty} [a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t)]$$
其中 ω₀ = 2π/T 为基波角频率。

#### 指数形式（傅里叶级数）
$$x(t) = \sum_{k=-\infty}^{\infty} a_k e^{jk\omega_0 t}$$
傅里叶系数：
$$a_k = \frac{1}{T} \int_{T} x(t) e^{-jk\omega_0 t} dt$$

#### 傅里叶系数的性质
- 线性：ax₁(t) + bx₂(t) ↔ aa_k + bk
- 时移：x(t - t₀) ↔ a_k e^{-jkω₀t₀}
- 时域反转：x(-t) ↔ a_{-k}
- 共轭对称性（实信号）：a_{-k} = a_k*
- Parseval 定理：$$\frac{1}{T}\int_{T}|x(t)|^2dt = \sum_{k=-\infty}^{\infty}|a_k|^2$$

### 3.2 离散时间周期信号的傅里叶级数（DFS）

$$x[n] = \sum_{k=<N>} a_k e^{jk(2\pi/N)n}$$
$$a_k = \frac{1}{N} \sum_{n=<N>} x[n] e^{-jk(2\pi/N)n}$$

## 第四章 傅里叶变换

### 4.1 连续时间傅里叶变换

#### 定义
正变换：$$X(j\omega) = \int_{-\infty}^{\infty} x(t) e^{-j\omega t} dt$$
逆变换：$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(j\omega) e^{j\omega t} d\omega$$

#### 典型信号的傅里叶变换
| 信号 x(t) | 傅里叶变换 X(jω) |
|-----------|------------------|
| e^{-at}u(t), a>0 | 1/(a+jω) |
| δ(t) | 1 |
| δ(t-t₀) | e^{-jωt₀} |
| 1 | 2πδ(ω) |
| e^{jω₀t} | 2πδ(ω-ω₀) |
| cos(ω₀t) | π[δ(ω-ω₀) + δ(ω+ω₀)] |
| sin(ω₀t) | π/j[δ(ω-ω₀) - δ(ω+ω₀)] |
| rect(t/τ) | τ·Sa(ωτ/2) |

#### 傅里叶变换的性质
- 线性：ax₁(t) + bx₂(t) ↔ aX₁(jω) + bX₂(jω)
- 时移：x(t-t₀) ↔ X(jω)e^{-jωt₀}
- 频移：x(t)e^{jω₀t} ↔ X(j(ω-ω₀))
- 尺度变换：x(at) ↔ (1/|a|)X(jω/a)
- 时域微分：dx(t)/dt ↔ jωX(jω)
- 频域微分：-jtx(t) ↔ dX(jω)/dω
- 时域卷积：x₁(t)*x₂(t) ↔ X₁(jω)X₂(jω)
- 频域卷积：x₁(t)x₂(t) ↔ (1/2π)X₁(jω)*X₂(jω)
- 对偶性：X(t) ↔ 2πx(-ω)

### 4.2 离散时间傅里叶变换（DTFT）

$$X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x[n] e^{-j\omega n}$$
$$x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega$$

DTFT 是 ω 的周期函数，周期为 2π。

### 4.3 傅里叶变换与 LTI 系统

LTI 系统的频率响应：
$$H(j\omega) = \int_{-\infty}^{\infty} h(t) e^{-j\omega t} dt$$

系统对复指数信号 e^{jωt} 的响应为：
$$y(t) = H(j\omega)e^{j\omega t}$$

|H(jω)| 为幅频响应，∠H(jω) 为相频响应。

## 第五章 采样定理

### 5.1 理想采样

理想采样信号：
$$x_s(t) = x(t) \cdot \sum_{n=-\infty}^{\infty} \delta(t - nT_s)$$

采样信号的频谱：
$$X_s(j\omega) = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X(j(\omega - k\omega_s))$$
其中 ω_s = 2π/T_s 为采样角频率。

### 5.2 奈奎斯特采样定理

**采样定理**：若带限信号 x(t) 的最高频率为 ω_m，则当采样频率 ω_s > 2ω_m 时，可以无失真地恢复原信号。

- ω_s = 2ω_m 称为奈奎斯特频率
- T_s = π/ω_m 称为奈奎斯特间隔

### 5.3 信号恢复

通过理想低通滤波器恢复信号：
$$H_r(j\omega) = \begin{cases} T_s, & |\omega| < \omega_c \\ 0, & |\omega| > \omega_c \end{cases}$$
其中 ω_m < ω_c < ω_s - ω_m。

恢复公式：
$$x(t) = \sum_{n=-\infty}^{\infty} x(nT_s) \frac{\sin[\pi(t-nT_s)/T_s]}{\pi(t-nT_s)/T_s}$$

## 第六章 拉普拉斯变换

### 6.1 拉普拉斯变换定义

$$X(s) = \int_{-\infty}^{\infty} x(t) e^{-st} dt$$
其中 s = σ + jω 为复频率。

收敛域（ROC）：使拉普拉斯变换收敛的 s 值集合。

### 6.2 拉普拉斯变换的性质

| 性质 | 时域 | 复频域 |
|------|------|--------|
| 线性 | ax₁(t) + bx₂(t) | aX₁(s) + bX₂(s) |
| 时移 | x(t-t₀) | e^{-st₀}X(s) |
| 频移 | e^{s₀t}x(t) | X(s-s₀) |
| 尺度 | x(at) | (1/|a|)X(s/a) |
| 微分 | dx(t)/dt | sX(s) - x(0) |
| 积分 | ∫x(τ)dτ | X(s)/s |
| 卷积 | x₁(t)*x₂(t) | X₁(s)X₂(s) |

### 6.3 拉普拉斯变换与系统函数

LTI 系统的系统函数：
$$H(s) = \frac{Y(s)}{X(s)} = \int_{-\infty}^{\infty} h(t) e^{-st} dt$$

系统函数 H(s) 的极点位置决定系统的特性：
- 极点都在左半平面 → 稳定系统
- 有极点在右半平面 → 不稳定系统
- 极点在虚轴上 → 临界稳定

### 6.4 拉普拉斯变换与傅里叶变换的关系

当 ROC 包含虚轴（jω 轴）时，拉普拉斯变换等于傅里叶变换：
$$X(j\omega) = X(s)|_{s=j\omega}$$

## 第七章 Z 变换

### 7.1 Z 变换定义

$$X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n}$$
其中 z = re^{jω} 为复变量。

### 7.2 Z 变换的性质

| 性质 | 时域 | Z 域 |
|------|------|------|
| 线性 | ax₁[n] + bx₂[n] | aX₁(z) + bX₂(z) |
| 时移 | x[n-n₀] | z^{-n₀}X(z) |
| 指数加权 | a^n x[n] | X(z/a) |
| 反转 | x[-n] | X(z^{-1}) |
| 卷积 | x₁[n]*x₂[n] | X₁(z)X₂(z) |

### 7.3 系统函数与系统特性

离散时间 LTI 系统的系统函数：
$$H(z) = \sum_{n=-\infty}^{\infty} h[n] z^{-n}$$

- 因果系统：ROC 为某个圆的外部，且包含 ∞
- 稳定系统：ROC 包含单位圆
- 因果稳定系统：所有极点都在单位圆内

## 第八章 状态变量分析

### 8.1 状态方程

连续时间系统状态方程：
$$\dot{x}(t) = Ax(t) + Bu(t)$$
$$y(t) = Cx(t) + Du(t)$$

离散时间系统状态方程：
$$x[n+1] = Ax[n] + Bu[n]$$
$$y[n] = Cx[n] + Du[n]$$

### 8.2 系统函数与状态方程的关系

连续时间系统函数：
$$H(s) = C(sI - A)^{-1}B + D$$

离散时间系统函数：
$$H(z) = C(zI - A)^{-1}B + D$$
