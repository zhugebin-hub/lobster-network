# 嵌入式系统开发

## 第一章 嵌入式系统概述

### 1.1 嵌入式系统的定义与特点

**定义**：以应用为中心、以计算机技术为基础、软硬件可裁剪、适用于应用系统对功能、可靠性、成本、体积、功耗有严格要求的专用计算机系统。

**特点**：
- 专用性强
- 资源受限
- 实时性要求
- 高可靠性
- 低功耗

### 1.2 嵌入式系统的组成

**硬件**：
- 处理器（MCU、MPU、DSP、SoC）
- 存储器（RAM、ROM、Flash）
- 接口电路（UART、SPI、I2C、USB、Ethernet）
- 外设（ADC、DAC、定时器、PWM）

**软件**：
- 引导程序（Bootloader）
- 操作系统（RTOS、Linux）
- 应用程序
- 驱动程序

### 1.3 嵌入式处理器

**ARM 架构**：
- ARM7：哈佛结构，三级流水线
- ARM9：哈佛结构，五级流水线
- Cortex-M：面向微控制器
- Cortex-A：面向应用处理器

**常见型号**：
- STM32（ARM Cortex-M）
- LPC（NXP ARM）
- MSP430（TI）
- PIC（Microchip）

## 第二章 单片机原理

### 2.1 单片机结构

**51 单片机结构**：
- CPU：8位微处理器
- RAM：128B/256B 数据存储器
- ROM：4KB 程序存储器
- I/O 口：4个8位并行口
- 定时器/计数器：2个16位
- 串行口：1个全双工
- 中断系统：5个中断源

### 2.2 指令系统

**寻址方式**：
- 立即寻址：MOV A, #30H
- 直接寻址：MOV A, 30H
- 寄存器寻址：MOV A, R0
- 寄存器间接寻址：MOV A, @R0
- 变址寻址：MOVC A, @A+DPTR
- 相对寻址：SJMP rel
- 位寻址：MOV C, 00H

**指令分类**：
- 数据传送指令
- 算术运算指令
- 逻辑运算指令
- 控制转移指令
- 位操作指令

### 2.3 中断系统

**中断源**：
- 外部中断0（INT0）
- 定时器0中断（T0）
- 外部中断1（INT1）
- 定时器1中断（T1）
- 串行口中断（RI/TI）

**中断优先级**：
- 高优先级可打断低优先级
- 同优先级不可嵌套
- 自然优先级：INT0 > T0 > INT1 > T1 > RI/TI

### 2.4 定时器/计数器

**工作模式**：
- 模式0：13位定时器
- 模式1：16位定时器
- 模式2：8位自动重装
- 模式3：两个8位定时器

**计数初值计算**：
$$X = 2^n - \frac{t}{T_{osc} \times 12}$$

### 2.5 串行通信

**工作方式**：
- 方式0：同步移位寄存器
- 方式1：8位UART，波特率可变
- 方式2：9位UART，波特率固定
- 方式3：9位UART，波特率可变

**波特率计算**（方式1）：
$$B = \frac{2^{SMOD}}{32} \times \frac{f_{osc}}{12(256 - TH1)}$$

## 第五章 嵌入式通信接口

### 5.1 UART 通信

**帧格式**：
- 起始位（1位）
- 数据位（5-9位）
- 校验位（0-1位）
- 停止位（1-2位）

**流控制**：
- 软件流控制（XON/XOFF）
- 硬件流控制（RTS/CTS）

### 5.2 SPI 通信

**信号线**：
- SCK：时钟
- MOSI：主出从入
- MISO：主入从出
- CS：片选

**工作模式**：
- CPOL：时钟极性
- CPHA：时钟相位

### 5.3 I2C 通信

**信号线**：
- SCL：时钟
- SDA：数据

**协议**：
- 起始条件
- 停止条件
- 应答信号
- 地址帧
- 数据帧

### 5.4 USB 通信

**版本**：
- USB 1.1：12Mbps
- USB 2.0：480Mbps
- USB 3.0：5Gbps

**设备类型**：
- 控制传输
- 批量传输
- 中断传输
- 等时传输

### 5.5 以太网

**MAC 层**：
- 帧格式

- CSMA/CD

**PHY 层**：
