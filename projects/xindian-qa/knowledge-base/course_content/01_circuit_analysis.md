# 电路分析基础

## 第一章 电路模型与电路定律

### 1.1 电路与电路模型

电路是电流流通的路径，由电路元器件相互连接而构成。电路的功能主要有两类：
- **能量的转换、传输和分配**：如电力系统中的发电、输电、配电
- **信息的传递和处理**：如通信电路、计算机电路

实际电路可以用理想电路元件来近似模拟，构成电路模型。理想电路元件包括：
- 电阻元件（R）：表示消耗电能的性质
- 电感元件（L）：表示储存磁场能量的性质
- 电容元件（C）：表示储存电场能量的性质
- 电源元件：表示将其他形式的能量转换为电能

### 1.2 电路的基本物理量

#### 电流（Current）
电流是电荷的定向移动。单位时间内通过导体截面的电荷量定义为电流：
$$i = \frac{dq}{dt}$$
- 单位：安培（A）
- 参考方向：任意假定的电流正方向，实际方向与参考方向一致时电流为正，反之为负

#### 电压（Voltage）
电压是电场力把单位正电荷从a点移动到b点所做的功：
$$u_{ab} = \frac{dW}{dq}$$
- 单位：伏特（V）
- 关联参考方向：电流从电压正极流入为关联参考方向

#### 功率（Power）
功率是单位时间内电场力所做的功：
$$p = ui$$
- 关联参考方向下：p > 0 表示吸收功率，p < 0 表示发出功率
- 非关联参考方向下：p > 0 表示发出功率，p < 0 表示吸收功率

### 1.3 电路元件

#### 电阻元件
电阻元件是表征电能转换成为热效应这种物理性质的理想电路元件。
$$u = Ri$$ （欧姆定律）
- R 为电阻，单位：欧姆（Ω）
- G = 1/R 为电导，单位：西门子（S）

电阻的功率：
$$p = ui = i^2R = \frac{u^2}{R}$$

#### 独立电源
- **理想电压源**：两端电压为定值或给定的时间函数，与流过的电流无关
- **理想电流源**：输出的电流为定值或给定的时间函数，与其两端电压无关

#### 受控电源
受控电源的输出受电路中另一处的电压或电流控制：
- 电压控制电压源（VCVS）
- 电流控制电压源（CCVS）
- 电压控制电流源（VCCS）
- 电流控制电流源（CCCS）

## 第二章 基尔霍夫定律

### 2.1 电路的拓扑概念

- **支路**：电路中通过同一电流的分支
- **节点**：三条或三条以上支路的连接点
- **回路**：电路中任一闭合路径
- **网孔**：内部不含支路的回路

### 2.2 基尔霍夫电流定律（KCL）

**内容**：在集总参数电路中，任何时刻，对任意节点，所有流出该节点的支路电流的代数和恒等于零。
$$\sum_{k=1}^{n} i_k = 0$$

**另一种表述**：在集总参数电路中，任何时刻，对任意节点，流出（或流入）该节点电流的代数和等于零。或者说，流入该节点的电流等于流出该节点的电流。

### 2.3 基尔霍夫电压定律（KVL）

**内容**：在集总参数电路中，任何时刻，沿任意回路，所有支路电压的代数和恒等于零。
$$\sum_{k=1}^{n} u_k = 0$$

**物理意义**：KVL 是能量守恒定律在电路中的体现。单位正电荷沿任一回路移动一周，其电位升等于电位降。

## 第三章 电阻电路的一般分析方法

### 3.1 支路电流法

以各支路电流为未知量，根据 KCL 和 KVL 列写方程求解。
- 对 n 个节点的电路，可列出 (n-1) 个独立的 KCL 方程
- 对 b 条支路的电路，还需列出 b-(n-1) 个独立的 KVL 方程

### 3.2 节点电压法

以节点电压为未知量，根据 KCL 列写方程。
- 对 n 个节点的电路，选定参考节点后，有 (n-1) 个独立节点
- 标准形式：
$$G_{11}u_{n1} + G_{12}u_{n2} + \cdots + G_{1,n-1}u_{n,n-1} = i_{S1}$$
$$G_{21}u_{n1} + G_{22}u_{n2} + \cdots + G_{2,n-1}u_{n,n-1} = i_{S2}$$

其中：
- G_ii 为自电导（连接在节点 i 的所有电导之和，恒为正）
- G_ij 为互电导（节点 i 与节点 j 之间的电导之和，恒为负）
- i_Si 为流入节点 i 的所有电流源电流的代数和

### 3.3 网孔电流法

以网孔电流为未知量，根据 KVL 列写方程。
- 对平面电路，网孔数 = 支路数 - 节点数 + 1
- 标准形式：
$$R_{11}i_{m1} + R_{12}i_{m2} + \cdots = u_{S1}$$
$$R_{21}i_{m1} + R_{22}i_{m2} + \cdots = u_{S2}$$

## 第四章 电路定理

### 4.1 叠加定理

**内容**：在线性电路中，任一支路的电流（或电压）等于电路中各个独立电源单独作用时，在该支路产生的电流（或电压）的代数和。

**注意事项**：
- 只适用于线性电路
- 功率不能叠加（功率是电流或电压的二次函数）
- 不作用的电压源短路，不作用的电流源开路
- 受控源应保留，不能单独作用

### 4.2 替代定理

**内容**：在任意电路中，若已知某支路的电压为 u_k、电流为 i_k，则该支路可以用以下任一元件替代：
- 电压为 u_k 的独立电压源
- 电流为 i_k 的独立电流源
- 阻值为 u_k/i_k 的电阻

### 4.3 戴维南定理与诺顿定理

**戴维南定理**：任何一个线性含源一端口网络，对外电路来说，总可以用一个电压源和电阻的串联组合来等效置换。
- 电压源的电压等于该一端口网络的开路电压 u_oc
- 电阻等于该一端口网络中所有独立电源置零后的输入电阻 R_eq

**诺顿定理**：任何一个线性含源一端口网络，对外电路来说，总可以用一个电流源和电阻的并联组合来等效置换。
- 电流源的电流等于该一端口网络的短路电流 i_sc
- 电阻等于该一端口网络中所有独立电源置零后的输入电阻 R_eq

### 4.4 最大功率传输定理

当负载电阻 R_L 等于一端口网络的等效电阻 R_eq 时，负载获得最大功率：
$$P_{max} = \frac{u_{oc}^2}{4R_{eq}}$$

## 第五章 一阶电路和二阶电路

### 5.1 动态元件

#### 电容元件
$$i = C\frac{du}{dt}$$
$$u(t) = \frac{1}{C}\int_{-\infty}^{t} i(\tau)d\tau = u(t_0) + \frac{1}{C}\int_{t_0}^{t} i(\tau)d\tau$$
储能：$$W_C = \frac{1}{2}Cu^2$$

#### 电感元件
$$u = L\frac{di}{dt}$$
$$i(t) = \frac{1}{L}\int_{-\infty}^{t} u(\tau)d\tau = i(t_0) + \frac{1}{L}\int_{t_0}^{t} u(\tau)d\tau$$
储能：$$W_L = \frac{1}{2}Li^2$$

### 5.2 一阶电路的零输入响应

RC 电路零输入响应：
$$u_C(t) = U_0 e^{-\frac{t}{RC}}$$
$$i(t) = -\frac{U_0}{R} e^{-\frac{t}{RC}}$$
时间常数：$$\tau = RC$$

RL 电路零输入响应：
$$i_L(t) = I_0 e^{-\frac{R}{L}t}$$
$$u_L(t) = -RI_0 e^{-\frac{R}{L}t}$$
时间常数：$$\tau = \frac{L}{R}$$

### 5.3 一阶电路的零状态响应

RC 电路零状态响应（充电过程）：
$$u_C(t) = U_S(1 - e^{-\frac{t}{RC}})$$
$$i(t) = \frac{U_S}{R} e^{-\frac{t}{RC}}$$

### 5.4 一阶电路的全响应

全响应 = 零输入响应 + 零状态响应
全响应 = 稳态分量 + 瞬态分量

**三要素法**：
$$f(t) = f(\infty) + [f(0_+) - f(\infty)]e^{-\frac{t}{\tau}}$$

其中：
- f(0+) 为初始值
- f(∞) 为稳态值
- τ 为时间常数

## 第六章 正弦稳态电路分析

### 6.1 正弦量

正弦电压和电流是按正弦规律变化的周期量：
$$i(t) = I_m \cos(\omega t + \psi_i)$$

- I_m 为振幅（最大值）
- ω 为角频率，ω = 2πf = 2π/T
- ψ_i 为初相位
- 有效值：$$I = \frac{I_m}{\sqrt{2}}$$

### 6.2 相量法

正弦量可以用相量表示：
$$i(t) = I_m \cos(\omega t + \psi_i) \leftrightarrow \dot{I}_m = I_m \angle \psi_i$$
$$i(t) = \sqrt{2}I \cos(\omega t + \psi_i) \leftrightarrow \dot{I} = I \angle \psi_i$$

相量运算：
- 同频率正弦量的加减 → 相量的加减
- 正弦量的微分 → 相量乘以 jω
- 正弦量的积分 → 相量除以 jω

### 6.3 阻抗与导纳

#### 无源一端口网络的阻抗
$$Z = \frac{\dot{U}}{\dot{I}} = R + jX = |Z|\angle\varphi$$
- R 为电阻分量
- X 为电抗分量
- |Z| = √(R² + X²) 为阻抗模
- φ = arctan(X/R) 为阻抗角

#### 三种基本元件的阻抗
- 电阻：Z_R = R
- 电感：Z_L = jωL = jX_L
- 电容：Z_C = 1/(jωC) = -jX_C

### 6.4 正弦稳态电路的功率

#### 瞬时功率
$$p(t) = u(t)i(t)$$

#### 平均功率（有功功率）
$$P = UI\cos\varphi$$
单位：瓦特（W）

#### 无功功率
$$Q = UI\sin\varphi$$
单位：乏（var）

#### 视在功率
$$S = UI = \sqrt{P^2 + Q^2}$$
单位：伏安（VA）

#### 功率三角形
$$S^2 = P^2 + Q^2$$
$$\cos\varphi = \frac{P}{S}$$ 为功率因数

## 第七章 频率响应与谐振

### 7.1 网络函数

网络函数定义为：
$$H(j\omega) = \frac{\dot{Y}(j\omega)}{\dot{X}(j\omega)} = |H(j\omega)|e^{j\varphi(\omega)}$$
- |H(jω)| 为幅频特性
- φ(ω) 为相频特性

### 7.2 RLC 串联谐振

谐振条件：ωL = 1/(ωC)，即 ω₀ = 1/√(LC)

谐振特点：
- 阻抗最小：Z₀ = R
- 电流最大：I₀ = U/R
- 电压与电流同相
- 电感和电容上的电压大小相等、方向相反

品质因数：
$$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 RC} = \frac{1}{R}\sqrt{\frac{L}{C}}$$

### 7.3 RLC 并联谐振

谐振条件：ωC = 1/(ωL)，即 ω₀ = 1/√(LC)

谐振特点：
- 导纳最小
- 阻抗最大
- 电压与电流同相

## 第八章 三相电路

### 8.1 三相电源

三相电源由三个频率相同、振幅相等、相位互差 120° 的正弦电压源组成：
$$u_A = U_m \cos(\omega t)$$
$$u_B = U_m \cos(\omega t - 120°)$$
$$u_C = U_m \cos(\omega t + 120°)$$

### 8.2 三相电路的连接

- **星形连接（Y 接）**：线电压 = √3 × 相电压，线电流 = 相电流
- **三角形连接（△ 接）**：线电压 = 相电压，线电流 = √3 × 相电流

### 8.3 三相功率

三相总有功功率：
$$P = 3U_p I_p \cos\varphi = \sqrt{3}U_l I_l \cos\varphi$$

三相总无功功率：
$$Q = 3U_p I_p \sin\varphi = \sqrt{3}U_l I_l \sin\varphi$$

三相总视在功率：
$$S = 3U_p I_p = \sqrt{3}U_l I_l$$
