# 数字电子技术基础

## 第一章 数制与码制

### 1.1 常用数制

- **二进制（Binary）**：基数为 2，数码为 0、1
- **八进制（Octal）**：基数为 8，数码为 0-7
- **十进制（Decimal）**：基数为 10，数码为 0-9
- **十六进制（Hexadecimal）**：基数为 16，数码为 0-9、A-F

### 1.2 数制转换

二进制转十进制：按权展开求和
$$(1011)_2 = 1×2^3 + 0×2^2 + 1×2^1 + 1×2^0 = 11$$

十进制转二进制：除 2 取余，逆序排列

### 1.3 二进制编码

- **BCD 码**：用 4 位二进制数表示 1 位十进制数
- **8421 码**：最常用的 BCD 码，各位权值为 8、4、2、1
- **格雷码（Gray Code）**：相邻两个代码之间只有一位不同
- **ASCII 码**：美国信息交换标准代码，7 位或 8 位编码

## 第二章 逻辑代数基础

### 2.1 基本逻辑运算

- **与运算（AND）**：Y = A·B，全 1 出 1，有 0 出 0
- **或运算（OR）**：Y = A + B，有 1 出 1，全 0 出 0
- **非运算（NOT）**：Y = Ā，0 出 1，1 出 0

### 2.2 复合逻辑运算

- **与非（NAND）**：Y = (A·B)̄
- **或非（NOR）**：Y = (A+B)̄
- **与或非（AND-OR-INVERT）**：Y = (A·B + C·D)̄
- **异或（XOR）**：Y = A⊕B = A·B̄ + Ā·B，相同出 0，不同出 1
- **同或（XNOR）**：Y = A⊙B = A·B + Ā·B̄，相同出 1，不同出 0

### 2.3 逻辑代数的基本定律

| 定律 | 公式 |
|------|------|
| 0-1 律 | A + 0 = A, A + 1 = 1, A·0 = 0, A·1 = A |
| 重叠律 | A + A = A, A·A = A |
| 互补律 | A + Ā = 1, A·Ā = 0 |
| 交换律 | A + B = B + A, A·B = B·A |
| 结合律 | (A+B)+C = A+(B+C), (A·B)·C = A·(B·C) |
| 分配律 | A·(B+C) = A·B + A·C, A+B·C = (A+B)·(A+C) |
| 德·摩根定律 | (A+B)̄ = Ā·B̄, (A·B)̄ = Ā+B̄ |
| 还原律 | Ā̄ = A |
| 吸收律 | A + A·B = A, A·(A+B) = A |
| 冗余定理 | A + Ā·B = A + B |

### 2.4 逻辑函数的表示方法

- **真值表**：列出所有输入组合及其对应的输出
- **逻辑表达式**：与或式、或与式等
- **卡诺图**：用方格图表示逻辑函数
- **逻辑图**：用逻辑门符号表示
- **波形图**：用时序波形表示

### 2.5 逻辑函数的化简

#### 公式化简法
利用逻辑代数定律进行化简。

#### 卡诺图化简法
- 2 变量卡诺图：4 个方格
- 3 变量卡诺图：8 个方格
- 4 变量卡诺图：16 个方格

化简原则：
- 合并 2^n 个相邻 1 方格，消去 n 个变量
- 圈尽可能大
- 圈尽可能少
- 每个圈至少包含一个新的 1 方格

## 第三章 组合逻辑电路

### 3.1 组合逻辑电路的分析方法

1. 根据逻辑图写出逻辑表达式
2. 化简逻辑表达式
3. 列出真值表
4. 分析逻辑功能

### 3.2 组合逻辑电路的设计方法

1. 分析逻辑要求，列出真值表
2. 写出逻辑表达式并化简
3. 根据化简结果画出逻辑图
4. 选择器件实现

### 3.3 常用组合逻辑电路

#### 编码器
- **二进制编码器**：将 2^n 个输入信号编成 n 位二进制代码
- **优先编码器**：允许多个输入信号同时有效，只对优先级最高的编码

#### 译码器
- **二进制译码器**：将 n 位二进制代码译成 2^n 个输出信号
- **显示译码器**：将 BCD 码译成七段显示码

#### 数据选择器（MUX）
从多路输入中选择一路输出：
$$Y = \sum_{i=0}^{2^n-1} D_i \cdot m_i$$
其中 m_i 为地址变量的最小项。

#### 数据分配器（DEMUX）
将一路输入分配到多路输出中的一路。

#### 加法器
- **半加器**：只考虑本位相加，不考虑低位进位
  - S = A⊕B, C = A·B
- **全加器**：考虑低位进位
  - S = A⊕B⊕C_{i-1}
  - C_i = A·B + (A⊕B)·C_{i-1}

#### 数值比较器
比较两个二进制数的大小，输出 A>B、A=B、A<B 三个结果。

### 3.4 组合逻辑电路的竞争冒险

**竞争**：信号经过不同路径到达输出端的时间不同。
**冒险**：竞争导致输出出现错误脉冲。

消除方法：
- 增加冗余项
- 接入滤波电容
- 选通脉冲

## 第四章 触发器

### 4.1 基本 RS 触发器

由两个与非门或或非门交叉耦合构成。

**特性表**：
| R | S | Q^{n+1} | 说明 |
|---|---|---------|------|
| 0 | 0 | Q^n | 保持 |
| 0 | 1 | 1 | 置 1 |
| 1 | 0 | 0 | 置 0 |
| 1 | 1 | 不定 | 禁止 |

**特性方程**：
$$Q^{n+1} = S + \bar{R}Q^n$$
约束条件：R·S = 0

### 4.2 同步 RS 触发器

在基本 RS 触发器基础上增加时钟控制。
- CP = 0：保持
- CP = 1：Q^{n+1} = S + R̄·Q^n，约束 RS = 0

### 4.3 主从 JK 触发器

**特性方程**：
$$Q^{n+1} = J\bar{Q}^n + \bar{K}Q^n$$

无约束条件，功能完善。

| J | K | Q^{n+1} | 说明 |
|---|---|---------|------|
| 0 | 0 | Q^n | 保持 |
| 0 | 1 | 0 | 置 0 |
| 1 | 0 | 1 | 置 1 |
| 1 | 1 | Q̄^n | 翻转 |

### 4.4 边沿 D 触发器

**特性方程**：
$$Q^{n+1} = D$$

在时钟上升沿（或下降沿）采样输入 D，输出随之改变。

### 4.5 T 触发器和 T' 触发器

**T 触发器**：
$$Q^{n+1} = T\bar{Q}^n + \bar{T}Q^n$$
T = 0 保持，T = 1 翻转。

**T' 触发器**：
$$Q^{n+1} = \bar{Q}^n$$
每来一个时钟翻转一次。

## 第五章 时序逻辑电路

### 5.1 时序逻辑电路的特点

- 任意时刻的输出不仅取决于当前输入，还与电路原来的状态有关
- 包含组合逻辑电路和存储电路两部分

### 5.2 时序逻辑电路的分类

- **同步时序电路**：所有触发器的时钟端连在一起，状态变化在同一个时钟脉冲控制下同时发生
- **异步时序电路**：触发器的时钟端不连在一起，状态变化不是同时发生的

### 5.3 时序逻辑电路的分析方法

1. 写出驱动方程、输出方程
2. 将驱动方程代入触发器特性方程，得状态方程
3. 列出状态表、画出状态图和时序图
4. 说明逻辑功能

### 5.4 计数器

#### 二进制计数器
- 同步二进制计数器：所有触发器同时翻转
- 异步二进制计数器：低位触发器的输出作为高位触发器的时钟

#### 十进制计数器
- 8421 码计数器：计数状态为 0000~1001

#### 可逆计数器
- 可设置计数方向（加计数/减计数）

### 5.5 寄存器

- **数码寄存器**：存放二进制代码
- **移位寄存器**：数据可以在寄存器中左移或右移

## 第六章 半导体存储器

### 6.1 只读存储器（ROM）

- **固定 ROM**：制造时写入，不可修改
- **PROM**：可编程 ROM，只能编程一次
- **EPROM**：可擦除可编程 ROM，紫外线擦除
- **EEPROM**：电可擦除可编程 ROM

### 6.2 随机存取存储器（RAM）

- **SRAM**：静态 RAM，触发器存储，速度快
- **DRAM**：动态 RAM，电容存储，需定期刷新

## 第七章 脉冲波形的产生与整形

### 7.1 多谐振荡器

**555 定时器构成多谐振荡器**：
- 输出连续的矩形波
- 周期：T = 0.7(R₁ + 2R₂)C
- 占空比：q = (R₁ + R₂)/(R₁ + 2R₂)

### 7.2 单稳态触发器

- 有一个稳态和一个暂稳态
- 触发后进入暂稳态，经过一段时间后自动返回稳态
- 暂稳态持续时间：t_w = 1.1RC

### 7.3 施密特触发器

- 具有回差特性的电路
- 正向阈值电压 V_T+ 和负向阈值电压 V_T-
- 回差电压：ΔV_T = V_T+ - V_T-
- 用于波形整形、脉冲鉴幅

## 第八章 数模转换与模数转换

### 8.1 D/A 转换器（DAC）

将数字量转换为模拟量。

**倒 T 型电阻网络 DAC**：
$$v_O = -\frac{V_{REF}R_f}{2^n R} \sum_{i=0}^{n-1} D_i 2^i$$

**主要指标**：
- 分辨率：1/(2^n - 1)
- 转换精度
- 转换速度

### 8.2 A/D 转换器（ADC）

将模拟量转换为数字量。

**转换步骤**：采样 → 保持 → 量化 → 编码

**常见类型**：
- **并行比较型 ADC**：速度最快，成本高
- **逐次逼近型 ADC**：速度和精度折中
- **双积分型 ADC**：精度高，抗干扰能力强，速度慢

**量化误差**：量化过程引起的误差，最小量化单位 Δ = V_REF / 2^n
