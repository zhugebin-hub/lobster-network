# 网络超时问题解决方案

## 🔴 问题描述

运行 `train.py` 时出现 `https.ConnectTimeout` 错误：

```
File "D:\python\Lib\site-packages\httpcore\_exceptions.py", line 10, in __init__
    self.gen.throw(value)
...
https.ConnectTimeout: [WinError 10060] 由于连接方在一段时间后没有正确答复或连接的主机没有反应，连接尝试失败。
```

**根本原因**：代码在初始化时尝试从 HuggingFace 下载预训练模型（BERT、Sentence-BERT），但网络连接超时。

---

## ✅ 已修复的内容

### 修复 1：配置文件字段名错误

**文件**：`config/default.yaml`

**问题**：
- 原来用的是 `model_name`，但代码里读取的是 `sentence_bert_model`
- 原来用的是 `yiyanghkust/finbert-tone-chinese`，这不是标准模型

**修复**：
```yaml
post_encoder:
  sentence_bert_model: "paraphrase-multilingual-MiniLM-L12-v2"  # ✅ 修正字段名
  bert_model: "bert-base-chinese"  # ✅ 使用标准模型
```

---

### 修复 2：添加离线模式支持

**文件**：`src/models/post_encoder.py`

**修复内容**：
- 优先尝试从本地缓存加载模型（`local_files_only=True`）
- 如果本地没有，再尝试联网下载
- 添加详细的加载日志，方便调试

**关键代码**：
```python
try:
    self.bert_tokenizer = AutoTokenizer.from_pretrained(
        config.model.post_encoder.bert_model,
        local_files_only=True  # 优先使用本地缓存
    )
    self.bert_model = AutoModel.from_pretrained(
        config.model.post_encoder.bert_model,
        local_files_only=True
    )
    print(f"[PostEncoder] BERT loaded from cache: {config.model.post_encoder.bert_model}")
except Exception as e:
    print(f"[PostEncoder] Loading BERT from cache failed, trying online: {e}")
    # 如果本地没有，尝试联网下载
    self.bert_tokenizer = AutoTokenizer.from_pretrained(config.model.post_encoder.bert_model)
    self.bert_model = AutoModel.from_pretrained(config.model.post_encoder.bert_model)
```

---

## 🚀 解决方案（按优先级）

### 方案 1：使用 HuggingFace 镜像（推荐）

**适用场景**：首次运行，本地没有模型缓存

**步骤**：

1. **设置环境变量**（Windows PowerShell）：
   ```powershell
   $env:HF_ENDPOINT = "https://hf-mirror.com"
   ```

2. **运行训练**：
   ```bash
   python train.py
   ```

3. **模型会自动下载到**：
   ```
   C:\Users\<用户名>\.cache\huggingface\hub\
   ```

**优点**：
- ✅ 一次设置，永久有效（下次运行会使用本地缓存）
- ✅ 下载速度快（国内镜像）
- ✅ 不需要修改代码

---

### 方案 2：手动下载模型（适合网络不稳定）

**适用场景**：网络不稳定，自动下载总是失败

**步骤**：

1. **在另一台能联网的电脑上下载模型**：
   ```python
   from transformers import AutoModel, AutoTokenizer
   from sentence_transformers import SentenceTransformer
   
   # 下载 BERT
   AutoTokenizer.from_pretrained("bert-base-chinese")
   AutoModel.from_pretrained("bert-base-chinese")
   
   # 下载 Sentence-BERT
   SentenceTransformer("paraphrase-multilingual-MiniLM-L12-v2")
   ```

2. **找到缓存目录**：
   ```
   Windows: C:\Users\<用户名>\.cache\huggingface\
   Linux/Mac: ~/.cache/huggingface/
   ```

3. **复制整个 `huggingface` 文件夹到目标电脑的相同位置**

4. **运行训练**：
   ```bash
   python train.py
   ```

**优点**：
- ✅ 完全离线，不需要网络
- ✅ 适合服务器环境

---

### 方案 3：使用离线测试脚本（验证流程）

**适用场景**：暂时无法下载模型，但想验证训练流程是否正常

**步骤**：

1. **运行离线测试**：
   ```bash
   python test_offline.py
   ```

2. **如果测试通过，说明代码逻辑没问题**

3. **等网络恢复后，再下载模型进行真实训练**

**优点**：
- ✅ 完全不依赖网络
- ✅ 快速验证代码逻辑
- ✅ 适合调试

---

### 方案 4：使用本地模型路径（高级）

**适用场景**：已经有本地模型文件

**步骤**：

1. **修改配置文件** `config/default.yaml`：
   ```yaml
   post_encoder:
     sentence_bert_model: "/path/to/local/sentence-bert"
     bert_model: "/path/to/local/bert-base-chinese"
   ```

2. **确保本地路径包含**：
   - `config.json`
   - `pytorch_model.bin` 或 `model.safetensors`
   - `tokenizer_config.json`
   - `vocab.txt`

3. **运行训练**：
   ```bash
   python train.py
   ```

## 📊 常见错误和解决方案

### 错误 1：`ConnectTimeout`

**原因**：网络连接超时

**解决方案**：
1. 使用 HuggingFace 镜像（方案 1）
2. 或手动下载模型（方案 2）

---

### 错误 2：`OSError: Can't load tokenizer for 'xxx'. If you were trying to load it from 'https://huggingface.co/models', make sure you don't have a local directory with the same name.`

**原因**：本地缓存损坏或不完整

**解决方案**：
1. 删除缓存目录：
   ```bash
   rm -rf ~/.cache/huggingface/hub/models--bert-base-chinese
   ```
2. 重新下载：
   ```bash
   python -c "from transformers import AutoModel; AutoModel.from_pretrained('bert-base-chinese')"
   ```

---

### 错误 3：`AttributeError: 'Config' object has no attribute 'sentence_bert_model'`

**原因**：配置文件字段名错误

**解决方案**：
确保 `config/default.yaml` 里是 `sentence_bert_model`，不是 `model_name`
