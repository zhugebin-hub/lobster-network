# 修复总结 - 网络超时问题

## 🔴 问题

运行 `train.py` 时出现 `https.ConnectTimeout` 错误，无法启动训练。

**根本原因**：代码尝试从 HuggingFace 下载预训练模型，但网络连接超时。

---

## ✅ 已修复的内容

### 1. 配置文件错误

**文件**：`config/default.yaml`

**修复**：
- ✅ 修正字段名：`model_name` → `sentence_bert_model`
- ✅ 使用标准模型：`yiyanghkust/finbert-tone-chinese` → `bert-base-chinese`

---

### 2. 添加离线模式支持

**文件**：`src/models/post_encoder.py`

**修复**：
- ✅ 优先从本地缓存加载模型（`local_files_only=True`）
- ✅ 如果本地没有，再尝试联网下载
- ✅ 添加详细的加载日志

---

### 3. 创建测试和启动脚本

**新增文件**：
- ✅ `test_model_loading.py` - 测试模型加载
- ✅ `test_offline.py` - 离线测试（不依赖网络）
- ✅ `run_train.ps1` - 自动设置环境变量并启动训练
- ✅ `网络超时问题解决方案.md` - 详细解决方案

---

## 🔍 如果还是失败

### 步骤 1：运行离线测试

```bash
python test_offline.py
```

**如果离线测试通过**：
- ✅ 说明代码逻辑没问题
- ❌ 问题在于模型下载

**如果离线测试失败**：
- ❌ 说明代码有其他问题
- 查看错误信息，可能是依赖问题

---

### 步骤 2：手动下载模型

如果网络不稳定，可以手动下载模型：

1. **在能联网的电脑上运行**：
   ```python
   from transformers import AutoModel, AutoTokenizer
   from sentence_transformers import SentenceTransformer
   
   AutoTokenizer.from_pretrained("bert-base-chinese")
   AutoModel.from_pretrained("bert-base-chinese")
   SentenceTransformer("paraphrase-multilingual-MiniLM-L12-v2")
   ```

2. **复制缓存目录**：
   ```
   源: C:\Users\<用户名>\.cache\huggingface\
   目标: 目标电脑的相同位置
   ```

3. **运行训练**：
   ```bash
   python train.py
   ```
