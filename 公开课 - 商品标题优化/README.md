- 📝 任务背景（模拟真实店铺情境）

## 🎯 核心知识点

### 标题公式
```
爆款标题 = 核心词 + 属性词 + 流量词 + 长尾词
```

### 平台规则
| 平台 | 字符限制 | 关键规则 |
|------|----------|----------|
| 淘宝/天猫 | 60 字符 | 避免堆砌，AI 语义权重高 |
| 亚马逊 | 200 字节 | 品牌首位，格式严格 |
| TikTok Shop | 150 字符 | 简洁明了，可加 emoji |
| 拼多多 | 60 字符 | 强调性价比，避免夸大 |

### 关键词工具
- **免费**：Google Trends、搜索下拉框、竞品分析
- **付费**：卖家精灵、店小秘、生意参谋

### 避坑指南
- ❌ 违禁词：最、第一、国家级、治愈率
- ❌ 侵权词：迪士尼、漫威、LV（未授权）
- ❌ 虚假宣传：历史最低价、全网第一（无数据）

## 📚 使用建议

### 教师使用
1. **课前准备**
   - 阅读教学设计，熟悉教学流程
   - 根据 PPT 大纲制作幻灯片
   - 打印学生任务书（每人 1 份）
   - 准备关键词工具账号（学生试用）

2. **课中实施**
   - 按教学设计流程授课
   - 控制各环节时间（导入 5′→新授 15′→实践 20′→总结 5′）
   - 巡回指导小组实践
   - 组织成果展示和互评

3. **课后跟进**
   - 收齐学生作业
   - 组织小组互评
   - 批改并反馈成绩
   - 整理优秀案例入库

### 学生使用
1. **课前预习**
   - 阅读任务书，了解任务要求
   - 注册关键词工具试用账号

2. **课中参与**
   - 积极参与互动问答
   - 认真记录标题公式和平台规则
   - 小组协作完成实践任务

3. **课后作业**
   - 独立完成任务书要求
   - 使用工具验证关键词
   - 按时提交作业
   - 认真参与互评
