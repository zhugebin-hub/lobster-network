## 第 4 页：什么是好标题？

```
好标题的三大标准：

1️⃣  searchable（可搜索）
   • 包含用户常搜关键词
   • 符合平台搜索算法

2️⃣  readable（可读）
   • 语句通顺，逻辑清晰
   • 避免关键词堆砌

3️⃣  clickable（可点击）
   • 突出卖点和差异化
   • 激发用户购买欲望
```

```

   ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐

## 第 6 页：要素详解——核心词

```
📦 核心词：产品的本质名称

作用：确定产品类目，匹配基础搜索

示例：
• 女包、运动鞋、保温杯、手机壳
• 连衣裙、咖啡机、收纳盒、台灯

⚠️ 注意：
• 使用行业通用词，避免自创词
• 可放在标题前、中、后任意位置
• 一个标题建议 1-2 个核心词
```

**互动**：让学生快速说出 5 个自己熟悉产品的核心词。

---

## 第 7 页：要素详解——属性词

```
🏷️ 属性词：产品的特征描述

作用：筛选目标用户，提高匹配精度

分类示例：
┌──────────┬─────────────────────────────┐
│ 材质     │ 真皮、纯棉、不锈钢、实木     │
│ 风格     │ ins 风、复古、简约、轻奢      │
│ 功能     │ 大容量、便携、防水、保暖     │
│ 人群     │ 学生、上班族、妈妈、老人     │
│ 场景     │ 通勤、运动、旅行、居家       │
└──────────┴─────────────────────────────┘
```

**案例**：同一产品不同属性词吸引不同人群。

---

## 第 8 页：要素详解——流量词

```
🔥 流量词：热门搜索词汇

作用：获取搜索流量，提升曝光量

来源：
• 季节热点：2025 新款、春季、夏季
• 风格热点：ins 风、网红同款、明星同款
• 营销热点：双 11、618、年货节
• 平台热点：抖音同款、小红书推荐

📊 数据：流量词可提升 3-5 倍曝光
```

**演示**：打开 Google Trends 展示「ins 风」搜索趋势。

---

## 第 9 页：要素详解——长尾词

```
🎯 长尾词：精准需求表达

作用：提高转化精度，降低竞争强度

特点：
• 搜索量较小，但转化率高
• 竞争度低，容易获得排名
• 用户需求明确，购买意向强

示例：
• 「小个子显高连衣裙」
• 「送妈妈生日礼物」
• 「办公室静音咖啡机」
• 「大码显瘦运动鞋」
```

**数据**：长尾词转化率通常是核心词的 2-3 倍。

## 第 17 页：避坑指南——违禁词

```
🚫 违禁词清单（2025 版）

❌ 最、第一、顶级、国家级、世界级
❌ 首选、独家、万能、永久

❌ 治愈率、有效率、100% 有效
