## 📋 功能模块

| 模块 | 功能说明 |
|------|----------|
| 🏠 首页 | 统计数据总览、使用指南 |
| 👨‍🏫 教师管理 | 添加/删除教师信息 |

## 💡 使用流程

1. **录入教师** - 添加所有任课教师
2. **录入班级** - 添加所有班级
3. **设置课程** - 为每个班级设置各科教师及课时
4. **设置会议** - 添加不能排课的时间（如升旗仪式）
5. **自动排课** - 点击"开始排课"按钮
6. **查看课表** - 选择班级查看课表

## 🔧 常见问题

**Q: 页面打不开？**
- 确认服务器已启动（运行 `python3 app.py`）
- 检查防火墙设置
- 尝试访问 http://localhost:5000

**Q: 排课失败？**
- 检查是否有足够的教师和时间槽
- 减少特殊要求限制
- 确保课程总课时不超过可用时间

**Q: 如何清空数据？**
- 点击"排课系统"页面的"清空数据"按钮
- 或删除 `data/school.db` 文件
