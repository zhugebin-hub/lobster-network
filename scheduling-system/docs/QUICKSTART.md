# 快速上手指南

## 🚀 第一步：启动系统

```bash
cd scheduling-system
./run.sh
# 或者
python3 src/main.py
```

## 📝 第二步：录入基础数据

### 1️⃣ 录入教师信息
- 菜单：数据管理 → 教师管理
- 点击"➕ 添加"
- 填写：姓名、学科、周课时上限、电话
- 示例：
  - 张老师，语文，12 课时
  - 李老师，数学，14 课时
  - 王老师，英语，12 课时

### 2️⃣ 录入班级信息
- 菜单：数据管理 → 班级管理
- 点击"➕ 添加"
- 填写：班级名称、年级、学生数
- 示例：
  - 高一 (1) 班，高一，45 人
  - 高一 (2) 班，高一，44 人

### 3️⃣ 设置课程
- 菜单：数据管理 → 课程设置
- 点击"➕ 添加"
- 选择：班级、教师、科目
- 填写：周课时、连堂数、特殊要求
- 示例：
  - 高一 (1) 班，张老师，语文，每周 5 节，不连堂
  - 高一 (1) 班，李老师，数学，每周 4 节，可连堂 2 节

### 4️⃣ 设置会议时间（可选）
- 菜单：数据管理 → 会议时间
- 添加学校固定会议时间
- 示例：
  - 周一上午第 1 节：升旗仪式
  - 周五下午第 8 节：教研活动

## 🎯 第三步：自动排课

1. 菜单：排课 → 自动排课
2. 系统自动计算
3. 完成后提示排课结果

## 📊 第四步：查看课表

1. 菜单：排课 → 课表查询
2. 选择班级
3. 查看该班级课表

## ⚠️ 注意事项

1. **数据录入顺序**：教师 → 班级 → 课程 → 会议
2. **周课时**：指该课程每周需要上的节数
3. **连堂**：1=单节，2=连堂（两节连上）
4. **特殊要求**：如"不排周一第一节"
5. **冲突检测**：系统自动检测教师和班级时间冲突

## 🔧 常见问题

**Q: 排课失败怎么办？**
- 检查教师周课时是否超限
- 检查是否有足够的可用时间槽
- 减少特殊要求限制

**Q: 如何修改课表？**
- 目前支持重新排课
- 手动调整功能开发中...

**Q: 数据保存在哪里？**
- `data/school.db` SQLite 数据库文件
- 可备份该文件保存数据
