## ✅ 申报 Checklist

### 通用材料检查

### 教 AI 案例专项检查

- [ ] 课堂实录视频
- [ ] 说课视频（≤10 分钟）

### 用 AI 案例专项检查

  - [ ] 案例概述（1-2 分钟）
  - [ ] 过程与方法（5-6 分钟）
  - [ ] 规范应用说明（1-2 分钟）
  - [ ] 成效与经验（1-2 分钟）
- [ ] 使用国内 AI 平台
- [ ] 体现规范应用意识

### 创 AI 案例专项检查
- [ ] 开发与应用报告（≤3000 字）
- [ ] 演示视频（≤8 分钟）
- [ ] 配套资源（代码/文档）
- [ ] 作者不超过 3 人
- [ ] 基于国产平台/大模型
- [ ] 可复现性说明

### 护 AI 案例专项检查
- [ ] 案例视频结构完整（≤8 分钟）
  - [ ] 规范指引理解（1-2 分钟）
  - [ ] 案例介绍（≤2 分钟）
  - [ ] 规范应用分析（≤3 分钟）
  - [ ] 方法总结（≤1 分钟）
- [ ] 对应 18 个行为示例之一
- [ ] 规范与非规范对比清晰

## 🎬 视频制作要点

### 录制前准备
- [ ] 撰写视频脚本/提纲
- [ ] 准备 PPT 课件
- [ ] 测试录屏软件
- [ ] 检查麦克风收音
- [ ] 准备安静的录制环境

### 录制注意事项
- [ ] PPT 使用官方模板
- [ ] 不出现平台 Logo
- [ ] 不出现二维码、网址、联系方式
- [ ] 主讲人不出镜（除非说课需要）
- [ ] 语速适中，表达清晰
- [ ] 操作演示流畅

### 后期制作
- [ ] 剪辑冗余内容
- [ ] 添加必要的字幕/标注
- [ ] 调整音量平衡
- [ ] 检查视频参数是否符合要求
- [ ] 导出 MP4 格式

### 推荐工具
- 录屏：OBS Studio、EV 录屏、Camtasia
- 剪辑：剪映专业版、必剪、Premiere
- 音频处理：Audacity

## ⚠️ 常见错误与规避

### 形式错误
| 错误 | 规避方法 |
|------|----------|
| 视频超时 | 提前彩排，严格计时 |
| 格式不符 | 仔细核对通知要求 |
| 缺少盖章 | 提前准备，预留时间 |
| 作者超限 | 确认各类别人数要求 |

### 内容错误
| 错误 | 规避方法 |
|------|----------|
| 脱离教学实际 | 基于真实实践，不包装 |
| 工具堆砌 | 突出教学逻辑，工具为教学服务 |
| 忽视规范 | 专门说明规范应用做法 |
| 效果夸大 | 用数据说话，实事求是 |
| 缺少反思 | 包含问题与改进思路 |

### 技术错误
| 错误 | 规避方法 |
|------|----------|
| 视频质量差 | 注意光线、收音、分辨率 |
| PPT 不规范 | 使用官方模板 |
| AI 内容未标注 | 逐一检查，统一标注 |
| 学生隐私泄露 | 不出现正面，隐去个人信息 |
