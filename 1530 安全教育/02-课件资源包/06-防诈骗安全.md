### 第 3 页：什么是诈骗

```
╔═══════════════════════════════════════════╗
║                                           ║
║          🎭 什么是诈骗？                   ║
║                                           ║
║   诈骗 = 虚构事实 + 隐瞒真相 + 骗取财物   ║
║                                           ║
║   诈骗分子常用手段：                      ║
║                                           ║
║   • 冒充熟人/老师/公检法                  ║
║   • 以利益诱惑（中奖、返利、兼职）        ║
║   • 制造紧急情况（家人出事、账户异常）    ║
║   • 利用同情心（求助、募捐）              ║
║                                           ║
║   💡 记住：天上不会掉馅饼！                ║
║                                           ║
╚═══════════════════════════════════════════╝
```

## 💡 互动环节

### 活动 1：诈骗情景判断 (5 分钟)
```
判断以下情况是否为诈骗：
1. 陌生人 QQ 说低价卖游戏皮肤 (✅诈骗)
2. 班级群"老师"收资料费 (⚠️需核实)
3. 刷单赚佣金，先垫付 (✅诈骗)
4. 中奖了但要先交税 (✅诈骗)
```

### 活动 2：防诈骗口诀接龙 (5 分钟)
```
不听 → 不信 → 不转账
不贪 → 不扫 → 不点击
```

### 活动 3：角色扮演 (5 分钟)
- 模拟诈骗场景
- 练习应对方法
- 评选"防诈小卫士"

## 📝 教学建议

### 重点强调
- 所有刷单都是诈骗
- 不贪小便宜
- 转账前必须核实
- 被骗后及时求助

### 教学资源
- 诈骗案例视频
- 反诈宣传材料
- 国家反诈中心 APP

### 注意事项
- 用真实案例警示
- 不制造恐慌
- 强调求助不丢人
