## 一、校园安全承诺

我承诺：

- [ ] 遵守校规校纪，注意安全
- [ ] 课间文明休息，不追逐打闹
- [ ] 上下楼梯靠右行，不拥挤推搡
- [ ] 爱护公共设施，发现隐患及时报告
- [ ] 团结同学，互帮互助，不欺凌他人
- [ ] 实验室听从指挥，不乱动仪器药品
- [ ] 体育活动做好热身，量力而行

---

## 二、交通安全承诺

我承诺：

- [ ] 遵守交通法规，文明出行
- [ ] 过马路走斑马线，不闯红灯
- [ ] 乘车系好安全带，不坐违规车
- [ ] 未满 12 周岁不骑自行车
- [ ] 未满 16 周岁不骑电动车
- [ ] 骑车戴头盔，不逆行不抢道
- [ ] 提醒家人遵守交通规则

---

## 三、防溺水安全承诺

我承诺：

- [ ] 不私自下水游泳
- [ ] 不擅自与他人结伴游泳
- [ ] 不在无家长或教师带领下游泳
- [ ] 不到无安全设施的水域游泳
- [ ] 不到不熟悉的水域游泳
- [ ] 不擅自下水施救
- [ ] 发现溺水及时呼救报警

---

## 四、消防安全承诺

我承诺：

- [ ] 不玩火、不携带火种
- [ ] 不私拉乱接电线
- [ ] 不使用违规电器
- [ ] 爱护消防设施
- [ ] 发现火险及时报告
- [ ] 掌握基本逃生技能
- [ ] 不在教室给电动车电池充电

---

## 五、网络安全承诺

我承诺：

- [ ] 文明上网，不沉迷网络
- [ ] 不浏览不良信息
- [ ] 不泄露个人信息
- [ ] 不随意约见网友
- [ ] 不参与网络暴力
- [ ] 警惕网络诈骗
- [ ] 合理安排上网时间

---

## 六、食品安全承诺

我承诺：

- [ ] 注意饮食卫生
- [ ] 不吃"三无"食品
- [ ] 不吃过期变质食品
- [ ] 饭前便后洗手
- [ ] 不暴饮暴食
- [ ] 多喝开水，少喝饮料
- [ ] 购买食品看保质期

---

## 七、居家安全承诺

我承诺：

- [ ] 注意用电安全
- [ ] 注意用气安全
- [ ] 不攀爬阳台窗户
- [ ] 不给陌生人开门
- [ ] 记住紧急联系电话
- [ ] 独自在家注意安全
- [ ] 发现隐患及时告知家长

---

## 八、心理健康承诺

- [ ] 珍爱生命，热爱生活
