## 协议目的

为进一步加强学生安全教育和管理，明确学校和家长的监护责任，共同保障学生的人身安全，特签订本协议。

---

## 一、甲方（学校）责任

### 1. 安全教育责任

- [ ] 按照"1530"模式开展安全教育
- [ ] 每月至少组织 1 次安全教育主题班会
- [ ] 每周进行 1 次安全提醒
- [ ] 每天放学前进行 1 分钟安全提示
- [ ] 定期组织应急演练

### 2. 安全管理责任

- [ ] 完善校园安全设施
- [ ] 定期排查安全隐患
- [ ] 加强校园安保工作
- [ ] 规范实验室、体育课管理
- [ ] 建立安全应急预案

### 3. 信息告知责任

- [ ] 及时告知家长学校安全要求
- [ ] 学生异常情况及时通知家长
- [ ] 放假前发放安全告知书
- [ ] 定期通报学校安全情况

---

## 二、乙方（家长）责任

### 1. 监护责任

- [ ] 履行法定监护职责
- [ ] 关注孩子身心健康
- [ ] 了解孩子去向和活动内容
- [ ] 教育孩子遵守安全规定
- [ ] 配合学校安全管理工作

### 2. 家庭教育责任

- [ ] 进行家庭安全教育
- [ ] 培养孩子安全意识
- [ ] 教导孩子自我保护技能
- [ ] 以身作则，做好表率
- [ ] 关注孩子心理健康

### 3. 配合责任

- [ ] 按时参加家长会和安全培训
- [ ] 及时签署学校安全通知
- [ ] 配合学校安全隐患排查
- [ ] 如实报告学生特殊情况
- [ ] 保持通讯畅通

---

## 三、重点安全事项

### 1. 上下学安全

**学校责任**：
- 组织错峰放学
- 安排教师值班
- 维护校门口秩序

**家长责任**：
- 按时接送孩子
- 教育孩子遵守交通规则
- 不让孩子乘坐违规车辆

### 2. 防溺水安全

**学校责任**：
- 开展防溺水教育
- 发放防溺水告知书
- 及时提醒预警

**家长责任**：
- 监管孩子不私自下水
- 了解孩子去向
- 教育孩子远离危险水域

### 3. 消防安全

**学校责任**：
- 开展消防教育
- 组织消防演练
- 维护消防设施

**家长责任**：
- 教育孩子不玩火
- 检查家庭消防隐患
- 教会孩子逃生技能

### 4. 网络安全

**学校责任**：
- 开展网络安全教育
- 引导学生文明上网
- 预防网络沉迷

**家长责任**：
- 监管孩子上网行为
- 安装绿色上网软件
- 控制上网时间

### 5. 心理健康

**学校责任**：
- 开展心理健康教育
- 建立心理咨询室
- 关注学生心理状态

**家长责任**：
- 关注孩子情绪变化
- 多与孩子沟通交流
- 必要时寻求专业帮助

## 五、违约责任

### 1. 学校责任

因学校管理不善或教育不到位造成学生伤害事故的，学校依法承担相应责任。

### 2. 家长责任

因家长监护不力或教育不当造成学生伤害事故的，家长依法承担相应责任。

### 3. 第三方责任

因第三方原因造成学生伤害事故的，由第三方依法承担责任。
