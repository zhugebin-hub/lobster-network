- 成功登录森兰 MES 系统

## 六、操作关键点总结

### 6.1 成功要素

1. **正确的菜单导航路径**
   - 生产任务 → 生产任务新增 → 标准任务
   - 生产任务管理 → 待启动任务

2. **准确的元素定位**
   - 使用 aria-ref 引用定位页面元素
   - 每次操作后刷新快照获取最新元素引用

3. **完整的配置复制**
   - 通过"现有计划查询"找到目标单据
   - 使用"复制"功能自动填充所有配置项

4. **两步提交确认**
   - 先"保存"生成单据编号
   - 再"确认"完成下单

### 6.2 注意事项

1. **登录状态保持**
   - 管理员账号需要正确切换标签页
   - 账号：00021，密码：123456

2. **页面加载等待**
   - 每次页面跳转后需等待快照加载完成
   - 元素引用失效时需重新获取快照

3. **数据验证**
   - 复制配置后需核对关键字段
   - 确认生产线、数量、规格等核心参数

4. **状态跟踪**
   - 启动任务后列表自动刷新
   - 新任务出现在列表第一位

```bash

# 打开页面
```
