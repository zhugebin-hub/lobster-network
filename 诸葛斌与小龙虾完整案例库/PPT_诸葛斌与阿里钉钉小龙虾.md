
## 六、技术架构详解

### 龙虾网络 (Lobster Network)

```
        ┌─────────────┐
        │  钉钉群入口  │
        └──────┬──────┘
               │
    ┌──────────┼──────────┐
    ↓          ↓          ↓
┌────────┐ ┌────────┐ ┌────────┐
│lobster │ │lobster │ │lobster │
│  001   │ │  002   │ │  003   │
│调度中枢│ │工作节点│ │工作节点│
└────────┘ └────────┘ └────────┘
```

### 核心组件

- **wrapper.py** - HTTP API 封装
- **dingtalk_sender.py** - 钉钉消息发送
- **lobster_scheduler.py** - 任务调度
- **systemd 服务** - 开机自启
