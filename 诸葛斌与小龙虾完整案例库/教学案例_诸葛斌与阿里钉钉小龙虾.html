一、案例背景

1.1 什么是”小龙虾”？

“阿里钉钉小龙虾” 并非官方产品名称，而是对 OpenClaw 开源 AI 智能体框架 的形象化、趣味化昵称。

特征 说明
名称来源 OpenClaw 图标形似龙虾钳子，社区戏称为”小龙虾”
技术本质 开源 AI 智能体 (Agent) 框架，支持多模态任务执行
核心优势 专属运行环境 + 长效记忆能力 + 钉钉原生集成
定位 能”干实事”的 AI 员工，而非仅能聊天的机器人

1.2 为什么是钉钉？

钉钉作为中国最大的企业级协同办公平台，拥有： - ✅ 1900 万+ 企业组织 - ✅ 5 亿+ 个人用户 - ✅ 完整的 API 生态（日历、审批、任务、组织架构） - ✅ 开放机器人接入能力

将 OpenClaw 接入钉钉，意味着 AI 智能体可以： - 📅 自动管理日程和会议 - 📋 处理审批流程 - 📊 生成业务报表 - 💬 在群聊中协同工作

5.2 核心组件

组件 功能 技术栈
wrapper.py HTTP API 封装 Python + Flask
dingtalk_sender.py 钉钉消息发送 钉钉开放 API
lobster_scheduler.py 任务调度核心 Python + cron
systemd 服务 开机自启、进程管理 Linux systemd

5.3 配置示例

# 环境变量配置
export LOBSTER_BOT_ID=lobster-001
export LOBSTER_DINGTALK_WEBHOOK=https://oapi.dingtalk.com/robot/send?access_token=xxx
export LOBSTER_MESSAGE_LOG=/home/admin/.openclaw/workspace/lobster-messages.json

# 启动服务
python3 ~/.openclaw/workspace/lobster-network/wrapper.py \
  --lobster-id=lobster-001 \
  --port=8001

# 配置自动轮询 (每分钟)
*/1 * * * * cd ~/.openclaw/workspace/skills/lobster-network && \
  ./lobster-dingtalk.sh poll >> ~/lobster-network.log 2>&1
