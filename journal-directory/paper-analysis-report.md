## 📊 论文核心贡献

1. **去中心化调度框架** - 摒弃中心化控制，在每个边缘节点部署轻量级自主代理
2. **动态 QoS 需求向量** - 紧迫度、重要度、满意度三维向量
3. **QoS 感知自适应定价** - 节点"QoS 感知指数"，负载与压力双高时主动降低报价
4. **数字信息素协作机制** - 借鉴蜂群信息素通信，避免中心化瓶颈
5. **仿真验证** - 在模拟边缘网络环境中验证效果
