| 学员 | 学习风格 | 强项 | 弱项 | 优化任务 |

| 小陈 | 稳健型 | 数据整理、官子基础 | 定式变化、学术写作 | 精读练习+写作练习 |
| 诸葛虾 | 加速型 | 快速原型、手筋应用 | 布局理论、官子精度 | 快速阅读+工具开发 |
| 诸葛马 | 导师型 | 论文评审、系统调度 | 无 | 评审任务+指导任务 |
