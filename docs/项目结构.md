## 核心模块说明

### node.py
定义节点模型，包含：
- 节点ID、名称、类型
- 种子参数（视角、知识、价值取向、学习率）
- 能力列表
- 世界状态

### dialogue.py
定义对话引擎，包含：
- 对话结果数据类
- 对话触发方法
- 涌现值计算
- 新见解生成

### emergence.py
定义涌现检测器，包含：
- 涌现事件数据类
- 涌现检测方法
- 涌现事件列表管理
- 统计信息计算

### world_state.py
定义世界状态管理器，包含：
- 世界状态数据类
- 状态获取和更新方法
- 状态导出功能

### lobster_network.py
定义主网络类，包含：
- 节点管理（添加、移除、获取）
- 对话触发
- 涌现检测
- 网络拓扑获取
- 状态导出

## 使用示例

```python
from lobster_network import LobsterNetwork, Node

# 创建网络
network = LobsterNetwork()

# 添加节点
node_a = Node("A", "节点A", perspective="技术", knowledge="编程")
node_b = Node("B", "节点B", perspective="行政", knowledge="管理")
network.add_node(node_a)
network.add_node(node_b)

# 触发对话
result = network.dialogue("A", "B")
print(f"涌现值: {result.emergence_score}")
print(f"新见解: {result.new_insight}")
```
