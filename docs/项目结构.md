## 核心模块说明

### 框架层 (src/lobster_network/)

| 模块 | 文件 | 功能 |
|------|------|------|
| 节点模型 | `node.py` | 认知编译系统的基本单元 |
| 对话引擎 | `dialogue.py` | 交叉编译器，计算涌现值 |
| 涌现检测 | `emergence.py` | 检测创造性输出 |
| 世界状态 | `world_state.py` | 按需渲染的过程生成引擎 |
| 时间套利 | `time_arbitrage.py` | 五维时间套利引擎 |
| 因陀罗网 | `network/indra_net.py` | 全互联拓扑 |
| 世界地图 | `world_map.py` | 集体记忆引擎 |
| 节点注册中心 | `registry.py` | 节点注册、心跳、健康检查 |
| 可靠消息传递 | `messenger.py` | ACK/NACK、自动重试、多通道故障切换 |
| 集成层 | `integration.py` | 统一API，整合注册中心和消息传递 |

### 运营层 (core/)

| 模块 | 文件 | 功能 |
|------|------|------|
| 任务调度器V3 | `dispatcher/go_coach_dispatcher_v3.py` | 基础28天训练计划 |
| 任务调度器V4 | `dispatcher/go_coach_dispatcher_v4.py` | 自适应难度 + 错题本复习 |
| 任务调度器V6 | `dispatcher/go_coach_dispatcher_v6_nocturnal.py` | 夜间高强度模式 |
| Agent守护进程 | `agents/lobster_agent.py` | 通用Agent守护进程 |
| 教练系统 | `coach/hermes_coach.py` | 教练分析与报告 |
| 围棋规则引擎 | `utils/process_go_move.py` | 19x19完整围棋规则 |
| 系统监控 | `utils/monitor.py` | 系统健康监控 |

### 应用层 (domains/)

| 领域 | 目录 | 功能 |
|------|------|------|
| 围棋训练 | `go/` | 三个差异化学生训练器 + 题库 |
| 海报设计 | `poster/` | HTML+Playwright渲染流水线 + PPT生成 |

## 使用示例

```python
from lobster_network import LobsterNetwork, Node

# 创建网络
network = LobsterNetwork()

# 添加节点
node_a = Node("A", "节点A", perspective="技术", knowledge="编程")
node_b = Node("B", "B", perspective="行政", knowledge="管理")
network.add_node(node_a)
network.add_node(node_b)

# 触发对话
result = network.dialogue("A", "B")
print(f"涌现值: {result.emergence_score}")
print(f"新见解: {result.new_insight}")
```
