# AI Agent 通识课 - 核心知识点汇总

## 一、基础概念

### 1.1 什么是"小龙虾"（OpenClaw）

| 对比维度 | ChatGPT | OpenClaw（小龙虾） |
|----------|---------|-------------------|
| 定位 | 客服（一问一答） | 正式员工（有工位） |
| 运行环境 | 受限 | 完整电脑环境 |
| 记忆力 | 聊完就忘 | 永久记忆 |
| 技能扩展 | 有限 | 无限扩展 |
| 工作时间 | 按需响应 | 7x24 小时自动运转 |

**核心定义**：OpenClaw 是一个拥有一台完整电脑的 AI，能记住事情、学会新技能、并且全天候自动工作。

## 二、小龙虾模式

### 2.1 范式转移

```
传统软件开发模式：
需求 → 代码 → 编译 → 运行（静态、僵化）

小龙虾模式：
指令 → 推理 → 编排 → 执行（动态、自适应）
```

### 2.2 三大颠覆性特征

| 特征 | 说明 | 意义 |
|------|------|------|
| 动态生成逻辑 | 不是预设好的，能根据指令灵活组装工具 | 无需预先编程所有场景 |
| 三级记忆架构 | 短期记忆 + 长期记忆 + 文件库 | 软件能持续学习和成长 |
| 模糊的开发边界 | 用自然语言就能"开发"软件 | 人人都能成为开发者 |

### 2.3 应用场景案例

#### 案例 1：会议室预约
- **用户指令**："明天下午 5 人开会，找个房间"
- **突破点**：认知理解、非结构化数据学习
- **传统方式**：需要开发完整的预约系统
- **小龙虾方式**：自然语言理解 + 自主执行

#### 案例 2：高校督导听课
- **能力**：角色定制（简单 Prompt 实现）
- **突破点**：读取督导手册，给出针对性建议
- **意义**：专家经验规模化复制

#### 案例 3：就业咨询
- **服务**：分析专业兴趣→推荐岗位→生成简历 PDF
- **突破点**：个性化服务零边际成本
- **意义**：软件从工具变成有温度的伙伴

## 三、小龙虾生态

### 3.1 生态构成

| 要素 | 对应物 | 说明 |
|------|--------|------|
| 龙虾 | AI Agent | 具备自主性、反应性、主动性的数字个体 |
| 池水 | 数据流和协议 | 钉钉平台、开放协议等 |
| 食物 | 算力和能源 | 维持 Agent 生存的根本资源 |
| 生态位 | 社会化分工 | 形成复杂的数字社会分工体系 |

### 3.2 成本结构转型

| 传统成本项 | AI Agent 成本项 | 说明 |
|------------|-----------------|------|
| 基本工资 | Token 消耗成本 | 高频互动和复杂任务导致高支出 |
| 加班费 | GPU 推理时长成本 | 复杂任务占用昂贵算力的时间 |
| 入职培训 | 微调和知识库构建 | 为 Agent 支付的"学费" |
| 办公场地 | 存储和上下文窗口成本 | 维持长期记忆和运行环境的固定资源 |

### 3.3 虚拟恩格尔系数（Ev）

**公式**：Ev = 单位时间算力成本 / 单位时间创造业务价值

**预测**：到 2036 年，Ev 将降至人类员工同等产出成本的 **1% 以下**

**意义**："养一只龙虾"成本可能是"养一个人"的千分之一，但产出效率是人类的百倍

### 3.6 风险与挑战

| 风险 | 说明 | 应对思考 |
|------|------|----------|
| 算力通胀 | 数百亿 Agent 运行可能导致全球电力短缺 | 能效优化、绿色计算 |
| 安全失控 | 高权限 Agent 若产生"幻觉"或被恶意注入，毫秒级造成巨大损失 | 安全沙箱、权限管控 |
| 结构性失业 | 虚拟员工大规模替代可能加剧贫富差距 | 全民基本收入、再培训 |
| 法律框架 | 现行法律难以适应 AI 时代 | 立法完善、伦理规范 |
