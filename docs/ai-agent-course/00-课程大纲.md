# AI Agent 通识课 - 课程大纲

## 课程信息

- **课程名称**：AI Agent 通识课——小龙虾模式与生态
- **讲师**：诸葛斌
- **适用对象**：AI 初学者、开发者、企业技术决策者
- **课程时长**：3 课时（每课时约 30-45 分钟）

---

## 课程结构

### 第一课：教你养龙虾——AI 员工部署教程

**主题**：从 0 到 1 部署你的第一个 AI 员工

**核心内容**：
1. OpenClaw 是什么（与 ChatGPT 的区别）
2. Manager-Worker 架构解析
3. 部署前准备（硬件、软件、账号）
4. 5 分钟快速部署流程
5. 接入钉钉机器人
6. 常见问题与避坑指南

**学习目标**：
- 理解 AI Agent 与传统聊天机器人的本质区别
- 能够在本地/云端部署 OpenClaw
- 完成钉钉机器人的接入和测试

---

### 第二课：小龙虾模式——AI 原生时代软件开发模式的颠覆与重塑

**主题**：从"写软件"到"养软件"的范式转移

**核心内容**：
1. 小龙虾模式的核心概念
2. 三大应用场景案例
   - 会议室预约（认知理解突破）
   - 高校督导听课（角色定制能力）
   - 就业咨询（零边际成本个性化服务）
3. 三大颠覆性特征
   - 动态生成逻辑
   - 三级记忆架构
   - 模糊的开发边界
4. Software as Agent 未来趋势

**学习目标**：
- 理解 AI 原生软件开发的新范式
- 掌握小龙虾模式的核心特征
- 能够识别适合 AI Agent 的应用场景

---

### 第三课：小龙虾生态——数百亿机器人与 AI Agent 社会化分工生态分析

**主题**：AI Agent 生态系统的未来愿景

**核心内容**：
1. "龙虾池"生态概念
   - 龙虾（AI Agent）
   - 池水（数据流和协议）
   - 食物（算力和能源）
   - 生态位（社会化分工）
2. 成本结构转型（薪资→Token）
3. 虚拟恩格尔系数（Ev）
4. 社会化分工体系（感知型、思考型、执行型、协调型）
5. 人才培养革命（云上小龙虾校招计划）
6. 风险与挑战（算力通胀、安全失控、结构性失业）

**学习目标**：
- 理解 AI Agent 生态系统的整体架构
- 认识未来人机协作的组织形态
- 思考 AI 时代的社会影响与应对策略
