> **导读**：2026 年 3 月 21 日，阿里云百炼平台与 WaytoAGI 联合举办的首届"阿里小龙虾大会"在杭州云谷中心圆满落幕。浙江工商大学萨塞克斯人工智能学院诸葛斌老师带领陈俊烨同学参赛，荣获"黑客松勇士"称号。

## 🏆 荣耀时刻

**【本站讯 记者/通讯员 诸葛斌】** 2026 年 3 月 21 日，由阿里云百炼平台与 WaytoAGI 联合举办的首届"**阿里小龙虾大会**"在杭州云谷中心圆满落幕。

浙江工商大学萨塞克斯人工智能学院**诸葛斌**老师带领**陈俊烨**同学参赛，经过激烈角逐，陈俊烨同学凭借出色的 OpenClaw 技能表现，从众多参赛者中脱颖而出，荣获"**黑客松勇士**"称号，并获得由阿里云百炼与 WaytoAGI 联合颁发的结业证书。

### OpenClaw（小龙虾）简介

OpenClaw 是一款开源 AI Agent 框架，由阿里云百炼平台支持，具有以下特点：

| 特点 | 说明 |
|------|------|
| **易于上手** | 无需编程基础，自然语言即可开发 |
| **功能强大** | 支持多种工具调用和技能扩展 |
| **生态完善** | ClawHub 技能市场提供丰富资源 |
| **应用广泛** | 适用于智能客服、数据分析、自动化办公等场景 |
