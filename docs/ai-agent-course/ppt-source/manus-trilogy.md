# Wide Research 工作原理

## 你的个人超级计算集群

1. **任务分解** → 主 Agent 将请求拆分为数百个独立子任务
2. **并行执行** → 每个子任务获得独立的 Agent 和全新上下文
3. **自主处理** → 子 Agent 独立研究、分析和创作
4. **整合汇总** → 主 Agent 收集所有结果，合成最终报告

::: notes
这个架构设计非常巧妙
子 Agent 之间不互相通信，避免了上下文污染和幻觉累积
主 Agent 负责分发和收集，实现了高效的大规模并行处理
这就像拥有一个百人研究团队，每个人都在独立工作
:::

# 第二部：Manus 双手

## Browser Operator — 把任何浏览器变成 AI 浏览器

- 🔌 **一个 Chrome 扩展**：将 Manus 连接到你的本地浏览器
- 🤝 **利用已登录会话**：无需重新登录，使用你现有的账号
- 🌐 **真实 IP 和网络环境**：绕过严格的安全检查和访问控制
- 🛡️ **完全透明和可控**：随时停止，全程可追溯

::: notes
Browser Operator 是 Manus 最具创新性的功能之一
它解决了 AI Agent 最大的痛点之一：如何访问需要登录的平台
传统的云端 Agent 无法绕过 2FA 和登录验证
Manus 通过浏览器扩展，直接使用用户的本地会话
这意味着它可以操作 LinkedIn、Twitter、CRM 系统等任何网页
:::

# Browser Operator 工作流程

## 三步开启自动化

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1️⃣ **连接浏览器** | 安装 Chrome 扩展 | 在 Manus Connector 中启用 |
| 2️⃣ **授予权限** | 允许访问浏览器 | 明确授权，用户始终掌控 |
| 3️⃣ **自主行动** | 下达任务，Agent 执行 | 规划→导航→点击→完成 |

::: notes
整个流程设计非常人性化
用户始终在掌控之中，可以随时停止 Agent 的操作
与传统的 RPA（机器人流程自动化）不同，Manus 不需要预设脚本
它通过理解自然语言任务，自主完成操作
:::

| 维度 | Manus（云端智能体） | OpenClaw（本地智能体） |
