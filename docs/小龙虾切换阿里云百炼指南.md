## 多模型配置（可选）

如果你想在多个模型间切换：

```yaml
models:
  default:
    provider: dashscope
    model: qwen3.5-plus
    apiKey: sk-你的-API-Key
  
  # 备用模型
  backup:
    provider: dashscope
    model: qwen3.5-turbo
    apiKey: sk-你的-API-Key
  
  # 代码模型
  coder:
    provider: dashscope
    model: qwen-coder
    apiKey: sk-你的-API-Key
```

**切换模型：**
```bash
# 查看可用模型
openclaw models list

# 切换到代码模型
openclaw models use coder
```

## 常见问题

### Q: 修改配置后服务启动失败？
A: 检查：
- API Key 是否正确（没有多余空格）
- 配置文件缩进是否正确（使用空格，不用 Tab）
- 查看日志：`journalctl -u openclaw -n 50`

### Q: 切换后 AI 回复很慢？
A: 检查：
- 阿里云百炼 API Key 是否有效
- 模型配额是否充足
- 服务器网络是否正常

### Q: 如何回退到之前的配置？
A: 修改配置文件，将 provider 改回原来的值，然后重启服务

### Q: API Key 泄露了怎么办？
A: 
1. 立即在阿里云百炼控制台删除旧 Key
2. 创建新的 API Key
3. 更新配置文件
4. 重启服务
