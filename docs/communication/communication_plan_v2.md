## 三层通信架构

### 第一层：GitHub工作流（短期 - 已就绪）✅

**状态**: 生产环境
**用途**: 训练计划、评估数据、结果同步
**优点**: 稳定可靠，所有节点都能访问

```
┌──────────┐    git push    ┌──────────┐    git pull    ┌──────────┐
│  诸葛马   │ ────────────→ │  GitHub  │ ←──────────── │  小陈    │
│  诸葛虾   │ ←──────────── │  仓库   │ ────────────→ │  qoder   │
└──────────┘    git pull    └──────────┘    git push   └──────────┘
```

**当前配置**:
- 仓库: `https://github.com/zhugebin-hub/lobster-network`
- 分支: `master` (主要), `gh-pages` (Pages)
- 认证: HTTPS Token (已配置)
- GitHub Pages: `https://zhugebin-hub.github.io/lobster-network/go-training-join/`

**数据流**:
```
/shared/training/go/ → git push → GitHub → git pull → /shared/training/go/
```

### 第三层：v0.6.0 HTTP传输层（长期 - 推荐部署）🌐

**状态**: 待部署
**用途**: 节点间实时消息传递、心跳检测
**脚本**: `scripts/deploy_http_transport.sh`
**端口**: 8199

```
┌──────────┐    HTTP    ┌──────────┐    HTTP    ┌──────────┐
│  诸葛马   │ ◄───────→ │  诸葛虾   │ ◄───────→ │  小陈    │
│ :8199    │           │ :8199    │           │ :8199    │
└──────────┘           └──────────┘           └──────────┘
       │                    │                    │
       └────────────────────┼────────────────────┘
                            │
                      qoder (内网)
                    192.168.1.161
```

**架构**:
```
HTTP Server (端口8199)
    ├── /api/v1/messages     (消息传递)
    ├── /api/v1/heartbeat    (心跳检测)
    ├── /api/v1/status       (状态查询)
    └── /api/v1/sync         (数据同步)
```

**优势**:
- 实时通信（秒级延迟）
- 心跳检测（节点健康监控）
- 自动重连（网络不稳定时）
- 消息队列（离线消息缓存）
