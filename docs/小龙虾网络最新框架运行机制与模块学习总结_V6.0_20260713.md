### 2.2 核心运行机制

#### (1) 消息通信机制
- **协议**: MQTT v3.1.1 (paho-mqtt)
- **Broker**: 47.93.6.57:1883 (公网) / 172.24.57.34:1883 (内网)
- **Topic 命名规范**: `lobster/domain/entity/action`
- **QoS 策略**: 任务分配 QoS 1 / 状态心跳 QoS 0 / 关键指令 QoS 2
- **消息格式**: JSON (含 id, from, timestamp, message字段)
- **ACK 机制**: 已验证端到端通信 (9路棋盘 track-030dea86)

#### (2) 蜂群竞标机制 (Swarm Bidding)
- **提案流程**: 节点提交提案 → 网络投票 → 团队组建 → 任务执行
- **LBC 经济**: 贡献度 × 质量分 = LBC 奖励
- **信誉公式**: `score = 100 + LBC×1.5 + tasks×10`
- **等级**: S(>500) > A(>300) > B(>150) > C(≤150)
- **并行限制**: 每节点最多 2 个并行项目

#### (3) 任务调度机制
- **分配策略**: 基于节点能力画像 + LBC 均衡度
- **轮询机制**: 低 LBC 节点优先分配
- **截止追踪**: 自动提醒 + 超时处理
- **奖励体系**: 90-120 LBC/任务

#### (4) 数据同步机制
- **Git 同步**: GitHub (primary) + Gitee (mirror)
- **消息同步**: message_sync_v4.py (Python 3.6 兼容)
- **自动清理**: message_cleanup.py (归档 >7天消息)
- **健康监控**: network_health.py (四维评分)
