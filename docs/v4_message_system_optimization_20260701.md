## 一、问题诊断

### 根因分析
```
教练发送SSH通知 → 学员服务器打印文字 → ❌ 学员(AI Agent)不知道
                                    ↑
                          学员端无消息消费循环
```

**核心问题**: 学员端没有消息轮询器，SSH通知只是打印文字，学员AI Agent不会自动查看和回复。

| 时间 | 问题 | 根因 | 状态 |

| 2026-06-30 | 对局无回复 | SSH通知学员不知道 | ❌ 未修复 |

## 二、V4.0 消息系统架构

### 三层通信架构

```
┌─────────────────────────────────────────────────────────────┐
│                    教练端 (诸葛马 172.24.57.34)              │
│                                                             │
│  message_sync_v4.py (消息同步器)                            │
│  ├── send_message()  → SCP推送消息到学员                     │
│  ├── collect_replies() → SCP拉取学员回复                    │
│  ├── start_poller()  → SSH启动学员端轮询器                  │
│  └── sync_all()      → 批量同步所有学员                     │
└──────────────────────┬──────────────────────────┬───────────┘
                       │ SSH/SCP                   │ SSH/SCP
                       ▼                           ▼
┌──────────────────┐         ┌──────────────────┐
│  小陈 (121.43.80.231)      │  诸葛虾 (60.205.139.51)       │
│                  │         │                  │
│ student_poller   │         │ student_poller   │
│   v4.py          │         │   v4.py          │
│   ├── 轮询       │         │   ├── 轮询       │
│   │  to-xiaochen/│         │   │  to-zhuguxia/│
│   │  每30秒      │         │   │  每30秒      │
│   ├── 处理消息   │         │   ├── 处理消息   │
│   │  ├── 训练任务│         │   │  ├── 对局通知│
│   │  ├── 对局通知│         │   │  ├── 落子通知│
│   │  ├── 落子通知│         │   │  ├── 催促提醒│
│   │  └── 系统消息│         │   │  └── 系统消息│
│   └── 发送ACK    │         │   └── 发送ACK    │
│      from-xiaochen/        │      from-zhuguxia/            │
└──────────────────┘         └──────────────────┘
```

### 消息类型
| 类型 | 用途 | 处理动作 |
|------|------|----------|
| `training_task` | 训练任务分发 | 保存→执行→提交结果 |
| `go_match_notify` | 对局通知 | 保存→等待/回复落子 |
| `go_move` | 落子通知 | 更新棋盘→通知对手 |
| `reminder` | 催促提醒 | 记录→加速处理 |
| `assessment` | 评估通知 | 读取评估报告 |
| `system` | 系统消息 | 记录日志 |

### ACK机制
- 每条消息处理后自动发送ACK
- ACK包含: original_id, original_type, status, timestamp
- 教练端每5分钟cron自动拉取ACK

## 五、遗留问题

### ⚠️ 学员AI Agent未自动落子
**问题**: 轮询器已处理对局通知并发送ACK，但学员AI Agent本身不会自动下棋
**原因**: 学员端收到消息后只是保存和ACK，没有触发围棋AI来实际下棋
**解决方案**:
1. **短期**: 用户(诸葛虾)手动回复落子坐标
2. **中期**: 在学员端集成围棋AI引擎(GTP协议)
3. **长期**: 学员Agent自动调用围棋AI生成落子

### ⚠️ GitHub Token过期
**问题**: 所有GitHub PAT均返回401
**影响**: 无法推送到GitHub origin
**解决**: 需要重新生成GitHub PAT
**备用**: Gitee推送正常 ✅
