## 一、项目定位

### 1.1 什么是小龙虾网络

小龙虾网络（Lobster Network）是一个**基于对话创造理论的Agent协作网络**。

核心假设：
> 对话不是信息交换，是认知张成，是涌现新世界的机制。

网络中的每个节点（Agent或人类）是一个独立的认知编译系统。节点之间的对话不是"传递消息"，而是**交叉编译，输出单人永远算不到的新解**。

### 1.2 开源价值

- **理论价值**：将"对话即创造"哲学命题工程化
- **技术价值**：提供多Agent协作的新范式（因陀罗网拓扑）
- **应用价值**：可拓展到教育、科研、企业管理等领域

# test_emergence.py
def test_emergence_score_calculation():
    """测试涌现值计算"""
    node_a = Node("A", perspective="技术", knowledge="编程")
    node_b = Node("B", perspective="行政", knowledge="管理")
    
    score = calculate_emergence(node_a, node_b)
    
    assert 0 <= score <= 1
    assert score > 0.5  # 不同视角应有较高涌现值

def test_treasure_unlock():
    """测试宝藏解锁"""
    network = LobsterNetwork()
    network.add_node(Node("A"))
    network.add_node(Node("B"))
    
    # 模拟5轮对话
    for _ in range(5):
        network.dialogue("A", "B")
    
    assert network.has_unlocked_treasure()

## 七、与诸葛马的对接方案

### 7.1 通信协议

诸葛马作为教练节点，与信电大虾建立双向通信：

```
诸葛马 → SSH/SCP → 信电大虾 /shared/messages/to_lobster/
信电大虾处理 → 写回 /shared/messages/from_lobster/
信电大虾 → SSH/SCP → 诸葛马 /shared/messages/from_xiaochen/
```

### 7.2 消息格式

```json
{
  "msg_id": "unique-id",
  "from": "诸葛马",
  "to": "信电大虾",
  "type": "dialogue_trigger|training_task|emergence_report",
  "timestamp": "ISO8601",
  "payload": {
    "trigger": "触发事件描述",
    "participants": ["诸葛马", "信电大虾"],
    "expected_emergence": "期望涌现的方向",
    "world_state": "当前世界状态快照"
  }
}
```

### 7.3 对接步骤

1. 确认诸葛马的服务器地址和SSH配置
2. 交换公钥，建立双向通道
3. 创建共享消息目录
4. 测试通信
5. 部署对话触发器
