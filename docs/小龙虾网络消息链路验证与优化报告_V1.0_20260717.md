## 三、 优化方案

### 3.1 路由协议升级 (解决环节 ⑤)
引入 **Hub-and-Spoke 路由表机制**：
- **Zhuge Ma (Hub)** 维护节点能力表 (`registry/nodes.json`)。
- 当收到车虾转发请求时，Hub 根据 `target_node` 字段查找专项虾 Topic，并执行 `republish`。
- **Topic 规范**: `lobster/<node_id>/inbox` (接收) / `lobster/<node_id>/result` (结果)。

### 3.2 端到端闭环机制 (解决环节 ⑥)
实现 **四步握手协议**：
1. **Request**: 车虾 → Hub → 专项虾
2. **Process**: 专项虾 处理任务
3. **Response**: 专项虾 → Hub → 车虾
4. **Ack**: 车虾 确认收到，链路闭合。

### 3.3 验证脚本开发
开发 `scripts/verify_full_chain.py`，模拟三个角色（车虾、诸葛马、专项虾）在同一 MQTT Broker 上的交互，自动验证链路连通性。
