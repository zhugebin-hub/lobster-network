## 五、消息轮询持久化

### 5.1 功能特性

| 功能 | 描述 |
|------|------|
| 持久化存储 | SQLite数据库存储所有消息 |
| 消息去重 | 基于message_id唯一约束 |
| 状态追踪 | pending→processing→completed/failed |
| 断点续传 | 重启后从上次位置继续轮询 |
| 重试机制 | 失败消息自动重试（最多3次） |
| 过期清理 | 自动清理7天前已完成/失败消息 |

### 5.2 数据库结构

```sql
CREATE TABLE messages (
    id TEXT PRIMARY KEY,
    message_id TEXT UNIQUE,
    from_sender TEXT,
    to_receiver TEXT,
    message_type TEXT,
    content TEXT,
    checksum TEXT,
    status TEXT DEFAULT 'pending',
    retry_count INTEGER DEFAULT 0,
    created_at TEXT,
    updated_at TEXT,
    processed_at TEXT,
    error_message TEXT
);
```
