## 📋 项目背景

诸葛虾在用 python-pptx 手动生成8页汇报PPT时发现：
1. 手动编码效率低，需反复调试布局
2. 文字遮挡、间距问题频发
3. 图片和二维码嵌入处理复杂

## 🎯 项目目标

开发PPT自动化生成模块，实现：
- 输入结构化内容（标题、正文、图片路径）→ 自动输出精美PPTX
- 内置多种模板（学术汇报、产品介绍、数据报告等）
- 自动处理布局、间距、文字遮挡问题
- 支持图片和二维码自动嵌入

## 🔧 技术方案

### 架构
```
输入 (JSON) → 布局引擎 → 模板渲染 → 输出生成 → PPTX文件
```

### 核心功能
1. **自动布局计算**: 根据内容长度自动调整卡片大小和间距
2. **文字遮挡检测**: 自动检测并修复文字重叠问题
3. **模板系统**: 预设5种常用模板风格
4. **媒体嵌入**: 自动处理图片和二维码插入

### 集成位置
- 目录: `sdk/ppt_generator/`
- 依赖: python-pptx, Pillow
- 接口: `generate_ppt(content: dict, template: str) -> bytes`
