## 一、项目概览

### 1.1 小龙虾网络 V3.0

小龙虾网络是一个**基于对话创造理论的多Agent协作网络**，将哲学命题"对话即创造"工程化为可运行的系统。

**核心理论**:
- **一人一世界**: 每个节点（Agent或人类）是独立的认知编译系统
- **世界是对话**: 对话不是信息传递，是认知张成——两个系统交叉编译，输出单人永远算不到的新解
- **世界是编程的**: 如同游戏中的程序化生成，世界按需渲染；宝藏不是预设的，是状态满足时的涌现输出

**架构分层（v0.6.0 六层架构）**:
