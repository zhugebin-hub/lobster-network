## 二、立项依据

### 2.1 研究背景与战略意义

低空经济作为国家战略性新兴产业，已被写入2024年政府工作报告，涵盖无人机物流、城市空中交通（UAM）、农业植保、应急救援、低空旅游等多个应用场景。据中国民航局数据，2025年我国低空经济市场规模已突破8000亿元，预计2030年将达到2万亿元。随着低空飞行器数量的爆发式增长（2025年注册无人机超200万架），低空交通系统面临以下核心挑战：

**（1）数据来源多、标准缺失**
低空飞行器、地面站、气象站、雷达站等多源异构数据缺乏统一标准，数据格式、编码方式、传输协议各异，难以实现跨系统互联互通。当前低空数据标准体系仍处于碎片化状态，缺乏国家层面的统一规范。

**（2）安全共享难**
低空数据涉及国家安全（空域信息）、商业机密（物流路线）、个人隐私（飞行轨迹），传统中心化数据共享模式存在单点故障和信任瓶颈。如何在保证数据安全的前提下实现高效共享，是低空经济规模化发展的关键瓶颈。

**（3）动态组网复杂**
低空飞行器高速移动（时速可达100-300km/h）、拓扑频繁变化、通信链路不稳定（城市峡谷效应、多径衰落），传统网络协议难以保证全链路安全。特别是在10%丢包率的高动态环境下，如何保持通信链路稳定是亟待解决的技术难题。

**（4）规模化运营瓶颈**
现有区块链共识算法（如PBFT、Raft）效率低下（吞吐量<1000 tps、延迟>1s），无法支撑大规模低空数据实时运营需求。低空交通系统需要每秒处理数万笔交易（飞行器身份验证、空域分配、数据共享），传统方案完全无法满足。

### 2.2 国内外研究现状与趋势

#### 国际研究现状

**（1）低空交通管理系统**
- **NASA UTM（Unmanned Aircraft System Traffic Management）**：美国NASA主导的无人机交通管理系统，聚焦空域管理、冲突检测与解脱，但数据安全与共享机制薄弱，未涉及区块链与密码学技术
- **EU U-space**：欧盟提出的无人机运行框架，强调标准化和互操作性，已发布ED-201标准，但区块链与密码学技术集成不足，访问控制仍依赖中心化CA机构
- **日本DIDRS**：日本国土交通省无人机信息系统，侧重飞行许可管理，数据共享范围有限

**（2）区块链共识算法**
- **Hyperledger Fabric**：IBM主导的联盟链框架，采用排序-执行架构，吞吐量约3500 tps，延迟约500ms，无法满足低空交通实时性要求
- **Ethereum 2.0**：采用PoS共识，吞吐量约1000-3000 tps，延迟约12s，更适合金融场景而非实时交通控制
- **Avalanche**：采用DAG结构，吞吐量约4500 tps，延迟约2s，性能有所提升但仍不足
- **最新进展**：2024-2025年学术界提出多种aBFT（异步拜占庭容错）算法，如Narwhal&Bullshark（吞吐量>10万tps）、DAG-Rider（延迟<100ms），为低空交通提供了新的技术路径

**（3）分布式访问控制**
- **ABE（Attribute-Based Encryption）**：基于属性加密技术已实现细粒度访问控制，但计算开销大（加密时间>100ms），难以满足低空交通实时性要求
- **CP-ABE（Ciphertext-Policy ABE）**：支持密文策略，但密钥更新效率低，不支持动态权限修改
- **最新进展**：2025年学术界提出轻量级ABE方案（如LRU-ABE），将加密时间压缩至50ms以内，支持动态权限更新

#### 国内研究现状

**（1）低空经济试点**
- **深圳**：全国首个低空经济产业试验区，已开通无人机物流航线超100条，但可信数据空间建设仍处于起步阶段
- **合肥**：低空经济创新发展试验区，聚焦无人机研发制造，数据共享平台建设滞后
- **北京**：亦庄新城低空经济示范区，探索城市空中交通管理，但跨部门数据共享机制尚未建立

**（2）学术研究进展**
- **异步区块链共识**：清华大学、北京大学等团队在aBFT算法方面取得突破，提出基于DAG的并行共识架构，吞吐量可达5万tps以上
- **分布式访问控制**：中国科学院信息工程研究所、上海交通大学等在ABE优化方面取得进展，提出轻量级多授权ABE方案
- **低空通信协议**：北京邮电大学、哈尔滨工业大学等在低空自组织网络（FANET）方面开展研究，提出基于MQTT的轻量级消息传输方案

**（3）存在的问题**
- 缺乏面向低空场景的系统性工程实践，学术研究与应用需求脱节
- 数据标准体系碎片化，缺乏国家/行业层面的统一规范
- 安全技术与性能指标难以兼顾，无法同时满足安全性、实时性、规模化要求

### 2.3 本项目创新点

本项目提出**"技术-标准"一体化**的可信数智空间架构，核心创新包括：

**创新点1：高性能异步区块链共识算法**
突破传统同步共识的效率瓶颈，基于DAG+分片技术实现交易并行验证，吞吐量≥50,000 tps，延迟≤50ms，满足大规模低空数据实时运营需求。

**创新点2：分布式细粒度访问控制机制**
无需可信中心，基于轻量级ABE+区块链实现权限验证，支持动态权限修改，单次共享延迟≤100ms，解决低空数据"不敢共享、不愿共享"难题。

**创新点3：低空动态组网全链路安全协议**
构建分布式密钥生命周期管理体系（生成/分发/更新/撤销），基于MQTT实现Ad-hoc自组织网络，在10%丢包率下保持连接稳定，通信链路误码率≤1%。

**创新点4：低空数据标准规范体系**
制定团体标准1项，填补低空数据元、接口、安全标准空白，推动低空经济标准化、规范化发展。

## 三、研究内容与技术路线

### 3.1 研究内容一：低空可信数智空间构建技术

**目标**：构建高性能异步区块链共识系统，支撑大规模低空数据运营

**研究内容**：
1. **异步拜占庭容错（aBFT）共识算法**：
   - 基于DAG（有向无环图）结构，实现交易并行验证
   - 引入分片技术，将网络划分为多个并行共识组
   - 优化通信复杂度从O(n²)降至O(n log n)
   - 设计低空场景专用的交易排序机制，保证飞行安全相关交易的优先级

2. **低空数据模型设计**：
   - 定义飞行器身份、飞行计划、遥测数据、气象数据等核心实体
   - 建立数据血缘追踪机制，确保数据可追溯、可审计
   - 设计低空数据分类分级标准，支撑差异化安全策略

3. **系统架构设计**：
   ```
   ┌─────────────────────────────────────────────┐
   │              应用层 (Application)            │
   │  飞行器调度 | 空域管理 | 数据共享 | 审计追踪  │
   ├─────────────────────────────────────────────┤
   │              智能合约层 (Smart Contract)     │
   │  访问控制合约 | 数据共享合约 | 审计合约      │
   ├─────────────────────────────────────────────┤
   │              共识层 (Consensus)              │
   │  aBFT 共识引擎 | DAG 存储 | 分片管理        │
   ├─────────────────────────────────────────────┤
   │              网络层 (Network)                │
   │  P2P 通信 | 消息路由 | 动态组网             │
   └─────────────────────────────────────────────┘
   ```

**技术路线**：
- 第一阶段：aBFT共识算法设计与仿真验证（NetSim/OMNeT++）
- 第二阶段：DAG存储结构与分片管理实现
- 第三阶段：系统集成与性能测试

**预期指标**：
- 系统支持 ≥500 个主体接入
- 系统延迟 ≤50ms
- 异步区块链吞吐量 ≥50,000 tps

### 3.2 研究内容二：分布式数据共享安全协议

**目标**：研制低空数据细粒度访问控制技术，实现数据安全流通共享

**研究内容**：
1. **基于属性加密（ABE）的访问控制**：
   - 支持多维度属性（角色、位置、时间、任务类型）
   - 实现细粒度权限策略（读取、写入、转发、删除）
   - 支持动态权限修改，无需重新加密数据
   - 优化ABE算法性能，将加密时间压缩至≤100ms

2. **分布式信任机制**：
   - 无需可信中心，基于区块链实现权限验证
   - 引入信誉评分机制，节点行为可追溯
   - 支持国密算法（SM2/SM3/SM4），满足合规要求

3. **隐私保护技术**：
   - 零知识证明（ZKP）验证数据合法性
   - 多方安全计算（MPC）实现联合数据分析
   - 差分隐私保护敏感信息

**技术路线**：
- 第一阶段：轻量级ABE算法设计与优化
- 第二阶段：分布式信任机制与区块链集成
- 第三阶段：隐私保护技术实现与性能评估

**预期指标**：
- 支持可证明安全、细粒度、无可信中心的分布式访问控制机制
- 支持动态访问权限修改
- 单次共享延迟 ≤100ms

### 3.3 研究内容三：低空动态组网全链路安全协议

**目标**：构建低空密钥安全全生命周期管理体系

**研究内容**：
1. **分布式密钥生成与更新**：
   - 基于门限密码学的分布式密钥生成（DKG）
   - 周期性密钥更新机制，支持热更新
   - 密钥撤销与恢复机制

2. **动态组网路由协议**：
   - 基于MQTT的轻量级消息传输协议
   - 支持Ad-hoc自组织网络
   - 10%丢包率下保持连接稳定

3. **全链路加密**：
   - 传输层：TLS 1.3 + 国密算法
   - 应用层：端到端加密（E2EE）
   - 存储层：透明加密（TDE）

**技术路线**：
- 第一阶段：DKG协议设计与实现
- 第二阶段：MQTT动态组网协议优化
- 第三阶段：全链路加密集成与测试

**预期指标**：
- 分布式密钥生成、分发、更新时延 ≤10ms
- 高通量加密/信息传输 ≤30ms
- 验证能力 ≥1000 TPS
- 10%丢包率下仍保持连接稳定
- 通信链路误码率 ≤1%

### 3.4 研究内容四：数据标准化研究

**目标**：构建低空数据标准规范体系

**研究内容**：
1. **数据元标准**：
   - 定义低空数据核心元数据（飞行器ID、位置、高度、速度、时间戳等）
   - 建立数据编码规范（JSON/XML/Protobuf）

2. **接口标准**：
   - 定义系统间API接口规范
   - 制定MQTT Topic命名规范

3. **安全标准**：
   - 制定数据分类分级标准
   - 建立访问控制策略模板

**预期产出**：
- 制定团体标准 1 项
