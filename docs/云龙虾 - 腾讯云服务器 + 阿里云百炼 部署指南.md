📍 **操作位置：** 云服务器 → 安全组 → 添加规则

```

4. 点击 "添加规则"
```

**需要放行的端口：**

|------|----------|------|------|
| TCP | 22 | 0.0.0.0/0 | SSH 远程登录 |
| TCP | 8000-9000 | 0.0.0.0/0 | OpenClaw 服务 |
| TCP | 443 | 0.0.0.0/0 | HTTPS（可选） |

📍 **操作位置：** 本地终端 或 腾讯云控制台

### 步骤 10：配置 OpenClaw 使用阿里云百炼

📍 **操作位置：** SSH 终端

```bash
# 进入 OpenClaw 配置目录
cd ~/.openclaw

# 初始化配置
openclaw init

# 配置模型
openclaw configure --model
```

**交互式配置：**
```
? 选择模型提供商：dashscope（阿里云百炼）
? 输入 API Key：sk-xxxxxxxxxxxxxxxxxxxxxxxx
? 选择模型：qwen3.5-plus
? 设置默认模型：是
```

**或手动编辑配置文件：**
```bash
nano ~/.openclaw/config/config.yaml
```

添加以下内容：
```yaml
models:
  default:
    provider: dashscope
    model: qwen3.5-plus
    apiKey: sk-你的API-Key
```

保存文件：`Ctrl+O` → `Enter` → `Ctrl+X`

## 第五部分：启动服务

### 步骤 14：启动 OpenClaw

📍 **操作位置：** SSH 终端

**方式一：直接运行（测试用）**
```bash
cd ~/.openclaw
openclaw gateway start
```

**预期输出：**
```
🦞 小龙虾 AI 启动中...
✅ 模型已加载：qwen3.5-plus
✅ 钉钉通道已启用
✅ 服务已启动：http://0.0.0.0:8000
```

**方式二：Systemd 服务（生产环境，推荐）**
```bash
# 创建服务文件
cat > /etc/systemd/system/openclaw.service << EOF
[Unit]
Description=OpenClaw AI Gateway
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/.openclaw
ExecStart=/usr/bin/openclaw gateway start
Restart=always
RestartSec=10
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
EOF

# 启用并启动服务
systemctl daemon-reload
systemctl enable openclaw
systemctl start openclaw

# 查看状态
systemctl status openclaw
```

**预期输出：**
```
● openclaw.service - OpenClaw AI Gateway
     Loaded: loaded (/etc/systemd/system/openclaw.service; enabled)
     Active: active (running) since Fri 2026-04-24 19:00:00 CST
```

## 🆘 常见问题

### Q: 腾讯云安全组怎么配置？
A: 登录腾讯云控制台 → 云服务器 → 安全组 → 添加规则 → 放行 22、8000-9000 端口

### Q: 钉钉机器人收不到消息？
A: 检查：
- 机器人是否已添加到群
- AppKey 和 AppSecret 是否正确
- 腾讯云安全组端口是否开放

### Q: AI 回复很慢？
A: 检查：
- 服务器网络是否正常
- 阿里云百炼 API Key 是否有效
- 模型配额是否充足

### Q: 服务启动失败？
A: 检查：
- 日志：`journalctl -u openclaw -n 50`
- 端口是否被占用：`netstat -tlnp | grep 8000`
- Node.js 版本是否正确：`node -v`
