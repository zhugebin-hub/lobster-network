# 🦞 云龙虾 - 阿里云部署指南

> 将 OpenClaw AI 助手部署到阿里云，实现手机端随时访问

---

## 📋 准备工作

### 1. 阿里云账号
- 访问 https://www.aliyun.com 注册/登录
- 完成实名认证

### 2. 创建 ECS 服务器

**推荐配置：**
- **地域：** 选择离您最近的（如：华东 1-杭州）
- **实例规格：** 
  - 入门：2 核 4G（约 ¥60/月）
  - 推荐：4 核 8G（约 ¥120/月）
- **镜像：** Ubuntu 22.04 LTS 或 Alibaba Cloud Linux 3
- **存储：** 40GB ESSD 云盘
- **网络：** 按量付费带宽 3-5Mbps

**安全组配置（重要！）：**
```
放行端口：
- 22 (SSH)
- 8000-9000 (OpenClaw 服务端口)
- 443 (HTTPS，可选)
```

### 3. 创建 SSH 密钥对
- 在阿里云控制台创建密钥对
- 下载私钥文件（.pem）
- 本地设置权限：`chmod 600 your-key.pem`

## 🚀 服务器环境搭建

### 步骤 1：SSH 登录服务器
```bash
ssh -i your-key.pem root@your-server-ip
```

### 步骤 2：更新系统
```bash
apt update && apt upgrade -y
```

### 步骤 3：安装基础依赖
```bash
# 安装 Node.js (v20+)
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs

# 安装 Git
apt install -y git

# 安装 Docker（可选，容器化部署）
curl -fsSL https://get.docker.com | bash
systemctl enable docker
systemctl start docker
```

### 步骤 4：安装 OpenClaw
```bash
# 克隆 OpenClaw 仓库
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# 安装依赖
npm install

# 全局安装（可选）
npm install -g .
```

---

## ⚙️ 配置 OpenClaw

### 步骤 5：初始化配置
```bash
cd ~/.openclaw
openclaw init
```

### 步骤 6：配置钉钉机器人

1. **创建钉钉机器人：**
   - 登录 https://open.dingtalk.com
   - 创建企业内部开发应用
   - 获取 AppKey 和 AppSecret

2. **配置 OpenClaw：**
```bash
openclaw configure --channel dingtalk
```

填写：
- `DINGTALK_APP_KEY`: 钉钉应用的 AppKey
- `DINGTALK_APP_SECRET`: 钉钉应用的 AppSecret
- `DINGTALK_BOT_CODE`: 机器人标识

### 步骤 7：配置 AI 模型
```bash
openclaw configure --model
```

推荐配置（阿里云百炼）：
- Provider: `dashscope`
- Model: `qwen3.5-plus`
- API Key: 在 https://dashscope.console.aliyun.com 获取

## 🏃 启动服务

### 方式一：直接运行
```bash
cd ~/.openclaw
openclaw gateway start
```

### 方式二：Docker 部署（推荐）
```bash
# 创建 docker-compose.yml
cat > docker-compose.yml << EOF
version: '3'
services:
  openclaw:
    image: openclaw/openclaw:latest
    ports:
      - "8000:8000"
    volumes:
      - ./workspace:/app/workspace
      - ./config:/app/config
    environment:
      - DINGTALK_APP_KEY=your-app-key
      - DINGTALK_APP_SECRET=your-app-secret
      - DASHSCOPE_API_KEY=your-api-key
    restart: always
EOF

# 启动
docker-compose up -d
```

### 方式三：Systemd 服务（生产环境）
```bash
# 创建服务文件
cat > /etc/systemd/system/openclaw.service << EOF
[Unit]
Description=OpenClaw AI Gateway
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/.openclaw
ExecStart=/usr/bin/openclaw gateway start
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# 启用服务
systemctl daemon-reload
systemctl enable openclaw
systemctl start openclaw
systemctl status openclaw
```

## 📱 手机端访问

### 方式一：钉钉群机器人
1. 在钉钉群中添加机器人
2. 选择"自定义"机器人
3. 填写 Webhook 地址（OpenClaw 提供的地址）
4. 完成配置后，在群里@机器人即可对话

### 方式二：钉钉个人聊天
1. 在钉钉搜索机器人名称
2. 添加为好友
3. 直接私聊对话

### 方式三：Web 界面（可选）
```bash
# 开放 Web 界面端口
openclaw web --port 3000 --host 0.0.0.0

# 手机浏览器访问：http://your-server-ip:3000
```

## ⚠️ 注意事项

1. **安全组：** 只开放必要端口，SSH 建议限制 IP
2. **API Key：** 不要提交到代码仓库
3. **数据备份：** 定期备份 workspace 和 config 目录
4. **监控：** 设置服务器监控告警（CPU、内存、磁盘）
5. **HTTPS：** 生产环境建议配置 SSL 证书

## 🆘 常见问题

### Q: 钉钉机器人收不到消息？
A: 检查：
- 机器人是否已添加到群
- Webhook 地址是否正确
- 安全组端口是否开放

### Q: AI 回复很慢？
A: 检查：
- 服务器网络是否正常
- API Key 是否有效
- 模型配额是否充足

### Q: 服务自动停止了？
A: 使用 systemd 或 docker-compose 设置自动重启
