## ⚠️ 重要经验教训

1. **技能广告陷阱识别**：ckt-design（创客贴）本质是导流到第三方商业平台，API 调用 + 编辑跳转 = 广告
2. **检查方法**：检查技能中的 API 调用是否指向第三方商业平台
3. **OpenClaw Agent Key ≠ DashScope API Key**：Agent Key 用于智能体连接 OpenClaw 实例，不能用于 DashScope 视觉模型
4. **NFS 通道不稳定**：/shared 挂载点经常不可用，重要文件需要通过其他方式传输
5. **PPT 文字布局**：使用 python-pptx 生成 PPT 时需要仔细控制间距，避免文字遮挡
