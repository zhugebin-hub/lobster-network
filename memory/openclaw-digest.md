## 【最新动态】

- OpenClaw 是一个自托管网关，连接 WhatsApp、Telegram、Discord、iMessage 等聊天应用到 AI 编码代理
- 项目采用 MIT 开源许可，由社区驱动开发
- 支持多通道网关：单个 Gateway 进程可同时服务 WhatsApp、Telegram、Discord 等
- 提供 Web Control UI 浏览器仪表盘，用于聊天、配置、会话和节点管理
- 支持 iOS 和 Android 节点配对，实现 Canvas、摄像头和语音功能
