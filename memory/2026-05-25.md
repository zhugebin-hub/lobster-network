### 技术细节

#### 中方课表结构
- 第1行：学期、课程名、课程代码/学院
- 第2行：星期一至星期日
- 第3-7行：上午/下午/晚上各大节
- 单元格内容格式：`教师职称/(节次)周次/地点/教学班/班级/人数/考核/学时`

#### 英方课表结构
- Row 0：课程标题（合并单元格）
- Row 1：表头（Day, Class, ZJSU Timetable, Monday-Sunday）
- Row 2-6：Morning（1.0-5.0节次）
- Row 7：Lunch Break
- Row 8-11：Afternoon（6.0-9.0节次）
- Row 12：Dinner Break
- Row 13-15：Evening（10.0-12.0节次）

#### 字段映射
- 班级：AI电子2401→REE 2401, AI通信2303→CE 2303
- 教学楼：下沙 A201→Building A, Room 201
- 周次：4-7周→Week 4-7
- 学时：理论:64,实验:32→32h Lab

### 转换命令
```bash
# 单文件转换
python3 scripts/convert_cn_to_uk_timetable.py \
  --source-file "AII040-数字信号处理.xls" \
  --template "2025-2026-2 Teaching Calender.xls" \
  --output "AII040_英方课表.xlsx" \
  --log "AII040_转换日志.json"

# .xls转.xlsx（LibreOffice不可用时）
python3 -c "
import xlrd, openpyxl
wb_xls = xlrd.open_workbook('file.xls')
wb_xlsx = openpyxl.Workbook()
for si in range(wb_xls.nsheets):
    ws_xls = wb_xls.sheet_by_index(si)
    ws_xlsx = wb_xlsx.create_sheet(title=ws_xls.name)
    for r in range(ws_xls.nrows):
        for c in range(ws_xls.ncols):
            ws_xlsx.cell(row=r+1, column=c+1, value=ws_xls.cell(r,c).value)
wb_xlsx.save('file.xlsx')
"
```
