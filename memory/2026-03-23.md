### 核心知识点

**小龙虾（OpenClaw）定义**：
- 拥有完整电脑环境的 AI Agent
- 永久记忆、技能无限扩展、7×24 小时运转
- 与 ChatGPT 对比：客服 vs 正式员工

**虚拟恩格尔系数（Ev）**：
```
Ev = 单位时间算力成本 / 单位时间创造业务价值
2026 年：Ev ≈ 10%
2030 年：Ev ≈ 3%
2036 年：Ev ≈ 1%
```

**Manager-Worker 架构**：
- Manager：任务拆解、工作流编排、结果聚合
- Worker：感知型、思考型、执行型、协调型
- AI Gateway：密钥管理、访问控制

**三大颠覆性特征**：
1. 动态生成逻辑（vs 静态编程）
2. 三级记忆架构（短期、长期、文件库）
3. 模糊的开发边界（人人都是开发者）
