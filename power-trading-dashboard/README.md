# ⚡ 电力调度与电价期货交易分析平台

## 📋 项目简介

本应用是一个电力调度主题的数据分析平台，引入了期货市场性质的电价交易机制。参考杭州烟草销售数据可视化应用的设计理念，打造专业的电力交易监控与分析系统。

## 🎯 核心功能

### 1. 实时 KPI 监控
- **实时负荷**：电网实时负荷监控（MW）
- **电价指数**：实时电价指数（元/MWh）
- **期货持仓量**：市场总持仓量（手）
- **日交易量**：当日交易总额（亿元）

### 2. 电价期货交易
- **多合约交易**：支持季度期货合约（ELEC-2024Q2/Q3/Q4 等）
- **实时报价**：合约价格与涨跌幅实时更新
- **买卖操作**：支持买入做多/卖出做空双向交易
- **交易记录**：实时成交记录追踪

### 3. 数据分析图表

#### 24 小时电力负荷与电价趋势
- 双轴折线图展示负荷与电价相关性
- 平滑曲线展示日内变化规律
- 面积图增强视觉效果

#### 期货合约成交量分布
- 饼图展示各合约成交占比
- 直观反映市场热度分布

#### 区域电力供需热力图
- 8 个城市 × 3 侧（发电/电网/用户）矩阵
- 颜色深浅表示供需紧张程度
- 显示负荷数据与供需缺口

#### 电价波动率分析
- 柱状图展示日内波动率
- 折线图对比历史波动率
- 帮助评估市场风险

### 4. 实时交易记录
- 时间、合约、方向、价格、数量、金额、状态
- 状态标识（成交/待成交）
- 自动刷新更新

## 📊 数据说明

### 模拟数据字段
| 字段 | 说明 | 单位 |
|------|------|------|
| 负荷 | 电网实时负荷 | MW |
| 电价 | 电力现货/期货价格 | 元/MWh |
| 持仓量 | 期货合约未平仓合约数 | 手 |
| 交易量 | 当日成交金额 | 亿元 |

### 合约命名规则
- **ELEC-YYYYQX**：电力期货合约
- **YYYY**：年份
- **QX**：季度（Q1/Q2/Q3/Q4）

## 🎨 设计特点

### 视觉风格
- **深色主题**：减少长时间监控的视觉疲劳
- **科技蓝紫**：主色调 #1a1a2e → #16213e
- **强调色**：#e94560（红色）用于关键指标
- **涨跌色**：绿色↑ #00d26a / 红色↓ #ff6b6b

### 交互设计
- **响应式布局**：适配不同屏幕尺寸
- **实时刷新**：KPI 数据 3 秒自动更新
- **悬停效果**：卡片/按钮交互反馈
- **图表联动**：ECharts 工具提示与缩放
