## 快速开始

### 学员学习路径

1. **阅读课程大纲** → 了解整体结构
2. **学习核心知识点** → 掌握关键概念
3. **观看 PPT** → 理解详细内容
4. **完成实践作业** → 动手部署 AI 员工

### 讲师备课路径

1. **阅读课程大纲** → 把握教学目标
2. **学习核心知识点** → 熟悉内容要点
3. **参考 PPT 索引** → 了解每页讲解要点
4. **准备演示环境** → 确保实操顺利
