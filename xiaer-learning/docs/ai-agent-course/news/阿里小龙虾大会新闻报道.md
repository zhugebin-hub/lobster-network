# 喜报！浙江工商大学人工智能学院学子荣获阿里小龙虾大会"黑客松勇士"称号

**【本站讯 记者/通讯员 诸葛斌】** 2026 年 3 月 21 日，由阿里云百炼平台与 WaytoAGI 联合举办的首届"阿里小龙虾大会"在杭州云谷中心圆满落幕。浙江工商大学萨塞克斯人工智能学院诸葛斌老师带领陈俊烨同学参赛，经过激烈角逐，陈俊烨同学凭借出色的 OpenClaw 技能表现，从众多参赛者中脱颖而出，荣获"黑客松勇士"称号，并获得由阿里云百炼与 WaytoAGI 联合颁发的结业证书。

## 大会背景

阿里小龙虾大会是阿里云百炼平台与 WaytoAGI 联合举办的首届 AI Agent 开发者大会，旨在推动 AI Agent 技术的发展与应用，培养 AI 开发人才。

</div>

**大会主题**："龙虾街区 盛大开业——你的虾从出生到上岗全包了"

**活动亮点**：
- 🏥 **龙虾接生站**：免费部署，安全护航
- 🏫 **龙虾学院**：技能学习，从入门到精通
- 🏢 **龙虾写字楼**：Skills 黑雪松，实战应用
- 🏥 **龙虾医院**：技术急诊，问题解答
- 🛒 **龙虾超市**：周边 get，技术周边

**现场专享**：
- 阿里云百炼 Coding Plan 新老客户有机会获得免费 Pro 级虾饲料
- 开发 Skills 即赠周边
- 上台分享可领龙虾大礼包、社区周边

**大会信息**：
- **时间**：2026 年 3 月 21 日 13:30-17:00
- **地点**：杭州西湖区灯彩街 1009 号 云谷中心（1 号门）B1 栋 2F
- **主办方**：云谷中心
- **承办方**：阿里云百炼 & WaytoAGI

## 参赛历程

本次大赛要求参赛者基于阿里云百炼平台和 OpenClaw 框架，开发具有创新性和实用性的 AI Agent 应用。陈俊烨同学在诸葛斌老师的指导下，经过数周的精心准备和开发，最终在众多参赛者中脱颖而出。

在比赛过程中，陈俊烨同学展现了扎实的 AI 开发能力和创新思维，其作品在功能性、创新性、实用性等方面均获得评委的高度认可，最终以"OpenClaw 技能满点"的优异成绩获得"黑客松勇士"荣誉称号。

### OpenClaw（小龙虾）简介

OpenClaw 是一款开源 AI Agent 框架，由阿里云百炼平台支持，具有以下特点：

| 特点 | 说明 |
|------|------|
| **易于上手** | 无需编程基础，自然语言即可开发 |
| **功能强大** | 支持多种工具调用和技能扩展 |
| **生态完善** | ClawHub 技能市场提供丰富资源 |
| **应用广泛** | 适用于智能客服、数据分析、自动化办公等场景 |
