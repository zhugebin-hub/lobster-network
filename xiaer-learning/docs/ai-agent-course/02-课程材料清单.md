## 📚 课程内容概览

### 第一课：教你养龙虾
**核心内容**：
- OpenClaw 是什么（与 ChatGPT 的区别）
- Manager-Worker 架构解析
- 部署前准备（硬件、软件、账号）
- 5 分钟快速部署流程
- 接入钉钉机器人
- 常见问题与避坑指南

**学习目标**：
- 理解 AI Agent 与传统聊天机器人的本质区别
- 能够在本地/云端部署 OpenClaw
- 完成钉钉机器人的接入和测试

---

### 第二课：小龙虾模式
**核心内容**：
- 小龙虾模式的核心概念
- 三大应用场景案例
  - 会议室预约（认知理解突破）
  - 高校督导听课（角色定制能力）
  - 就业咨询（零边际成本个性化服务）
- 三大颠覆性特征
  - 动态生成逻辑
  - 三级记忆架构
  - 模糊的开发边界
- Software as Agent 未来趋势

**学习目标**：
- 理解 AI 原生软件开发的新范式
- 掌握小龙虾模式的核心特征
- 能够识别适合 AI Agent 的应用场景

---

### 第三课：小龙虾生态
**核心内容**：
- "龙虾池"生态概念
- 成本结构转型（薪资→Token）
- 虚拟恩格尔系数（Ev）
- 社会化分工体系（感知型、思考型、执行型、协调型）
- 人才培养革命（云上小龙虾校招计划）
- 风险与挑战（算力通胀、安全失控、结构性失业）

**学习目标**：
- 理解 AI Agent 生态系统的整体架构
- 认识未来人机协作的组织形态
- 思考 AI 时代的社会影响与应对策略
