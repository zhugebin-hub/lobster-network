## 二、知识准备（课前预习）

### 2.1 函数定义格式

```python
def 函数名(参数1, 参数2, ...):
    """说明这个函数做什么"""
    # 函数体（缩进4个空格）
    代码语句
    return 返回值   # 可选
```

### 2.2 调用函数

```python
# 调用方式
函数名(实际参数1, 实际参数2)

# 接收返回值
结果 = 函数名(实际参数1, 实际参数2)
```

### 2.3 关键概念速查

| 概念 | 说明 | 示例 |
|------|------|------|
| `def` | 定义函数的关键字 | `def my_func():` |
| 参数 | 函数接收的输入 | `(name, price)` |
| `return` | 返回结果 | `return total` |
| 函数调用 | 执行函数 | `my_func("小明", 15.5)` |
