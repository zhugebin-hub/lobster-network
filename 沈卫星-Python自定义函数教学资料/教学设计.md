## 二、教学目标

### 2.1 知识目标
1. 理解函数的概念及其在程序设计中的作用
2. 掌握使用 `def` 关键字定义函数的基本语法
3. 理解函数参数（位置参数、默认参数、关键字参数）的概念与用法
4. 掌握 `return` 语句的功能，理解返回值的作用
5. 学会正确调用自定义函数

### 2.2 能力目标
1. 能够独立编写简单的自定义函数解决实际问题
2. 能够根据需求设计函数的参数和返回值
3. 具备基本的代码调试能力，能发现并修正函数定义中的常见语法错误
4. 能够将复杂问题分解为多个函数模块

### 2.3 素养目标
1. 培养模块化编程思维，体会"分而治之"的编程思想
2. 养成规范的代码编写习惯（命名规范、注释习惯）
3. 通过小组合作提升沟通协作能力和表达能力
4. 结合浙江电商产业场景，激发学习兴趣和专业认同感

## 五、教学过程（45分钟）

### 5.1 导入环节（5分钟）—— 生活中的"函数"

**教师活动：**
- 展示PPT：奶茶店点单场景图片
- 提问引导：
  - "同学们，在奶茶店点一杯珍珠奶茶，你需要告诉店员什么信息？"（杯型、甜度、加料）
  - "店员根据你提供的信息做出一杯奶茶，这个过程像不像Python中的什么？"
- 引出概念：就像奶茶店根据配方制作奶茶一样，Python中的函数就是根据我们写的"配方"（代码）来完成特定任务的"机器"

**学生活动：**
- 思考并回答问题
- 观察PPT中的类比示意图

**设计意图：** 用学生熟悉的生活场景类比抽象概念，降低认知门槛，激发学习兴趣。

### 5.2 新授环节（15分钟）—— 函数的定义、参数与返回值

#### 5.2.1 什么是函数（3分钟）

**讲解要点：**
- 函数是一段**可重复使用**的代码块
- 函数有**名字**、可以接收**输入**、能产生**输出**
- 类比：函数 = 配方（输入食材 → 加工处理 → 输出菜品）

```python
# 生活中的函数类比
# 输入：面粉 + 鸡蛋 + 糖
# 处理：混合 → 搅拌 → 烘烤
# 输出：蛋糕
```

#### 5.2.2 函数的定义格式（4分钟）

**讲解要点：**
- 使用 `def` 关键字定义函数
- 函数名命名规则（与变量名规则相同）
- 函数体必须缩进（4个空格）
- 函数定义不会自动执行，需要调用

```python
def greet():
    """向用户打招呼"""  # 文档字符串（可选）
    print("你好，欢迎来到Python世界！")

# 调用函数
greet()  # 输出：你好，欢迎来到Python世界！
```

**⚠️ 强调：** 定义函数 ≠ 执行函数！定义只是"写好配方"，调用才是"开始做菜"。

#### 5.2.3 函数参数（4分钟）

**讲解要点：**

**① 位置参数**（按顺序传递）
```python
def make_tea(name, sweetness):
    """制作奶茶"""
    print(f"制作一杯 {sweetness} 的 {name}")

make_tea("珍珠奶茶", "三分甜")  # 输出：制作一杯 三分甜 的 珍珠奶茶
```

**② 默认参数**（提供默认值）
```python
def make_tea(name, sweetness="五分甜"):
    print(f"制作一杯 {sweetness} 的 {name}")

make_tea("奶茶")              # 使用默认值：五分甜
make_tea("奶茶", "三分甜")    # 覆盖默认值
```

**③ 关键字参数**（按名称传递，更清晰）
```python
def make_tea(name, sweetness="五分甜"):
    print(f"制作一杯 {sweetness} 的 {name}")

make_tea(sweetness="不甜", name="绿茶")  # 顺序可以调换
```

#### 5.2.4 函数返回值（4分钟）

**讲解要点：**
- `return` 语句用于返回结果
- 有 `return` 的函数可以赋值给变量
- 没有 `return` 的函数默认返回 `None`

```python
# 有返回值的函数
def calculate_price(name, quantity, unit_price):
    """计算订单金额"""
    total = quantity * unit_price
    return total

# 调用并接收返回值
price = calculate_price("手机壳", 3, 15.5)
print(f"订单金额：{price}元")  # 输出：订单金额：46.5元

# 无返回值的函数（只执行操作）
def show_order(name, quantity):
    print(f"您购买了 {quantity} 件 {name}")

result = show_order("数据线", 2)
print(result)  # 输出：None
```

**设计意图：** 通过电商场景案例，将知识点串联起来，让学生在真实情境中理解函数各要素的作用。

### 5.3 演示环节（10分钟）—— 教师示范

**教师活动：** 在投影仪上演示完整代码编写过程

**演示案例：电商促销计算器**

```python
# ============================
# 电商促销计算器
# 模拟淘宝/天猫店铺促销活动
# ============================

# 1. 定义计算商品价格的函数
def calc_item_price(name, price, quantity=1):
    """计算单个商品总价"""
    total = price * quantity
    print(f"📦 {name} × {quantity} = {total:.2f}元")
    return total

# 2. 定义计算折扣的函数
def apply_discount(total, discount_rate=0.9):
    """应用折扣，返回折后价"""
    discounted = total * discount_rate
    saved = total - discounted
    print(f"💰 原价：{total:.2f}元，折扣：{discount_rate*10:.0f}折")
    print(f"💰 折后价：{discounted:.2f}元，节省：{saved:.2f}元")
    return discounted

# 3. 定义生成订单的函数
def generate_order(customer_name):
    """生成订单信息"""
    print(f"\n🛒 订单信息")
    print(f"👤 顾客：{customer_name}")
    print(f"📅 日期：2026-04-24")
    print("-" * 30)

# 4. 主程序调用
generate_order("小明同学")
item1 = calc_item_price("手机壳", 15.5, 2)
item2 = calc_item_price("数据线", 25.0, 1)
total = item1 + item2
final_price = apply_discount(total, 0.85)
print(f"\n✅ 实付金额：{final_price:.2f}元")
```

**演示要点：**
1. 逐步编写，每写一个函数就调用测试
2. 展示常见错误（如忘记缩进、拼写错误）及修正方法
3. 演示在Python交互环境中逐行测试

**学生活动：**
- 观察教师操作
- 在任务单上记录关键步骤

### 5.4 实践环节（10分钟）—— 学生上机练习

**学生活动：** 独立完成学习任务单中的基础任务和进阶任务

**教师巡视指导要点：**
- 检查函数定义格式是否正确（`def`、冒号、缩进）
- 指导学生理解参数传递过程
- 帮助调试常见错误
- 鼓励完成挑战任务的学生

**分层指导策略：**
| 学生层次 | 指导重点 |
|----------|----------|
| 基础薄弱 | 帮助完成基础任务，确保理解 `def` 和 `return` 的基本用法 |
| 中等水平 | 引导完成进阶任务，理解默认参数和关键字参数 |
| 学有余力 | 鼓励挑战任务，尝试编写带多种参数的综合函数 |

### 5.5 展示评价环节（5分钟）—— 小组展示与互评

**活动流程：**
1. **小组推选**（1分钟）：每组推选1名代表展示代码
2. **作品展示**（2分钟）：2-3组上台展示，说明函数设计思路
3. **互评打分**（1分钟）：其他小组根据评价标准打分
4. **教师点评**（1分钟）：总结优点，指出共性问题

**评价维度：**
- ✅ 代码能否正确运行
- ✅ 函数命名是否规范
- ✅ 参数设计是否合理
- 💡 是否有创意亮点

## 六、板书设计

```
┌─────────────────────────────────────────────────────────┐
│              自定义函数 —— 写好你的"代码配方"              │
│                                                         │
│  一、什么是函数？                                        │
│     可重复使用的代码块 = 配方                             │
│     输入(参数) → 处理(函数体) → 输出(返回值)              │
│                                                         │
│  二、定义函数                                            │
│     def 函数名(参数):                                    │
│         函数体(缩进4空格)                                 │
│         return 返回值                                    │
│                                                         │
│  三、函数参数                                            │
│     位置参数：按顺序传    make_tea("奶茶","三分甜")       │
│     默认参数：有默认值    make_tea("奶茶")               │
│     关键字参数：按名字传  make_tea(sweetness="不甜",     │
│                                  name="绿茶")            │
│                                                         │
│  四、返回值                                              │
│     return → 返回结果，可赋值给变量                       │
│     无return → 返回None                                  │
│                                                         │
│  五、调用函数                                            │
│     函数名(实参)  →  结果 = 函数名(实参)                 │
│                                                         │
│  ⚠️ 常见错误：                                           │
│     ① 忘记冒号 :                                         │
│     ② 缩进不对                                           │
│     ③ 定义后忘记调用                                     │
└─────────────────────────────────────────────────────────┘
```

## 七、教学反思

### 7.1 预期效果
- 学生能够理解函数的基本概念，区分"定义"和"调用"
- 80%以上的学生能独立完成基础任务
- 60%左右的学生能完成进阶任务
- 部分优秀学生能完成挑战任务

### 7.2 可能的问题与对策
| 可能问题 | 应对策略 |
|----------|----------|
| 学生对缩进概念模糊 | 提前复习缩进规范，用颜色标注强调 |
| 参数传递理解困难 | 用"快递包裹"类比：实参是包裹内容，形参是收件人 |
| return与print混淆 | 强调：print是"说出来"，return是"装进盒子递出去" |
| 部分学生进度落后 | 提供半成品代码框架，降低起步难度 |

### 7.3 改进方向
- 后续课程可引入Python 3.12+的更好错误提示特性，帮助学生更快定位错误
- 可增加"函数调试"专项练习，培养学生独立排错能力
- 结合浙江电商产业，后续可设计更复杂的综合项目（如购物车系统）
