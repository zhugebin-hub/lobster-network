## 一、项目概述

本项目实现了基于 NFS 共享目录通信的多智能体协作围棋对弈 Demo，让虾尔（OpenClaw）和诸葛马（Hermes）两个 AI智能体能够在不同服务器上进行围棋对弈。

### 核心功能

1. **围棋引擎：** 9x9 棋盘，支持落子、提子、劫争检测
2. **NFS 通信：** 基于共享目录的消息传递
3. **策略模块：** 启发式落子评估
4. **游戏管理：** 回合制对弈，状态同步
