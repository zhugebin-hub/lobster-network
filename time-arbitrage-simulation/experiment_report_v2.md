## 三、实验原理

### 3.1 时间套利概念（受电网启发）

**电网类比**：

| 电网 | 云计算 |
|------|--------|
| 发电机组 | CPU/GPU/NPU 资源 |
| 电力负载 | 计算任务 |
| 抽水蓄能 | 任务队列 |
| 分时电价 | 现货实例定价 |
| 频率稳定 | SLA 保证 |

**时间套利**：利用资产价格在不同时间点的差异，在低价时买入、高价时卖出，获取差价收益。

在云计算场景中：
- **低价时段**：夜间、周末（价格折扣 30-50%）
- **高价时段**：工作时间、业务高峰（价格溢价 20-50%）
- **套利策略**：延迟非紧急任务到低价时段执行

### 3.2 异构云计算

**异构云**：由多个不同云服务商组成的计算环境，特点：
- 价格差异：各云服务商定价策略不同
- 性能差异：计算能力、网络带宽等不同
- 地域差异：数据中心分布不同

### 3.3 调度优化目标

$$\min \sum_{j=1}^{m} cpu_j \times price_{assigned(j)}(start\_time_j)$$

约束条件：
- 截止时间约束：$completion\_time_j \leq deadline_j$
- 优先级约束：高优先级任务优先
- 任务完整性：任务不可拆分

## 四、实验步骤

### 4.1 文献调研（Manus 主导）

**步骤**：
1. 搜索"time arbitrage cloud scheduling power grid"相关文献
2. 整理电网调度与云调度的类比关系
3. 提炼研究 gap 和创新点

**关键发现**：
- 电网有成熟的时间平移机制（抽水蓄能、电池储能）
- 云调度主要关注空间优化，时间优化研究较少
- 参考文献报告 27.45% 成本节省

### 4.2 算法设计（小龙虾主导）

**三种调度算法**：

1. **轮询调度（Round-Robin）**：基准算法，任务均匀分配
2. **贪婪调度**：总是选择当前最便宜的云服务商
3. **时间套利调度**：考虑未来价格趋势，优化执行时间
4. **ML 预测调度**：基于移动平均预测的调度

## 七、问题与解决

### 7.1 遇到的问题

**问题 1：索引越界错误**
- 现象：仿真运行时出现 IndexError
- 原因：时间索引超出价格数组范围
- 解决：添加边界检查，限制索引范围

**问题 2：ML 预测效果不佳**
- 现象：ML 预测调度成本高于贪婪调度
- 原因：简单移动平均预测准确性有限
- 解决：在论文中如实报告，分析原因
