## 图片素材说明

### 建议准备的图片类型：

1. **产品图片**（用于宣传单）
   - 咖啡饮品图片 3 张
   - 建议尺寸：800×600 像素以上
   - 格式：JPG 或 PNG

2. **新闻图片**（用于新闻稿）
   - 活动场景图片 2 张
   - 建议尺寸：1024×768 像素以上
   - 格式：JPG

3. **美食图片**（用于推荐卡）
   - 绍兴特色美食图片 2-3 张
   - 建议尺寸：800×600 像素以上
   - 格式：JPG 或 PNG

4. **个人照片**（用于名片）
   - 证件照或生活照 1 张
   - 建议尺寸：400×500 像素
   - 格式：JPG 或 PNG

### 图片素材获取建议：
- 使用学校自有素材库
- 从免费图片网站下载（如 Pixabay、Unsplash）
- 学生自备个人照片
- 使用 WPS 内置剪贴画
