## 一、项目概述

### 1.1 项目背景

本项目旨在实现基于 NFS 共享目录通信的多智能体协作密室逃脱 Demo，让虾尔（OpenClaw）和诸葛马（Hermes）两个 AI智能体能够在不同服务器上进行协作逃脱。

### 1.2 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                    NFS 共享目录 (/shared)                     │
│  ┌─────────────────────┐    ┌─────────────────────┐         │
│  │  from-lobster/      │    │  from-hermes/       │         │
│  │  (虾尔→诸葛马)       │    │  (诸葛马→虾尔)       │         │
│  └─────────────────────┘    └─────────────────────┘         │
│  ┌─────────────────────────────────────────────────┐        │
│  │  escape-room/                                   │        │
│  │    room-state.json  (密室状态)                    │        │
│  │    clue-queue/    (线索队列)                      │        │
│  │    puzzle-log.json (谜题日志)                     │        │
│  └─────────────────────────────────────────────────┘        │
└─────────────────────────────────────────────────────────────┘

┌──────────────────┐          ┌──────────────────┐
│   虾尔 (OpenClaw) │          │  诸葛马 (Hermes)  │
│                  │          │                  │
│  room_engine.py  │          │  room_engine.py  │
│  agent.py        │          │  agent.py        │
│  skills.py       │          │  skills.py       │
└──────────────────┘          └──────────────────┘
```

### 1.3 核心功能

- **密室引擎：** 5x5 网格地图，支持房间、谜题、线索系统
- **NFS 通信：** 基于共享目录的消息传递
- **智能体模块：** 4种角色（侦探、工程师、学者、向导）
- **游戏模式：** 单人、协作、竞赛

## 二、系统实现

### 2.1 密室引擎

| 功能 | 实现 |
|------|------|
| 地图表示 | 5x5 网格，25个房间 |
| 房间类型 | 19种（入口、书房、走廊等） |
| 谜题系统 | 4种类型（密码锁、机关、逻辑推理、路径规划） |
| 线索系统 | 5种类型（文献、密码、机关、地图、物品） |
| 钥匙系统 | 部分房间需要钥匙才能进入 |

### 2.2 NFS 通信总线

| 功能 | 实现 |
|------|------|
| 消息发送 | 写入 from-lobster/ 目录 |
| 消息接收 | 读取 from-hermes/ 目录 |
| 密室同步 | room-state.json 序列化 |
| 线索队列 | clue-queue/ 目录 |
| 事件记录 | puzzle-log.json |

### 2.3 智能体模块

| 角色 | 技能 | 职责 |
|------|------|------|
| 🔍 侦探 | 逻辑推理、线索分析 | 分析线索、推理谜题 |
| 🔧 工程师 | 机械操作、密码破解 | 破解密码、操作机关 |
| 📚 学者 | 古文解读、知识检索 | 提供知识支持、解读古文 |
| 🗺️ 向导 | 路径规划、空间感知 | 规划路线、避免陷阱 |
