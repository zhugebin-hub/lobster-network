## 一、项目概述

### 1.1 项目背景

在人工智能快速发展的今天，多智能体协作系统成为研究热点。本项目旨在实现基于 NFS 共享目录通信的多智能体协作密室逃脱 Demo，让虾尔（OpenClaw）和诸葛马（Hermes）两个 AI智能体能够在不同服务器上进行协作逃脱。

密室逃脱作为一种典型的协作任务，要求多个智能体在有限时间内，通过信息共享、分工合作、策略规划等方式，解决一系列谜题，最终逃脱密室。这个项目不仅考验每个智能体的个体能力，更考验智能体之间的协作效率。

### 1.2 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                    NFS 共享目录 (/shared)                     │
│  ┌─────────────────────┐    ┌─────────────────────┐         │
│  │  from-lobster/      │    │  from-hermes/       │         │
│  │  (虾尔→诸葛马)       │    │  (诸葛马→虾尔)       │         │
│  └─────────────────────┘    └─────────────────────┘         │
│  ┌─────────────────────────────────────────────────┐        │
│  │  escape-room/                                   │        │
│  │    room-state.json  (密室状态)                    │        │
│  │    clue-queue/    (线索队列)                      │        │
│  │    puzzle-log.json (谜题日志)                     │        │
│  └─────────────────────────────────────────────────┘        │
└─────────────────────────────────────────────────────────────┘

┌──────────────────┐          ┌──────────────────┐
│   虾尔 (OpenClaw) │          │  诸葛马 (Hermes)  │
│                  │          │                  │
│  room_engine.py  │          │  room_engine.py  │
│  agent.py        │          │  agent.py        │
│  skills.py       │          │  skills.py       │
└──────────────────┘          └──────────────────┘
```

### 1.3 核心功能

- **密室引擎：** 5x5 网格地图，支持房间、谜题、线索系统
- **NFS 通信：** 基于共享目录的消息传递
- **智能体模块：** 4种角色（侦探、工程师、学者、向导）
- **游戏模式：** 单人、协作、竞赛

## 二、系统实现

### 2.1 密室引擎

| 功能 | 实现 |
|------|------|
| 地图表示 | 5x5 网格，25个房间 |
| 房间类型 | 19种（入口、书房、走廊、实验室、出口、储藏室、客厅、厨房、卧室、花园、地下室、工坊、图书馆、观察室、塔楼、地牢、祭坛、密室、宝库） |

### 2.2 NFS 通信总线

| 功能 | 实现 |
|------|------|
| 消息发送 | 写入 from-lobster/ 目录 |
| 消息接收 | 读取 from-hermes/ 目录 |
| 密室同步 | room-state.json 序列化 |
| 线索队列 | clue-queue/ 目录 |
| 事件记录 | puzzle-log.json |

| 🔍 侦探 | 逻辑推理、线索分析 | 分析线索、推理谜题 |
| 🔧 工程师 | 机械操作、密码破解 | 破解密码、操作机关 |
| 📚 学者 | 古文解读、知识检索 | 提供知识支持、解读古文 |
| 🗺️ 向导 | 路径规划、空间感知 | 规划路线、避免陷阱 |

## 八、问题分析与改进建议

### 8.1 当前问题

1. **解谜率为0%**
   - 原因：智能体技能匹配要求严格，需要特定角色才能解决特定谜题
   - 影响：13个谜题全部未解决

2. **线索收集率仅28.6%**
   - 原因：线索需要特定技能才能收集
   - 影响：14个线索只收集了4个

3. **房间探索率88%**
   - 原因：部分房间需要钥匙才能进入
   - 影响：塔楼、密室、宝库未探索

### 8.2 改进建议

1. **增加协作机制**
   - 允许智能体之间传递线索
   - 实现技能共享机制
   - 增加协作解谜功能

2. **优化路径规划**
   - 向导智能体优先探索未访问房间
   - 增加钥匙寻找策略
   - 实现最优逃脱路线规划

3. **增强谜题解决**
   - 降低技能匹配要求
   - 增加提示系统
   - 实现多智能体协作解谜
