# 多智能体协作密室逃脱系统

## 概述

基于 NFS 共享目录通信的多智能体协作密室逃脱 Demo。

## 场景设计

### 密室逃脱任务

多个 AI智能体被关在一个虚拟密室中，每个智能体拥有不同的技能和知识。他们必须通过协作、信息共享和分工合作来解决谜题、收集线索，最终逃脱密室。

### 智能体角色

| 角色 | 技能 | 职责 |
|------|------|------|
| 🔍 侦探 | 线索分析、逻辑推理 | 分析线索、推理谜题 |
| 🔧 工程师 | 机械操作、密码破解 | 破解密码、操作机关 |
| 📚 学者 | 知识储备、文献检索 | 提供知识支持、解读古文 |
| 🗺️ 向导 | 空间感知、路径规划 | 规划路线、避免陷阱 |

### 谜题类型

1. **密码锁** - 需要学者解读古文获得密码
2. **机关陷阱** - 需要工程师破解机械装置
3. **逻辑推理** - 需要侦探分析线索
4. **路径规划** - 需要向导规划安全路线
5. **资源管理** - 需要合理分配有限的工具

## 技术栈

- **语言：** Python 3
- **通信：** NFS 共享目录（文件消息）
- **协议：** JSON 格式消息
- **密室：** 5x5 网格地图

## 消息协议

```json
{
  "type": "clue_share",
  "from": "lobster-001",
  "to": "hermes",
  "room_id": "escape-room-20260603",
  "clue": {
    "type": "password",
    "content": "密码是 42",
    "location": "书房",
    "timestamp": 1717400000
  }
}
```
