## 1. 引言：AI 时代电力教育的"生产力觉醒"

- **跨学科融合** - 需要融合 AI、大数据、物联网等新技术

## 3. 实操流程：利用 Manus 打造"电力调度三部曲"课件

### 3.1 第一步：素材喂养与意图对齐 (Feed & Align)

#### 目标
让 Manus 理解电力调度主题、核心知识点和教学意图。

#### 操作步骤

**1. 导入素材**
将以下材料提供给 Manus：
- 电力调度规程文档
- 电网运行技术标准
- 典型调度案例
- 个人教学构思

**2. 明确意图**
清晰告知 Manus：
- 教学目标：培养调度员核心能力
- 目标受众：电力专业本科生/企业内训
- 课件时长：每部 15-20 分钟
- 重点内容：调度流程、应急处理、新能源消纳

#### 关键对话示例

```
"我需要为电力专业学生制作一份关于'电力调度三部曲'的教学 PPT 和配套文档。
这是我整理的核心概念和参考资料：
- 电力调度规程（附件）
- 电网运行技术标准（附件）
- 典型故障案例库（链接）

PPT 大约 15-20 页，重点讲解：
1. 负荷预测与发电计划
2. 实时调度与应急处理
3. 新能源并网与电网稳定

请你先帮我梳理一下核心逻辑和知识点。"
```

#### Manus 处理逻辑

1. **文档解析** - 读取调度规程、技术标准
2. **概念提取** - 识别关键术语（负荷、出力、频率等）
3. **知识图谱** - 构建调度知识关联
4. **意图确认** - 反馈理解并请求确认

---

### 3.2 第二步：结构化大纲生成与迭代 (Outline & Iterate)

#### 目标
与 Manus 协作，构建符合电力教学逻辑的大纲。

#### 操作步骤

**1. 生成初稿大纲**

要求 Manus 生成包含以下结构的大纲：
```
第一部：《清晨的调度室》
├── 调度员交接班流程
├── 负荷预测方法
├── 发电计划制定
└── 与电厂协调沟通

第二部：《午后的波动》
├── 故障监测与报警
├── 应急预案启动
├── 调度指令下达
└── 故障恢复与总结

第三部：《夜幕的守护》
├── 晚高峰调度挑战
├── 新能源波动调节
├── 夜间负荷管理
└── 电网稳定评估
```

**2. 提出修改意见**

根据教学经验调整：
- 增加**实际案例**（如某次真实故障处理）
- 加入**对比分析**（传统调度 vs 智能调度）
- 添加**互动环节**（调度决策模拟）
- 补充**课程思政**（电力人的责任担当）

#### 关键对话示例

```
"这个大纲不错，但需要以下调整：

1. 在'负荷预测'部分增加人工智能预测方法的介绍
2. '应急预案'部分加入一个 220kV 线路跳闸的具体案例
3. 增加一个互动环节：让学生扮演调度员做决策
4. 每部结尾加入'课程思政'小节，体现电力人的使命感

请根据这些意见修改大纲。"
```

#### 迭代优化要点

| 迭代轮次 | 优化重点 | 预期效果 |
|----------|----------|----------|
| 第 1 轮 | 内容完整性 | 覆盖所有核心知识点 |
| 第 2 轮 | 案例真实性 | 加入实际调度场景 |
| 第 3 轮 | 互动设计 | 增强学生参与感 |
| 第 4 轮 | 视觉呈现 | 优化图表和布局 |

---

### 3.3 第三步：自动化渲染与视觉优化 (Render & Refine)

#### 目标
将结构化大纲转化为具有专业视觉效果的 PPT。

#### 操作步骤

**1. 选择风格**

明确告知 Manus 视觉风格要求：
```
"请采用以下视觉风格：
- 整体风格：专业、科技感
- 主色调：国家电网绿 (#009B4D) + 科技蓝
- 字体：思源黑体（标题）、思源宋体（正文）
- 布局：简洁大气，每页不超过 5 个要点
- 图表：电网拓扑图采用标准电气符号"
```

**2. 指令生成**

使用 Manus 工具生成 PPT：
```
slide_initialize --template power_grid --theme professional
slide_edit --content final_outline.md --style tech_green
slide_generate --format pptx --output 电力调度三部曲.pptx
```

**3. 细节调整**

审阅后提出微调：
- 调整电网图的配色和线宽
- 优化负荷曲线的标注
- 统一专业术语的表达
- 添加动画效果（故障传播、潮流变化）

#### 视觉元素建议

| 页面类型 | 视觉元素 | 说明 |
|----------|----------|------|
| 封面页 | 电网航拍图 + 标题 | 体现专业感 |
| 目录页 | 三部曲时间轴 | 清晰展示结构 |
| 知识页 | 流程图/架构图 | 解释调度流程 |
| 案例页 | 电网拓扑 + 数据面板 | 展示故障场景 |
| 总结页 | 关键要点 + 思考题 | 强化学习效果 |

## 4. 电力调度专业内容的 AI 生成技巧

### 4.1 电网拓扑图生成

**提示词示例：**
```
"请生成一张 220kV 变电站的电气主接线图，包含：
- 2 台主变压器（220kV/110kV）
- 4 回 220kV 出线
- 8 回 110kV 出线
- 母线分段断路器
- 标注关键设备名称和参数

使用标准电气符号，颜色区分电压等级。"
```

### 4.2 负荷曲线生成

**提示词示例：**
```
"请生成某城市典型日的负荷曲线图：
- 横轴：24 小时（0-24 点）
- 纵轴：负荷（MW）
- 展示早高峰（8-10 点）、晚高峰（19-21 点）
- 叠加光伏发电曲线（8-18 点）
- 标注最大负荷和最小负荷

数据参考：最大负荷 5000MW，最小负荷 2000MW"
```

### 4.3 调度对话脚本生成

**提示词示例：**
```
"请生成一段调度员与电厂值长的对话脚本：
场景：晚高峰前，要求电厂增加出力
角色：省调调度员、电厂值长
内容：
- 调度员下达出力调整指令
- 电厂确认执行时间
- 双方复诵确认
- 记录调度日志

要求使用标准调度术语，体现规范化流程。"
```

### 4.4 故障案例生成

**提示词示例：**
```
"请生成一个 220kV 线路跳闸的故障案例：
- 故障时间：夏季午后 14:30
- 故障原因：雷击导致绝缘子闪络
- 保护动作：线路保护跳闸，重合闸失败
- 调度处置：启动应急预案，调整潮流分布
- 恢复时间：30 分钟后恢复供电
- 经验总结：加强雷雨季节设备巡视

包含故障前、中、后三个阶段的电网状态描述。"
```

将任务分解为清晰阶段：
```
阶段 1：请帮我梳理电力调度的核心知识点

```

## 6. 教学案例展示

### 6.1 第一部《清晨的调度室》课件结构

```
第 1 页：封面
  - 标题：电力调度三部曲（一）清晨的调度室
  - 副标题：负荷预测与发电计划
  - 背景：调度控制中心实景

第 2 页：学习目标
  - 理解负荷预测的基本方法
  - 掌握发电计划制定流程
  - 了解调度员交接班规范

第 3 页：调度员的一天
  - 时间轴展示 24 小时调度工作
  - 重点标注清晨 6 点交接班

第 4 页：负荷预测方法
  - 传统方法：时间序列、回归分析
  - AI 方法：神经网络、机器学习
  - 对比表格展示精度差异

第 5 页：发电计划制定
  - 流程图：预测→计划→协调→确认
  - 考虑因素：负荷、检修、备用、经济

第 6 页：案例：某日发电计划
  - 展示真实计划表
  - 标注关键决策点

第 7 页：课程思政
  - 电力人的责任：每一度电都是承诺
  - 讨论：如何平衡经济性与安全性

第 8 页：小结与思考
  - 3 个核心知识点
  - 2 个思考题
  - 1 个实践任务
```

### 6.2 第二部《午后的波动》课件结构

```
第 1 页：封面
  - 标题：电力调度三部曲（二）午后的波动
  - 副标题：实时调度与应急处理
  - 背景：警报闪烁的调度台

第 2 页：学习目标
  - 掌握故障监测与报警流程
  - 理解应急预案启动条件
  - 学会调度指令规范下达

第 3 页：电网故障类型
  - 线路跳闸、变压器故障、母线故障
  - 故障原因分类：雷击、设备老化、外力破坏

第 4 页：故障处理流程
  - 发现→汇报→判断→处置→恢复→总结
  - 时间要求：5 分钟内完成初步处置

第 5 页：案例：220kV 线路跳闸
  - 故障发生：14:28 雷击
  - 保护动作：14:28:03 跳闸
  - 调度处置：14:30 启动预案
  - 恢复供电：14:58 送电成功

第 6 页：互动环节
  - 场景：多条线路同时故障
  - 任务：学生分组制定处置方案
  - 评价：安全性、时效性、经济性

第 7 页：课程思政
  - 15 分钟决定一座城市的光明
  - 讨论：压力下的决策能力

第 8 页：小结与思考
  - 核心知识点回顾
  - 应急能力自评
  - 拓展阅读推荐
```

### 6.3 第三部《夜幕的守护》课件结构

```
第 1 页：封面
  - 标题：电力调度三部曲（三）夜幕的守护
  - 副标题：电网稳定与新能源消纳
  - 背景：城市夜景与电网叠加

第 2 页：学习目标
  - 理解晚高峰调度挑战
  - 掌握新能源波动调节方法
  - 认识电网稳定的重要性

第 3 页：晚高峰调度
  - 负荷特点：19:00-21:00 达到峰值
  - 挑战：负荷陡增、调节资源紧张
  - 策略：提前准备、多源协调

第 4 页：新能源并网挑战
  - 光伏发电：昼发夜停
  - 风力发电：随机波动
  - 对电网的影响：频率波动、调峰困难

第 5 页：智能调度技术
  - 储能系统：削峰填谷
  - 需求响应：引导用户错峰
  - 虚拟电厂：聚合分布式资源

第 6 页：案例：某省新能源消纳
  - 背景：光伏装机占比 30%
  - 问题：午间弃光严重
  - 方案：储能 + 需求响应 + 跨省互济
  - 效果：弃光率从 15% 降至 3%

第 7 页：课程思政
  - 万家灯火，由我们守护
  - 讨论：双碳目标下的电力人使命

第 8 页：课程总结
  - 三部曲知识图谱
  - 能力要求对照表
  - 职业发展建议
```
