## 三、教学过程

### 第一部分：导入新课（5 分钟）

**情境创设：**
> "同学们，想象一下，如果把你关在一个密闭的房间里，没有食物、没有水、没有空气流通，你能坚持多久？而一株植物，只要给它阳光、空气和水，它就能自己制造养分，茁壮成长。这是为什么呢？"

**复习提问：**
1. 什么是光合作用？
2. 光合作用的场所是什么？
3. 光合作用的原料和产物分别是什么？

**光合作用的反应式：**
```
        光能
二氧化碳 + 水  ————→  有机物（储存能量）+ 氧气
        叶绿体
```

---

### 第二部分：探究影响光合作用的因素（25 分钟）

#### 因素一：光照强度 ⭐

**实验探究：**
- 实验材料：相同的天竺葵植株
- 实验变量：光照强度（弱光、中等光、强光）
- 测量指标：单位时间内氧气的释放量

**实验结果曲线：**
```
光合作用速率
    ↑
    |        ╱────── 饱和点
    |      ╱
    |    ╱
    |  ╱
    |╱_______________→ 光照强度
   0  补偿点
```

**关键概念：**
- **光补偿点：** 光合作用速率 = 呼吸作用速率时的光照强度
- **光饱和点：** 光合作用速率达到最大值时的最小光照强度

**结论：**
1. 在一定范围内，光合作用速率随光照强度增强而加快
2. 达到光饱和点后，光照再增强，光合作用速率不再增加
3. 光照过强可能导致叶片灼伤，反而降低光合作用效率

**农业应用：**
- 合理密植，避免植株相互遮挡
- 温室栽培中适时补光
- 阴生植物和阳生植物的分类种植

---

#### 因素二：二氧化碳浓度 🌿

**实验探究：**
- 实验设计：密闭容器中种植植物，改变 CO₂浓度
- 测量指标：光合作用速率

**实验结果曲线：**
```
光合作用速率
    ↑
    |        ╱────── CO₂饱和点
    |      ╱
    |    ╱
    |  ╱
    |╱_______________→ CO₂浓度
   0  补偿点
```

**关键数据：**
- 大气中 CO₂浓度：约 0.04%（400 ppm）
- CO₂补偿点：约 0.005%
- CO₂饱和点：约 0.1%

**结论：**
1. CO₂是光合作用的原料之一
2. 在一定范围内，光合作用速率随 CO₂浓度升高而加快
3. 达到饱和点后，增加 CO₂浓度效果不明显

**农业应用：**
- 温室中施用"气肥"（CO₂发生器）
- 通风换气，保证 CO₂供应
- 有机肥分解可释放 CO₂

---

#### 因素三：温度 🌡️

**实验探究：**
- 实验设计：相同光照和 CO₂条件下，改变温度
- 测量指标：光合作用速率

**实验结果曲线：**
```
光合作用速率
    ↑
    |     /\
    |    /  \
    |   /    \
    |  /      \
    | /        \
    |/__________\___→ 温度
   0  10  25  35  45℃
```

**关键数据：**
- 最适温度：25-30℃（大多数植物）
- 最低温度：5-10℃
- 最高温度：35-40℃

**结论：**
1. 温度通过影响酶的活性来影响光合作用
2. 在最适温度下，光合作用速率最高
3. 温度过低或过高都会降低光合作用效率

**农业应用：**
- 温室控温（白天 25-30℃，夜间适当降低）
- 夏季遮阴降温
- 选择适宜季节种植

---

#### 因素四：水分 💧

**影响机制：**
1. 水是光合作用的原料
2. 水分影响气孔开闭，进而影响 CO₂吸收
3. 严重缺水会导致叶片萎蔫，减少受光面积

**结论：**
- 适度干旱会降低光合作用速率
- 水分过多会导致根部缺氧，也会影响光合作用

**农业应用：**
- 合理灌溉，保持土壤适度湿润
- 滴灌、喷灌等节水技术
- 抗旱品种的选择

---

#### 因素五：矿质营养 🧪

**主要元素：**
- **氮（N）：** 叶绿素、酶的组成成分
- **磷（P）：** ATP、NADPH 的组成成分
- **钾（K）：** 调节气孔开闭
- **镁（Mg）：** 叶绿素的核心元素

**农业应用：**
- 合理施肥，补充必需矿质元素
- 叶面喷肥，快速补充营养

---

### 第三部分：综合应用（10 分钟）

#### 案例分析：温室蔬菜高产技术

**问题：** 如何利用光合作用原理提高温室蔬菜产量？

**学生讨论后总结：**

| 措施 | 原理 |
|------|------|
| 延长光照时间 | 增加光合作用时间 |
| 适当增加 CO₂浓度 | 提供充足原料 |
| 控制适宜温度 | 保证酶的最佳活性 |
| 合理灌溉 | 保证水分供应 |
| 定期施肥 | 补充矿质营养 |
| 合理密植 | 充分利用光能 |

---

### 第四部分：课堂小结（3 分钟）

**知识框架：**
```
影响光合作用的因素
├── 光照强度 → 光补偿点、光饱和点
├── 二氧化碳浓度 → 原料供应
├── 温度 → 酶活性
├── 水分 → 原料 + 气孔调节
└── 矿质营养 → 叶绿素、酶的组成
```

**核心要点：**
1. 光合作用受多种环境因素共同影响
2. 各因素之间存在相互制约关系
3. 农业生产中要综合考虑，优化条件

---

### 第五部分：课堂练习（2 分钟）

**选择题：**

1. 下列哪项不是影响光合作用的环境因素？（  ）
   - A. 光照强度
   - B. 二氧化碳浓度
   - C. 土壤酸碱度
   - D. 温度
   
   **答案：C**

2. 在光饱和点之后，继续增加光照强度，光合作用速率会（  ）
   - A. 继续增加
   - B. 保持不变
   - C. 下降
   - D. 先增加后下降
   
   **答案：B**

**思考题：**
> 夏季中午，植物光合作用速率反而下降，可能的原因是什么？
> 
> **提示：** 从温度、水分、气孔开闭等角度分析
> 
> **参考答案：** 夏季中午温度过高，植物为减少水分散失，气孔关闭，导致 CO₂吸收减少，光合作用速率下降（"午休现象"）
