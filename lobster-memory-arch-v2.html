🧠 二、三级记忆架构详解

🔴 L1 — 工作记忆

SHORT-TERM
  • 📌 当前会话上下文（最近 N 轮对话）
  • 📌 用户即时提问与追问意图
  • 📌 百炼 RAG 检索到的知识片段
  • 📌 当前回答的中间推理链
  • ⏱ 生命周期：单次对话会话
  • 💾 存储：OpenClaw Session Context

🔵 L2 — 知识记忆

RETRIEVAL
  • 📌 信电学院课程知识
  • 📌 百炼知识库向量索引
  • 📌 行业术语表 & 知识图谱
  • 📌 FAQ 标准问答对
  • ⏱ 生命周期：持久化，定期更新
  • 💾 存储：百炼知识库 + 向量数据库

🟢 L3 — 长期记忆

LONG-TERM
  • 📌 用户学习画像（偏好/薄弱点）
  • 📌 高频问题 & 知识盲区统计
  • 📌 对话摘要 & 经验教训
  • 📌 系统提示词 & 行为规则
  • ⏱ 生命周期：永久，持续进化
  • 💾 存储：OpenClaw 文件系统

4.3 百炼 CLI 集成（新增）

# 百炼 CLI 安装与配置 # 参考：https://mp.weixin.qq.com/s/3_CBCcARtfipa0PPxOU93g # 1. 安装百炼 CLI pip install bailian-cli # 2. 配置 API Key bailian config set --api-key "sk-bailian-xxxxxxxx" # 3. 创建知识库 bailian kb create --name "信电学院课程知识库" --embedding-model "text-embedding-v3" # 4. 上传教材文档 bailian kb upload --kb-id "kb-xxxxxxxx" --file "教材01_基础理论.pdf" # 5. 语义检索 bailian kb search --kb-id "kb-xxxxxxxx" --query "电路分析基础" --top-k 5 # 6. AI Agent 接入（一行命令） bailian agent connect --kb-id "kb-xxxxxxxx" --model "qwen-max"

# Phase 1: 百炼知识库搭建（1-2天） # ───────────────────────────────── 1. 开通阿里云百炼服务 → 创建知识库实例 2. 上传 10+ 本教材 → 配置分块策略（800字/块） 3. 选择 Embedding 模型（text-embedding-v3） 4. 测试检索效果 → 调整 chunk_size / top_k 5. 配置重排序模型（gte-rerank）提升精度 # Phase 2: 百炼 CLI 集成（新增）（1天） # ───────────────────────────────── 6. 安装百炼 CLI：pip install bailian-cli 7. 配置 API Key：bailian config set --api-key "sk-xxx" 8. 创建知识库：bailian kb create --name "信电学院课程知识库" 9. 上传教材：bailian kb upload --kb-id "kb-xxx" --file "教材.pdf" 10. 测试检索：bailian kb search --kb-id "kb-xxx" --query "电路分析" # Phase 3: OpenClaw 集成（2-3天） # ───────────────────────────────── 11. 编写百炼 API 调用 Skill 12. 配置 L2 记忆路由（百炼 RAG 优先） 13. 编写 L3 长期记忆沉淀逻辑 14. 设计 Prompt 模板（课程知识问答专用） 15. 测试端到端问答流程 # Phase 4: 钉钉对接（1天） # ───────────────────────────────── 16. 创建钉钉机器人 → 配置 Webhook 17. 对接 OpenClaw 钉钉扩展 18. 群聊权限配置 → 邀请成员测试 19. 上线运行 → 收集反馈迭代 # Phase 5: 优化运营（持续） # ───────────────────────────────── 20. 分析高频问题 → 补充 FAQ 到知识库 21. 监控回答质量 → 调整检索参数 22. 用户画像分析 → 个性化推荐 23. 定期更新教材 → 增量入库
