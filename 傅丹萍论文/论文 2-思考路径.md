# 论文 2 思考路径

## 论文题目
分解•抽象•优化：中职 Python 教学中计算思维的培养策略——以冒泡排序为例

## 写作时间
2026 年 4 月 23 日

---

## 一、选题分析

### 1.1 为什么选这个题目？

**背景驱动：**
- 计算思维成为信息时代核心素养
- 中职 Python 教学"重语法轻思维"
- 仅 23% 学生能独立设计算法（调查数据）

**问题意识：**
- 如何在中职 Python 教学中培养计算思维？
- 冒泡排序作为经典算法有何教学价值？
- 如何设计有效的培养路径？

**价值定位：**
- 理论价值：丰富计算思维在职业教育中的培养理论
- 实践价值：为 Python 教师提供可操作的教学策略

### 1.2 目标读者

- 中职信息技术教师
- 职业教育研究者
- 师范院校师生
- 课程开发者

## 四、核心观点

### 4.1 主要论点

1. 中职 Python 教学存在"三重三轻"问题
2. 三阶段模型符合认知规律
3. 冒泡排序是培养计算思维的理想载体
4. 实验班计算思维成绩显著提升（p<0.01）

### 4.2 论据支撑

| 论点 | 论据 |
|------|------|
| 教学有问题 | 调查数据：23% 学生能设计算法 |
| 三阶段有效 | 理论支撑 + 实践验证 |
| 冒泡排序适合 | 逻辑清晰、易于理解、便于拓展 |
| 效果显著 | 实验班 vs 对照班对比 |
