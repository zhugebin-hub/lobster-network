## 使用说明

### 编辑 PPT

1. **使用 Microsoft PowerPoint**
   - 直接打开 `物联网技术导论.pptx`
   - 可编辑所有文字、调整布局、添加动画
   - 支持 PowerPoint 2007 及以上版本

2. **使用 WPS Office**
   - 完全兼容 PPTX 格式
   - 免费替代方案

3. **使用 LibreOffice Impress**
   - 开源免费
   - 支持 PPTX 格式导入导出

4. **使用 Google Slides**
   - 上传到 Google Drive
   - 在线编辑和协作

### 从 Markdown 重新生成

如需修改内容后重新生成 PPT：

```bash

# Ubuntu/Debian
sudo apt install pandoc

# macOS
brew install pandoc

# 转换命令
pandoc content.md -o 物联网技术导论.pptx
```

## 教学建议

### 课时分配
- **第一部分**：20 分钟 - 课程导入
- **第二部分**：40 分钟 - 发展历史
- **第三部分**：40 分钟 - 技术架构
- **第四部分**：50 分钟 - 关键技术
- **第五部分**：30 分钟 - 发展现状
- **第六部分**：40 分钟 - 应用领域
- **第七部分**：20 分钟 - 总结展望

总计约 4 学时（180 分钟），可根据实际情况调整。

### 教学方法
1. **理论讲解**：使用 PPT 展示核心概念
2. **案例分析**：结合智慧城市建设等实际案例
3. **演示实验**：展示 IoT 设备或平台操作
4. **课堂讨论**：针对思考题展开讨论
5. **课后实践**：布置 IoT 小项目

### 配套资源建议
- 实验指导书
- 开发板（ESP32、树莓派等）
- 云平台账号（阿里云 IoT、华为云 IoT）
- 在线课程链接
- 参考书籍清单
