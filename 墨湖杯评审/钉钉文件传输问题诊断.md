## 可能原因

### 原因 1: 钉钉机器人文件权限不足 ⭐⭐⭐
**问题**: 钉钉机器人需要额外配置才能接收文件  
**解决**: 
1. 登录钉钉开放平台
2. 进入应用管理 → 机器人配置
3. 开启"接收文件"权限
4. 保存并重新发布

### 原因 2: 文件大小超过限制 ⭐⭐
**问题**: 钉钉机器人有文件大小限制（通常 100MB）  
**解决**: 
- 压缩文件到 100MB 以内
- 或分卷压缩后分批发送

### 原因 3: OpenClaw 钉钉插件配置不完整 ⭐⭐
**问题**: 可能缺少文件接收配置  
**解决**:
```bash
# 检查钉钉插件配置
cat ~/.openclaw/extensions/dingtalk/config.json

# 添加文件接收配置（如需要）
{
  "receiveFiles": true,
  "maxFileSize": 104857600
}
```

### 原因 4: 存储路径权限问题 ⭐
**问题**: `/home/admin/.openclaw/media/inbound/` 写入权限不足  
**解决**:
```bash
chmod 755 /home/admin/.openclaw/media/inbound/
```

### 原因 5: 钉钉客户端发送方式问题 ⭐⭐
**问题**: 可能使用了错误的发送方式  
**正确方式**:
1. 在聊天窗口点击 📎 附件按钮
2. 选择"文件"（不是图片）
3. 选择 ZIP 文件
4. 发送
