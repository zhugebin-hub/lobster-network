## 🔧 解决方案

### 方案一：使用百度网盘客户端（推荐）

**步骤**:
1. 在服务器上安装百度网盘客户端
   ```bash
   # 下载并安装
   wget https://issuecdn.baidupcs.com/issue/netdisk/Linux/BaiduNetdisk_linux_3.0.0.tar.gz
   tar -xzf BaiduNetdisk_linux_3.0.0.tar.gz
   cd BaiduNetdisk_linux_3.0.0
   ./BaiduNetdisk
   ```

2. 登录账号
3. 下载文件到本地
4. 移动到工作目录

### 方案五：使用 aria2 下载（需要 cookies）

```bash
# 安装 aria2
sudo apt-get install aria2

# 从浏览器导出百度网盘 cookies
# 然后下载
aria2c \
  --header="User-Agent: netdisk;pan.baidu.com" \
  --header="Cookie: [你的 cookies]" \
  -o 理工论坛稿件整理.zip \
  "https://pan.baidu.com/s/1UYFDxy0zrGF6lTmBO5HB9A?pwd=6666"
```
