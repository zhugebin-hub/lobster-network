## 📐 宜搭组件清单

### 用车申请表单组件

| 字段 | 组件类型 | 配置说明 |
|------|---------|---------|
| 申请人 | 成员单选 | 默认值=当前用户，只读 |
| 申请部门 | 部门单选 | 默认值=当前用户部门，只读 |
| 申请时间 | 日期时间 | 默认值=当前时间，只读 |
| 用车时间 | 日期时间区间 | 必填，结束时间>开始时间 |
| 出发地点 | 单行文本 | 必填 |
| 目的地 | 单行文本 | 必填 |
| 用车事由 | 多行文本 | 必填，最多 500 字 |
| 乘车人数 | 数字 | 必填，1-99，默认 1 |
| 车型要求 | 单选 | 选项：不限/轿车/商务车/大巴 |
| 附件 | 上传 | 可选，最多 5 个文件 |

### 车辆信息表单组件

| 字段 | 组件类型 | 配置说明 |
|------|---------|---------|
| 车牌号 | 单行文本 | 必填，唯一 |
| 车型 | 单选 | 选项：轿车/商务车/大巴 |
| 座位数 | 数字 | 必填 |
| 颜色 | 单行文本 | 可选 |
| 车辆状态 | 单选 | 选项：可用/使用中/维修中 |
| 绑定司机 | 成员单选 | 可选 |
| 备注 | 多行文本 | 可选 |

### 订单管理表单组件

| 字段 | 组件类型 | 配置说明 |
|------|---------|---------|
| 订单编号 | 公式 | 系统自动生成：#YYYYMMDDNNN |
| 申请人信息 | 关联表单 | 关联用车申请 |
| 派车状态 | 单选 | 选项：待派车/已派车/已完成/已取消 |
| 指派车辆 | 关联表单 | 关联车辆信息 |
| 指派司机 | 成员单选 | 可选 |
| 实际里程 | 数字 | 司机填写 |
| 完成时间 | 日期时间 | 司机确认时自动记录 |
| 评价 | 评分 | 1-5 星，可选 |
