# 🚗 钉钉宜搭公务用车系统 - 快速搭建指南

> **预计耗时**：2-3 小时  
> **难度**：⭐⭐ 简单（拖拽式操作，无需编程）

---

## 📋 准备工作

### 1. 权限确认
```
✅ 需要钉钉管理员权限
✅ 或宜搭应用管理员权限
```

### 2. 登录宜搭
```
1. 打开钉钉 PC 客户端
2. 点击左侧【工作台】
3. 找到【宜搭】应用（如没有，联系管理员添加）
4. 点击进入宜搭后台
```

### 3. 创建应用
```
1. 点击【创建应用】→【从空白创建】
2. 应用名称：公务用车
3. 应用图标：🚗（选择一个车辆图标）
4. 应用分组：行政管理
5. 点击【确定】
```

## 🔄 第四步：配置审批流程（30 分钟）

### 4.1 创建流程
```
1. 点击【创建页面】
2. 选择【流程页面】
3. 页面名称：用车审批流程
4. 点击【确定】
```

### 4.2 设计流程
```
进入流程设计器，按以下顺序配置：

┌─────────────────────────────────────────────────────────────┐
│  开始 → 提交申请 → 车管员派车 → 司机接单 → 完成确认 → 结束  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 开始节点                                                │
│     触发方式：用户提交表单                                  │
│                                                             │
│  2. 提交申请节点（发起人）                                  │
│     操作人：所有人                                          │
│     可编辑字段：用车申请表单所有字段                        │
│     提交后：自动流转到下一节点                              │
│                                                             │
│  3. 车管员派车节点                                          │
│     操作人：指定成员 → 选择车管员                           │
│     可编辑字段：                                            │
│       - 派车状态（改为"已派车"）                            │
│       - 指派车辆                                            │
│       - 指派司机                                            │
│       - 备注                                                │
│     通知方式：钉钉消息通知                                  │
│     超时设置：可选（如 2 小时未处理，提醒）                   │
│                                                             │
│  4. 司机接单节点                                            │
│     操作人：指定成员 → 选择指派的司机                       │
│     可编辑字段：                                            │
│       - 实际里程                                            │
│       - 完成时间                                            │
│       - 派车状态（改为"已完成"）                            │
│     通知方式：钉钉消息通知                                  │
│                                                             │
│  5. 完成确认节点（申请人评价）                              │
│     操作人：发起人（申请人）                                │
│     可编辑字段：                                            │
│       - 评价                                                │
│     通知方式：钉钉消息通知                                  │
│                                                             │
│  6. 结束节点                                                │
│     数据归档                                                │
│     发送完成通知给相关人员                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 配置消息通知
```
在流程设计器中，点击【消息通知】配置：

1. 提交申请时：
   - 通知对象：车管员
   - 通知内容：
     "新用车申请：{申请人} - {用车时间} - {出发地点}→{目的地}"

2. 派车时：
   - 通知对象：申请人、司机
   - 通知内容：
     "已派车：车辆{车牌号}，司机{司机姓名}，请准时到达"

3. 完成时：
   - 通知对象：申请人、车管员
   - 通知内容：
     "行程已完成，请评价"
```

### 4.4 保存并发布流程
```
1. 点击右上角【保存】
2. 点击【发布】
3. 选择发布范围：全员可见
4. 点击【确定】
```

## 📱 第六步：配置钉钉工作台入口（15 分钟）

```

2. 点击【工作台】→【应用管理】
3. 点击【添加应用】→【宜搭应用】
4. 选择"公务用车"应用
5. 配置可见范围：全员可见
6. 配置应用入口：
   - 应用名称：公务用车
   - 应用图标：🚗
   - 应用分组：行政管理
```

### 6.2 配置菜单导航
```
1. 进入宜搭应用后台
2. 点击【页面管理】
3. 配置导航菜单：
   
   一级菜单：
   - 我要用车（链接到：用车申请）
   - 我的订单（链接到：订单调度，筛选：我的申请）
   - 车辆信息（链接到：车辆管理）
   - 用车统计（链接到：用车统计）
   
   管理员菜单（仅车管员可见）：
   - 订单调度
   - 车辆管理
   - 用车统计
```

### 6.3 配置权限
```
1. 点击【权限管理】
2. 创建角色：
   
   角色 1：普通员工
   - 可见页面：用车申请、我的订单、车辆信息
   - 可操作：提交申请、查看自己的订单、评价
   
   角色 2：车管员
   - 可见页面：全部页面
   - 可操作：派车、管理车辆、查看统计
   
   角色 3：司机
   - 可见页面：我的订单（指派给自己的）
   - 可操作：确认出车、填写里程、确认完成

3. 分配角色：
   - 车管员：指定具体人员
   - 司机：指定具体人员
   - 普通员工：全员
```
