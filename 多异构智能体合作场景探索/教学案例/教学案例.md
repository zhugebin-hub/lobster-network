## 一、案例背景

### 1.1 实验目的

本实验旨在探索多异构智能体（Multi-Heterogeneous Agent, MHA）在复杂任务中的协作模式。通过构建一个包含多个小龙虾·虾尔智能体和钉钉 AI 助理的钉钉群，让不同角色定位的智能体针对特定场景共同完成一个复杂任务，观察和分析智能体之间的协作机制、任务分配、信息流转和问题解决过程。

### 1.2 实验场景

**任务：** 浙江工商大学外语学院"数字人文与跨文化传播"学术研讨会策划  
**时间要求：** 两周内完成所有准备工作  
**会议规模：** 线下 80-100 人，线上 200+ 人  
**会议形式：** 线上线下混合模式  
**预算：** 约 3 万元

### 1.3 智能体角色设计

| 智能体 | 角色定位 | 核心能力 | 性格特征 |
|--------|---------|---------|---------|
| 🦞 虾尔 | 项目管理 | 统筹规划、任务分解、进度跟踪 | 组织能力强、注重细节 |
| 📚 文心 | 内容策划 | 议程设计、嘉宾邀请、学术资源 | 学术素养高、善于沟通 |
| 🔧 小钉 | 技术支持 | 技术方案、设备配置、风险预案 | 技术思维、务实严谨 |
| 🎨 画灵 | 视觉设计 | 平面设计、品牌视觉、物料制作 | 创意丰富、审美敏锐 |

## 二、对话记录（按模块）

### 模块 1：任务启动与分工（14:00-14:02）

**过程描述：** 虾尔作为项目管理智能体，首先接收任务并分配角色。各智能体确认职责后，立即提出各自需要的信息。

**关键对话：**
- 虾尔明确分配四个角色，建立协作框架
- 文心提出议程设计的初步框架（三大板块）
- 小钉列出技术参数确认清单（混合模式、同传、字幕等）
- 画灵列出设计所需的基础信息（关键词、VI 规范、物料清单）

**教学分析：**

| 维度 | 分析 |
|------|------|
| AI 能力展示 | 各智能体展现了角色专业化能力，能快速理解任务并提出结构化问题 |
| 提问技巧 | 用户通过明确任务背景（规模、预算、时间），让智能体能精准提问 |
| 输出质量 | 各智能体的首轮回复都展现了领域专业性，信息密度高 |
| 教学价值 | 展示了"角色分工 → 信息确认"的协作启动模式 |

### 模块 2：需求确认与方案细化（14:05-14:12）

**过程描述：** 虾尔汇总宝怡老师的需求后，各智能体输出详细方案。

**关键产出：**
- 文心：完整议程表（含时间轴、环节设计、嘉宾安排）
- 小钉：技术方案（钉钉会议+直播+录播方案、设备清单、风险评估）
- 画灵：物料清单（7 类物料、设计风格建议）

**教学分析：**

| 维度 | 分析 |
|------|------|
| AI 能力展示 | 各智能体在各自领域输出了可直接执行的方案，展现了深度专业能力 |
| 提问技巧 | 用户提供了具体约束条件（人数、预算、时间），使方案更具可操作性 |
| 输出质量 | 方案结构清晰、表格化呈现、包含风险评估，可直接用于执行 |
| 教学价值 | 展示了"约束条件驱动 → 专业方案输出"的协作深化模式 |

### 模块 3：方案整合与优化（14:15-14:22）

**过程描述：** 虾尔整合各方案，制定项目时间表和预算分配。各智能体确认时间节点并提出执行层面的具体问题。

**关键产出：**
- 虾尔：项目时间表（8 个里程碑）、预算分配表
- 文心：嘉宾邀请进度、分论坛主持人建议
- 小钉：技术确认清单（投影仪规格、摄像设备、直播权限）
- 画灵：设计素材需求（LOGO 矢量文件、VI 规范、横幅尺寸）

**教学分析：**

| 维度 | 分析 |
|------|------|
| AI 能力展示 | 虾尔展现了跨领域整合能力，能将不同专业方案整合为统一执行计划 |
| 提问技巧 | 各智能体从"方案设计"转向"执行确认"，提问更加具体和可操作 |
| 输出质量 | 时间表和预算表可直接用于项目管理，体现了 AI 的实用价值 |
| 教学价值 | 展示了"方案整合 → 执行细化"的协作落地模式 |

### 模块 4：风险预案与收尾（14:25-14:26）

**过程描述：** 虾尔总结风险预案和沟通机制，各智能体确认并表达协作意愿。

**关键产出：**
- 虾尔：5 项风险清单 + 应对策略、沟通机制（日报+协调会）
- 各智能体：确认方案，表达协作意愿

**教学分析：**

| 维度 | 分析 |
|------|------|
| AI 能力展示 | 展现了风险识别和预案制定能力，体现了项目管理的完整性 |
| 提问技巧 | 用户无需额外干预，智能体自主完成收尾 |
| 输出质量 | 风险预案全面，沟通机制清晰 |
| 教学价值 | 展示了"风险识别 → 机制建立"的协作闭环模式 |

## 三、关键技巧提炼

### 3.1 提问技巧

1. **明确任务背景** — 提供具体约束条件（规模、预算、时间），使智能体输出更具针对性
2. **角色定义清晰** — 为每个智能体设定明确的角色定位和能力边界
3. **结构化输出要求** — 要求表格化呈现，便于整合和比较

### 3.2 追问分析

1. **从宏观到微观** — 先确认整体框架，再细化执行细节
2. **跨智能体协调** — 通过项目管理智能体（虾尔）整合各方案，避免信息碎片化
3. **风险前置** — 在方案阶段就识别风险并制定预案

### 3.3 验证方法

1. **方案可行性验证** — 检查技术方案是否匹配实际需求
2. **时间线合理性验证** — 确认各里程碑时间节点是否合理
3. **预算合理性验证** — 对比市场价格，确认预算分配是否合理

## 五、反思与讨论

### 5.1 使用心得

1. **角色专业化是关键** — 每个智能体有明确的角色定位，避免了"万金油"式的泛泛回答
2. **项目管理智能体的价值** — 虾尔作为协调者，有效整合了各智能体的输出，避免了信息碎片化
3. **结构化输出提升效率** — 表格化呈现使方案更清晰，便于比较和决策
4. **风险预案体现成熟度** — 智能体能主动识别风险并制定预案，展现了项目管理的完整性

### 5.2 学生讨论题

1. **角色设计：** 如果让你重新设计智能体角色，你会增加或删减哪些角色？为什么？
2. **协作模式：** 多智能体协作与单智能体多次对话相比，优势在哪里？劣势在哪里？
3. **质量控制：** 如何确保多个智能体输出的一致性和准确性？
4. **应用场景：** 除了学术研讨会策划，多智能体协作还适合哪些场景？
5. **伦理思考：** 多智能体协作中，人类的角色是什么？如何平衡 AI 自主性和人类控制？
