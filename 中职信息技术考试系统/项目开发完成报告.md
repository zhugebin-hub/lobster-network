## 使用说明

### 快速启动

```bash
# 方法 1: 命令行运行
cd 中职信息技术考试系统
python main.py

# 方法 2: 打包后运行
双击 "打包.bat" 生成 EXE
运行 "dist/中职信息技术考试系统.exe"
```

## 技术特点

1. **零依赖运行**: 基础功能无需安装任何第三方库
2. **跨版本兼容**: 支持 Python 3.6+
3. **数据持久化**: JSON + CSV 存储，易于备份和迁移
4. **模块化设计**: 各功能模块独立，便于维护
5. **友好界面**: 中文界面，操作简单直观
