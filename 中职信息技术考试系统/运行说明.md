# 中职信息技术考试系统 - 运行说明

## 系统简介

本系统是一个面向中职学校的信息技术理论题考试系统，支持单机运行，无需网络环境。

### 功能特点

- ✅ 学生登录（姓名、班级、身份证号、密码验证）
- ✅ 在线考试（单选 30 题、多选 10 题、判断 10 题）
- ✅ 自动计时（60 分钟）
- ✅ 自动评分（交卷后立即显示成绩）
- ✅ 成绩管理（CSV/Excel 导出）
- ✅ 题库管理（JSON 格式，可增删改查）

---

## 环境要求

### 最低配置

- **操作系统**: Windows 7/8/10/11
- **Python 版本**: Python 3.6 或更高版本
- **内存**: 512MB 以上
- **硬盘空间**: 100MB 以上

### 检查 Python 版本

打开命令提示符（CMD），输入：

```bash
python --version
```

或

```bash
python3 --version
```

## 快速开始

### 方法一：直接运行（推荐）

1. 打开命令提示符（CMD）
2. 进入系统目录：
   ```bash
   cd 中职信息技术考试系统
   ```
3. 运行程序：
   ```bash
   python main.py
   ```

### 方法二：双击运行（需先配置）

1. 确保 `.py` 文件已关联 Python
2. 双击 `main.py` 即可运行

## 使用说明

### 学生考试流程

1. **登录系统**
   - 输入姓名、班级、身份证号
   - 密码默认为身份证末 6 位
   - 点击"登录考试"

2. **开始答题**
   - 单选题：30 题，每题 2 分，共 60 分
   - 多选题：10 题，每题 3 分，共 30 分
   - 判断题：10 题，每题 2 分，共 20 分
   - 总分：100 分

3. **交卷**
   - 点击"交卷"按钮
   - 确认后系统自动评分
   - 显示成绩（含各题型得分）

### 管理员功能

1. **进入管理界面**
   - 在主界面点击"管理员入口"
   - 输入管理员密码（默认：`admin123`）

2. **题库管理**
   - 添加题目：选择题型，填写题目信息
   - 编辑题目：双击题目或选中后点击"编辑"
   - 删除题目：选中后点击"删除"
   - 保存题库：修改后记得点击"保存"

3. **成绩查询**
   - 在主界面点击"成绩查询"
   - 可按身份证号查询或直接查看全部
   - 支持导出 CSV 格式

## 题库格式说明

题库采用 JSON 格式存储，文件名为 `questions.json`。

### 单选题格式

```json
{
  "id": 1,
  "question": "计算机中用来表示信息的最小单位是？",
  "options": ["A. 字节", "B. 位", "C. 字", "D. 双字"],
  "answer": "B",
  "category": "计算机基础"
}
```

### 多选题格式

```json
{
  "id": 31,
  "question": "下列属于计算机硬件的是？（多选）",
  "options": ["A. CPU", "B. 内存", "C. Windows", "D. 硬盘"],
  "answer": "ABD",
  "category": "计算机基础"
}
```

### 判断题格式

```json
{
  "id": 41,
  "question": "计算机只能处理数字信息。",
  "options": ["正确", "错误"],
  "answer": "错误",
  "category": "计算机基础"
}
```

## 常见问题

### Q1: 提示"找不到 Python"

**解决方法**：
1. 访问 https://www.python.org/downloads/
2. 下载并安装 Python 3.8 或更高版本
3. 安装时勾选"Add Python to PATH"

### Q2: 密码错误

**说明**：默认密码为身份证末 6 位
- 如身份证号：330101200801011234
- 默认密码：011234

### Q3: 无法导出 Excel

**解决方法**：
1. 安装依赖：
   ```bash
   pip install pandas openpyxl
   ```
2. 或使用 CSV 格式导出（无需额外依赖）

### Q4: 修改管理员密码

**方法**：
1. 打开 `admin.py` 文件
2. 搜索 `admin123`
3. 修改为新的密码
4. 保存文件
