# 诸葛斌老师与"小龙虾"AI 数字员工：教学创新案例

## 一、案例背景

### 1.1 时代背景

2025-2026 年，人工智能技术迎来爆发式发展，特别是以大语言模型为核心的 AI Agent 技术，正在深刻改变教育、产业和社会的方方面面。国家持续推进"人工智能+"行动计划，教育部也明确提出要深化教育数字化转型。

### 1.2 教育挑战

- **技术门槛高**：传统 AI 开发需要编程基础，普通师生难以快速上手
- **教学场景单一**：AI 工具在教学中的应用多停留在表面，缺乏深度整合
- **人才培养滞后**：传统计算机教育模式难以适应 AI Agent 时代的需求
- **产学研脱节**：高校教学与企业实际需求存在差距

### 1.3 诸葛斌教授的探索

诸葛斌，浙江工商大学信息与电子工程学院（萨塞克斯人工智能学院）教授，研究方向为互联网应用开发，获浙江省技术发明一等奖。近年来，他积极探索 AI 技术在教育领域的创新应用，特别是基于 OpenClaw（小龙虾）AI 数字员工的教学实践。

## 二、核心理念

### 2.1 "意图即应用"

诸葛斌教授提出 **"意图即应用"** 的核心理念：

> 未来的开发不再局限于逐行编写代码，而是通过自然语言提示词"调教"和"约束"大模型，使其成为能自主调用工具与 API 完成任务的超级智能体。

这一理念将开发模式从"为计算机服务"转向"让计算机为人服务"，有望让开发者规模跃迁至亿级。

### 2.2 "AI+ 教育"深度融合

- **从工具到伙伴**：AI 不仅是辅助工具，更是教学伙伴
- **从知识到能力**：培养 AI 编排与管理能力，而非单纯的知识记忆
- **从个体到协同**：人机协同成为新的工作模式

### 2.3 "龙虾生态"理论

诸葛斌团队构建了完整的 AI 生态理论：

| 元素 | 比喻 | 含义 |
|------|------|------|
| 龙虾（AI Agent） | 数字员工 | 能自主完成任务的智能体 |
| 池水（数据流/协议） | 基础设施 | 数据流转和通信协议 |
| 食物（算力/能源） | 资源 | 计算能力和能源供应 |
| 生态位（社会化分工） | 组织结构 | AI 与人类的协作关系 |

## 三、教学实践

### 3.1 课程体系

#### 3.1.1 研究生课程：《数字人文：AI 情感分析与文化生成》

- **教材**：袁非牛等著《数字人文：AI 情感分析与文化生成》
- **内容**：AI 情感分析技术、文化生成应用、数字人文实践
- **特色**：理论与实践结合，项目驱动学习

#### 3.1.2 研究生课程：《DeepSeek 操作实战》

- **内容**：DeepSeek 智能平台实战应用、跨平台协同方法
- **特色**：零基础入门，5 分钟完成基础部署
- **成果**：学生能够搭建自动化办公系统

#### 3.1.3 本科生课程：《钉钉低代码开发》

- **教材**：《钉钉低代码开发零基础入门》（国内首本宜搭低代码开发教材）
- **认证**：钉钉宜搭低代码开发师认证考核指定参考书
- **支持**：教育部--阿里云产学合作协同育人项目

### 3.2 教学方法

#### 3.2.1 实战演示法

在阿里百炼平台上进行"期末考试智能体"的实战演示：

1. **配置基础参数**：名称、模型、提示词
2. **导入知识库**：C 语言期末题库
3. **绑定知识库**：构建智能体知识体系
4. **测试应用**：出题、批改、统计全流程

**效果**：智能体可根据教学大纲和知识点权重精准生成符合要求的试卷，大幅提升教学管理效率。

#### 3.2.2 项目驱动法

- **学生科技活动**：围绕宜搭展开学生科技活动
- **联合钉钉**：编写国内首本宜搭低代码开发教材
- **开源贡献**：鼓励学生在开源社区贡献技能包

#### 3.2.3 产学研结合

- **企业合作**：与阿里云、钉钉等企业合作
- **实践基地**：建立 AI 应用实践基地
- **就业导向**：培养企业需要的 AI 应用人才

### 3.3 教学成果

#### 3.3.1 学生获奖

- **首届阿里小龙虾大会"黑客松勇士"**：指导学生团队获得荣誉
- **低代码开发认证**：多名学生通过钉钉宜搭低代码开发师认证

#### 3.3.2 教材出版

- 《钉钉低代码开发零基础入门》：国内首本宜搭低代码开发教材
- 《数字人文：AI 情感分析与文化生成》：数字人文领域重要教材

#### 3.3.3 项目立项

- **教育部--阿里云产学合作协同育人项目**：获得项目支持
- **浙江省技术发明一等奖**：研究成果获得省级奖励

## 四、"小龙虾"AI 数字员工在教学中的应用

### 4.1 技术架构

OpenClaw（小龙虾）采用 **Manager-Worker 架构**：

- **Manager**：接收任务、把控进度
- **AI Gateway**：管理密钥，保障数据安全
- **Worker**：不同类型 Worker 各司其职

### 4.2 核心优势

| 特性 | 说明 |
|------|------|
| 逻辑动态生成 | 根据任务需求动态生成执行逻辑 |
| 记忆持续增强 | 通过对话历史持续优化响应质量 |
| 边界模糊化 | 支持多模态交互，打破传统应用边界 |
| 预设技能 | 内置多种技能，开箱即用 |
| 永久记忆 | 支持长期记忆，保持上下文连贯性 |
| 7×24 小时响应 | 全天候不间断服务 |

### 4.3 应用场景

#### 4.3.1 教学辅助

- **智能出题**：根据教学大纲自动生成试卷
- **作业批改**：自动批改作业，提供详细反馈
- **成绩分析**：自动提取关键指标，生成可视化图表

#### 4.3.2 办公自动化

- **会议室预约**：自动化会议室管理
- **文档撰写**：自动生成会议记录、报告等
- **数据查询**：快速查询和处理数据

#### 4.3.3 创新实践

- **数字员工定制**：根据需求定制情绪状态和功能
- **技能包开发**：开发定制化技能包
- **生态建设**：构建 AI 应用生态

### 4.4 部署方案

#### 4.4.1 基础部署（5 分钟）

1. 创建机器人
2. 连接平台
3. 配置参数
4. 测试运行

#### 4.4.2 进阶配置

1. 导入知识库
2. 配置技能
3. 设置权限
4. 优化提示词

#### 4.4.3 生产环境

1. 多节点部署
2. 负载均衡
3. 监控告警
4. 持续优化
