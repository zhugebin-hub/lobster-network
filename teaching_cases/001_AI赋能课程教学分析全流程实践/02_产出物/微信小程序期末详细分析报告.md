### 1.1 🥇 冠军作品：校智匣 —— 功能集成+智能服务的校园生活管理系统

**团队：** 没有名字队（宁浩、潘叶翔、张琪、岳丹）
**评分：95/100**

#### 作品概述

"校智匣"是一款集二手市场、校园圈子、兼职招聘、跑腿代办四大板块于一体的校园生活管理小程序，其最大亮点是搭载了AI智能体"小智"，实现了从内容发布到社区运营的全流程自动化。

#### 核心技术亮点

**（1）AI智能体"小智"—— 三层能力架构**

智能体"小智"是该作品最突出的创新点，具备三层核心能力：

| 能力层级 | 功能描述 | 技术实现 |
|----------|----------|----------|
| 知识库查询 | 支持高校官方新闻网、校内资料、社交媒体内容及系统数据的多源知识问答 | EasySpider爬虫 + MediaCrawler社交媒体采集 + RAG检索增强生成 |
| 工作流调用 | 意图识别、信息补全、数据标准化与接口调用的全流程自动化 | Coze平台工作流引擎 + LLM语义解析 |
| 大模型调用 | 自动发帖、自主评论、热点分析等无人化运营能力 | 大语言模型 + 社交媒体爬虫API |

**（2）三大工作流引擎**

- **Workflow_Main_Publisher（意图识别与分类工作流）**：依托LLM语义解析能力，将用户自然语言输入精准分类为二手商品/校园圈子/兼职招聘/跑腿代办四大类别，以标准JSON格式输出并路由至对应子工作流。

- **Workflow_Auto_Comment（自主评论工作流）**：每24小时巡查校园圈子评论，通过LLM筛选符合规则的评论，从社交媒体数据库检索历史案例进行润色，自动生成回复并发布。

- **Workflow_HotTopic_Posts（自主发帖工作流）**：每月定期读取系统数据，通过RAG处理提炼核心热点，驱动社交媒体爬虫（覆盖小红书、抖音、B站、微博、贴吧、知乎六大平台）定向采集内容，经LLM清洗整合后自动生成并发布优质帖子。

**（3）知识库系统—— 四大数据来源**

| 数据来源 | 采集方式 | 用途 |
|----------|----------|------|
| 高校官方新闻网 | EasySpider开源爬虫（二次开发为增量爬取模式+API封装） | 智能问答的官方信息支撑 |
| 社交媒体话题帖子及评论 | MediaCrawler开源项目（二次开发适配小程序帖子属性） | 校园圈子内容供给+自主评论信息支撑 |
| 校内人员上传资料 | 管理系统专属上传入口（格式校验+标签分类） | 智能问答的本土化信息支撑 |
| 校智匣系统数据库 | 数据表API接口调用+结构化处理 | 小程序业务信息查询 |

**（4）知识库参数调优**

团队对Coze平台知识库调用参数进行了系统测试，发现"最大召回数量"对回答效果影响最显著：
- 取值1-5：回答精简，精准响应核心问题
- 取值6-7：回答适度扩展，补充信息合理
- 取值8-10：回答扩展显著，包含大量关联信息

最终将最大召回数量设定为**6**，在准确性基础上兼顾内容丰富度。

#### 产品架构

```
校智匣
├── 二手市场板块（智能体自动发布/评论/管理）
├── 校园圈子板块（UGC+AI自动运营）
├── 兼职招聘板块（智能匹配+自动化发布）
├── 跑腿代办板块（任务发布+智能调度）
├── 管理端（用户管理/内容审核/数据分析）
└── AI智能体"小智"

    ├── 自动化内容发布（四大板块工作流）
    ├── 自主评论运营（24h定时巡查）
    └── 月度热点分析（六平台数据采集+LLM生成）
```

### 1.2 🥈 亚军作品：青禾记账 —— 高保真微信记账小程序

**团队：** 疯狂星期（4）（茆希妍、王殷瑜、肖智恒、孙琳曦）
**评分：93/100**

#### 作品概述

一款以"高保真、高颜值、强实用"为定位的微信记账小程序，通过精美的UI/UX设计、智能统计与预算管理功能，帮助用户清晰掌握个人财务状况。

#### 核心技术亮点

**（1）UI/UX设计理念**

| 设计维度 | 具体实现 |
|----------|----------|
| 卡片化设计 | 圆角卡片布局，增强视觉层次，信息聚焦更清晰 |
| 色彩心理学 | 翡翠绿主色调（象征财富增长），资产正→绿渐变/负→红渐变，预算绿/橙/红三级预警 |
| 数据可视化 | 接入ECharts图表库，呈现收支趋势、支出构成 |
| 极简交互 | 中心化金额输入（自动适配大小）、网格化分类选择、胶囊型切换器 |

**（2）核心功能模块**

- **首页仪表盘**：智能总资产卡片（实时展示正负资产）、月度收支概览、动态预算管理（三色进度条）、最近记录列表
- **极简记账流程**：3秒完成记账——胶囊型收支切换→居中金额输入→网格化分类选择→日期+备注→一键保存
- **多维度财务分析**：月度/年度自由切换、支出构成饼图、年度收支趋势柱状图、支出排行、分类详情跳转

**（3）技术实现**

- 前端：微信小程序原生（WXML + WXSS + JavaScript）
- 后端：微信云开发 Cloud DB（免服务器、数据同步）
- 可视化：ECharts图表库（专业图表渲染）

#### 制作难点分析

团队在PPT中详细分析了制作过程中的难点，体现了深度思考：

| 难点类型 | 具体问题 |
|----------|----------|
| 用户体验与交互 | 记账流程追求极简但容错性要求高；空账单、加载中、无网络等异常状态设计易被忽略 |
| 功能逻辑设计 | 分类图标、账单修改/删除、预算提醒的联动逻辑复杂；不同用户记账习惯差异大 |
| 技术适配 | 微信小程序不同机型/版本兼容性差，图表渲染/页面适配易出问题；云开发数据库查询效率有限 |
| 合规与安全 | 用户消费隐私数据加密要求高；微信小程序隐私合规严格 |

#### 评价

**优势：**
- UI设计精致，色彩心理学应用到位
- 制作难点分析体现了工程思维
- 预算管理功能（三色预警）实用性强
- 团队分工明确，开发流程规范

**可改进：**

```
buildMessages → 格式转换（动态适配不同服务商入参）
    ↓
sendChat → 统一分发（根据kind字段路由）
    ↓
标准化响应解析 → 统一返回 {content, error}
```

**（3）核心设计创新：会话级AI快照**

> "如果所有聊天都用同一个AI，一旦你换了个AI模型，之前的聊天上下文和风格就乱了。"

解决方案：每个会话保存一份完整、不可变的AI配置快照（conv.ai），修改全局默认设置不影响历史会话。

**（4）数据模型设计**

```javascript
// 单Key存储，状态合一
{
  presetId: "openai",        // 全局默认AI
  darkMode: false,           // 全局UI
  activeConvId: "conv_123",  // 当前会话
  conversations: [
    {
      id: "conv_123",
      title: "新对话",
      ai: { ... },          // 会话级AI快照
      messages: [ ... ]     // 对话历史
    }
  ]
}
```

#### 评价

**优势：**
- 技术架构精巧，协议适配层设计优秀
- "隐私优先"理念先进
- 数据归一化（normalize）机制保障健壮性
- 合规意识强（明确告知API密钥存储风险）

## 五、📈 课程总结与教学评估

### 5.1 教学成效

**✅ 显著成效：**

5. **优秀作品已达可上线水平**：校智匣、青禾记账、校园记账小程序等作品具备直接上线的条件

**⚠️ 待改进之处：**

1. **技术深度不均**：部分作品（如智慧停车、单位转换助手）技术实现过于简单
2. **两个团队未提交作品**：我没招了对对队（4人）和吴彦组（5人）共9人未提交PPT
3. **基础知识薄弱**：多名学生反映JS/SQL/PHP等基础知识不足
4. **AI依赖风险**：部分学生可能过度依赖AI生成代码，对底层原理理解不足

### 5.2 课程特色总结

本课程作为浙江工商大学通识课，最大的特色是**"AI赋能+实战驱动"**：

1. **不教语法教产品**：课程重心不在逐行敲代码，而是"需求拆解→AI生成→人工优化"的产品开发流程
2. **工具链丰富**：涵盖微信开发者工具、DeepSeek、Manus、百炼平台、IMA知识库、云开发等
3. **场景贴近学生**：大部分作品聚焦校园生活场景，学生天然理解用户需求
4. **通识课定位准确**：不追求培养专业程序员，而是培养"会用工具、会想产品、会做判断"的数字化时代学习者
