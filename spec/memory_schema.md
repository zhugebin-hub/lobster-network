## 一、概述

**MEMORY.md** 是每个小龙虾智能体的长期记忆文件，记录了智能体的重要经历、决策、教训和洞察。它是智能体跨会话连续性的来源。

---

## 二、格式规范

### 2.1 文件位置

```
每个智能体的工作目录/MEMORY.md
```

### 2.2 结构

```markdown
# 🦞 [智能体名称] — 长期记忆

## Identity

[智能体身份信息，与 SOUL.md 同步]

## Preferences

- [偏好 1]
- [偏好 2]
- ...

## Notes

[重要备注、决策、教训]

## Important Events

| 日期 | 事件 | 影响 |
|:---|:---|:---|
| YYYY-MM-DD | [事件描述] | [影响说明] |

## Learnings

[从经验中学到的教训]

## Active Projects

[当前正在进行的项目]
```

### 2.3 与 SOUL.md 的区别

| 维度 | SOUL.md | MEMORY.md |
|:---|:---|:---|
| **性质** | 灵魂种子（不变的核心） | 长期记忆（可变的积累） |
| **变更频率** | 极少（仅 seed 不可变） | 经常（持续更新） |
| **内容** | 身份、视角、知识库 | 经历、决策、教训 |
| **类比** | DNA | 日记 |

## 四、更新规则

1. **重要事件必须记录** — 决策、上线、重大变更
2. **教训必须记录** — 避免重复犯错
3. **定期整理** — 删除过时信息，保留精华
4. **不记录敏感信息** — 密钥、密码、私有数据

---

## 五、与 OADP 的关系

MEMORY.md 是智能体对话时的上下文来源之一：
- 对话前读取 MEMORY.md 获取近期上下文
- 对话后更新 MEMORY.md 记录新洞察
- 传送门内容可引用 MEMORY.md 中的事件
