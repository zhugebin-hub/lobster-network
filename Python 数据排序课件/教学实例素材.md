## 实例一：成绩排名

### 场景描述
班主任需要对班级学生的考试成绩进行排名，生成成绩单。

### 数据
```python
scores = [
    {'name': '张三', 'score': 85},
    {'name': '李四', 'score': 92},
    {'name': '王五', 'score': 78},
    {'name': '赵六', 'score': 95},
    {'name': '钱七', 'score': 88},
    {'name': '孙八', 'score': 72},
    {'name': '周九', 'score': 90},
    {'name': '吴十', 'score': 85}
]
```

### 任务要求
1. 按成绩降序排序
2. 成绩相同时按姓名升序
3. 输出排名、姓名、成绩
4. 标注及格/不及格（60 分及格）

### 参考代码
```python
# 排序
scores.sort(key=lambda x: (-x['score'], x['name']))

# 输出
for i, student in enumerate(scores, 1):
    status = '及格' if student['score'] >= 60 else '不及格'
    print(f"第{i}名：{student['name']} {student['score']}分 ({status})")
```

## 实例二：商品价格排序

### 场景描述
电商平台需要展示商品列表，支持按价格升序/降序排列。

### 数据
```python
products = [
    {'name': 'iPhone 15', 'price': 6999, 'category': '手机'},
    {'name': 'AirPods', 'price': 1299, 'category': '耳机'},
    {'name': 'MacBook', 'price': 9999, 'category': '电脑'},
    {'name': '鼠标', 'price': 89, 'category': '配件'},
    {'name': '键盘', 'price': 199, 'category': '配件'},
    {'name': 'iPad', 'price': 3999, 'category': '平板'},
    {'name': '充电器', 'price': 149, 'category': '配件'}
]
```

### 任务要求
1. 按价格从低到高排序
2. 按价格从高到低排序
3. 按类别分组后按价格排序
4. 输出格式化商品列表

### 参考代码
```python
# 价格从低到高
cheap = sorted(products, key=lambda x: x['price'])

# 价格从高到低
expensive = sorted(products, key=lambda x: x['price'], reverse=True)

# 输出
print("价格从低到高：")
for p in cheap:
    print(f"{p['name']}: ¥{p['price']}")
```

## 实例三：时间排序

### 场景描述
学校需要安排活动日程，按时间先后排序。

### 数据
```python
events = [
    {'name': '开学典礼', 'time': '2026-09-01 08:00'},
    {'name': '期中考试', 'time': '2026-11-15 09:00'},
    {'name': '运动会', 'time': '2026-10-20 08:30'},
    {'name': '期末考试', 'time': '2027-01-10 09:00'},
    {'name': '元旦晚会', 'time': '2026-12-31 19:00'},
    {'name': '家长会', 'time': '2026-11-20 14:00'}
]
```

### 任务要求
1. 按时间先后排序
2. 输出活动日程表
3. 计算距离现在的天数

### 参考代码
```python
from datetime import datetime

# 排序
events.sort(key=lambda x: datetime.strptime(x['time'], '%Y-%m-%d %H:%M'))

# 输出
print("活动日程表：")
for event in events:
    print(f"{event['time']} - {event['name']}")
```

## 实例四：多条件排序

### 场景描述
企业招聘需要对候选人进行多条件筛选排序。

### 数据
```python
candidates = [
    {'name': '张三', 'experience': 5, 'education': '本科', 'score': 85},
    {'name': '李四', 'experience': 3, 'education': '硕士', 'score': 90},
    {'name': '王五', 'experience': 5, 'education': '硕士', 'score': 88},
    {'name': '赵六', 'experience': 2, 'education': '本科', 'score': 92},
    {'name': '钱七', 'experience': 4, 'education': '博士', 'score': 85}
]
```

### 任务要求
1. 先按分数降序
2. 分数相同时按工作经验降序
3. 经验相同时按学历排序（博士>硕士>本科）
4. 输出候选人排名

### 参考代码
```python
# 学历映射
edu_map = {'博士': 3, '硕士': 2, '本科': 1}

# 多条件排序
candidates.sort(key=lambda x: (-x['score'], -x['experience'], -edu_map[x['education']]))

# 输出
for i, c in enumerate(candidates, 1):
    print(f"第{i}名：{c['name']} 分数:{c['score']} 经验:{c['experience']}年 学历:{c['education']}")
```

## 实例五：字符串特殊排序

### 场景描述
需要对混合类型的字符串进行特殊规则排序。

### 数据
```python
items = [
    'item_10',
    'item_2',
    'item_1',
    'item_20',
    'item_3'
]
```

### 任务要求
1. 按数字部分排序（不是字母顺序）
2. 输出正确顺序：1, 2, 3, 10, 20

### 参考代码
```python
import re

# 提取数字
def get_number(s):
    return int(re.search(r'\d+', s).group())

# 排序
items.sort(key=get_number)

print(items)  # ['item_1', 'item_2', 'item_3', 'item_10', 'item_20']
```
