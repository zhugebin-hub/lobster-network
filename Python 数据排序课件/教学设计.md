# Python 数据排序 教学设计

## 一、教学基本信息

| 项目 | 内容 |
|------|------|
| 课程名称 | Python 编程基础 |
| 教学主题 | 数据排序 |
| 授课对象 | 中等职业学校计算机专业一年级学生 |
| 课时安排 | 2 课时（90 分钟） |
| 教学环境 | 多媒体机房（安装 Python 3.8+） |

---

## 二、教学目标

### 知识目标
- 理解排序的基本概念和应用场景
- 掌握列表的 sort() 方法和参数
- 掌握 sorted() 函数的用法和参数
- 理解 sort() 与 sorted() 的区别

### 能力目标
- 能够对列表进行升序/降序排序
- 能够使用 key 参数自定义排序规则
- 能够解决实际生活中的排序问题
- 能够选择合适的排序方法

### 素养目标
- 培养逻辑思维与数据分析能力
- 养成规范编程与调试习惯
- 提升问题解决与自主学习能力
- 增强团队协作与交流表达能力

---

## 三、教学重难点

### 教学重点
- sort() 方法与 sorted() 函数的用法
- reverse 参数的使用
- key 参数自定义排序规则

### 教学难点
- sort() 与 sorted() 的区别
- key 参数函数的编写
- 多条件排序的实现

---

## 四、学情分析

### 学生基础
- 已掌握 Python 基本语法（变量、数据类型、列表）
- 了解列表的基本操作（增删改查）
- 对函数有初步认识
- 编程实践能力参差不齐

### 学习特点
- 喜欢动手实践，不喜欢纯理论
- 对实用案例兴趣浓厚
- 需要清晰的步骤指导
- 容易混淆相似概念

### 应对策略
- 采用案例驱动教学法
- 提供详细代码示例
- 对比讲解易混概念
- 分层布置练习任务

## 六、教学过程

### 第一课时（45 分钟）

- 展示成绩单、商品列表、活动日程

- 思考排序方法
- 回答问题

**设计意图：**
- 激发学习兴趣
- 认识排序的实用性
- 明确学习目标

#### 2. 新知讲授（25 分钟）

**学生活动：**
- 观看教师演示

#### 3. 教学实例一（10 分钟）

**实例：成绩排名**

**教师活动：**
- 展示成绩数据

**学生活动：**
- 跟随教师操作

#### 4. 课堂小结（5 分钟）

## 九、板书设计

```
Python 数据排序

一、sort() 方法
   列表名.sort(reverse=False)
   - 修改原列表
   - 无返回值

二、sorted() 函数
   sorted(可迭代对象，reverse=False)
   - 不修改原数据
   - 返回新列表

三、key 参数
   - 自定义排序规则
   - 常用函数：len, str.lower, abs

四、多条件排序
   - 元组作为 key 返回值
   - 负数实现降序

五、记忆口诀
   sort 修改原列表，
   sorted 返回新列表，
   key 来自定规则，
   reverse 控升降序！
```

## 十、教学反思

### 预期效果
- 90% 学生能够区分 sort() 与 sorted()
- 80% 学生能够使用 key 参数
- 70% 学生能够完成多条件排序

### 可能问题
- sort() 与 sorted() 容易混淆
- key 参数函数编写有困难
- 多条件排序理解不够

### 改进措施
- 增加对比练习
- 提供 key 函数模板
- 分步讲解多条件排序
- 安排操作快的学生帮助慢的学生

## 十二、附录

### 常见错误速查

| 错误 | 原因 | 解决 |
|------|------|------|
| sort() 返回 None | 误以为有返回值 | 直接打印原列表 |
| sorted() 不生效 | 未接收返回值 | 用变量接收返回值 |
| key 参数错误 | 函数调用加括号 | 只写函数名 |
| 中文排序异常 | 编码问题 | 使用 locale 模块 |
