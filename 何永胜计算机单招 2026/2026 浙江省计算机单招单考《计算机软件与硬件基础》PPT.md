## 幻灯片 5：1.1 计算机发展历史
**第一代（1946-1957 年）**
- 电子元件：电子管
- 特点：体积大、功耗高、可靠性差
- 代表机型：ENIAC

**第二代（1958-1964 年）**
- 电子元件：晶体管
- 特点：体积缩小、可靠性提高
- 代表语言：汇编语言

**第三代（1965-1970 年）**
- 电子元件：集成电路
- 特点：体积更小、速度更快
- 代表系统：操作系统出现

**第四代（1971 年至今）**
- 电子元件：大规模集成电路
- 特点：微型化、智能化、网络化
- 代表产品：微型计算机

## 幻灯片 6：1.2 计算机特点
**五大特点：**
1. 运算速度快

## 幻灯片 10：2.1 CPU 组成

```
┌─────────────────────────┐
│       中央处理器        │
│  ┌───────┐  ┌───────┐  │
│  │运算器  │  │控制器  │  │
│  │ (ALU) │  │ (CU)  │  │
│  └───────┘  └───────┘  │
│  ┌───────┐  ┌───────┐  │
│  │寄存器  │  │ 缓存   │  │
│  │       │  │(Cache)│  │

└─────────────────────────┘
```

**各部分功能：**
- 运算器：算术逻辑运算

- 寄存器：临时存储数据
- 缓存：高速缓冲存储器

## 幻灯片 13：2.4 CPU 工作原理
**指令执行过程：**

```
取指 → 译码 → 执行 → 访存 → 写回
 ↓      ↓      ↓      ↓      ↓
从内存  解析   执行   访问   写回
取指令  指令   操作   内存   结果
```

**指令周期：**
- 取指阶段：从内存取出指令
- 译码阶段：解析指令含义
- 执行阶段：执行指令操作
- 访存阶段：访问内存数据
- 写回阶段：写回运算结果

## 幻灯片 18：3.4 存储器容量换算
**换算关系：**
```
1B（字节）= 8bit（位）
1KB = 1024B = 2^10B
1MB = 1024KB = 2^20B
1GB = 1024MB = 2^30B
1TB = 1024GB = 2^40B
```

**计算公式：**
存储容量 = 存储单元数 × 字长

**高考真题：**
（2024 年计算）某硬盘标称容量 500GB，实际可用容量约为多少？
**答案：** 500×1000³/1024³ ≈ 465GB

**注意：** 厂商标称用 1000 进制，计算机用 1024 进制

## 幻灯片 29：6.1 软件定义与特点
**软件定义：**
软件是计算机系统中与硬件相互依存的另一部分，包括程序、数据及相关文档的完整集合。

**软件特点：**
1. 无形性：没有物理形态
2. 复制成本低：复制几乎无成本
3. 易修改：可以方便地修改
4. 会退化：不会磨损但会过时
5. 开发成本高：人力成本为主

**软件与硬件区别：**
| 特性 | 硬件 | 软件 |
|------|------|------|
| 形态 | 有形 | 无形 |
| 磨损 | 会磨损 | 不会磨损 |
| 复制 | 成本高 | 成本低 |
| 开发 | 制造为主 | 设计为主 |

## 幻灯片 37：8.2 编译与解释
**翻译方式对比：**

| 方式 | 过程 | 优点 | 缺点 | 代表语言 |
|------|------|------|------|----------|
| 编译 | 先编译后执行 | 执行速度快 | 移植性差 | C/C++ |
| 解释 | 边解释边执行 | 移植性好 | 执行速度慢 | Python |
| 混合 | 先编译成字节码再解释 | 兼顾两者 | - | Java |

**工作流程：**

```
编译方式：
源代码 → 编译器 → 目标代码 → 执行

解释方式：
源代码 → 解释器 → 执行（逐行）
```
