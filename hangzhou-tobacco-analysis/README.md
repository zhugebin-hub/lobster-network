# 📊 杭州烟草销售数据分析系统

> 基于 Streamlit 的数据可视化与预测分析系统  
> 适用于教学演示、数据分析实训、毕业设计参考

---

## 📁 项目结构

```
hangzhou-tobacco-analysis/
├── data/                    # 数据文件目录
│   ├── sales_records.csv    # 销售记录（54,750 条）
│   ├── shops.csv            # 店铺信息（10 家）
│   ├── products.csv         # 商品信息（15 个品规）
│   ├── shop_summary.csv     # 店铺汇总
│   ├── brand_summary.csv    # 品牌汇总
│   └── date_summary.csv     # 日期汇总
├── src/                     # 源代码目录
│   ├── generate_data.py     # 数据生成脚本
│   └── app.py               # Streamlit 主程序
├── docs/                    # 文档目录
├── requirements.txt         # Python 依赖
└── README.md               # 项目说明
```

---

## 🚀 快速开始

### 1. 安装依赖

```bash
cd hangzhou-tobacco-analysis
pip install -r requirements.txt
```

### 2. 生成数据（可选）

如果 `data/` 目录为空，运行：

```bash
python src/generate_data.py
```

### 3. 启动应用

```bash
streamlit run src/app.py
```

### 4. 访问系统

浏览器打开：http://localhost:8501

## 📋 功能模块

| 模块 | 功能描述 | 技术实现 |
|------|---------|---------|
| 🏠 首页 | 数据概览、关键指标、销售趋势 | 指标卡片 + 折线图 |
| 📈 数据分析 | 18 种可视化图表、多维度分析 | Plotly 交互图表 |

| 📥 数据导入 | 支持 CSV/XLSX 上传 | Pandas 读取 |
| 📤 数据导出 | 导出 Excel 文件 | XlsxWriter |
| 📋 结论与建议 | 分析总结 + 策略建议 | 文本报告 |

## 📊 数据集说明

### 销售记录 (sales_records.csv)
- **数据量：** 54,750 条
- **时间范围：** 2025 年 1 月 1 日 - 2025 年 12 月 31 日
- **字段：** 日期、店铺 ID、店铺名称、区域、品类 ID、品牌、品规、价格、档次、销售数量、销售金额

### 店铺信息 (shops.csv)
- **数据量：** 10 家店铺
- **字段：** 店铺 ID、店铺名称、区域、面积、店员数
- **区域分布：** 上城区、下城区、江宁区、拱墅区、西湖区、滨江区、萧山区、余杭区、临安区、富阳区

### 商品信息 (products.csv)
- **数据量：** 15 个品规
- **品牌：** 中华、利群、芙蓉王、黄鹤楼、南京、黄山、玉溪、云烟
- **档次：** 低档、中档、高档

## 🌐 部署方案

### 方案 1：本地运行（推荐教学用）
```bash
streamlit run src/app.py
```

### 方案 2：Streamlit Cloud（免费）
1. 上传代码到 GitHub
2. 在 [share.streamlit.io](https://share.streamlit.io) 部署
3. 获取公开访问链接

### 方案 3：服务器部署
```bash
# 安装依赖
pip install -r requirements.txt

# 后台运行
nohup streamlit run src/app.py --server.port 8501 &
```
