### 任务 3：数据可视化（2 课时）

#### 步骤 3.1：创建饼图
```python
import plotly.express as px

# 按档次汇总
category_sales = df.groupby("档次")["销售金额"].sum().reset_index()

# 绘制饼图
fig = px.pie(
    category_sales,
    values="销售金额",
    names="档次",
    title="各档次销售占比"
)
fig.show()
```

#### 步骤 3.2：创建柱状图
```python
# 按品牌汇总
brand_sales = df.groupby("品牌")["销售金额"].sum().reset_index()
brand_sales = brand_sales.sort_values("销售金额", ascending=False)

# 绘制柱状图
fig = px.bar(
    brand_sales,
    x="品牌",
    y="销售金额",
    title="品牌销售额排名",
    color="销售金额"
)
fig.show()
```

#### 步骤 3.3：创建折线图
```python
# 按日期汇总
daily_sales = df.groupby("日期")["销售金额"].sum().reset_index()

# 绘制折线图
fig = px.line(
    daily_sales,
    x="日期",
    y="销售金额",
    title="每日销售趋势"
)
fig.show()
```

**✅ 检查点：** 创建 3 种不同类型的图表

### 任务 4：Streamlit 应用开发（2 课时）

#### 步骤 4.1：创建基础页面
创建 `src/app.py`：
```python
import streamlit as st
import pandas as pd

st.title("📊 数据分析系统")

# 加载数据
df = pd.read_csv("data/sales_records.csv")

# 显示指标
col1, col2 = st.columns(2)
col1.metric("总销售额", f"¥{df['销售金额'].sum():,.0f}")
col2.metric("总销量", f"{df['销售数量'].sum():,} 条")
```

#### 步骤 4.2：添加侧边栏
```python
st.sidebar.title("📊 导航")
page = st.sidebar.radio(
    "选择页面",
    ["首页", "销售分析", "店铺排名"]
)
```

#### 步骤 4.3：添加图表
```python
if page == "销售分析":
    import plotly.express as px
    
    category_sales = df.groupby("档次")["销售金额"].sum().reset_index()
    fig = px.pie(category_sales, values="销售金额", names="档次")
    st.plotly_chart(fig)
```

#### 步骤 4.4：运行应用
```bash
streamlit run src/app.py
```

**✅ 检查点：** 应用成功运行并可交互

## 六、常见问题

### Q1：依赖安装失败
**解决：** 使用国内镜像源
```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple streamlit pandas plotly
```

### Q2：中文显示乱码
**解决：** 确保 CSV 文件使用 UTF-8 编码
```python
df.to_csv("data.csv", index=False, encoding="utf-8-sig")
```

### Q3：图表不显示
**解决：** 检查是否正确调用 `st.plotly_chart()`

### Q4：应用运行慢
**解决：** 使用 `@st.cache_data` 缓存数据
