**任务：** 添加品牌筛选下拉框

<select id="brand-filter" onchange="filterData()">

2. 在 JavaScript 中添加筛选函数：
```javascript
function filterData() {
    const selectedBrand = document.getElementById('brand-filter').value;
    const filteredData = selectedBrand === 'all' 
        ? salesData 
        : salesData.filter(item => item.品牌 === selectedBrand);
    // 重新绘制图表
    initOverview(filteredData);
}
```

#### 5.2 添加数据导出

**任务：** 添加导出为 CSV 功能

function exportCSV() {
    const csv = salesData.map(item => 
        `${item.日期},${item.店铺名称},${item.品牌},${item.销售金额}`
    ).join('\n');
    
    const blob = new Blob([csv], { type: 'text/csv' });

## 六、常见问题

### Q1：网页打不开
**解决：** 检查本地服务器是否启动，访问 http://localhost:8000

### Q2：图表不显示
**解决：** 检查 ECharts CDN 是否加载，打开浏览器控制台查看错误

### Q3：修改后没变化
**解决：** 刷新页面（Ctrl+F5 强制刷新），清除浏览器缓存

### Q4：JSON 数据加载失败
**解决：** 必须用本地服务器，不能直接打开 HTML 文件

### Q5：代码不会改
**解决：** 先复制原代码，小步修改，每改一次就刷新测试
