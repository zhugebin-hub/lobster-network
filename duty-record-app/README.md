# 🏫 学校值班记录系统

初中部中层干部值班记录小程序 - 支持 3 年级 24 个班级的卫生、纪律、学习多维度记录与 AI 周报总结

## 📋 功能特点

- ✅ **9 个值班时段**：晨间、上午、大课间、午餐、午间、下午、晚餐、晚间、晚自习
- ✅ **3 个评分维度**：卫生、纪律、学习（各 5 分制）
- ✅ **拍照上传**：现场情况拍照记录
- ✅ **双入口设计**：公开查看 + 登录记录
- ✅ **AI 周报总结**：自动生成周度分析报告
- ✅ **24 个班级**：3 年级 × 8 班

## 🛠️ 技术栈

**后端**
- Node.js + Express
- SQLite 数据库
- JWT 认证
- 文件上传（multer）

**前端**
- 微信小程序
- 原生 WXML/WXSS

**AI 功能**
- 通义千问（可选配置）
- 自动周报生成

## 🚀 快速部署

### 1. 后端部署

```bash
cd backend

# 安装依赖
npm install

# 初始化数据库
npm run init-db

# 启动服务
npm start
```

服务将运行在 `http://localhost:3000`

### 2. 微信小程序配置

1. 打开微信开发者工具
2. 导入 `wechat-miniprogram` 目录
3. 修改 `app.js` 中的 `apiUrl` 为你的服务器地址
4. 编译预览

### 3. 环境变量（可选）

配置 AI 总结功能：

```bash
export DASHSCOPE_API_KEY=your_api_key
```

## 📱 使用说明

### 管理员登录
- 默认账号：`admin`
- 默认密码：`admin123`
- ⚠️ 首次登录后请修改密码

### 记录流程
1. 登录系统
2. 选择日期、时段、班级
3. 评分（卫生/纪律/学习）
4. 填写备注（可选）
5. 拍照上传（可选）
6. 提交记录

### 查看周报
1. 进入"周报总结"页面
2. 选择日期范围
3. 点击"生成 AI 总结"
4. 查看分析报告和班级排名

## 📊 API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/login` | POST | 管理员登录 |
| `/api/classes` | GET | 获取班级列表 |
| `/api/time-periods` | GET | 获取时段列表 |
| `/api/records` | GET/POST | 记录查询/提交 |
| `/api/stats/weekly` | GET | 周统计数据 |
| `/api/ai/weekly-summary` | POST | AI 周报总结 |

## 🔐 安全建议

1. 修改默认管理员密码
2. 配置 HTTPS（生产环境）
3. 设置 JWT_SECRET 环境变量
4. 定期备份数据库

## 📝 数据库结构

- `users` - 管理员用户
- `classes` - 班级信息（24 个班）
- `duty_records` - 值班记录
- `time_periods` - 时段配置（9 个时段）
