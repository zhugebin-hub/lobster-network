## 🎙 配音录制指南

### 录音环境要求
```
✅ 安静封闭的房间
✅ 无回声（可挂窗帘、铺地毯）
✅ 关闭空调、风扇等噪音源
✅ 手机静音
✅ 告知他人不要打扰
```

### 设备建议
```
专业级：
- 麦克风：Blue Yeti / Rode NT-USB
- 声卡：Focusrite Scarlett
- 监听耳机：Audio-Technica M50x

入门级：
- 手机录音（安静环境下）
- 有线耳机自带麦克风
- 电脑内置麦克风（近距录音）
```

### 录音软件
```
专业：Adobe Audition / Logic Pro
免费：Audacity / 剪映内置录音
手机：语音备忘录 / 录音机
```

## 🔊 后期处理

### 音频处理参数
```
降噪：轻度降噪（保留自然感）
压缩：阈值 -20dB，比率 3:1
均衡：高频 +2dB（增加清晰度）
限幅：上限 -3dB（防止爆音）
```

### 导出格式
```
格式：WAV（母版）/ MP3（使用版）
采样率：44.1kHz
位深：16bit
码率：320kbps（MP3）
```
