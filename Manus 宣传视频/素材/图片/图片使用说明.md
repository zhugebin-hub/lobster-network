## 🖼 如何使用

### 方法一：直接用 SVG 文件

**剪映专业版**支持直接导入 SVG 文件：
1. 打开剪映 → 导入素材
2. 选择 SVG 文件
3. 拖入时间线使用

### 方法二：转换为 PNG

#### 在线转换
1. 访问 https://cloudconvert.com/svg-to-png
2. 上传 SVG 文件
3. 设置尺寸为 1080×1920
4. 下载 PNG 文件

#### 使用浏览器
1. 用 Chrome/Edge 打开 SVG 文件
2. 右键 → 另存为 → 选择 PNG
3. 或使用截图工具截取

#### 使用 Photoshop
1. 文件 → 打开 → 选择 SVG
2. 设置尺寸为 1080×1920
3. 文件 → 导出 → PNG

## 🎨 自定义修改

### 修改文字内容

用文本编辑器打开 SVG 文件，找到对应文字：

```xml
<text x="540" y="800" font-size="72" fill="#FFFFFF">
  人人都是开发者
</text>
```

修改引号内的文字即可。

### 修改颜色

找到颜色代码替换：

```xml
fill="#0066FF"  <!-- 科技蓝 -->
fill="#FFFFFF"  <!-- 白色 -->
fill="#000000"  <!-- 黑色 -->
```

### 修改尺寸

在文件开头修改 width 和 height：

```xml
<svg width="1080" height="1920" ...>
```
