## 📋 使用流程

### 第一步：阅读材料（30 分钟）
1. 打开 `01-视频脚本详细版.md` 了解整体内容
2. 查看 `02-分镜图.md` 理解画面构成
3. 阅读 `04-制作指南.md` 了解制作方法

### 第二步：准备素材（2-3 小时）
1. 根据 `03-素材清单.md` 准备所需素材
2. 优先准备高优先级素材（书籍封面、录屏等）
3. 整理素材到对应文件夹

### 第三步：录制配音（1 小时）
1. 使用 `05-配音文案.md` 中的标准版
2. 按配音指南录制
3. 检查音质和时长

### 第四步：制作视频（6-8 小时）
1. 按照 `04-制作指南.md》逐步制作
2. 参考 `02-分镜图.md` 安排画面
3. 添加文字、特效、音乐、音效

### 第五步：审核修改（1-2 小时）
1. 内部审看
2. 诸葛老师审看
3. 根据反馈修改

### 第六步：发布（30 分钟）
1. 使用 `06-发布文案.md》准备发布内容
2. 选择合适时间发布
3. 监控数据并互动
