## 📋 制作流程

### 第一阶段：准备工作（1-2 小时）

#### 1.1 创建项目
```
打开剪映 → 新建项目 → 名称"Manus 宣传视频"
→ 比例选择 9:16 → 分辨率 1080×1920 → 帧率 30fps
```

#### 1.2 导入素材
```
点击"导入" → 选择所有素材文件 → 确认导入
建议建立素材文件夹：
├── 图片
├── 视频
├── 音频
└── 字体
```

#### 1.3 设置草稿
```
保存项目 → 命名为"Manus 宣传视频_v1"
开启自动保存（每 5 分钟）
```

---

### 第二阶段：粗剪（2-3 小时）

#### 2.1 导入配音
1. 将配音音频拖入音轨
2. 根据配音节奏标记时间节点
3. 使用"分割"工具切割音频段落

```
时间标记点：
0s    - 开场
5s    - 技术演进
15s   - Manus 展示
25s   - 书籍展示
35s   - 作品展示
45s   - 团队介绍
55s   - 结尾
```

#### 2.2 放置主画面
1. 根据时间标记放置对应画面素材
2. 调整每个镜头的时长
3. 确保画面与配音同步

#### 2.3 添加转场
```
推荐转场效果：
- 镜头 1→2：向左滑动
- 镜头 2→3：模糊过渡
- 镜头 3→4：向上滑动
- 镜头 4→5：缩放过渡
- 镜头 5→6：淡入淡出
- 镜头 6→7：淡入淡出

转场时长：0.3-0.5 秒
```

---

### 第三阶段：精剪（3-4 小时）

#### 3.1 添加文字
1. 点击"文本" → "新建文本"
2. 输入对应文字内容
3. 设置字体、大小、颜色
4. 添加文字动画

**文字动画推荐：**
- 标题：放大进入
- 副标题：从下向上
- 说明文字：淡入
- 强调文字：闪烁/放大

#### 3.2 添加特效
```
镜头 1：发光效果（文字）
镜头 2：代码雨效果（可搜索"黑客帝国"特效）
镜头 3：屏幕边框 + 阴影
镜头 4：3D 旋转（书籍）
镜头 5：四宫格布局 + 放大效果
镜头 6：照片墙拼贴
镜头 7：渐变背景
```

#### 3.3 添加背景音乐
1. 导入背景音乐
2. 音量设置为 70%（避免盖过配音）
3. 在配音处添加"闪避"效果
4. 结尾音乐渐弱

#### 3.4 添加音效
```
按照音效清单，在对应时间点添加：
- 开场"叮"声（0s）
- 键盘声（5-8s）
- 转场声（每镜头切换）
- 翻书声（28-31s）
- 高亮"叮"声（31-35s）
- 结束音（58s）
```

---

### 第四阶段：调色与优化（1-2 小时）

#### 4.1 色彩校正
```
调整参数参考：
- 亮度：根据画面调整
- 对比度：+10 至 +20
- 饱和度：+5 至 +10
- 色温：偏冷（科技感）
- 色调：正常
```

#### 4.2 统一风格
1. 创建调整图层
2. 应用 LUT 滤镜（推荐"科技蓝"）
3. 调整不透明度至 30-50%

#### 4.3 检查节奏
- 播放完整视频
- 检查每个镜头时长是否合适
- 调整过快或过慢的部分
- 确保转场流畅

---

### 第五阶段：导出与检查（30 分钟）

#### 5.1 导出设置
```
格式：MP4
分辨率：1080×1920
帧率：30fps
码率：15-20 Mbps
音频：AAC, 320kbps
```

#### 5.2 视频号优化
```
剪映导出预设：
→ 选择"抖音/视频号"
→ 分辨率 1080P
→ 编码 H.264
→ 勾选"智能 HDR"
```

#### 5.3 质量检查清单
- [ ] 画面清晰无模糊
- [ ] 文字无错别字
- [ ] 配音清晰无杂音
- [ ] 音乐音量适中
- [ ] 转场流畅
- [ ] 时长在 60 秒内
- [ ] 文件大小不超过 100MB
- [ ] 二维码可扫描

## 🎨 设计要点

### 色彩搭配
```
主色：#000000（黑）#1a1a2e（深蓝灰）
辅色：#0066FF（科技蓝）#0099FF（亮蓝）
文字：#FFFFFF（白）#CCCCCC（灰）
```

### 字体使用
```
标题：思源黑体 Bold, 60px
副标题：思源黑体 Medium, 36px
正文：思源黑体 Regular, 28px
```

### 动画原则
1. **简洁**：避免过度动画
2. **一致**：同类元素动画风格统一
3. **流畅**：使用缓入缓出
4. **适度**：每屏动画不超过 3 个
