## ✅ 素材检查清单

### 图片检查
- [ ] 分辨率达标（≥1920×1080）
- [ ] 格式正确（PNG/JPG）
- [ ] 无水印
- [ ] 色彩正常
- [ ] 文件命名规范

### 视频检查
- [ ] 分辨率 1920×1080
- [ ] 帧率 30fps
- [ ] 格式 MP4（H.264）
- [ ] 无明显抖动
- [ ] 鼠标移动平滑

### 音频检查
- [ ] 无背景噪音
- [ ] 音量适中（-6dB 至 -3dB）
- [ ] 格式正确（WAV/MP3）
- [ ] 配音清晰
- [ ] 音乐无版权风险
