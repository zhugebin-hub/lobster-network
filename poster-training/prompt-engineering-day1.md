## 📚 训练一：对比实验

### 实验 1：学术讲座海报

| 维度 | 内容 |
|------|------|
| **场景** | 学术讲座 |
| **主题** | 人工智能与未来教育 |
| **主讲** | 张三教授 |
| **时间** | 2026年6月25日 14:00 |
| **地点** | 浙江大学图书馆报告厅 |

#### ❌ 差 Prompt（直接描述）
```
做一个讲座海报，讲人工智能的
```

**预期问题**:
- 风格不明确
- 缺少关键信息
- AI 随机发挥，质量不稳定

#### ✅ 优化后 Prompt
```
制作一张学术讲座海报，主题是"人工智能与未来教育"，现代科技风格，蓝白色调，
包含抽象的神经网络图形元素，文字内容：主讲人张三教授，时间2026年6月25日14:00，
地点浙江大学图书馆报告厅，比例16:9，要求简洁专业、信息层级清晰
```

**优化要点**:
- 指定了场景类型（学术讲座）
- 指定了风格（现代科技）
- 指定了色调（蓝白）
- 指定了视觉元素（神经网络图形）
- 指定了比例（16:9）
- 指定了质量要求（简洁专业、信息层级清晰）

## 📊 评估标准

每次生成后，用以下标准评估：

| 维度 | 评分 (1-5) | 说明 |
|------|------------|------|
| 信息层级 | | 主次是否分明？ |
| 色彩搭配 | | 是否和谐？符合场景？ |
| 字体可读性 | | 文字是否清晰可读？ |
| 风格匹配 | | 是否符合要求的风格？ |
| 整体美观 | | 整体效果如何？ |

**总分 ≥ 20 分**：优秀，可直接使用
**总分 15-19 分**：良好，可微调
**总分 < 15 分**：需要重新优化 Prompt
