# 海报 Prompt 优化自主学习记录

## 2026-06-20

### 🎯 实战任务 1：日签海报

**原始 Prompt：**
```
做一个日签
```

**优化后 Prompt：**
```
制作一张日签海报，清新简约风格，淡雅蓝绿色调，包含抽象的水墨山水元素，
文字内容：2026年6月20日 周五，落子无悔，人生如棋，比例3:4，
要求简洁美观、有禅意
```

**生成结果：**
- API 返回 4 个方案 ✅
- 尺寸：400×712（3:4 竖版）✅
- 文件大小：223KB - 407KB

**自我评估：**

| 维度 | 评分 | 说明 |
|------|------|------|
| 信息层级 | 4 | 日期+语录，层级清晰 |
| 色彩搭配 | 4 | 蓝绿色调符合禅意要求 |
| 字体可读性 | 3 | 缩略图看不清字体细节 |
| 风格匹配 | 4 | 水墨山水+简约风格 |
| 整体美观 | 4 | 整体效果良好 |

**总分：19/25（良好，可微调）**

**改进建议：**
1. 可以更具体描述文字排版位置
2. 可以增加留白要求
3. 可以指定具体的字体风格

### 📊 Prompt 优化经验总结

| 优化前 | 优化后 | 效果提升 |
|--------|--------|----------|
| 模糊描述 | 具体场景+风格+色调 | ✅ 生成质量稳定 |
| 缺少比例 | 明确指定尺寸 | ✅ 比例正确 |
| 无文字要求 | 完整文字内容 | ✅ 信息完整 |
| 无风格关键词 | 指定风格+色调 | ✅ 风格一致 |

**核心经验：**
1. Prompt 质量决定设计质量
2. 场景+风格+色调+元素+文字+比例 = 完整 Prompt
3. API 会返回多个方案，可以对比选择
4. 在线编辑链接可以让用户二次调整
