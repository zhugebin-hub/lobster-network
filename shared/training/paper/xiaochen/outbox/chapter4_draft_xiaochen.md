## 4.1 实验总体设计

本章详细阐述「小龙虾网络」多智能体围棋教育框架的实验设计方案。实验设计的核心目标是验证以下三个研究假设：

- **H1**: 在多智能体协作框架下，LLM驱动的围棋教学系统在教学质量上显著优于单Agent基线
- **H2**: 角色专业化（教练、学员、评审员分工）能够显著提升学习效率和学习深度
- **H3**: 多Agent之间的知识共享（文献精读互审、章节互评）能够产生正向的协同效应

实验采用对比实验设计，设置三组条件：单Agent基线组（Single）、非角色化多Agent组（Flat）、小龙虾网络完整组（Lobster），每组在相同的围棋训练任务和论文写作任务上进行评估。

### 4.1.1 实验变量

**自变量**：
- 系统架构类型（3个水平：Single / Flat / Lobster）
- 任务类型（2个水平：围棋训练 / 论文写作）
- 训练阶段（Day 1-5 共5个水平）

**因变量**：
- 围棋训练：解题正确率、解题时间、策略多样性、知识迁移能力
- 论文写作：字数产出量、文献引用密度、章节逻辑连贯性、同行评审评分
- 通用指标：任务完成率、Agent活跃度、知识流动网络密度

**控制变量**：
- 统一使用GPT-4级别LLM后端
- 统一的任务prompt和评估标准
- 相同的计算资源和时间限制
- 所有Agent初始状态一致（零知识起点）

实验涉及四个核心Agent角色和两个辅助角色：

## 4.2 围棋训练实验

### 4.2.1 训练任务设计

围棋训练任务覆盖五大维度，每个维度设计5道题目：

1. **死活题（Life & Death）**：从基础两眼活棋到高级三手诘棋
2. **手筋题（Tesuji）**：局部巧手与战术组合
3. **定式题（Joseki）**：AI时代的新型定式理解
4. **官子题（Endgame）**：精确的终局计算
5. **布局题（Fuseki）**：全局战略思维

题目难度分为四个等级：初级（1段）、中级（3-5段）、高级（7-8段）、九段。每个学员根据自己的Level匹配相应难度的题目。训练总周期为5天，每天完成一个维度的5道题。

### 4.2.2 实验流程

围棋训练实验按以下流程进行：

**步骤1：任务分发**
教练（hermes）在每日开始时间所有学员的inbox/发送当天的训练任务JSON。任务包含完整的题目描述、棋盘状态、难度级别和预期完成时间。

**步骤2：独立解题**
学员Agent独立阅读题目，调用围棋引擎（go_training_engine.py）进行局面分析，生成解题思路和最终答案。每道题的输出包含：答案序列、关键见解、解题时长。

**步骤3：答案提交**
学员将解题结果写入outbox/目录的JSON文件。文件名格式：go_training_day{N}_{role}.json。

**步骤4：教练评审**
教练读取所有学员的outbox，对比标准答案进行评分。评分维度：正确性（60%）、思路清晰度（25%）、额外洞察（15%）。

**步骤5：集体复盘**
每日训练结束后，教练汇总所有学员的表现，生成日度训练报告，指出共性问题和个性化改进建议。

### 4.2.3 评估指标

**定量指标**：
- 解题正确率（Correct Rate）：正确解答的题目数/总题目数
- 平均解题时间（Average Time）：每道题从读取到提交的时间
- 策略多样性（Strategy Diversity）：不同学员对同一题目的解法差异度
- 知识迁移率（Knowledge Transfer）：Day N+1相比Day N的正确率提升幅度

**定性指标**：
- 解题思路的深度（由教练主观评分，1-5分）
- 术语使用的准确性
- 对AI时代新概念（逆收优先、先手效率等）的掌握程度

## 4.3 论文写作实验

### 4.3.1 写作任务设计

论文题目为「小龙虾网络：基于大语言模型的多智能体围棋教育框架」。论文写作任务分为五个阶段：

| 阶段 | 任务 | 负责学员 | 产出要求 |
|------|------|---------|---------|
| Phase 1 | 文献挖掘与精读 | 全体学员 | ≥45篇文献的精读笔记 |
| Phase 2 | 大纲撰写 | hermes | 8章完整大纲 |
| Phase 3 | 章节起草 | 分工协作 | 各学员负责章节的完整初稿 |
| Phase 4 | 同行评审 | 环形互审 | 每人2篇评审报告 |
| Phase 5 | 修订润色 | 全体修订 + hermes统稿 | 最终完整初稿 |

### 4.3.2 实验流程

**Phase 1 - 文献挖掘（Day 1）**：
- qoder: 挖掘多智能体系统+LLM围棋教育论文 ≥15篇
- xiaochen: 挖掘围棋AI+强化学习论文 ≥10篇
- zhuguxia: 挖掘工具链+可视化论文 ≥10篇
- hermes: 挖掘教育理论+评估方法论文 ≥10篇

每个学员使用paper_agent.py工具进行文献搜索和精读，产出三遍阅读法笔记，存入shared/training/paper/{role}/outbox/。

**Phase 2 - 大纲撰写（Day 2）**：
教练基于Phase 1的文献成果，综合生成八章大纲。大纲需明确每章的核心论点、关键文献引用、负责学员分工。

**Phase 3 - 章节起草（Day 3-4）**：
各学员按分工撰写负责章节。写作要求：
- 引言（qoder）: 研究背景、问题定义、贡献声明，目标10000字
- 相关工作（hermes）: 多智能体系统、围棋教育、LLM教育应用三个子领域综述
- 方法论（qoder）: 龙虾网络的核心算法和协作机制
- 系统架构（zhuguxia）: V5.2完整架构、14模块详解
- 实验设计（xiaochen）: 本章内容
- 结果分析（xiaochen）: 实验数据的统计分析和可视化
- 讨论（hermes）: 结果解释、局限分析、未来工作
- 结论（qoder统稿）: 核心发现总结

**Phase 4 - 同行评审（Day 4-5）**：
采用环形分配：qoder审xiaochen、xiaochen审zhuguxia、zhuguxia审hermes、hermes审qoder。评审标准包括：逻辑完整性、技术准确性、文献充分性、表达清晰度。

**Phase 5 - 修订润色（Day 5）**：
各学员根据评审意见修订章节，hermes最终统稿并输出完整论文初稿。

### 4.3.3 评估指标

**定量指标**：
- 文献挖掘数量与质量（被后续章节实际引用的比例）
- 章节字数产出量
- 同行评审评分（1-10分，四个维度平均）
- 修订采纳率（被作者实际采纳的评审意见比例）

**定性指标**：
- 章节间的逻辑一致性（由hermes统一评估）
- 创新点的深度和新颖性
- 多Agent协作的流畅度（消息交换密度、反馈响应速度）

## 4.4 多Agent协作效果评估

### 4.4.1 知识流动分析

为评估多Agent之间的协同效应，引入「知识流动网络」分析：

- **节点**：每个Agent是一个节点
- **边**：Agent之间的信息交换（inbox/outbox读写）
- **边权重**：交换的信息量（消息数 × 每条消息的信息密度）

通过网络密度（Density）、聚类系数（Clustering Coefficient）、中心性（Centrality）等指标量化多Agent协作的紧密程度。

### 4.4.2 协同效应量化

定义协同效应指数（Synergy Index, SI）：

$$SI = \frac{P_{multi} - \sum P_{single}/N}{\sum P_{single}/N}$$

其中 $P_{multi}$ 为多Agent组的综合表现分数，$P_{single}$ 为各单Agent独立表现分数。SI > 0 表示正向协同效应。

### 4.4.3 消融实验

为验证龙虾网络各组件的贡献，设计以下消融条件：

| 条件 | 移除的组件 | 预期影响 |
|------|----------|---------|
| 无教练 | 移除hermes的调度和评估 | 任务分配混乱，质量下降 |
| 无评审 | 移除同行评审环节 | 章节质量下降，错误增多 |
| 无共享记忆 | 移除三层记忆系统 | 知识无法积累，重复错误 |
| 无角色分工 | 所有Agent同质化 | 丧失专业化优势 |

## 4.5 实验环境与工具

- **LLM后端**: GPT-4级别API，温度0.7，最大token 4096
- **围棋引擎**: 自研go_training_engine.py，基于GTP协议
- **文件系统**: 本地文件系统，共享目录 /shared/training/
- **版本管理**: Git (GitHub + Gitee双平台同步)
- **数据记录**: JSON格式的任务记录，自动持久化
- **运行环境**: macOS 15.7.1，Python 3.11+

## 4.6 预期结果

基于龙虾网络的设计理念，我们预期：

1. **H1验证**：Lobster组在围棋解题正确率和论文质量上显著优于Single组（预期提升≥30%）
2. **H2验证**：角色专业化组的任务完成效率高于非角色化组（预期效率提升≥25%）
3. **H3验证**：存在同行评审和知识共享的组，其学习深度（知识迁移率）显著高于无共享组（预期SI > 0.3）
4. **消融实验**：移除教练角色的影响最大，其次是移除共享记忆，表明「调度中枢 + 知识积累」是龙虾网络的核心竞争力
