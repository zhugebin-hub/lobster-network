## 幻灯片 7：考核机制的特殊设计

### ① "试错容错"制度
> "完善应用试错容错管理制度"
>
> **解读：** 这不是"必须成功"的考核，而是"鼓励尝试"的考核。地方政府和企业在AI应用探索中允许失败，不会因为试错而被问责。

### ② "示范引领"机制
> "要强化示范引领，适时总结推广经验做法"
>
> **解读：** 考核不是"一刀切"，而是先试点、后推广。成功的案例会被总结并全国推广。

### ③ "开放度评价"机制
> "健全人工智能应用场景建设指引、开放度评价与激励政策"
>
> **解读：** 考核地方政府和行业的"场景开放程度"——你开放了多少场景给AI/智能体去应用？开放越多，考核越好。

### ④ "国有资本考核"
> "健全国有资本投资人工智能领域考核评价和风险监管等制度"
>
> **解读：** 国企投资AI不再按传统ROI考核，而是按"战略价值+风险可控"考核。这意味着国企可以"亏钱投AI"，只要战略价值达标。

## 幻灯片 8：AI+能源双向赋能

### 核心逻辑链

```
┌─────────────────────────────────────────────────┐
│          智能体（驾驶员）                         │
│     70% 普及率 · 亿级并发 · 2027 目标            │
└──────┬──────────────────────┬───────────────────┘
       │ 需要                  │ 反哺
       ▼                      ▼
┌──────────────┐      ┌──────────────┐
│  算力（发动机）│  ←→  │  能源（燃料）  │
│  3700亿度/年  │      │  80% 绿电     │
│  PUE<1.25    │      │  新型电力系统  │
└──────────────┘      └──────────────┘
```

**双向赋能的本质：**
- **能源 → AI**：没有绿电，智能体跑不起来（3700亿度/年的用电需求）
- **AI → 能源**：没有智能体，电网管不过来（六网协同需要AI调度）

**这不是"AI+能源"，这是"AI×能源"——乘法关系，不是加法。**

## 幻灯片 14：两种打法，两种逻辑

### 中国移动：向内降本
- 8万数智员工全部用在自己身上
- 网络鉴伪、研发设计、营销服务、综合管理
- AI替代和辅助内部人工，降本增效
- **逻辑：** 把数字员工当成管理工具，而不是商业产品

### 中国电信：向外创收
- 依托"翼智企2.0"能力体系，面向中小微企业
- 首期8类，年底前扩展到50类
- 覆盖行政、财务、客服、销售等核心岗位
- **逻辑：** "数字员工+Token+连接"套餐，低成本、快速应用
- **风险：** 场景不够深，客户留不住

## 幻灯片 15：Token计费的战略意义

> **国发〔2025〕11号原文：**
> "培育人工智能应用服务商，发展'模型即服务'、'**智能体即服务**'等，打造人工智能应用服务链。"

**电信的"数字员工+Token+连接"套餐，就是"智能体即服务"的实战落地。**

| 传统计费 | Token计费 | 差异 |
|---------|----------|------|
| 卖流量（按GB） | 卖Token（按消耗量） | Token是"智能"的计量单位 |
| 卖带宽（按Mbps） | 卖连接（按设备数） | 连接是"协同"的计量单位 |
| 卖软件（按License） | 卖数字员工（按任务数） | 数字员工是"劳动力"的计量单位 |

**Token消耗 = 智能体运行 = 持续收入。这就是为什么电信要推套餐——锁定长期Token消耗。**
