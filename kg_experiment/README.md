# 知识图谱实验项目

## 项目说明

本项目实现了基于医疗领域的知识图谱构建与应用，包括：
- 知识图谱数据结构与构建
- 实体识别与关系抽取
- 知识查询与推理
- 可视化展示

## 文件结构

```
kg_experiment/
├── kg_main.py              # 主程序（知识图谱构建与查询）
├── visualization.html      # 可视化页面（D3.js 力导向图）
├── experiment_report.md    # 实验报告（Markdown）
├── experiment_report.docx  # 实验报告（Word）
├── knowledge_graph.json    # 知识图谱数据
├── visualization_data.json # 可视化数据
├── statistics.json         # 统计数据
└── README.md               # 本文件
```

## 快速开始

### 1. 运行主程序

```bash
python3 kg_main.py
```

输出示例：
```
============================================================
知识图谱构建与可视化实验
============================================================

【步骤 1】构建医疗知识图谱...
✓ 实体数量：20
✓ 关系数量：18

【查询测试】
疾病：糖尿病
  症状：多饮，多食，多尿
  药品：二甲双胍 (用法：500mg bid), 胰岛素 (用法：遵医嘱)
  科室：内分泌科
```

### 2. 查看可视化

在浏览器中打开 `visualization.html` 文件，即可看到交互式知识图谱。

### 3. 查看实验报告

- Markdown 格式：`experiment_report.md`
- Word 格式：`experiment_report.docx`

## 功能特性

### 知识图谱构建
- ✅ 6 类实体（疾病、症状、药品、检查、科室、医生）
- ✅ 5 类关系（症状、治疗、检查、科室、医生）
- ✅ 实体属性存储

### 查询功能
- ✅ 根据疾病查询症状
- ✅ 根据疾病查询药品
- ✅ 根据疾病查询科室
- ✅ 实体路径查询

### 文本处理
- ✅ 基于词典的实体识别
- ✅ 症状分析
- ✅ 疾病推测

### 可视化
- ✅ 力导向网络图
- ✅ 节点拖拽交互
- ✅ 悬停提示信息
- ✅ 统计面板
- ✅ 图例展示

## 技术栈

- **前端**: D3.js v7
- **数据格式**: JSON
- **文档**: Markdown / Word
