# WorkBuddy/CodeBuddy Research Report

## 1. Product Positioning and Publisher

### Tencent Claw Trio Relationship:

- **CodeBuddy**: Technical foundation (launched earliest in 2025)
- **WorkBuddy**: Based on CodeBuddy architecture, oriented towards enterprise office scenarios
- **QClaw**: Oriented towards individual users, WeChat direct connection to control computer

## 3. Feature Highlights

### WorkBuddy Core Capabilities:

- ✅ **No Deployment Required** - Download package, ready in 20 seconds
- ✅ **Multi-platform Remote Control** - Control computer via WeCom/QQ/Feishu
- ✅ **Pre-integrated Models** - Built-in Tencent HunYuan large model
- ✅ **Security Audit** - Tencent security gateway, enterprise-level data protection
- ✅ **20+ Built-in Skills** - Write reports, create PPT, analyze data

### Functional Modules:

1. **Claw** - Core AI engine
2. **Expert** - Domain expert knowledge base
3. **Skills** - Skills extension ecosystem
4. **Plugins** - Third-party plugin integration
5. **Automation** - Workflow automation

### CodeBuddy Core Capabilities:

- ✅ **Conversational Programming** - Describe requirements in natural language, AI writes code
- ✅ **Craft Mode** - Generate complete runnable applications in one sentence
- ✅ **IDE Plugins** - Full coverage of VS Code + JetBrains
- ✅ **Full Process Coverage** - Design → Development → Testing → Deployment
- ✅ **Cross-file Understanding** - Project-level code understanding

### QClaw Core Capabilities:

- ✅ **WeChat Direct Connection** - Scan code to bind, control computer via chat
- ✅ **Multi-model Switching** - Kimi/MiniMax/GLM/DeepSeek
- ✅ **5000+ Skills** - Access to ClawHub + GitHub skills market
- ✅ **Memory Function** - Continuously remembers user preferences

## 5. Selection Recommendations

### Enterprise Users:
- Recommend **WorkBuddy**
- Reason: Security gateway, enterprise-level data protection, no deployment required

### Developers:
- Recommend **CodeBuddy**
- Reason: Complete IDE plugins, full process coverage, cross-file understanding

### Individual Users:
- Recommend **QClaw**
- Reason: Completely free, WeChat direct connection, rich skills ecosystem

---

## 6. Key Findings

1. **Tencent Strategy**: Not making a "universal lobster", but creating differentiated products for three groups: enterprise users, ordinary users, and programmers

2. **Technical Relationship**: CodeBuddy → WorkBuddy → Enterprise AI Middle Platform (progressive layers)

3. **Ecosystem Competition**: QClaw has accessed 5000+ Skills, richest ecosystem

4. **Security Reminder**: QClaw all operations based on local running, enterprise scenarios recommended to use WorkBuddy's security gateway
