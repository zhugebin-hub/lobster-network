## 幻灯片 4：Premiere 概述
**Adobe Premiere Pro 简介：**
- Adobe 公司推出的专业视频编辑软件
- 广泛应用于电影、电视、网络视频
- 行业标准，与 After Effects 等软件无缝集成

**主要功能：**
- 视频剪辑与修剪
- 转场与特效应用
- 字幕与图形设计
- 音频处理与混音
- 颜色校正与调色
- 多格式导出

## 幻灯片 7：项目创建
**新建项目步骤：**
1. 启动 Premiere Pro
2. 点击"新建项目"
3. 设置项目名称和位置
4. 配置项目设置
5. 点击"确定"

**项目设置：**
- 渲染引擎：Mercury Playback Engine
- 视频显示格式：帧
- 音频显示格式：音频采样

## 幻灯片 10：时间轴基础
**时间轴概念：**
- 横向表示时间
- 纵向表示轨道

**轨道类型：**
- 视频轨道（V1、V2、V3...）
- 音频轨道（A1、A2、A3...）

**创建序列方法：**

## 幻灯片 27：视频导出
**导出方法：**
- 文件→导出→媒体（Ctrl+M）
- 序列→导出→媒体

**导出设置：**
- 格式：H.264（MP4）
- 预设：匹配源 - 高比特率
- 比特率：根据需求设置
- 分辨率：根据需求设置

---

## 幻灯片 28：常见导出格式
| 格式 | 用途 |
|------|------|
| H.264（MP4） | 网络视频、通用播放 |
| HEVC（H.265） | 4K 视频、高压缩 |
| QuickTime（MOV） | 专业制作、Mac 平台 |
| AVI | Windows 平台 |
| GIF | 动图、网络分享 |
