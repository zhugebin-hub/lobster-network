### 3.2 关键算法

**健康检查算法**:
```python
def _check_health(self):
    now = time.time()
    for node_id, node in self.nodes.items():
        elapsed = now - node["last_heartbeat"]
        ttl = node.get("ttl_seconds", 300)
        
        if elapsed < ttl:
            continue  # 正常
        
        if elapsed < ttl * 3:
            node["status"] = "suspected"  # 疑似离线
        else:
            node["status"] = "offline"    # 确认离线
```

**任务调度算法**:
```python
def get_optimal_schedule(self):
    scheduled = []
    available_resources = self.resource_usage.copy()
    
    for task in self.task_queue:  # 已按优先级排序
        if self._check_resources(task, available_resources):
            scheduled.append(task)
            self._allocate_resources(task, available_resources)
    
    return scheduled
```

**成本估算算法**:
```python
def get_cost_estimate(self, task_duration_hours, resource_usage):
    cpu_cost = resource_usage["cpu"] * 0.05 * task_duration_hours
    memory_cost = resource_usage["memory"] * 0.01 * task_duration_hours
    gpu_cost = resource_usage["gpu"] * 0.50 * task_duration_hours
    
    return cpu_cost + memory_cost + gpu_cost
```
