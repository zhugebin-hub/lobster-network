## 四、CC Protocol通信机制

### 4.1 协议版本

- **当前版本**: V1.1
- **传输层**: SSH + GitHub + NFS（NFS不可用）
- **消息格式**: JSON
- **路由机制**: Topic-based Pub/Sub

### 4.2 消息类型

| 类型 | 说明 | 示例 |
|------|------|------|
| SCIENCE_HELLO | 智能体注册 | 新节点加入 |
| SCIENCE_TASK | 任务分配 | Day1任务分配 |
| SCIENCE_RESULT | 结果汇报 | 研究成果汇报 |
| SCIENCE_REVIEW | 评审反馈 | 交叉评审意见 |
| SCIENCE_HEARTBEAT | 心跳检测 | 定期状态检查 |

### 4.3 ACK机制

| 消息类型 | ACK超时 | 说明 |
|---------|---------|------|
| 训练报告 | 4小时 | 学员训练进度汇报 |
| 同步请求 | 2小时 | 数据同步请求 |
| 一般通知 | 24小时 | 普通通知消息 |

## 五、安全与护栏机制

### 5.1 三层安全护栏

| 层级 | 功能 | 说明 |
|------|------|------|
| L1 输入过滤 | 过滤危险输入 | 防止注入攻击 |
| L2 执行白名单 | 限制可执行操作 | 25+白名单操作 |
| L3 输出审核 | 审核输出内容 | 防止数据泄露 |

### 5.2 差分隐私保护

- **机制**: 拉普拉斯机制
- **隐私预算**: ε=1.0
- **应用**: 科学智能体数据共享

### 5.3 Bypass机制

- **状态**: 已启用
- **授权角色**: 教练、评审
- **用途**: 紧急情况下的权限提升

## 十一、总结
