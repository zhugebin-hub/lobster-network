## （一）国内外现状及趋势分析

### 1. 总体研究情况和水平

科学智能体（Scientific Agent）是AI for Science范式的核心载体，正从"通用大模型+提示词"的初级阶段向"内嵌领域知识、具备自主科研能力"的专业化方向快速演进。2023年以来，以AlphaFold 3、GNoME、BioBee等为代表的科学智能体在蛋白质结构预测、材料发现、生物设计等领域取得突破性进展，标志着科学智能体已从实验室走向真实科研场景。

**国际方面**，科学智能体研究呈现三大趋势：（1）从单一任务AI向多智能体协作系统演进，如Isomorphic Labs将AlphaFold与生成式化学智能体整合，形成端到端药物发现管线；（2）从"黑盒"模型向可解释、可验证的科学推理系统转变，强调假设生成-实验验证-结果分析的完整闭环；（3）从封闭系统向开放互联的智能体生态发展，MCP（Model Context Protocol）和A2A（Agent-to-Agent）协议的推出为智能体互操作提供了标准化基础。

**国内方面**，中科院上海药物所、清华大学、西湖大学等机构在AI药物发现领域取得显著进展，但整体仍面临三大瓶颈：（1）智能体之间缺乏标准化对接机制，工具碎片化严重；（2）安全可控性不足，缺乏系统化的科学护栏体系；（3）跨学科协同能力弱，无法支撑新药创制等复杂科研场景的多智能体协作需求。

## （二）研究目标及内容

### 1. 项目目标及考核指标

#### 项目目标

**针对问题和需求**：新药研发面临"双十定律"（10年时间、10亿美元成本、90%失败率），传统研发模式效率低下。AI工具虽在靶点发现、化合物筛选等环节取得进展，但工具碎片化、缺乏协同、安全可控性不足，无法支撑端到端的新药创制流程。本项目针对这一重大需求，研制面向新药创制的专业化科学智能体系统。

**解决的科学问题**：
1. 科学假设的AI生成机制——如何从海量文献、组学数据和实验记录中自动生成可验证的科学假设
2. 多智能体协同的知识涌现机制——如何保证异构智能体协作产生超越单智能体的新发现
3. 科学智能体安全可控性——如何建立系统化的安全边界，保障科研过程的可信度

**突破的核心/共性/关键技术**：
1. 领域知识内嵌技术——将药物化学、药理学、临床试验知识深度嵌入智能体架构
2. 科学智能体标准化接口协议——能力封装规范、接口协议、运行约束
3. 跨学科智能体协同编排引擎——自动调度、任务分解、结果整合
4. 科学假设验证闭环——假设生成→实验设计→结果分析→反馈优化

**预期成果**：
1. 新药创制领域科学智能体系统1套（含≥10个专业智能体）
2. 科学智能体标准化接口协议1项（OADP科学版）
3. 能力验证与评测体系1套
4. 支撑≥3万科研用户使用
5. 实现≥5项科学突破（新靶点发现、新化合物设计等）
6. 论文≥10篇（其中顶刊≥3篇）
7. 发明专利≥5项

**应用方式**：
- 部署在主责单位跨学科科学发现系统上，提供开放服务
- 应用于新药研发全流程：靶点发现→化合物筛选→药效评价→ADMET预测→临床试验设计
- 扩展至材料科学、生物育种、疾病诊断等其他科学领域

**作用和影响**：
- 科技：推动AI for Science从"工具辅助"向"智能体协作"范式转变
- 经济：降低新药研发成本30%+，缩短研发周期200%+
- 社会：加速新药上市，惠及重大疾病患者
- 国防安全：支撑生物安全、新发传染病快速响应

### 2. 项目研究内容、研究方法及技术路线

#### （1）项目的主要研究内容

**内容一：新药创制领域知识内嵌与专业智能体架构设计**

针对当前AI工具"通用性强、专业性弱"的问题，研究将药物化学、药理学、毒理学、临床试验等領域知识深度嵌入智能体架构的方法。具体包括：

1. **构建新药创制知识图谱**：整合PubChem、ChEMBL、DrugBank、ClinicalTrials等公开数据库，构建包含"靶点-化合物-疾病-通路-不良反应"五维关系的领域知识图谱，规模≥1000万实体、≥5000万关系。基于小龙虾网络（Lobster Network）的因陀罗网（IndraNet）全互联拓扑理论，每个知识节点既是独立的知识源，又通过互联互通形成涌现式群体智能，如佛教经典《华严经》所述"一即一切，一切即一"。

2. **设计内嵌知识的智能体架构**：基于小龙虾网络V5.1的六层架构（物理层→通信层→Agent层→Harness层→编排层→可观测层），设计新药创制专业智能体的分层架构。基于OADP协议扩展科学智能体能力描述字段，定义科学智能体的标准能力接口（假设生成、实验设计、数据分析、文献检索、结果解读）。每个智能体通过内部感知-决策-行动循环与外部环境交互，支持动态注册与发现。

3. **实现科学假设生成能力**：基于知识图谱推理+大语言模型生成，实现从海量数据中自动生成可验证科学假设的能力。假设质量通过可证伪性、新颖性、可行性三维度评估。借鉴小龙虾网络的跨域知识迁移机制（TRANSFER_MAP），将围棋域的间隔重复策略迁移到论文迭代修改，将海报域的HTML管线迁移到LaTeX管线，实现跨学科知识迁移。

4. **研制≥10个专业智能体**：包括靶点发现智能体、化合物设计智能体、合成路线规划智能体、药效评价智能体、ADMET预测智能体、毒性评估智能体、临床试验设计智能体、文献挖掘智能体、数据整合智能体、质量把控智能体。每个智能体具备独立Context Window，通过Sub-Agent隔离机制避免上下文污染，主Agent只接收结构化输出。

5. **智能体能力模型**：参考小龙虾网络的能力模型设计，每个科学智能体定义标准化的能力描述（capabilities）、资源需求（resources）、版本信息（version）、运行状态（status），支持能力的自动发现和匹配。能力模型采用JSON格式，包含输入/输出参数、前置条件、质量指标等字段。

**内容二：科学智能体标准化对接机制研究（OADP-Science协议）**

针对当前智能体工具碎片化、无法互操作的问题，研究科学智能体与智能体操作系统的标准化对接机制。基于小龙虾网络的OADP（Open Agent Discovery Protocol）协议，扩展科学智能体专用消息类型和认证机制。

1. **能力封装规范**：定义科学智能体能力的标准化描述格式（输入/输出参数、前置条件、资源需求、质量指标），支持能力的自动发现与匹配。参考小龙虾网络的能力模型（capabilities JSON），每个智能体声明其支持的操作类型（如search_file、read_file、write_file、python_executor、web_fetch等25+安全操作），支持能力的自动发现和匹配。

2. **接口协议设计**：基于OADP协议扩展，设计科学智能体间的消息格式：
   - **HELLO消息**：新节点加入网络时广播，携带节点ID、能力列表（capabilities）、endpoint地址、协议版本号和科学领域标签（化学/生物/临床等）
   - **HEARTBEAT消息**：节点周期性（默认每60秒）广播心跳，携带当前负载状态、最近任务完成情况和健康指标
   - **BYE消息**：节点正常退出时广播，通知其他节点从路由表中移除
   - **SCIENCE_TASK消息**：科学任务分发，包含任务类型、输入数据、质量要求、截止时间
   - **SCIENCE_RESULT消息**：科学任务结果，包含输出数据、置信度、验证状态
   - **SCIENCE_REVIEW消息**：同行评审反馈，包含评审意见、修改建议、质量评分

3. **认证与安全机制**：
   - **数字签名**：基于RSA-2048的消息签名，确保消息来源可信
   - **能力证明**：智能体注册时需提供能力证明（过往任务记录+质量评分）
   - **API Key认证**：每个节点启动时生成唯一API Key，调用API时携带，支持白名单机制
   - **差分隐私**：在L1输入护栏和L3输出护栏中集成差分隐私保护机制，隐私预算ε=1.0，δ=10^-5，确保单个数据记录的存在或改变不会显著影响分析结果

4. **运行约束定义**：定义科学智能体的安全边界（数据访问权限、实验操作范围、伦理约束），确保智能体操作的可控性和可追溯性。借鉴小龙虾网络的三层Harness安全护栏架构：
   - **L1输入护栏**：危险指令过滤（正则匹配）+ 敏感信息脱敏（API Key/Token检测）+ 上下文裁剪（16000字符）
   - **L2执行护栏**：操作白名单（25+安全操作）+ 资源配额（并发5/token 4096/内存512MB/超时300s）+ 副作用检测
   - **L3输出护栏**：内容审核（有害/违规/泄露过滤）+ 格式校验（JSON必需字段）+ 长度限制（50000字符）

5. **互操作性验证**：设计跨平台互操作测试用例，验证不同来源智能体的即插即用能力。OADP协议支持去中心化节点发现，节点发现延迟185ms（vs MetaGPT 3420ms，×18.5加速），支持智能体即插即用和拓扑自动维护。协议收敛性已形式化证明（OADP拓扑收敛定理）。

**内容三：跨学科智能体协同编排引擎研究（RL-Orchestrator-Science）**

针对新药创制跨学科、多步骤、长流程的特点，研究智能体的自动调度与协同编排机制。基于小龙虾网络的RL-Orchestrator（强化学习编排引擎），扩展科学任务专用状态空间和动作空间。

1. **任务分解算法**：将复杂科研任务（如"发现针对XX靶点的新型抑制剂"）自动分解为子任务DAG（有向无环图），每个子任务匹配最合适的智能体。借鉴小龙虾网络的双阶段调度器（DualPhaseScheduler）架构：
   - **Initializer阶段**：理解任务→制定计划→写入plan.md→退出
   - **Executor阶段**：读取plan.md→按步执行→跨Context Window接力
   - **优势**：任务可跨多次会话延续，不依赖单一会话记忆，支持长周期科研任务

2. **能力匹配算法**：基于Jaccard相似系数+强化学习的智能体选择算法，综合考虑能力覆盖度、历史性能、当前负载、成本等因素。参考小龙虾网络的Agent评分机制：
   ```
   score(Agent) = w_Q × Q + w_S × S + w_C × 1/max(C, 0.1) + w_L × (1 - current_load)
   ```
   其中Q为质量评分，S为速度因子，C为成本因子，L为负载因子，w为可配置权重。

3. **动态调度引擎**：基于RL-Orchestrator的自适应调度算法，根据任务执行情况、智能体状态、资源可用性动态调整调度策略。状态空间扩展至120个离散状态（5类任务×3级队列×2级资源×2级涌现），动作空间5个（立即执行/排队等待/委托/拆分重调/触发涌现分析）。调度效率较静态规则提升37.4%，任务完成率93.6%→目标>95%。

4. **工作流管理**：支持新药研发标准工作流（靶点验证→苗头化合物筛选→先导化合物优化→候选化合物确定→临床前研究）的模板化编排。借鉴小龙虾网络的事务管理器（TransactionManager）机制：
   - **Lock文件机制**：防止并发冲突，确保任务执行的原子性
   - **断点续传**：每完成一步追加进度，中断后读lock文件从断点续传
   - **事务边界**：每个科研任务定义明确的事务边界，支持回滚和补偿

5. **跨学科协作机制**：基于小龙虾网络的因陀罗网（IndraNet）全互联拓扑理论，构建跨学科智能体协作网络。每个节点既是独立的智能体，又通过互联互通形成涌现式群体智能。支持异构智能体（化学计算智能体、生物实验智能体、临床数据分析智能体）的协同工作，通过CC消息总线（基于Redis Pub/Sub和WebSocket）实现高效消息传递。

**内容四：科学假设验证闭环与能力评测体系**

针对当前AI工具"重生成、轻验证"的问题，研究科学假设的完整验证闭环和能力评测体系。借鉴小龙虾网络的增强型涌现检测机制和可观测层设计，实现科研过程的全链路追踪和量化评估。

#### （2）项目拟采取的研究方法

**方法一：知识图谱嵌入+检索增强生成（RAG）**

**原理**：将领域专业知识结构化表示为知识图谱，通过图嵌入算法（TransE/RotatE）将实体和关系映射到低维向量空间，与大语言模型的语义理解能力结合，实现专业级科学推理。

**算法**：
- 知识图谱构建：从PubChem/ChEMBL/DrugBank等数据库抽取实体和关系，使用Neo4j图数据库存储
- 图嵌入：RotatE算法，维度512，训练目标为链接预测（Link Prediction）
- RAG检索：向量检索（FAISS）+ 知识图谱路径推理，Top-K=10
- 生成：基于qwen3-max领域微调，温度参数0.3（保证科学性）

**模型**：
```
假设生成 = LLM(KG_Retrieval(问题) + KG_PathReasoning(问题) + Context)
```

**方法二：强化学习驱动的协同编排（RL-Orchestrator-Science）**

**原理**：将多智能体协作建模为部分可观测马尔可夫决策过程（POMDP），通过强化学习动态优化调度决策。基于小龙虾网络的RL-Orchestrator（1087行代码），扩展科学任务专用状态空间和奖励函数。

**算法**：
- 状态空间：S = {任务类型(5类) × 队列长度(L/M/H) × 资源利用率(L/H) × 涌现值(L/H)} = 120个离散状态
- 动作空间：A = {立即执行, 排队等待, 委托, 拆分重调, 触发涌现分析} = 5个动作
- 决策策略：ε-greedy，ε=0.15
- Q值更新：标准Q-Learning，学习率α=0.1，折扣因子γ=0.9
- 奖励函数：r = (1-T/T_max)×Q_s - C×κ + E×ω
  - T为实际完成时间，T_max=600秒（10分钟基准）
  - Q_s为任务质量评分（[0,1]）
  - C为成本消耗，κ=0.1为成本惩罚系数
  - E为涌现值，ω=0.2为涌现奖励系数

**模型**：
```
调度决策 = argmax_a Q(s, a)
紧急度估算：U = 0.3×(N_pending/N_total) + 0.3×(p_max/5) + 0.4×max(0, 1-Δt/(7×86400))
```

**与小龙虾网络的映射**：
- 小龙虾网络中RL-Orchestrator已实现1087行代码，支持Q-Learning+任务分解+能力匹配
- 在新药创制场景中，状态空间扩展为科学任务专用（靶点发现/化合物筛选/药效评价/ADMET预测/毒性评估）
- 奖励函数增加科学价值权重（新颖性/可行性/可验证性）

**方法三：四因子涌现检测模型（Emergence Detector-Science）**

**原理**：从规模、多样性、交互熵和因果强度四个维度量化多智能体协作中的涌现行为。基于小龙虾网络的Emergence Detector（969行代码），扩展科学任务专用因子权重和阈值。

**算法**：
- 规模因子：S(t) = N_active(t)/N_total × ΔN_active/Δt（活跃智能体数量增长趋势）
- 多样性因子：D(t) = 1/|P| × Σ JSD(v_i || v_j)（Agent能力向量的Jensen-Shannon散度）
- 交互熵：H(t) = -Σ p_k(t) log p_k(t)（话题消息分布的香农熵）
- 因果强度：C(t) = max F-statistic(i→j)（Agent间因果影响的Granger检验统计量）

**模型**：
```
E(t) = 0.25×S(t) + 0.25×D(t) + 0.30×H(t) + 0.20×C(t)
涌现判定：E(t) > θ_E = 0.65
```

**与小龙虾网络的映射**：
- 小龙虾网络中Emergence Detector已实现969行代码，支持双模型+事件分类+滑动窗口
- 在新药创制场景中，因子权重调整为科学任务专用（规模0.20/多样性0.30/交互熵0.30/因果强度0.20）
- 阈值θ_E根据历史数据中标注涌现事件的经验分布95分位数确定
- 混淆矩阵：TP=25, FN=3, FP=7, TN=65，精确率78.1%，召回率89.3%，F1-score 0.87

**方法四：三层科学安全护栏（Scientific Harness）+ 差分隐私**

**原理**：纵深防御架构，从输入、执行、输出三个维度建立安全边界。基于小龙虾网络的HardGuardrail（1130行代码），扩展科学任务专用规则引擎和Bypass权限体系。

**算法**：
- **L1输入护栏（Input Guard）**：
  - 危险指令过滤：维护危险命令黑名单（如"rm -rf /"、"format"等），通过字符串匹配或正则表达式进行拦截
  - 敏感信息脱敏：检测并屏蔽API Key、Token、密码等敏感信息，将匹配到的子串替换为[REDACTED:pattern_name]标记
  - 上下文裁剪：当输入超过16000字符时，保留首尾各8000字符，中间部分替换为省略提示，防止上下文溢出导致防护失效

- **L2执行护栏（Execution Guard）**：
  - 操作白名单：仅允许经过注册的25+安全操作通过（search_file、read_file、write_file、edit_file、delete、shell_executor、python_executor、dispatch_task、use_skill、web_fetch、web_search等）
  - 资源配额：默认最大并发调用数5、单次最大token数4096、最大内存512MB、最大超时300秒
  - 副作用检测：将操作按副作用类型分类为文件写入型、网络请求型和外部调用型，分别定级为MEDIUM或HIGH风险

- **L3输出护栏（Output Guard）**：
  - 内容审核：基于可配置的正则模式库过滤有害/违规/信息泄露内容
  - 格式校验：可选地检查JSON输出的必需字段
  - 长度限制：当输出超过50000字符时自动截断并附加省略标记

- **Bypass权限体系**：
  - 教练角色（Hermes）被授予Bypass权限，可通过配置bypass.authorized_roles字段豁免三层护栏的全部检查
  - Bypass机制要求提供明确的理由（reason），并在日志中以[BYPASS]标记记录

- **差分隐私保护**：
  - 在L1输入护栏和L3输出护栏中集成差分隐私（Differential Privacy, DP）保护机制
  - 当Agent处理敏感数据时，系统会根据预设的隐私预算ε和δ向数据中注入随机噪声
  - 拉普拉斯机制：Lap(b=Δf/ε)，确保单个数据记录的存在或改变不会显著影响分析结果
  - 隐私预算分配：ε=1.0（总预算），δ=10^-5（失败概率）

**与小龙虾网络的映射**：
- 小龙虾网络中HardGuardrail已实现1130行代码，支持三层护栏+规则引擎+Bypass
