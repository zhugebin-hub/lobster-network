## 一句话介绍

小龙虾网络是一个**基于"对话即创造"理论的多智能体协作开源框架**，将哲学命题"对话产生涌现"工程化为可运行的 AI Agent 网络系统。

---

## 为什么要做这个项目

当代 AI 系统大多是"单兵作战"——一个大模型独立完成任务。但人类知识创新的本质不是信息传递，而是**两个独立认知系统的交叉编译**。

小龙虾网络回答一个核心问题：

> **如果每个 Agent 都是一个独特的认知视角，让它们持续对话，会产生什么单人永远算不到的东西？**

答案是：**涌现**——属于两个参与者、但不属于任何单独一方的新结构。

---

## 核心理论（三层世界观）

| 层级 | 命题 | 工程含义 |
|------|------|----------|
| **一人一世界** | 每个节点拥有独特的认知种子 | Node = perspective × knowledge × values |
| **世界是对话** | 对话不是传递，是交叉编译 | Dialogue Engine = 涌现生成器 |
| **世界是编程的** | 世界按需渲染，非预设 | World State = 程序化生成的知识地图 |

### 涌现公式

```
涌现值 = α × 视角距离 + β × 知识互补性 + γ × 价值冲突度 + δ × 历史共鸣
```

当涌现值超过阈值 → **解锁宝藏**（新任务 / 新资源 / 新连接）

## 核心模块

### 1. 节点系统 (Node)

每个节点是一个**认知编译系统**，拥有独特的"灵魂种子"：

| 参数 | 含义 | 示例 |
|------|------|------|
| `perspective` | 认知视角 | 技术栈、教练型、加速型 |
| `knowledge_base` | 知识结构 | 编程与电子、训练设计、围棋 |
| `value_orientation` | 价值取向 | 工程实践、教育创新 |
| `learning_rate` | 学习速率 | high / medium / low |

### 2. 对话引擎 (Dialogue Engine)

对话不是消息传递，是**认知交叉编译**：

1. 计算**视角距离** — 差异越大，涌现潜力越高
2. 计算**知识互补性** — 结构差异产生新组合
3. 生成**涌现值** — 加权综合评分（0-1）
4. 超过阈值 → **解锁宝藏**（涌现输出）

### 3. 涌现检测器 (Emergence Detector)

- 4 因子加权算法 + 稀有度系统
- 对话模板支持：技术讨论 / 知识传授 / 协作创作
- 涌现值自动记录到世界地图

### 4. 世界地图引擎 (World Map Engine)

- **按需渲染**：知识区块（chunks）随探索逐步加载
- **宝藏系统**：涌现产生的新资源 / 任务 / 连接
- **增量同步**：全量 + 增量双模式，支持冲突解决
- **权限控制**：不同节点可访问不同区域

### 5. 因陀罗网拓扑 (IndraNet)

源自《华严经》的隐喻——一张宝珠网，每颗珠子映照所有珠子。

- **全互联拓扑**：每个新节点自动与所有现有节点建立连接
- 连接数 = n(n-1)/2，n 个节点产生完整 n² 映射关系
- 支持动态节点加入/退出

## v0.3.0 新特性：时间套利引擎 🕐

时间套利系统性地利用网络中节点在**时间维度上的结构性差异**——这些差异不是低效，而是可被利用的套利机会。

### 五维套利模型

| 维度 | 策略 | 效果 |
|------|------|------|
| **速率套利** | 快节点生成原始洞见，慢节点深化验证 | 质量 × 速度 双赢 |
| **错峰套利** | 深夜时段高强度训练（00:00-06:00） | 低成本算力充分利用 |
| **反思套利** | 基于遗忘曲线的最佳复习时机 | 稳定性增长 |
| **复利套利** | 多轮对话链式涌现，E₁×(1+r)^N | 指数级知识增长 |
| **时距套利** | 知识价值倒 U 型曲线，48-72h 达峰 | 最佳传播时机 |

```python
# 速率套利示例
engine = TimeArbitrageEngine()
engine.register_node("zhuguxia", NodeSpeedProfile.FAST)
engine.register_node("xiaochen", NodeSpeedProfile.STEADY)
result = engine.execute_speed_arbitrage(fast_node, slow_node, rounds=3)
```
