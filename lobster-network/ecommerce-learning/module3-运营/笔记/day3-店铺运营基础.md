## 二、商品上架完整流程

```
1. 选择类目 → 2. 填写标题 → 3. 设置属性 → 4. 上传主图 → 
5. 编写详情 → 6. 设置价格/库存 → 7. 设置运费 → 8. 提交审核
```

### 关键注意事项
- 类目必须准确（影响搜索排名）
- 标题 30 字充分利用
- 属性填写完整（提高匹配度）
- 主图顺序有讲究（主图→细节→场景→尺寸→好评）

## 三、客服自动回复设置

### 常见问题话术库

**Q1：什么时候发货？**
A：下单后 48 小时内发货，偏远地区可能延迟 1-2 天。

**Q2：支持退换吗？**
A：支持 7 天无理由退换，运费险已购买。

**Q3：多久能到？**
A：大部分地区 3-5 天，偏远地区 5-7 天。

**Q4：有优惠吗？**
A：关注店铺可领 5 元优惠券，满 50 可用。

### 自动回复设置步骤
1. 千牛工作台 → 客服 → 自动回复
2. 设置欢迎语
3. 设置常见问题快捷回复
4. 设置离线自动回复

## 四、数据分析基础

### 核心指标

| 指标 | 含义 | 健康值 |
|------|------|--------|
| 访客数 (UV) | 独立访客 | 日增 10%+ |
| 浏览量 (PV) | 页面浏览次数 | PV/UV > 3 |
| 转化率 | 下单人数/访客数 | 2%-5% |
| 客单价 | 平均订单金额 | 行业均值以上 |
| 退款率 | 退款订单/总订单 | < 5% |

### 生意参谋查看路径
1. 登录生意参谋：https://sycm.taobao.com/
2. 实时概况 → 今日数据
3. 流量分析 → 店铺来源
4. 商品分析 → 单品表现
