## 内容结构（8 大部分）

### 第一部分 古代意大利（公元前 800-27 年）
- 伊特鲁里亚文明
- 希腊殖民
- 罗马建城传说
- 王政时期
- 共和国建立与扩张
- 凯撒与帝国建立

### 第二部分 罗马帝国（公元前 27 年 - 公元 476 年）
- 帝国政治制度
- 五贤帝盛世
- 疆域扩张
- 罗马化进程
- 基督教兴起
- 三世纪危机
- 帝国分裂
- 西罗马灭亡

### 第三部分 中世纪意大利（476-1400 年）
- 东哥特王国
- 拜占庭统治
- 伦巴第王国
- 教皇国兴起
- 查理曼加冕
- 城市共和国（威尼斯、热那亚、佛罗伦萨）
- 教皇与皇帝之争
- 黑死病

### 第四部分 文艺复兴时期（1400-1600 年）
- 人文主义
- 文艺复兴三杰（达·芬奇、米开朗基罗、拉斐尔）
- 艺术与建筑成就
- 科学革命
- 马基雅维利政治思想
- 意大利战争
- 宗教改革影响

### 第五部分 外国统治时期（1600-1800 年）
- 西班牙统治
- 奥地利统治
- 启蒙运动
- 拿破仑时代
- 维也纳会议

### 第六部分 统一与王国时期（1800-1922 年）
- 复兴运动
- 加富尔、马志尼、加里波第
- 统一战争
- 1861 年王国建立
- 焦利蒂时代
- 殖民扩张
- 第一次世界大战

### 第七部分 法西斯与二战（1922-1945 年）
- 法西斯兴起
- 墨索里尼独裁
- 内外政策
- 种族法
- 参战与失败
- 抵抗运动

### 第八部分 共和国时期（1946 年至今）
- 共和国建立
- 1948 年宪法
- 经济奇迹
- 铅色年代（恐怖主义）
- 净手运动
- 贝卢斯科尼时代
- 欧盟一体化
- 当代挑战

## 使用建议

### 课时安排
- **完整讲授**：约 6-8 学时
- **精简版**：3-4 学时（聚焦重点时期）

### 教学方法
1. 按时间顺序系统讲解
2. 重点深入：罗马帝国、文艺复兴、统一运动、法西斯时期
3. 结合地图、图片、视频资料
4. 讨论历史对当代的启示

### 配套资源建议
- 古罗马地图
- 文艺复兴艺术品图片
- 历史纪录片
- 相关文学作品
