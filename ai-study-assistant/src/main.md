# AI 学习助手 - 核心逻辑

## 应用入口

本应用通过 OpenClaw AI 助手（小龙虾）自然语言交互，无需单独启动程序。

## 功能模块

### 1️⃣ 学习提醒模块

**触发词：** "提醒我"、"记得"、"每天"、"每周"

**实现逻辑：**
```
用户输入 → 识别时间表达式 → 调用 schedule-reminder → 创建提醒任务 → 返回确认
```

**示例：**
- "提醒我每天晚上 8 点复习机器学习"
- "明天下午 3 点提醒我交作业"
- "每周一早上 9 点提醒我开组会"

---

### 2️⃣ 知识问答模块

**触发词：** "什么是"、"怎么理解"、"解释"、"搜索"

**实现逻辑：**
```
用户问题 → 调用 searxng 搜索 → 整理搜索结果 → 生成答案 → 返回用户
```

**示例：**
- "什么是 Transformer 架构？"
- "反向传播算法怎么理解？"
- "搜索一下最新的 GPT 模型资料"

---

### 3️⃣ 学习追踪模块

**触发词：** "学习记录"、"学习时长"、"进度"、"统计"

**实现逻辑：**
```
用户查询 → 读取学习日志 → 统计分析 → 生成报告 → 返回结果
```

**示例：**
- "我这周学习了多久？"
- "显示我的学习进度"
- "生成学习总结报告"

---

### 4️⃣ 报告导出模块

**触发词：** "导出"、"生成报告"、"Word"、"PDF"

**实现逻辑：**
```
用户请求 → 收集学习数据 → 格式化内容 → 调用 docx-export → 发送文件
```

**示例：**
- "导出我的学习报告"
- "生成一份 Word 文档"
- "把这周的学习内容整理成 PDF"

---

## 交互流程

```
┌──────────────┐
│   用户输入   │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  意图识别    │ ──→ 提醒类 → schedule-reminder
└──────┬───────┘      问答类 → searxng + web-access
       │              统计类 → study-habits
       │              导出类 → docx-export
       ▼
┌──────────────┐
│  技能调用    │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  结果处理    │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  返回用户    │
└──────────────┘
```

---

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 技能未安装 | 提示用户并引导安装 |
| 搜索无结果 | 告知用户并建议换关键词 |
| 时间格式错误 | 提示正确格式示例 |
| 文件导出失败 | 检查权限并重试 |
