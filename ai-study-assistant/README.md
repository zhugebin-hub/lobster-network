## 二、应用功能

### 2.1 核心功能

| 功能模块 | 描述 | 使用技能 |
|---------|------|---------|
| 📅 学习提醒 | 设置学习任务提醒，支持一次性/周期性 | schedule-reminder, cron-helper |
| 📚 知识问答 | 搜索学科知识点，解答学习疑问 | web-access, searxng |
| 📊 进度追踪 | 记录学习时长，统计完成情况 | study-habits |
| 📝 报告生成 | 自动生成学习总结报告 | docx-export |

### 2.2 特色亮点

- ✅ **双保险提醒机制** - 即使 Gateway 失效也能准时送达
- ✅ **多渠道推送** - 支持钉钉、微信、Telegram 等
- ✅ **智能知识检索** - 自动搜索最新学习资料
- ✅ **学习数据分析** - 可视化学习进度统计

```
用户：提醒我每天晚上 8 点复习人工智能
```

```
用户：什么是 Transformer 架构？
助手：[自动搜索并整理知识点...]
```

#### 查看学习统计
```
用户：我这周学习了多久？
助手：[生成学习报告...]
```

### 6.2 遇到的问题及解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 技能安装失败 | 依赖冲突 | 使用 skill-vetter 检查兼容性后安装 |
| 文档格式错乱 | 模板不匹配 | 调整 Markdown 格式后重新转换 |
| 提醒推送延迟 | 网络波动 | 启用双保险提醒机制 |
