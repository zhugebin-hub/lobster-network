#### 1.2.1 什么是网页
网页是互联网上最基本的信息载体，通过浏览器访问和显示。网页由 HTML、CSS、JavaScript 等技术构建。

#### 1.2.2 HTML 简介
HTML（HyperText Markup Language，超文本标记语言）是用于创建网页的标准标记语言。

**HTML 发展历程：**
- HTML 1.0（1991 年）：最初版本
- HTML 4.01（1999 年）：广泛应用
- XHTML（2000 年）：更严格的语法
- HTML5（2014 年）：当前标准，新增多媒体、语义化标签

#### 1.2.3 HBuilder 介绍

## 第 4 课 图像与链接标签

### 4.1 学习目标
- 掌握图像标签的使用
- 理解相对路径与绝对路径
- 掌握超链接标签的使用

### 4.2 知识讲解

#### 4.2.1 图像标签
```html
<img src="images/logo.png" alt="网站 Logo" title="鼠标悬停提示" width="200" height="100">
```

**属性说明：**
- src：图像路径（必需）
- alt：替代文本（图片无法显示时）
- title：鼠标悬停提示
- width/height：宽高（像素或百分比）

#### 4.2.2 路径类型
- **相对路径**：相对于当前文件的位置
  - `images/logo.png`（同级目录）
  - `../images/logo.png`（上级目录）
- **绝对路径**：完整的 URL 或文件路径
  - `https://www.example.com/images/logo.png`
  - `C:/website/images/logo.png`

#### 4.2.3 超链接标签
```html
<a href="https://www.example.com" target="_blank" title="示例网站">点击访问</a>
```

**属性说明：**
- href：链接地址（必需）
- target：打开方式（_self 当前窗口，_blank 新窗口）
- title：鼠标悬停提示

#### 4.2.4 链接类型
- 外部链接：`<a href="https://www.baidu.com">百度</a>`
- 内部链接：`<a href="about.html">关于我们</a>`
- 锚点链接：`<a href="#top">返回顶部</a>`
- 下载链接：`<a href="file.zip" download>下载文件</a>`

## 第 7 课 CSS 入门与选择器

### 7.1 学习目标
- 理解 CSS 的作用与优势
- 掌握 CSS 的三种引入方式
- 熟悉常用选择器的使用

### 7.2 知识讲解

#### 7.2.1 CSS 简介
CSS（Cascading Style Sheets，层叠样式表）用于控制网页的外观和布局。

**CSS 优势：**
- 内容与样式分离
- 提高开发效率
- 便于维护和更新
- 支持多种设备

#### 7.2.2 CSS 引入方式

**行内样式：**
```html
<p style="color: red; font-size: 16px;">文本内容</p>
```

**内部样式：**
```html
<head>
    <style>
        p { color: red; font-size: 16px; }
    </style>
</head>
```

**外部样式（推荐）：**
```html
<head>
    <link rel="stylesheet" href="css/style.css">
</head>
```

#### 7.2.3 CSS 选择器

| 选择器 | 语法 | 说明 |
|--------|------|------|
| 标签选择器 | p {} | 选择所有 p 标签 |
| 类选择器 | .classname {} | 选择 class 匹配的标签 |
| ID 选择器 | #idname {} | 选择 id 匹配的标签 |
| 后代选择器 | div p {} | 选择 div 内的 p 标签 |
| 子选择器 | div > p {} | 选择 div 的直接子元素 p |
| 并集选择器 | h1, h2, h3 {} | 同时选择多种标签 |
| 伪类选择器 | a:hover {} | 选择特定状态的标签 |

## 第 11 课 CSS 优先级与继承

### 11.1 学习目标
- 理解 CSS 优先级规则
- 掌握继承的概念
- 能够解决样式冲突问题

### 11.2 知识讲解

#### 11.2.1 优先级规则

**优先级从高到低：**
1. !important 声明
2. 行内样式（1000）
3. ID 选择器（100）
4. 类选择器、属性选择器、伪类（10）
5. 标签选择器、伪元素（1）

**示例：**
```css
/* 优先级 1 */
#header .nav li a { }  /* 100+10+1+1=112 */

/* 优先级 2 */
.nav li a { }  /* 10+1+1=12 */

/* 优先级 3 */
li a { }  /* 1+1=2 */
```

#### 11.2.2 继承规则

**可继承的属性：**
- 文本相关：color, font-family, font-size, line-height
- 列表相关：list-style

**不可继承的属性：**
- 盒模型相关：width, height, margin, padding, border
- 背景相关：background
- 定位相关：position, float, display

#### 11.2.3 优先级计算
```
行内样式 > ID 选择器 > 类选择器 > 标签选择器
1000      > 100      > 10       > 1
```

```css

}
```

- 向左或向右移动
- 后续元素环绕浮动元素

**清除浮动：**
```css

    clear: both;
}
```

#### 12.2.2 定位
```css
.box {
    position: relative;  /* 相对定位 */

    left: 20px;
}

.box {
    position: absolute;  /* 绝对定位 */
    top: 0;
    right: 0;
}

.box {
    position: fixed;  /* 固定定位 */
    bottom: 0;
    right: 0;
}
```

#### 12.2.3 定位类型

| 类型 | 说明 | 参照物 |
|------|------|--------|
| static | 默认，无定位 | - |
| relative | 相对定位 | 自身原位置 |
| absolute | 绝对定位 | 最近的定位祖先 |
| fixed | 固定定位 | 浏览器窗口 |
| sticky | 粘性定位 | 滚动位置 |
