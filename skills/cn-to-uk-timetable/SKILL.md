# 目标

把用户本次上传的一个中方课程课表 `.xls/.xlsx` 转换成仿英方 Teaching Calendar 风格的单课程课表。

**不要套用模板，不要复制英方模板 sheet，不要依赖英方模板文件。** 必须从空白 workbook 重新绘制。

默认行为：

- 每次只处理 `--source-file` 指定的一个中方课表。
- 不扫描同目录下其他课程，不批量转换。
- 输出文件只保留当前课程一个 sheet。
- 任意一门 `AIIxxx-课程名.xls/.xlsx`，只要结构与现有中方课表类似，都按同一逻辑转换。
- 手机微信预览优先输出 `.xls`；桌面 Excel/WPS 也可输出 `.xlsx`。

# 英方课表布局

必须重新画出以下结构：

1. 第 1 行：课程标题，横向合并，灰色底，居中加粗。
2. 第 2 行：`Day`、`Class`、`ZJSU Timetable\n(FYI)`、`Monday` 到 `Sunday`。
3. A 列纵向合并 `Morning / Afternoon / Evening`。
4. Class 1-5 为上午，Class 6-9 为下午，Class 10-12 为晚上。
5. 第 8 行 `Lunch Break` 必须整行合并为灰色横条。
6. 第 13 行 `Dinner Break` 必须整行合并为灰色横条。
7. 所有表格区域必须有边框，文字居中、自动换行。
8. 列宽、行高要仿英方样例，不能输出成普通裸 Excel 网格。

基础列布局：

- A列：Day
- B列：Class
- C列：ZJSU Timetable (FYI)
- 默认工作日使用两个子列：D:E Monday、F:G Tuesday、H:I Wednesday、J:K Thursday、L:M Friday
- 默认周末使用一个子列：Saturday、Sunday
- 如果某一天同一时段出现多条不同安排，必须给该天动态增加子列，让它们左右分开显示。

# 解析与输出文本

每条课程块按以下顺序换行：

```text
Week 周次
课时h 课程类型
Class: 班级列表
Building X, Room Y
```

Lab 通常不加 `Class:`，可直接写班级列表。

班级翻译：

- `AI电子2401` → `REE 2401`
- `AI通信2401` → `CE 2401`
- 同类班级合并，例如 `REE 2401, 2402, 2403`

地点翻译：

- `A201` → `Building A, Room 201`
- `萨塞克斯305` → `Building Lab, Room 305`
- `信电楼电路218` → `Building SIEE, Room 218`

课程类型：

- `-01` 通常为 `Lecture`。
- `-01A/-01B/-01C` 通常为 `Lab`。
- 如果课程映射中指定了特殊类型，优先按映射。

# 同一时段合并与分格规则（重要）

这是本版最关键的规则：

1. **同一星期、同一节次、同一周次、同一课程类型、同一班级、同一教室的课程块，属于完全相同的可视课程块，必须合并成一个单元格/一个色块。** 不要重复拆成两个相邻单元格。
2. **同一时段但不同教室、不同班级、不同教学班或不同周次的安排，必须拆成不同子列/不同单元格并排显示。** 不要堆在同一个格子里。
3. 如果某天某时段只有一条安排，优先横向合并该天全部子列，提升可读性。
4. 如果同一时段有 3 条及以上不同安排，必须动态增加该天的第 3、第 4 个子列。
5. 多节连续课程必须纵向合并成完整课程块，例如 `2h Lab` 覆盖 2 个节次高度，`3h Lecture` 覆盖 3 个节次高度，不要逐行重复写文字。
6. **相邻连续节次的同一可视课程块也必须合并**：如果同一天相邻节次的周次、类型、班级、教室完全一致，例如 `(6-7节)` + `(8-8节)`，应合并为一个 `3h` 课程块。不能输出成上下两个小块。

# 颜色规则

颜色要尽量与用户提供的英方/WPS 样例保持一致，不要使用过亮的纯色。

| 颜色 | 色值 | 含义 |
|---|---|---|
| 黄色 | `#FFC000` | 纯 Lecture 理论课（含连续 3h+） |
| 绿色 | `#92D050` | 实验课 / 上机课 / Lab |
| 蓝色 | `#9DC3E6` | Workshop / Lecture-Workshop / Project / Special / Intensive / 明确特殊安排 |
| 灰色 | `#A6A6A6` | 标题行、Lunch Break、Dinner Break |
| 白色 | `#FFFFFF` | 空白无课区域 |

说明：

- 有排课的课程块才填黄/绿/蓝。
- 没有排课的空白区域不能填黄/绿/蓝；为兼容微信手机预览，空白区域必须填白底，而不是透明无填充。
- 蓝色不是 Lab；蓝色表示 Workshop/Lecture-Workshop、Project/Special/Intensive 或明确特殊安排。
- 合并课程块时，合并区域内每个单元格都要写入同样的填充、边框、字体、对齐和换行，避免手机预览只读取左上角样式。

# 手机微信/WPS 可读性规则

- 手机微信预览优先导出 `.xls`。
- `.xls` 空白区域必须白底，否则微信预览可能显示成黑色。
- 课程块字体使用 14pt，Times New Roman；若文字过多，必须配合更宽列宽、更高行高、自动换行与 shrink-to-fit。
- 主体行高不少于 120pt，动态课程列宽不少于 34。
- 启用自动换行、居中、shrink-to-fit。
- 对包含 4–5 行文字的课程块，要动态增加行高，最大可到 160pt。
- 如果某天没有冲突，课程块应横向合并该天子列，减少文字截断。

# Break 行强制规则

- `Lunch Break` 和 `Dinner Break` 必须在所有课程块写入完成后，再强制合并一次。
- 合并范围为实际课表宽度：第 8 行 `A8:最后一列8`，第 13 行 `A13:最后一列13`。
- 如果动态增加了子列，Break 行也必须扩展到新的最后一列。
- 两行必须灰色底、居中、保留边框。

# 输出要求

- 默认输出 `.xls`，同时输出转换日志 `.json`。
- 日志记录课程代码、课程名、解析到的排课条数、无法解析行、同格冲突/分格情况、token 估算和人工复核项。
- 控制台输出每门课的估算 token，例如：`Token estimate: input≈1,850, output≈980, total≈2,830 tokens / course`。
- 不要凭空补课、删课或改周次；无法确定时保留原信息并标注 warning。

# 推荐命令

```bash
python scripts/convert_cn_to_uk_timetable.py \
  --source-file "AII030-无线电频率工程.xls" \
  --output "AII030_无线电频率工程_英方课表.xls" \

```

## 重要修复：课程块颜色持久化

在生成 `.xls` 给手机微信预览时，必须避免把合并课程块内部的空白子单元格当成“无排课空白格”清成白色。
规则如下：

1. 写入课程块时，先给目标矩形区域的每个单元格写入颜色、边框、字体和对齐，再执行合并。
2. 最后清理空白区域时，只能清理真正无排课的单元格。
3. 合并课程块中除左上角外的单元格虽然没有文本，但属于课程块，不允许清成白底。
4. 空白区域使用白色底，避免微信预览显示黑底。
5. 课程颜色保持：纯 Lecture 黄色 `#FFC000`，实验课绿色 `#92D050`，Workshop/Lecture-Workshop/Project/Special/Intensive 蓝色 `#9DC3E6`；Lecture 无论 1h、2h、3h 或更长都必须保持黄色 `#FFC000`。

- 课时规则保持 v31：3 节及以上按实际钟点时长向下取整，例如 6-8 节为 2h，6-9 节为 3h。


## v34 最终合并规则补充

- 在 v32/v33 基础上，合并依据改为：同一天 + 同一原始节次范围 + 同一课程类型 + 同一老师，并且满足“同一教室或同一班级/学生组”之一。
- 同一老师、同一教室、同一时间时，即使班级不同，也合并为一个课程块，班级信息合并显示。
- 同一老师、同一班级、同一时间时，即使教室不同，也合并为一个课程块，教室信息合并显示。
- 同一老师但时间不同，不合并；同一时间但教室和班级都不同，不合并。
- 日志版本号必须为 `v37_reference_merge_contiguous_weeks_same_slot`。


## v37 合并规则修正

废弃 v35 的跨时间拆分逻辑，恢复并修正为更接近英方原表的显示方式：

1. 先合并同一老师、同一周次、同一班级、同一教室、同一课程类型的相邻节次。
   - 例如同一组的 6-7 节和 8-9 节应先合并为一个 6-9 节课程块。
2. 再处理同一老师同一时间段的并班/并室合并。
3. 同一老师、同一时间、同一教室但班级不同，可以合并；但必须是同一周次范围。
4. 如果周次不同，例如 Week 13 / Week 14 / Week 15 对应不同班级，即使老师和教室相同，也必须分成并排的不同单元格，不能合成一个 “Week 13,14,15” 大块。
5. 不同原始时间段不能被第二次错误合并。
6. Workshop / Lecture-Workshop / Project / Special 使用蓝色；Lecture 使用黄色；Lab 使用绿色。


## v37 周次连续合并规则

- 在同一天、同一时间段、同一老师、同一课程类型、同一班级、同一教室完全一致的情况下，如果只有周次不同且周次连续或重叠，必须合并成一个课程块。
- 例如 `Week 2-3` 和 `Week 4` 应合并显示为 `Week 2-4`。
- 如果班级不同、教室不同、老师不同、时间段不同，不能因为周次连续就合并。
- 如果周次不连续，例如 `Week 2-3` 和 `Week 5`，仍然分成不同课程块。
