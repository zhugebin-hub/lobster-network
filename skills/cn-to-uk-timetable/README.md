# 中方课表转英方课表 Skill v26

本版基于 v24 固定行高、居中、Times New Roman 字体规则，并舍弃 v25。

关键规则：

- 不套用英方模板，重新绘制英方 Teaching Calendar 样式。
- 课程标题 20pt Times New Roman，其他英文/数字 14pt Times New Roman。
- 标题行高 24.6 磅；第 2 行、Lunch Break、Dinner Break、课程主体行高 40.05 磅。
- 所有课表内单元格水平/垂直居中，自动换行。
- Lecture 全黄色；Lab 绿色；Project/Special/Intensive 蓝色。
- 保留中方课时文本，不改 `2h/3h` 数字。
- 如果源节次的实际钟点时间不足对应课时，只扩展课程块视觉合并范围：例如 3-4 节仍显示 2h，但色块覆盖 3-5 节。

运行示例：

```bash
python scripts/convert_cn_to_uk_timetable.py \
  --source-file "AII003-电磁学和电机导论.xls" \
  --output "AII003_电磁学和电机导论_英方课表_v26.xls" \
  --log "AII003_电磁学和电机导论_英方课表_v26_log.json"
```


## v28 correction
When adjacent/continuation source entries are merged into one visual course block, keep the displayed hour label from the original/main teaching-hour value. Do not sum 2h + 1h into 3h merely because the visual block spans three Chinese timetable rows. The color block may span 6-8 for visual fit, but the cell text must remain 2h if the course arrangement is 2h.


## v29 按老师合并规则

- 在布局前先解析每条中方记录的教师字段（原始记录第一个 `/` 之前的内容），并去掉常见职称后缀，如“教授/副教授/讲师/无”。
- 课程分块不再优先按教室拆分。
- 如果同一天、同一时间段、同一教师、同一课程类型的记录同时出现，即使周次或教室不同，也先合并为一个可视课程块。
- 合并时要把周次、班级、教室合并到同一个单元格文字里，例如：`Week 3-4,7-8`、`Building Lab, Room 310, 301`。
- 不同教师在同一时间段仍然拆成不同子列并排显示。
- 同一教师的相邻连续节次如果合并后周次/班级/教室一致，还要继续纵向合并成一个完整课程块。
- 输出日志版本号必须为 `v37_reference_merge_contiguous_weeks_same_slot`。


## v32 Workshop 蓝色规则 + v31 课时显示修正

- 保留 v29 的“同一时段按老师合并”规则。
- 课时文本不再简单沿用合并前第一条记录的 2h。
- 课时文本按中方原始节次跨度换算：每节按 45 分钟，`显示小时 = ceil(节次数 × 45 / 60)`。
- 例：`6-7节` 显示 `2h`；`6-8节` 显示 `3h`；`6-9节` 显示 `3h`。
- 这个计算发生在视觉扩展之前；视觉扩展不能把 `2h` 误改成 `3h`。
- 输出日志版本号必须为 `v37_reference_merge_contiguous_weeks_same_slot`。


## v32 Workshop 蓝色规则 + v31 课时显示规则修正
- 在 v29 按老师合并的基础上继续执行。
- 1 节显示 1h，2 节显示 2h。
- 3 节及以上不能按节次数直接进位，也不能向上取整。必须按实际钟点时长向下取整。
- 例如 6-8 节是 13:40-16:15，共 2 小时 35 分钟，只能显示 2h，不能显示 3h。
- 例如 6-9 节是 13:40-17:10，共 3 小时 30 分钟，显示 3h。
- 视觉色块仍按实际覆盖节次绘制，不改变中方原始节次。


## v34 规则更新：按老师合并，允许同室不同班合并

- 课程块可以按老师合并，但必须同时满足：同一天、同一原始节次范围、同一课程类型、同一老师。
- 在上述前提下，如果同一老师、同一时间、同一教室，即使班级不同，也可以合并为一个课程块，并把班级列表合并显示。
- 在上述前提下，如果同一老师、同一时间、同一班级，但多个教室，也可以合并为一个课程块，并在地点行合并显示多个 Room。
- 如果同一老师但上课时间不同，必须分开；如果同一时间但教室和班级都不同，也必须分开。
- 颜色规则保持：Lecture=黄色，Lab=绿色，Workshop/Lecture-Workshop/Project/Special=蓝色。
- 课时规则保持 v31：3 节及以上按实际钟点时长向下取整，例如 6-8 节为 2h，6-9 节为 3h。


## v34 最终合并规则补充

- 在 v32/v33 基础上，合并依据改为：同一天 + 同一原始节次范围 + 同一课程类型 + 同一老师，并且满足“同一教室或同一班级/学生组”之一。
- 同一老师、同一教室、同一时间时，即使班级不同，也合并为一个课程块，班级信息合并显示。
- 同一老师、同一班级、同一时间时，即使教室不同，也合并为一个课程块，教室信息合并显示。
- 同一老师但时间不同，不合并；同一时间但教室和班级都不同，不合并。
- 日志版本号必须为 `v37_reference_merge_contiguous_weeks_same_slot`。


## v37 合并规则修正

废弃 v35 的跨时间拆分逻辑，恢复并修正为更接近英方原表的显示方式：

1. 先合并同一老师、同一周次、同一班级、同一教室、同一课程类型的相邻节次。
   - 例如同一组的 6-7 节和 8-9 节应先合并为一个 6-9 节课程块。
2. 再处理同一老师同一时间段的并班/并室合并。
3. 同一老师、同一时间、同一教室但班级不同，可以合并；但必须是同一周次范围。
4. 如果周次不同，例如 Week 13 / Week 14 / Week 15 对应不同班级，即使老师和教室相同，也必须分成并排的不同单元格，不能合成一个 “Week 13,14,15” 大块。
5. 不同原始时间段不能被第二次错误合并。
6. Workshop / Lecture-Workshop / Project / Special 使用蓝色；Lecture 使用黄色；Lab 使用绿色。


## v37 周次连续合并规则

- 在同一天、同一时间段、同一老师、同一课程类型、同一班级、同一教室完全一致的情况下，如果只有周次不同且周次连续或重叠，必须合并成一个课程块。
- 例如 `Week 2-3` 和 `Week 4` 应合并显示为 `Week 2-4`。
- 如果班级不同、教室不同、老师不同、时间段不同，不能因为周次连续就合并。
- 如果周次不连续，例如 `Week 2-3` 和 `Week 5`，仍然分成不同课程块。
