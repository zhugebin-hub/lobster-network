# 微信公众号文章转 PDF 技能

## 功能说明

将微信公众号文章链接转换为格式良好的 PDF 文档，文件名自动使用文章标题。

## 使用方法

1. 提供微信公众号文章链接（mp.weixin.qq.com 开头）
2. 技能自动访问并提取文章内容
3. 使用浏览器渲染生成高质量 PDF
4. 文件名自动使用文章标题

## 技术实现

由于微信公众号有严格的反爬机制，本技能采用以下策略：

1. **使用 Playwright 浏览器**模拟真实访问
2. **等待页面完全加载**后获取内容
3. **使用浏览器原生 PDF 导出**功能
4. **自动清理**不需要的元素（广告、推荐等）

## 文件结构

```
skills/wechat-pdf/
├── SKILL.md              # 技能说明
└── convert.py            # 转换脚本
```

## 输出

- PDF 文件保存在指定目录
- 文件名格式：`文章标题.pdf`
- 包含完整的图文内容
