## 🎓 学习评估

### 自我检查清单
- [ ] 理解数字人文的基本概念
- [ ] 掌握至少一种文本分析工具
- [ ] 能够编写简单的 Python 脚本
- [ ] 完成至少一个小型项目
- [ ] 能够解读和展示分析结果

### 项目评估标准
1. **问题意识**: 研究问题是否清晰
2. **方法适当**: 方法选择是否合理
3. **技术实现**: 代码/工具使用是否正确
4. **结果呈现**: 可视化是否有效
5. **学术价值**: 对人文研究是否有贡献
