# 死活形分类与解题方法（Life & Death Reference）

## 基本死活形

### 一、基础活形（无需补棋即可活）

| 棋形 | 目数 | 说明 |
|------|------|------|
| 直四 | 4 目 | 中间两点都是眼位 |
| 曲四 | 4 目 | 弯四，同直四 |
| 板六 | 6 目 | 最强活形 |
| 双活 | — | 双方共活 |

### 二、基础死形（无法做活）

| 棋形 | 说明 |
|------|------|
| 直二 | 两点一线，无法做两眼 |
| 方四 | 四点成方块，一点即死 |
| 丁四 | 三点一线加一点 |
| 刀把五 | 五点成刀把形 |
| 花五（梅花五） | 五点成花形 |
| 花六 | 六点成花形 |

### 三、需要补棋的形

| 棋形 | 补法 | 不补的结果 |
|------|------|------------|
| 直三 | 中间做眼 | 被点死 |
| 曲三 | 中间做眼 | 被点死 |
| 笠帽四 | 要点做眼 | 被点死 |
| 角上板六 | 注意气紧 | 可能劫活或净死 |

## 角部特殊死活

### 角上板六

**基本型：**
```
    A B C
 3 O O O
 2 X . X
 1 . X .
```
- 外气充足：活
- 外气紧：劫活
- 无外气：净死（盘角曲四）

### 盘角曲四

**结论：劫尽棋亡**
- 当外围所有劫材都用完后，角上曲四是死的
- 这是围棋规则中的重要定理

### 金柜角

- 基本型是劫活
- 变化复杂，是经典死活题素材

## 死活解题方法论

### 解题步骤

1. **判断类型**：是做活题还是杀棋题？
2. **找急所**：双方必争的要点在哪里？
3. **计算变化**：按"正解 → 最强抵抗 → 结论"的顺序
4. **验证结论**：净活/净死/劫活/劫杀？
5. **检查遗漏**：是否有其他变化？

### 解题技巧

#### 做活题
- **先扩大后做眼**：先扩大眼位再做眼
- **占据要点**：直三/曲三的中间点
- **利用对方弱点**：借力做活
- **做劫**：无法净活时争取劫活

#### 杀棋题
- **先缩小后点杀**：先压缩眼位再点要害
- **从外部进攻**：不要急于进入对方眼位
- **利用气紧**：紧气是杀棋的重要手段
- **制造打劫**：无法净杀时争取劫杀

#### 对杀题
- **数气**：先数清楚双方的气
- **紧气顺序**：先紧外气还是先紧内气？
- **有眼杀瞎**：有眼一方通常有利
- **长气杀短气**：气长的一方胜利

## 经典死活题集

### 初级题（10级-5级）
1. 直三做活
2. 曲三做活
3. 直三杀棋
4. 吃子练习（征子、枷）

### 中级题（4级-1段）
1. 角上板六
2. 金柜角基本型
3. 对杀基础
4. 做劫与打劫

### 高级题（2段以上）
1. 复杂角部变化
2. 多块棋的对杀
3. 连环劫、万年劫
4. AI 新型死活题

## 死活训练建议

### 日常训练
- 每天做 10-20 道死活题
- 从适合自己水平的难度开始
- 做错的题要重新做直到完全理解

### 计算力训练
- **盲算练习**：不看棋盘，心算变化
- **限时练习**：在规定时间内完成
- **深度练习**：计算到最终结论再落子

### 比赛实战
- 实战中遇到的死活问题要记录下来
- 赛后复盘分析死活判断的失误
- 总结常犯的错误类型
