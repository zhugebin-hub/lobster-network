# 全局战略与形势判断（Strategy Reference）

## 全局思维

### 一、大局观的核心

**九段棋手 vs 低段棋手的区别：**

| 维度 | 低段 | 九段 |
|------|------|------|
| 关注点 | 局部死活 | 全局平衡 |
| 计算 | 局部变化 | 全局关联 |
| 判断 | 吃子=好 | 效率=好 |
| 取舍 | 处处争先 | 有所舍弃 |

### 二、核心战略原则

#### 1. 急所大于大场

**急所**：当前全局最紧迫的点
**大场**：价值大但不紧迫的点

- 急所未走，不占大场
- 急所判断是棋力分水岭

#### 2. 厚薄意识

**厚势的价值：**
- 攻击的基地
- 潜力转化为实地
- 对全局的影响力

**薄形的危险：**
- 被攻击的目标
- 需要补棋的负担
- 影响全局行棋

#### 3. 轻重判断

**重棋**：不能弃的棋，需要救援
**轻棋**：可以弃的棋，灵活处理

- 重棋要治，轻棋可弃
- 不要把轻棋走重
- 弃子是高级战术

#### 4. 先后手

**先手的价值：**
- 掌握主动权
- 可以转向更大处
- 先手利必须走

**后手的代价：**
- 失去主动权
- 可能被对方抢先
- 后手要足够大

## 布局战略

### 布局原则

1. **先占角，后占边，最后中央**
2. **金角银边草肚皮**（角部效率最高）
3. **保持全局平衡**（实地与外势的平衡）
4. **子效最大化**（每手棋都要有明确目的）

### 现代布局趋势

**AI 时代的变化：**
- 点三三大量使用
- 早期接触战增多
- 更注重全局配合
- 实地与外势的界限模糊

**传统布局的精华：**
- 中国流：快速展开
- 小林流：坚实取地
- 村正妖刀：复杂战斗

## 中盘战略

### 战斗方向

**选择战斗的原则：**
1. 己方厚，对方薄 → 主动开战
2. 己方薄，对方厚 → 避免正面冲突
3. 双方都厚 → 慎重选择战场
4. 双方都薄 → 先补强自己

### 攻击方法

**攻击的目的不是吃棋，而是获利：**
- 通过攻击获得外势
- 通过攻击获得实地
- 通过攻击获得先手

**攻击的要点：**
- 不急于吃，保持压力
- 给对方留活路，但让其苦活
- 借攻击走厚自己

### 防守策略

**防守不是被动挨打：**
- 轻灵处理，不加重负担
- 必要时果断弃子
- 防守中蕴含反击机会

## 形势判断

### 判断要素

1. **确定实地**：已经围住的目数
2. **潜在实地**：有望围住的目数（打折扣）
3. **厚薄**：厚味相当于多少目
4. **先手权**：谁掌握主动权
5. **劫材**：劫材的多少和质量

### 判断公式（粗略）

```
形势 = 黑实地 + 黑潜力 + 黑厚味 - (白实地 + 白潜力 + 白厚味) - 贴目

> 0 → 黑优势
< 0 → 白优势
```

### AI 时代的形势判断

- AI 的胜率评估更精确
- 但人类仍需理解"为什么"
- 学习 AI 的判断逻辑，而非盲从数字

## 终盘策略

### 胜负处

**关键决策点：**
- 何时收官 vs 继续战斗
- 何时妥协 vs 强硬
- 何时冒险 vs 稳健

### 读秒策略

**读秒下的原则：**
1. 先走确定的大官子
2. 避免复杂变化
3. 保持冷静，不随手
4. 优势时简化局面
5. 劣势时制造混乱

## 棋力提升路径

### 业余 → 专业

1. **加强计算力**：死活题日常训练
2. **培养大局观**：多看高手棋谱
3. **实战经验**：多下慢棋，认真复盘
4. **理论学习**：学习围棋理论和经典棋谱

### 专业 → 高段

1. **AI 辅助训练**：用 AI 分析自己的棋
2. **深入研究**：专攻某一领域（布局/中盘/官子）
3. **比赛经验**：参加正式比赛积累实战经验
4. **心理训练**：提高比赛中的心理素质
