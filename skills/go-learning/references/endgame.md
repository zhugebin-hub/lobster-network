# 官子计算与收官技巧（Endgame Reference）

## 官子分类

### 按先后手分类

| 类型 | 定义 | 优先级 | 举例 |
|------|------|--------|------|
| **双先** | 双方都是先手 | 最高 | 双方先手扳粘 |
| **单先** | 一方先手，一方后手 | 次高 | 先手扳粘 vs 后手挡 |
| **逆收** | 后手方抢先手官子 | 第三 | 逆收 X 目 |
| **双后** | 双方都是后手 | 最低 | 后手 X 目 |

### 官子大小计算

**出入计算法：**
```
官子价值 = 黑方所得 + 白方所得（相对变化）
```

**计算方法：**
1. 计算黑走后的目数变化
2. 计算白走后的目数变化
3. 两者相加 = 官子总价值

## 常见官子型

### 一、基本官子

#### 1. 一路扳粘

```
    A B C
 2 O O O
 1 . X X
```
- **价值**：后手 2 目
- **要点**：双方都很大

#### 2. 二路扳粘

```
    A B C
 3 . . .
 2 X O .
 1 X O .
```
- **价值**：后手 4-6 目（视具体情况）
- **要点**：注意后续手段

#### 3. 大飞伸腿

- **价值**：后手 7-9 目
- **要点**：最大的后手官子之一

### 二、先手官子

#### 1. 先手扳粘

```
白先手扳 → 黑必须应 → 白先手粘
```
- **价值**：先手 2 目
- **优先级**：高于所有后手官子

#### 2. 先手利

- 利用对方缺陷的先手便宜
- 价值虽小但必须走

### 三、逆收官子

**逆收 X 目**：相当于后手 2X 目的价值
- 逆收 3 目 ≈ 后手 6 目
- 逆收 4 目 ≈ 后手 8 目

## 收官顺序

### 正确顺序

1. **双方先手官子**（全部走完）
2. **单方先手官子**（先手方走）
3. **大逆收官子**（逆收价值 ≥ 最大后手）
4. **大后手官子**（从大到小）
5. **小官子**（从大到小）
6. **单官**（填单官）

### 常见错误

❌ 先走后手大官子，漏掉先手官子
❌ 逆收价值判断错误
❌ 官子大小计算错误
❌ 顺序颠倒导致损失目数

## 形势判断

### 数目方法

**中国规则（数子法）：**
- 终局时数一方总子数
- 黑 185 子胜（贴 3¾子 = 7.5 目）

**日本规则（数目法）：**
- 计算双方目数差
- 黑贴 6.5 目

**实用方法：**
1. 计算双方确定的实地
2. 估算双方潜力（厚味、外势）
3. 比较差距

### 中盘形势判断

```
黑实地：XX 目
白实地：XX 目
黑潜力：XX 目
白潜力：XX 目
贴目：6.5 目

结论：黑/白 领先约 X 目
```

## 官子训练

### 练习题类型

1. **官子大小排序**：给出一组官子，按正确顺序排列
2. **目数计算**：计算指定官子的目数价值
3. **先后手判断**：判断某手棋是先手还是后手
4. **收官实战**：给出终盘局面，走出最优收官

### 训练建议

- 从简单的后手官子开始练习
- 逐步加入先手官子和逆收
- 实战对局后复盘官子阶段
- 使用 AI 验证官子判断
