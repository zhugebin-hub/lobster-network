# Travel Planner - 旅行规划技能

## 核心功能

### 1. 预算规划
- 交通（机票/火车/当地交通）
- 住宿（酒店/青旅/民宿）
- 餐饮（每日预算）
- 门票/活动
- 购物/备用金

### 2. 行程规划
- D1-Dn 详细安排
- 景点优先级排序
- 交通接驳时间
- 自由活动时间

### 3. 打包清单
- 证件类（身份证/护照/签证）
- 衣物类（根据目的地气候）
- 电子类（充电器/转换插头）
- 药品类（常用药/高原反应药）
- 其他（防晒霜/雨伞等）

### 4. 实用工具
- 预算计算器：`python scripts/budget_calculator.py`
- 打包清单生成：`python scripts/packing_list.py`

## 使用示例

**用户**: "我想去云南玩 5 天，预算 3000，帮我规划一下"

**处理流程**:
1. 确认出发地、时间、偏好
2. 调用预算计算器估算各项开支
3. 生成行程草案
4. 生成打包清单
5. 提供预订建议

## 注意事项

1. **旺季提醒**: 7-8 月、春节、国庆价格翻倍，提前预订
2. **高反预防**: 拉萨/稻城等高原地区，预留适应时间
3. **证件检查**: 国际旅行提前确认签证有效期
4. **保险建议**: 推荐购买旅行意外险
