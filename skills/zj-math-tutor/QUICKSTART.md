## 🔧 工具脚本

学习进度跟踪脚本位置：
```
/home/admin/.openclaw/workspace/skills/zj-math-tutor/scripts/track-progress.py
```

### 使用示例

```bash
# 记录章节学习
python3 scripts/track-progress.py add-chapter \
  --student "图图" \
  --chapter "八上第 2 章 特殊三角形" \
  --status learning \
  --proficiency 3

# 记录错题
python3 scripts/track-progress.py add-error \
  --student "图图" \
  --problem "-2² = 4" \
  --reason "混淆了 -2² 和 (-2)²" \
  --topic "有理数的乘方"

# 更新学习统计
python3 scripts/track-progress.py update-stats \
  --student "图图" \
  --hours 1.5 \
  --problems 10 \
  --correct 8

# 生成学习报告
python3 scripts/track-progress.py report --student "图图"
```

## 🎓 教学特色

### 苏格拉底式教学
> 不直接给答案，通过提问引导学生思考

**引导流程：**
1. 理解题意 → "题目要求什么？已知什么？"
2. 分析已知 → "从这个条件能得到什么？"
3. 联想知识 → "想到了哪个知识点？"
4. 尝试解法 → "你打算从哪里入手？"
5. 验证反思 → "答案合理吗？学到了什么？"

### 个性化学习
- 根据年级调整难度
- 根据掌握度推荐练习
- 针对薄弱点专项训练

### 错题价值最大化
- 分析错误原因（概念/计算/思路）
- 定位薄弱知识点
- 推荐同类练习
- 定期复习提醒

## 💡 使用建议

### 给学生
1. **预习时**：先自己阅读教材，再向助手提问
2. **解题时**：先独立思考 10 分钟，再请求引导
3. **错题时**：主动分析错误原因，不要只看答案
4. **提优时**：确保基础题 100% 正确后再挑战难题

### 给家长
1. 定期查看学习报告（每周一次）
2. 关注薄弱知识点，督促专项练习
3. 鼓励孩子独立思考，不要直接给答案
4. 重视错题本，定期回顾

### 给老师
1. 可作为课后辅导的补充工具
2. 查看学生错题分布，调整教学重点
3. 推荐学生使用提优题库
4. 收集学生常见问题，优化技能内容
