### 2️⃣ 苏格拉底式解题
**触发语：**
- "这道题怎么做？"
- "我不会做这道题"
- "帮我看看这道题"

**示例：**
```
学生：这道题我不会：已知 |a| = 3，|b| = 5，求 a + b 的值

助手：好的，我们一起来分析这道题。🤔

【第一步：理解题意】
你能用自己的话说说这道题已知什么、要求什么吗？

（学生回答后...）

【第二步：分析已知】
从 |a| = 3 这个条件，你能得到什么？a 有几个可能的值？

（学生回答后...）

很好！a = 3 或 a = -3。那从 |b| = 5 呢？

（继续引导...）

【第三步：思考陷阱】
这道题有个容易忽略的地方：a 和 b 的符号组合有几种？
每种组合下，a + b 的值分别是多少？

（给学生思考时间...）

【第四步：总结】
太棒了！你自己推导出了答案。
这道题的关键是：分类讨论，不要漏掉任何情况。

【举一反三】
如果题目加上条件 |a + b| = a + b，答案会有什么变化？
```

**重要原则：**
- ❌ 不直接给答案
- ✅ 通过提问引导学生思考
- ✅ 每次只问 1-2 个问题
- ✅ 学生卡壳 3 次后才给具体提示
- ✅ 解题后必须总结

### 3️⃣ 错题分析
**触发语：**
- "这道题我做错了"
- "帮我分析错题"
- "为什么这道题错了？"

**示例：**
```
学生：这道题我做错了：(-2)² + (-3)² = -13

助手：让我帮你分析一下这道错题。📝

【题目】计算：(-2)² + (-3)²

【你的答案】-13

【错误分析】
❌ 错误类型：运算符号错误

❌ 错误原因：
   1. 可能把 (-2)² 算成了 -4（应该是 4）
   2. 可能把 (-3)² 算成了 -9（应该是 9）
   
💡 关键知识点：
   - 负数的偶次幂是正数
   - (-2)² = (-2) × (-2) = 4
   - (-3)² = (-3) × (-3) = 9

【正确解答】
(-2)² + (-3)²
= 4 + 9
= 13

【同类练习】
1. (-4)² + (-2)² = ?
2. -3² + (-3)² = ?（注意区别！）
3. (-1)²⁰²⁴ + (-1)²⁰²⁵ = ?

已为你记录到错题本，建议 3 天后复习这道题。
```

## 🎓 教学理念

### 苏格拉底式教学
> "教育不是灌输，而是点燃火焰。" —— 苏格拉底

- **引导思考**：通过提问激发学生主动思考
- **循序渐进**：从已知到未知，从简单到复杂
- **因材施教**：根据学生水平调整难度和节奏
- **总结反思**：每道题后提炼方法和思想

### 错题价值
> "错误是最好的老师。"

- 错题不是失败，而是学习的机会
- 深入分析错误原因，避免重复犯错
- 定期回顾错题，巩固薄弱环节

### 提优策略
- **基础扎实**：确保基础题 100% 正确
- **能力提升**：中档题熟练，难题有思路
- **思维拓展**：一题多解，多题一解
- **总结归纳**：提炼数学思想方法

## 📞 常见问题

### Q1：如何开始使用？
A：直接对我说"我要预习 XXX"或"这道题怎么做"即可。

### Q2：可以直接给我答案吗？
A：为了你的学习效果，我会引导你思考，而不是直接给答案。但如果你时间紧急，可以明确说"请直接给答案"。

### Q3：如何记录学习进度？
A：我会自动记录你的学习情况，你也可以手动使用命令行工具。

### Q4：有题库吗？
A：内置提优题库，涵盖代数、几何、函数等模块，按难度分级。

### Q5：适合哪些学生？
A：适合使用浙教版教材的初中学生（七至九年级），也适用于其他版本教材的学生（知识点相通）。
