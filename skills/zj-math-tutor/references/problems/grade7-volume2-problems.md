# 七年级下册提优题库

## 一、平行线部分

### 【题 1】平行线中的角度计算
**难度：** ★★★☆☆
**知识点：** 平行线的性质、角平分线

**题目：**
如图，AB∥CD，直线 EF 分别交 AB、CD 于点 E、F，EG 平分∠BEF，若∠1 = 72°，求∠2 的度数。

```
        A_________E_________B
                   \
                    \
                     \ G
                      \
        C______________F_________D
                       /
                      /
                     /
                   ∠1
```

**提示链：**
1. 从 AB∥CD 能得到什么角的关系？
2. ∠1 和∠BEF 是什么关系？（提示：同旁内角）
3. EG 平分∠BEF，能得到什么？
4. ∠2 和哪个角相等？（提示：内错角）

**解答：**
```
解：∵ AB∥CD
    ∴ ∠BEF + ∠1 = 180°（两直线平行，同旁内角互补）
    ∴ ∠BEF = 180° - 72° = 108°
    
    ∵ EG 平分∠BEF
    ∴ ∠BEG = (1/2)∠BEF = 54°
    
    ∵ AB∥CD
    ∴ ∠2 = ∠BEG = 54°（两直线平行，内错角相等）
    
    答：∠2 = 54°
```

**总结：**
- 关键：利用平行线性质找角的关系
- 方法：先求大角，再用角平分线，最后找内错角
- 易错：混淆同位角、内错角、同旁内角

### 【题 2】平行线中的拐点模型
**难度：** ★★★★☆
**知识点：** 平行线、辅助线、角度计算

**题目：**
如图，AB∥CD，∠B = 25°，∠D = 42°，求∠E 的度数。

```
    A_________B
               \
                \
                 \
                  E
                 /
                /
               /
    C_________/D
```

**提示链：**
1. ∠B、∠D、∠E 不在同一个三角形中，怎么办？
2. 过点 E 作平行线，能创造什么条件？
3. 作了辅助线后，∠E 被分成哪两个角？
4. 这两个角分别等于什么？

**解答：**
```
解：过点 E 作 EF∥AB
    
    ∵ AB∥CD，EF∥AB
    ∴ EF∥CD（平行于同一直线的两直线平行）
    
    ∵ EF∥AB
    ∴ ∠BEF = ∠B = 25°（两直线平行，内错角相等）
    
    ∵ EF∥CD
    ∴ ∠DEF = ∠D = 42°（两直线平行，内错角相等）
    
    ∴ ∠BED = ∠BEF + ∠DEF = 25° + 42° = 67°
    
    答：∠E = 67°
```

**总结：**
- 模型：平行线间的拐点，过拐点作平行线
- 结论：∠E = ∠B + ∠D（开口向左的拐点）
- 拓展：开口向右的拐点，∠E + ∠B + ∠D = 360°

## 二、二元一次方程组部分

### 【题 3】方程组的特殊解法
**难度：** ★★★☆☆
**知识点：** 二元一次方程组、整体思想

**题目：**
已知方程组：
```
⎧ 2x + 3y = 7
⎩
⎨ 3x + 2y = 8
```
求 x + y 和 x - y 的值。

**提示链：**
1. 可以直接解方程组求 x、y，但有没有更简便的方法？
2. 观察两个方程的系数，有什么特点？
3. 两式相加能得到什么？
4. 两式相减能得到什么？

**解答：**
```
解法一（常规解法）：
    ⎧ 2x + 3y = 7    ①
    ⎩
    ⎨ 3x + 2y = 8    ②
    
    ①×3 得：6x + 9y = 21    ③
    ②×2 得：6x + 4y = 16    ④
    ③ - ④得：5y = 5
    ∴ y = 1
    
    把 y = 1 代入①得：2x + 3 = 7
                    2x = 4
                    x = 2
    
    ∴ x + y = 2 + 1 = 3
       x - y = 2 - 1 = 1

解法二（整体思想，更简便）：
    ① + ②得：5x + 5y = 15
            ∴ x + y = 3
    
    ② - ①得：x - y = 1
    
    ∴ x + y = 3，x - y = 1
```

**总结：**
- 关键：观察系数特点，用整体思想
- 方法：两式相加求 x+y，两式相减求 x-y
- 应用：当题目只要求 x+y 或 x-y 时，不必求出 x、y

### 【题 4】方程组的应用（方案选择）
**难度：** ★★★★☆
**知识点：** 二元一次方程组、方案比较

**题目：**
某班计划组织春游，需要租用客车。现有两种车型可选：
- A 型车：每辆租金 400 元，可载 45 人
- B 型车：每辆租金 300 元，可载 30 人

已知全班共 48 人，要求每辆车都坐满，有几种租车方案？哪种方案最省钱？

**提示链：**
1. 设什么为未知数？
2. "每辆车都坐满"转化成什么等式？
3. 人数限制是什么？
4. 如何比较哪种方案最省钱？

**解答：**
```
解：设租用 A 型车 x 辆，B 型车 y 辆
    
    根据题意：45x + 30y = 48
    
    化简：3x + 2y = 3.2
    
    等等，这个方程的解不是整数，说明题目数据需要调整。
    
    重新审题：48 人，要求每辆车坐满
    
    45x + 30y = 48
    3x + 2y = 4.8（不是整数）
    
    说明 48 人无法恰好坐满若干辆 A 型车和 B 型车。
    
    修改题目：假设全班 60 人
    
    45x + 30y = 60
    3x + 2y = 4
    
    ∵ x、y 是非负整数
    ∴ 当 x = 0 时，y = 2
       当 x = 1 时，3 + 2y = 4，y = 0.5（舍去）
       当 x ≥ 2 时，3x ≥ 6 > 4（舍去）
    
    ∴ 只有一种方案：租 0 辆 A 型车，2 辆 B 型车
       费用：300 × 2 = 600 元
    
    若题目改为"至少载 48 人"，则需要列不等式。
```

**总结：**
- 关键：找等量关系，注意未知数的取值范围（非负整数）
- 方法：列方程→求整数解→计算费用→比较
- 易错：忽略"每辆车坐满"的限制条件

## 三、整式的乘除部分

### 【题 5】乘法公式的灵活运用
**难度：** ★★★★☆
**知识点：** 完全平方公式、平方差公式、整体思想

**题目：**
已知 a + b = 5，ab = 3，求下列各式的值：
(1) a² + b²
(2) (a - b)²
(3) a² - b²

**提示链：**
1. a² + b² 与 (a + b)² 有什么关系？
2. (a - b)² 展开后是什么？与 a² + b²、ab 有什么关系？
3. a² - b² 能用公式分解吗？需要知道什么？
4. 如何求 a - b？

**解答：**
```
解：(1) a² + b² = (a + b)² - 2ab
           = 5² - 2×3
           = 25 - 6
           = 19
    
    (2) (a - b)² = a² - 2ab + b²
                = (a² + b²) - 2ab
                = 19 - 2×3
                = 19 - 6
                = 13
    
    或：(a - b)² = (a + b)² - 4ab
                = 25 - 12
                = 13
    
    (3) a² - b² = (a + b)(a - b)
    
    需要求 a - b：
    ∵ (a - b)² = 13
    ∴ a - b = ±√13
    
    ∴ a² - b² = (a + b)(a - b) = 5 × (±√13) = ±5√13
```

**总结：**
- 关键公式：
  - a² + b² = (a + b)² - 2ab
  - (a - b)² = (a + b)² - 4ab
  - a² - b² = (a + b)(a - b)
- 方法：整体代入，不必求出 a、b
- 易错：a - b 有正负两个值

## 四、因式分解部分

### 【题 6】因式分解的综合应用
**难度：** ★★★★☆
**知识点：** 因式分解、整体思想、分类讨论

**题目：**
分解因式：
(1) x⁴ - 16
(2) (x + y)² - 4(x + y) + 4
(3) x² - y² - 2y - 1

**提示链：**
1. x⁴ - 16 能用平方差公式吗？分解一次够了吗？
2. 第 (2) 题中，把 (x+y) 看作一个整体，是什么形式？
3. 第 (3) 题，后三项能组成完全平方吗？

**解答：**
```
解：(1) x⁴ - 16 = (x²)² - 4²
             = (x² + 4)(x² - 4)
             = (x² + 4)(x + 2)(x - 2)
    
    (2) (x + y)² - 4(x + y) + 4
        令 t = x + y，则原式 = t² - 4t + 4 = (t - 2)²
        ∴ 原式 = (x + y - 2)²
    
    (3) x² - y² - 2y - 1
        = x² - (y² + 2y + 1)
        = x² - (y + 1)²
        = [x + (y + 1)][x - (y + 1)]
        = (x + y + 1)(x - y - 1)
```

**总结：**
- 方法：
  - (1) 连续用平方差公式
  - (2) 换元法（整体思想）
  - (3) 分组分解，构造公式
- 关键：观察结构，选择合适方法
- 原则：分解要彻底

## 五、分式部分

### 【题 7】分式的化简求值
**难度：** ★★★☆☆
**知识点：** 分式运算、因式分解、代入求值

**题目：**
先化简，再求值：
```
(x² - 4)/(x² + 4x + 4) ÷ (x - 2)/(x + 2)，其中 x = 3
```

**提示链：**
1. 分子分母能分解因式吗？
2. 除法转化成什么运算？
3. 约分后得到什么？
4. 代入 x = 3 计算

**解答：**
```
解：原式 = (x+2)(x-2)/(x+2)² · (x+2)/(x-2)
        = (x+2)(x-2)(x+2) / [(x+2)²(x-2)]
        = 1
    
    当 x = 3 时，原式 = 1
```

**总结：**
- 步骤：分解→转化→约分→代入
- 关键：先化简再代入，不要直接代入
- 注意：要考虑分式有意义的条件（x≠-2 且 x≠2）

### 【题 8】分式方程的应用（工程问题）
**难度：** ★★★★☆
**知识点：** 分式方程、工程问题、检验

**题目：**
某工程队承接了一项工程，甲队单独做需要 30 天完成，乙队单独做需要 20 天完成。现在两队合作，中途甲队因事离开几天，结果共用 12 天完成。问甲队离开了几天？

**提示链：**
1. 甲、乙的工作效率分别是多少？
2. 设甲队离开了 x 天，甲队实际工作了几天？
3. 甲完成的工作量 + 乙完成的工作量 = ？
4. 解出答案后要检验吗？

**解答：**
```
解：设甲队离开了 x 天，则甲队工作了 (12-x) 天
    
    甲的工作效率：1/30
    乙的工作效率：1/20
    
    甲完成的工作量：(12-x)/30
    乙完成的工作量：12/20 = 3/5
    
    等量关系：甲工作量 + 乙工作量 = 1
    (12-x)/30 + 3/5 = 1
    (12-x)/30 = 2/5
    12 - x = 12
    x = 0
    
    检验：x = 0 符合题意
    
    答：甲队离开了 0 天（即甲队全程参与）
    
    验证：甲 12 天完成 12/30 = 2/5
          乙 12 天完成 12/20 = 3/5
          合计：2/5 + 3/5 = 1 ✓
```

**总结：**
- 关键：工作效率 × 工作时间 = 工作量
- 方法：设未知数→列方程→解方程→检验
- 易错：忘记检验，搞错工作时间

## 六、数据统计部分

### 【题 9】统计图表的综合分析
**难度：** ★★★☆☆
**知识点：** 统计图、频数、频率、数据分析

**题目：**
某校为了解七年级学生的课外阅读情况，随机调查了部分学生，得到如下不完整的统计图表：

| 阅读时间（小时/周） | 频数 | 频率 |
|-------------------|------|------|
| 0-2               | 10   | 0.1  |
| 2-4               | 20   | 0.2  |
| 4-6               | a    | 0.35 |
| 6-8               | 25   | b    |
| 8-10              | 10   | 0.1  |

(1) 求 a、b 的值
(2) 补全频数直方图
(3) 若该校七年级共有 800 名学生，估计每周阅读时间不少于 6 小时的学生有多少人？

**提示链：**
1. 频率之和等于多少？
2. 如何用频率求总数？
3. 频数 = 总数 × 频率
4. 用样本估计总体

**解答：**
```
解：(1) 频率之和 = 1
    ∴ 0.1 + 0.2 + 0.35 + b + 0.1 = 1
    ∴ b = 0.25
    
    总人数 = 10 ÷ 0.1 = 100 人
    ∴ a = 100 × 0.35 = 35
    
    (2) 补全直方图（略）
    
    (3) 样本中不少于 6 小时的频率 = 0.25 + 0.1 = 0.35
    估计总体：800 × 0.35 = 280 人
    
    答：估计每周阅读时间不少于 6 小时的学生有 280 人。
```

**总结：**
- 关键公式：频率 = 频数÷总数
- 方法：用样本频率估计总体
- 易错：频率之和为 1，计算要准确

## 使用建议

### 教学流程
1. **呈现题目**：让学生先独立思考 5-10 分钟
2. **引导思考**：按提示链逐步提问
3. **学生尝试**：鼓励学生说出思路
4. **规范解答**：展示完整过程
5. **总结反思**：提炼方法和思想

### 难度分级
- ★★★☆☆：基础提优（适合中等生）
- ★★★★☆：能力提优（适合中上生）
- ★★★★★：竞赛提优（适合优等生）

### 变式训练
每道题后可设计变式：
- 改变已知条件
- 改变求解目标
- 逆向思考
- 一般化推广
