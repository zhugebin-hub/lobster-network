## 💡 答辩 Q&A 准备

**Q1: 简报功能的使用场景？**
> A: 预约成功后，用户需要确认凭证。简报包含完整的预约信息、位置指引、注意事项，适合打印张贴或存档。Word 格式方便正式交付和二次编辑。

**Q2: Word 文档的格式规范？**
> A: 字体统一使用仿宋，符合中文办公文档规范。适用于周报、日报、报告等正式场景。

**Q3: 如何接入学校真实系统？**
> A: 我们设计了模块化架构，只需替换数据层接口。已与学校信息中心初步沟通，支持标准 API 对接。预计下周接入浙江工商大学宜搭平台。

**Q4: 技术壁垒是什么？**
> A: 中文自然语言解析的准确率、智能推荐算法的优化、快速部署能力，以及完整的文档生成链（预约→简报→Word）是我们的核心优势。
