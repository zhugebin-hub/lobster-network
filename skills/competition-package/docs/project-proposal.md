# 会议室预约虾 - 项目申报书

## 赛道二 | AI 合伙人

---

## 一、项目概述

### 1.1 项目名称
**会议室预约虾**（Meeting Room Shrimp）

### 1.2 一句话介绍
用自然语言一句话完成会议室预约，替代人工操作 UI 流程的 AI 自动化系统。

### 1.3 核心价值
- **替代岗位**：行政助理/教务员的会议室预约管理工作
- **效率提升**：从 3-5 分钟手动操作 → 10 秒语音/文字指令
- **7×24 小时**：无需人工值守，自动处理预约请求

---

## 二、痛点分析

### 2.1 现状问题
| 场景 | 痛点 | 耗时 |
|------|------|------|
| 学生预约自习室 | 需要登录系统→选择楼栋→查看空闲→填写信息→提交确认 | 3-5 分钟 |
| 社团预约会议室 | 需要联系管理员→确认时间→填写申请表→等待审批 | 1-3 天 |
| 教师预约研讨室 | 需要打电话确认→现场登记→手动排期 | 10-15 分钟 |

### 2.2 核心痛点
1. **流程繁琐**：需要多次点击、填写表单、确认信息
2. **信息分散**：不同楼栋、不同类型的房间在不同系统
3. **时间冲突**：手动查询容易遗漏，导致重复预约
4. **审批等待**：需要人工审核，响应慢

---

## 三、解决方案

### 3.1 产品形态
```
用户输入："给我预约周三下午的五人会议室"
         ↓
   自然语言理解 (NLU)
         ↓
   解析：时间=周三下午，人数=5，类型=会议室
         ↓
   智能匹配算法
         ↓
   推荐：小型会议室 D102 (行政楼 1 楼，6 人容量)
         ↓
   自动提交预约
         ↓
   返回：预约成功！预约号 BK1774460446696
```

### 3.2 技术架构

```
┌─────────────────────────────────────────────────────┐
│                    用户交互层                        │
│         钉钉/微信/网页对话框 (自然语言输入)            │
└─────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│                  AI 理解层 (NLU)                      │
│   • 时间解析：周三下午 → 2026-03-31 14:00-18:00      │
│   • 人数解析：五人 → capacity=5                      │
│   • 类型解析：会议室 → roomType=会议室               │
└─────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│                  智能匹配层                           │
│   • 容量过滤：capacity >= 5                          │
│   • 类型过滤：roomType = 会议室                      │
│   • 时间匹配：availableSlots 查询                    │
│   • 推荐排序：容量最接近优先                         │
└─────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│                  执行层                              │
│   • 预约提交：写入 bookings.json / 调用学校 API       │
│   • 冲突检测：防止重复预约                           │
│   • 通知反馈：返回预约号、房间信息、时间             │
└─────────────────────────────────────────────────────┘
```

### 3.3 核心功能

| 功能 | 说明 | 技术实现 |
|------|------|----------|
| 自然语言解析 | 理解"周三下午五人会议室" | 正则匹配 + 中文数字转换 |
| 智能推荐 | 自动选择最优房间 | 容量差值最小化算法 |
| 冲突检测 | 防止重复预约 | 预约记录查询 |
| 预约管理 | 查看/取消我的预约 | bookings.json 持久化 |
| **预约简报** | **自动生成预约确认简报** | **Markdown + Word 文档** ⭐ |
| **MD 转 Word** | **简报自动转换为 Word** | **md2word-cn 技能** ⭐ |
| **钉钉提醒** | **定时发送参会提醒** | **Cron + 钉钉消息** ⭐ |
| 多校区支持 | 下沙/钱江湾切换 | 数据源配置化 |
