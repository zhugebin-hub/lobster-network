### 3. 智能容量匹配 ⭐

**功能**: 避免容量浪费，智能匹配需求

**优化前**:
```javascript
// 简单过滤：容量 >= 需求
if (room.capacity < parsed.capacity) continue;
```

**优化后**:
```javascript
// 智能匹配：避免过大浪费
if (room.capacity < parsed.capacity * 0.8) continue;  // 最多小 20%
if (room.capacity > parsed.capacity * 2) continue;    // 不超过 2 倍
```

**效果**:
- 10 人需求 → 推荐 8-20 人房间
- 避免 10 人订 80 人报告厅的浪费
- 提高房间利用率

### 4. 推荐评分系统 ⭐

**功能**: 多维度评分，智能排序

**评分维度**:
| 维度 | 分值 | 说明 |
|------|------|------|
| 热门房间 | +30 | 历史使用率高 |
| 用户偏好 | +50 | 用户常订房间 |
| 容量匹配 | +20 | 容量接近需求 |
| 时段偏好 | +20 | 用户偏好时段 |

**实现**:
```javascript
let score = 0;

// 热门房间加分
if (popularRooms.includes(room.name)) score += 30;

// 用户偏好房间加分
if (userPref && userPref.favoriteRooms.includes(room.name)) score += 50;

// 容量匹配度
const capacityDiff = Math.abs(room.capacity - parsed.capacity);
score += Math.max(0, 20 - capacityDiff * 2);

// 用户偏好时段加分
if (userPref && userPref.favoriteSlot === parsed.slot) score += 20;
```

**效果**:
- 综合评分排序
- 优先推荐最优选择
- 个性化推荐
