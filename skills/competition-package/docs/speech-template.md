## 📋 用户指令下发模板

### 如何给我（AI 助手）下发指令

**格式**:
```
[任务类型] + [具体内容] + [要求/限制]
```

**示例**:

**1. 生成文档**
```
帮我写一份项目申报书，要求包含痛点分析、解决方案、市场规模，不超过 5000 字。
```

**2. 优化代码**
```
优化会议室预约脚本，增加用户偏好学习功能，基于历史预约记录推荐房间。
```

**3. 分析数据**
```
分析 bookings.json 中的 1033 条预约记录，统计热门房间 TOP10、活跃用户、时间段分布。
```

**4. 生成 PPT**
```
生成 12 页路演 PPT 大纲，包含封面、痛点、解决方案、演示、测试、市场、商业，每页配演讲词。
```

**5. 打包提交**
```
将所有比赛材料打包成 ZIP，包含文档、脚本、数据文件，生成提交清单。
```

**6. 模拟答辩**
```
模拟评委提问，生成 10 个可能的答辩问题和标准答案。
```

## 🎯 演讲技巧提示

### 语速控制
- 正常语速：180 字/分钟
- 5 分钟演讲：约 900 字
- 本模板：约 850 字（留有余地）

### 停顿技巧
- 金句前后：停顿 2-3 秒
- 数字强调：放慢语速
- 问题转换：停顿 1 秒

### 肢体语言
- 手势：自然，不要过多
- 眼神：轮流接触三位评委
- 站姿：双脚与肩同宽，站稳

### 应急处理
- 忘词：看 PPT 提示，不要慌
- 演示失败：切换备用录屏
- 时间超限：加速完成，保证结尾完整
