# 课程教学分析技能

接收课程期末材料，完成作品评分、教学分析、报告生成全流程。

## 输入材料

通常来自 `/shared/` 目录或用户直接提供：

| 文件 | 说明 |
|------|------|
| 期末汇报PPT压缩包 | 含各团队汇报PPT（.pptx），可能含.zip附件 |
| 班级名单.xlsx | 学生姓名、序号、团队、作品名、队长、专业等 |
| 课程学习心得.txt | 学生课程反思，用于教学成效分析 |

## 处理流程

### 1. 解压与提取

```bash
# GBK编码ZIP解压（macOS创建的中文ZIP常见编码问题）
bsdtar -xf "期末汇报-2026春-XXX.zip" -C 期末汇报_extracted/

# 提取所有PPT文本
python3 scripts/extract_ppt_text.py <ppt_dir> <output_json>
```

提取时注意：
- macOS创建的ZIP文件中文文件名可能是GBK编码，用 `bsdtar` 解压
- 用 `python-pptx` 提取PPT文本，限制每文件3000字符避免过长
- 保存为JSON供后续分析使用

### 2. 读取班级名单

```bash
python3 -c "
import openpyxl
wb = openpyxl.load_workbook('<名单.xlsx>')
ws = wb[wb.sheetnames[0]]
for row in ws.iter_rows(min_row=1, max_row=ws.max_row, values_only=False):
    vals = [str(c.value) if c.value is not None else '' for c in row]
    print(' | '.join(vals))
"
```

提取关键信息：团队名称、作品名称、成员、队长、专业分布。

### 3. 评分标准

按五维标准对每个团队作品打分（总分100）：

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 功能完整性 | 25% | 核心功能是否齐全，业务流程是否闭环 |
| 技术实现 | 25% | 技术栈选择、代码质量、架构设计 |
| UI/UX设计 | 20% | 界面美观度、交互体验、设计一致性 |
| 创新与实用价值 | 15% | 创意独特性、市场需求、应用场景 |
| 文档与汇报质量 | 15% | PPT逻辑性、内容完整性、表达清晰度 |

等级划分：
- 优秀（90-100）：功能全面+技术深入+创新突出
- 良好（85-89）：功能完整+技术合理+有一定创新
- 中等（80-84）：功能基本完整+技术实现一般
- 及格（75-79）：功能简单+技术实现薄弱
- 不及格（<75）：功能过于简单+技术实现明显不足

### 4. 教学成效分析

从学习心得中提取核心收获，统计各维度提及频率：

```
收获维度 → 提及次数 → 典型表述
```

分析维度包括：
- 从零到一的开发能力
- AI辅助开发体验
- 前后端交互理解
- 调试能力与逻辑思维
- 云开发技能
- 与AI沟通的能力
- 技术普惠认知
- 产品思维培养

### 5. 生成报告

报告结构（详见 `references/report-outline.md`）：

1. 执行摘要（核心数据概览）
2. 优秀团队作品深度剖析（TOP 5）
3. 良好作品精选分析
4. 作品主题与技术分析
5. 课程学习心得深度分析
6. 课程教学质量分析
7. 附录：完整评分表 + 评分标准说明
8. 改进建议与未来展望

输出格式：
- **Markdown**：完整分析报告
- **Word（.docx）**：使用 `python-docx` 生成，含表格、标题层级
- **PPT（.pptx）**：14页汇报PPT，含作品展示、数据图表

### 6. 协作分发

如需多智能体协作：

```bash
# 打包所有材料
zip 分析报告_打包.zip *.md *.docx *.pptx *.txt *.xlsx

# 通过NFS共享目录通知其他智能体
cp 分析报告_打包.zip /shared/
# 发送消息到 /shared/messages/from-lobster/
```

## 输出文件

| 文件 | 说明 |
|------|------|
| 课程分析报告.md | 完整Markdown报告 |
| 课程分析报告.docx | Word格式报告 |
| 课程教学分析汇报.pptx | 汇报PPT |
| 分析报告_打包.zip | 所有材料打包 |

## 注意事项

- PPT文本提取时注意编码问题（GBK/UTF-8）
- 评分保持客观，基于PPT内容而非主观印象
- 未提交作品的团队标注"未评分"而非打0分
- 学习心得分析关注高频关键词和典型表述
- 报告中的表格使用 `python-docx` 的 Table API 生成
