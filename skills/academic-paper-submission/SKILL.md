# 📝 Academic Paper Submission Workflow - 学术论文投稿流程

帮助研究者完成从论文定稿到成功发表的全流程管理。

## ✨ 功能

- **🎯 期刊/会议选择** - 根据研究领域和影响因子推荐合适的投稿目标
- **📋 投稿材料清单** - 生成完整的投稿所需材料清单
- **✉️ 投稿信模板** - 提供 Cover Letter 模板和写作指南
- **🔍 审稿流程跟踪** - 跟踪投稿状态和审稿进度
- **📊 投稿状态管理** - 管理多篇论文的投稿状态
- **📝 回复审稿意见** - 提供 Response Letter 写作指导

## 🔧 使用方法

### 1. 期刊选择建议

```
请帮我推荐适合投稿的期刊，我的论文信息：
- 研究领域：[填写领域]
- 关键词：[填写关键词]
- 期望影响因子：[填写范围]
- 开放获取偏好：[是/否]
```

### 2. 生成投稿材料清单

```
我需要准备 [期刊名称] 的投稿材料，请列出清单。
```

### 3. 生成投稿信模板

```
请帮我生成一封 Cover Letter，论文信息：
- 标题：[填写标题]
- 主要发现：[简述创新点]
- 推荐审稿人：[可选]
- 回避审稿人：[可选]
```

### 4. 跟踪投稿状态

```
更新投稿状态：
- 论文标题：[填写]
- 投稿期刊：[填写]
- 当前状态：[Submitted/Under Review/Revision/Accepted/Rejected]
- 投稿日期：[填写]
```

### 5. 回复审稿意见

```
我收到了审稿意见，请帮我草拟回复：
- 审稿人 1 意见：[粘贴意见]
- 我的回应要点：[简述]
```

## 📊 投稿状态模板

| 状态 | 说明 | 预计时间 |
|------|------|---------|
| Submitted | 已提交 | - |
| With Editor | 编辑处理中 | 1-2 周 |
| Under Review | 审稿中 | 4-12 周 |
| Revision Required | 需要修改 | - |
| Accepted | 已接收 | - |
| Rejected | 被拒绝 | - |

## 📋 标准投稿材料清单

- [ ] 主文稿 (Manuscript)
- [ ] 摘要 (Abstract)
- [ ] 图表 (Figures & Tables)
- [ ] 补充材料 (Supplementary Materials)
- [ ] 投稿信 (Cover Letter)
- [ ] 推荐审稿人 (Suggested Reviewers)
- [ ] 利益冲突声明 (Conflict of Interest)
- [ ] 作者贡献声明 (Author Contributions)
- [ ] 数据可用性声明 (Data Availability)
- [ ] 伦理审批证明 (Ethics Approval, 如适用)

## ✉️ Cover Letter 模板

```
[日期]

Dear Editor [编辑姓名],

We are pleased to submit our manuscript entitled "[论文标题]" for consideration 
in [期刊名称].

[研究背景 - 2-3 句]

[主要发现 - 2-3 句]

[创新点和意义 - 2-3 句]

We believe this work is particularly relevant to the readership of [期刊名称] 
because [说明相关性].

所有作者已阅读并同意投稿，不存在利益冲突。

We suggest the following potential reviewers:
- [姓名], [机构], [邮箱]

Thank you for your consideration.

Sincerely,
[通讯作者姓名]
[机构]
[联系方式]
```

## 💡 投稿建议

### 选择期刊的考虑因素
1. **研究领域匹配度** - 确保期刊范围与论文主题相符
2. **影响因子** - 根据研究质量选择合适的 IF 范围
3. **审稿周期** - 考虑时间要求
4. **开放获取政策** - 根据经费和偏好选择
5. **发表费用** - 了解 APC (Article Processing Charge)

### 避免常见错误
- ❌ 未按照期刊格式要求准备稿件
- ❌ Cover Letter 过于模板化，缺乏针对性
- ❌ 推荐不合适的审稿人
- ❌ 未充分说明研究创新性
- ❌ 忽略利益冲突声明

### 应对拒稿
1. 仔细阅读审稿意见
2. 评估是否需要补充实验
3. 修改后转投其他期刊
4. 如有异议可考虑申诉

## 📈 投稿时间线参考

```
第 1 周：选择目标期刊
第 2 周：准备投稿材料
第 3 周：提交稿件
第 4-8 周：等待审稿
第 9-12 周：收到审稿意见
第 13-16 周：修改并返回
第 17-20 周：最终决定
```
