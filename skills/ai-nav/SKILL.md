# AI 导航技能

图图老师精选 AI 工具导航，帮助用户快速找到合适的 AI 网站和工具。

## 核心能力

1. **场景化推荐** - 根据用户需求（写代码、生成图片、做视频等）推荐合适的工具
2. **分类查询** - 按 16 个分类快速检索工具
3. **工具说明** - 解释每个工具的主要用途

## 使用方式

### 1. 场景化推荐

当用户描述需求时，匹配对应分类并推荐工具：

```
用户："我想生成一些图片"
→ 推荐：🖼️ AI 文生图分类（MidJourney、FLUX、LiblibAI 等）

用户："需要写代码的 AI 工具"
→ 推荐：💻 AI 编程分类（GitHub Copilot、Cursor+Zion、智谱 AI Code 等）

用户："有什么可以做视频的工具？"
→ 推荐：🎬 AI 视频分类（可灵 Kling、即梦 AI、Runway 等）
```

### 2. 分类查询

用户可以直接询问某个分类：

```
用户："有哪些 AI 大模型？"
→ 列出 🤖 AI 大模型 分类下的所有工具

用户："龙虾生态有哪些工具？"
→ 列出 🦞 龙虾生态 分类下的所有工具
```

### 3. 工具查询

用户询问特定工具时，提供说明和链接：

```
用户："MidJourney 是做什么的？"
→ 说明：AI 文生图工具，擅长艺术创作
→ 链接：https://www.midjourney.com/

用户："ClawHub 怎么用？"
→ 说明：OpenClaw 技能市场，可以搜索、安装、发布技能
→ 链接：https://clawhub.ai/
```

## 推荐策略

### 优先级规则

1. **国内可访问优先** - 优先推荐国内工具（Kimi、智谱、文心等）
2. **免费/低成本优先** - 优先推荐有免费额度的工具
3. **热门工具优先** - 同一分类内按热门推荐顺序

## 数据源

工具数据存储在 `references/tools.json`，包含：
- 分类名称
- 工具名称
- 工具 URL
- 工具图标（首字）

如需更新工具列表，直接编辑该 JSON 文件。

## 注意事项

1. **链接验证** - 推荐时确保 URL 有效
2. **访问性说明** - 如知道某工具需要特殊网络条件，应提醒用户
3. **持续更新** - AI 工具生态变化快，定期更新工具列表
4. **龙虾生态优先** - 当用户询问 OpenClaw 相关工具时，优先推荐 🦞 龙虾生态 分类
