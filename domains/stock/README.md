## 模块概述

炒股模块是小龙虾网络的应用层模块之一，基于 Signal Arena 虚拟炒股平台，实现多智能体协作的股票交易和学习系统。

### 核心理念

**对话即交易**：每个智能体通过对话产生交易决策，多智能体协作产生超越单个智能体的交易策略。

**世界是市场**：市场是多智能体交互的涌现结果，每个智能体的交易行为都在"渲染"市场状态。

**交易即学习**：每笔交易都是学习机会，通过世界地图记录交易知识碎片和涌现洞察。

## 涌现机制

### 涌现场景

| 场景 | 描述 | 涌现值 |
|------|------|--------|
| 策略碰撞 | 不同交易策略的对话产生新策略 | 高 |
| 市场洞察 | 多智能体分析产生市场规律认知 | 高 |
| 风险控制 | 风险识别和应对策略的涌现 | 中 |
| 组合优化 | 分散投资策略的涌现 | 中 |

### 涌现计算示例

```python
# 虾尔（技术分析）与诸葛马（基本面分析）对话
agent1 = {
    "perspective": "技术分析",
    "knowledge_base": "K 线形态 均线系统 成交量"
}

agent2 = {
    "perspective": "基本面分析",
    "knowledge_base": "财务报表 估值模型 行业研究"
}

# 对话产生新策略
result = calculate_emergence_score(
    agent1, agent2,
    dialogue_rounds=6,
    new_chunks=2,
    total_chunks=4
)

# 涌现等级：high（高涌现）
# 解锁宝藏：技术 + 基本面融合策略
```

## 参与方式

### 智能体角色

| 角色 | 能力 | 职责 |
|------|------|------|
| 交易员 | 技术分析、快速决策 | 执行交易、仓位管理 |
| 分析师 | 基本面研究、行业分析 | 选股建议、风险评估 |
| 策略师 | 策略设计、回测优化 | 策略开发、参数调优 |
| 风控官 | 风险控制、合规检查 | 仓位限制、止损设置 |

### 对话流程

```
1. 分析师提供选股建议（基本面分析）
2. 交易员确定入场时机（技术分析）
3. 策略师评估策略有效性（回测验证）
4. 风控官检查风险敞口（仓位控制）
5. 多智能体对话产生最终决策（涌现）
6. 执行交易并记录到世界地图
7. 定期复盘，优化策略
```
