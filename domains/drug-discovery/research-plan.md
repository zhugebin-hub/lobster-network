# 食物过敏防治药物研制 · 详细研究计划

> 版本：V1.0 | 日期：2026-07-09 | 发起人：诸葛斌

## 1. 项目概述

### 1.1 科学问题
食物过敏（Food Allergy）是免疫系统对食物蛋白的异常反应，全球患病率持续上升。当前治疗以回避和急救为主，缺乏根治性药物。本项目利用 AI 多智能体协作，加速从靶点发现到候选药物评估的全流程。

### 1.2 技术路线
```
过敏原知识图谱 → 靶点识别 → 虚拟筛选 → 先导优化 → ADMET评估 → 临床前评估
                                                              ↓
                                                     免疫疗法设计 → 临床方案
```

### 1.3 创新点
- 多智能体协作药物发现（小龙虾网络6+节点并行）
- 食物过敏专属知识图谱（10万+节点）
- AI驱动的靶点-化合物-临床全链路评估
- 学习+研究并行模式（60道专业题库 + 实例验证）

| # | 靶点 | 蛋白 | 作用机制 | 评分 | 治疗策略 |

3. **口服耐受通路**：口服抗原→Treg诱导→FOXP3→免疫耐受

## 3. Phase 2: 计算筛选 (Day 8-18)

### 3.1 虚拟筛选管线
**负责人**：qoder 小龙虾

**管线流程**：
```
化合物库准备 → Lipinski过滤 → 药物相似性筛选 → 分子对接 → 结合能排序 → 簇分析
```

**化合物库**：
- PubChem：1.1亿化合物
- ZINC：7.5亿化合物（可购买子集）
- DrugBank：已上市药物（重定位）

**对接参数**：
- 软件：AutoDock Vina
- 搜索空间：30×30×30 Å
- 对接模式：exhaustiveness=32
- 评分阈值：≤ -8.0 kcal/mol

### 3.2 候选化合物优化
**负责人**：诸葛虾

**优化方法**：
- 构效关系（SAR）分析
- RDKit 子结构搜索
- MM-PBSA 结合自由能计算
- 分子动力学模拟（50 ns）

### 3.3 ADMET预测
**负责人**：诸葛斌 + qoder

**ADMET五维评估**：
| 维度 | 指标 | 工具 | 阈值 |
|------|------|------|------|
| 吸收(A) | Caco-2渗透性 | pkCSM | > -5.15 |
| 分布(D) | 血浆蛋白结合 | pkCSM | < 90% |
| 代谢(M) | CYP450抑制 | RDKit | 无抑制 |
| 排泄(E) | 清除率 | pkCSM | > 0.5 |
| 毒性(T) | hERG抑制 | pkCSM | 无抑制 |

## 4. Phase 3: 评估与写作 (Day 19-30)

**负责人**：诸葛马 + 诸葛斌
