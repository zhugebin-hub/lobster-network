## 一、过敏机制核心通路

### 1. Th2 免疫应答通路

```
过敏原进入 → 树突状细胞呈递 → Naive T细胞 → Th2分化
    ↓
GATA3 (转录因子) → IL-4, IL-5, IL-13 分泌
    ↓
B细胞类别转换 → IgE产生 → 结合肥大细胞/嗜碱性粒细胞
```

**关键靶点**:
- GATA3: Th2分化的主调控因子
- STAT6: IL-4/IL-13信号传导
- IL-4: Th2细胞因子
- IL-13: Th2细胞因子

### 2. IgE 信号通路

```
过敏原交联IgE → FCεRI受体激活 → SYK磷酸化
    ↓
肥大细胞脱颗粒 → 组胺、白三烯、前列腺素释放
    ↓
早期反应: 血管扩张、平滑肌收缩、黏液分泌
晚期反应: 嗜酸性粒细胞浸润、组织炎症
```

**关键靶点**:
- IgE: 免疫球蛋白E
- FCεRI: 高亲和力IgE受体
- SYK: 脾酪氨酸激酶
- Orai1: CRAC通道（钙内流）

### 3. 上皮屏障通路

```
过敏原穿透 → 上皮细胞释放TSLP, IL-25, IL-33
    ↓
激活2型固有淋巴细胞 (ILC2)
    ↓
Th2炎症反应放大
```

**关键靶点**:
- TSLP: 胸腺基质淋巴细胞生成素
- IL-25: IL-17家族细胞因子
- IL-33: IL-1家族细胞因子
- 紧密连接蛋白: 上皮完整性标志物

## 二、已验证药物靶点

### 靶点1: IgE

| 属性 | 详情 |
|------|------|
| 靶点名称 | Immunoglobulin E (IgE) |
| 基因 | IGHG1 |
| 类型 | 抗体 |
| 作用机制 | 阻断IgE与FCεRI结合 |
| 已上市药物 | Omalizumab (Xolair) |
| 在研药物 | Ligelizumab, GNC 035G |
| 临床效果 | 降低游离IgE水平，减少过敏反应 |
| 局限 | 价格昂贵（$10,000+/年），部分患者无效 |

### 靶点2: IL-4Rα

| 属性 | 详情 |
|------|------|
| 靶点名称 | Interleukin-4 Receptor Alpha |
| 基因 | IL4RA |
| 类型 | 细胞因子受体 |
| 作用机制 | 阻断IL-4和IL-13信号传导 |
| 已上市药物 | Dupilumab (Dupixent) |
| 在研药物 | Itepekimab |
| 临床效果 | 改善特应性皮炎，食物过敏在研 |
| 局限 | 注射给药，长期安全性待观察 |

### 靶点3: TSLP

| 属性 | 详情 |
|------|------|
| 靶点名称 | Thymic Stromal Lymphopoietin |
| 基因 | TSLP |
| 类型 | 细胞因子 |
| 作用机制 | 阻断上游上皮信号 |
| 已上市药物 | Tezepelumab (Tezspire) |
| 在研药物 | AMG 157 |
| 临床效果 | 减少哮喘发作，食物过敏在研 |
| 优势 | 上游靶点，可能影响多个炎症通路 |

### 靶点4: FCεRI

| 属性 | 详情 |
|------|------|
| 靶点名称 | High-affinity IgE Receptor |
| 基因 | FCER1A |
| 类型 | 受体 |
| 作用机制 | 阻断IgE结合位点 |
| 在研药物 | Lumiliximab |
| 临床效果 | 减少肥大细胞激活 |
| 局限 | 免疫抑制风险 |

### 靶点5: JAK激酶

| 属性 | 详情 |
|------|------|
| 靶点名称 | Janus Kinase 1/3 |
| 基因 | JAK1, JAK3 |
| 类型 | 非受体酪氨酸激酶 |
| 作用机制 | 阻断细胞因子信号传导 |
| 在研药物 | Ruxolitinib, Upadacitinib |
| 优势 | 小分子口服，成本低 |
| 局限 | 免疫抑制，感染风险 |

### 靶点6: SYK

| 属性 | 详情 |
|------|------|
| 靶点名称 | Spleen Tyrosine Kinase |
| 基因 | SYK |
| 类型 | 非受体酪氨酸激酶 |
| 作用机制 | 阻断FCεRI下游信号 |
| 在研药物 | Fostamatinib |
| 优势 | 直接阻断肥大细胞激活 |
| 局限 | 脱靶效应 |

### 靶点7: CRTH2

| 属性 | 详情 |
|------|------|
