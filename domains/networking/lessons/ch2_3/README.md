# 第二、三章 交换机原理与STP算法

## 📖 知识点讲解

### 2.1 交换机工作原理

#### MAC地址学习过程
1. **初始状态**：交换机MAC地址表为空
2. **学习过程**：
   - PC1发送数据帧到交换机
   - 交换机查看**源MAC地址**
   - 将源MAC与端口映射记录到MAC地址表
   - 后续发往该MAC的数据直接转发到对应端口

#### 数据帧转发规则
| MAC表状态 | 处理方式 |
|-----------|----------|
| 目的MAC在表中 | 单播转发到对应端口 |
| 目的MAC不在表中 | 泛洪（Flooding）到所有端口 |
| 广播MAC（FF:FF:FF:FF:FF:FF） | 泛洪到所有端口 |

### 2.2 STP算法（生成树协议）

#### STP工作流程
1. **根桥选举**：所有交换机中Bridge ID最小的成为根桥
   - Bridge ID = 优先级(默认32768) + MAC地址
   - 优先级相同则比较MAC地址

2. **端口角色确定**：
   - **根端口(Root Port)**：非根桥上到根桥路径开销最小的端口
   - **指定端口(Designated Port)**：每个网段上到根桥路径开销最小的端口
   - **阻塞端口(Blocking)**：既不是根端口也不是指定端口的端口

3. **BPDU交换**：交换机之间定期发送BPDU（桥协议数据单元）

#### STP端口状态
| 状态 | 说明 |
|------|------|
| Blocking | 不转发数据，只接收BPDU |
| Listening | 不转发数据，参与STP计算 |
| Learning | 不转发数据，学习MAC地址 |
| Forwarding | 正常转发数据 |
| Disabled | 端口禁用 |

### 2.3 环路防止机制

- **冗余链路**：提高可靠性，但会产生环路
- **STP作用**：通过阻塞端口打破环路
- **收敛时间**：传统STP约30-50秒

## 📝 习题库

### 选择题

1. 交换机学习MAC地址的依据是：
   - A. 数据帧的源MAC地址
   - B. 数据帧的目的MAC地址
   - C. ARP请求
   - D. ICMP报文
   **答案: A**

2. STP根桥选举的依据是：
   - A. Bridge ID最小
   - B. Bridge ID最大
   - C. MAC地址最小
   - D. 优先级最大
   **答案: A**

3. 以下哪个不是STP端口角色？
   - A. 根端口
   - B. 指定端口
   - C. 阻塞端口
   - D. 转发端口
   **答案: D**

### 判断题

1. 交换机通过查看数据帧的源MAC地址来学习。（对）
2. 优先级值越大越可能成为根桥。（错，越小越优先）
3. STP通过阻塞端口来防止网络环路。（对）

### 填空题

1. 交换机建立的表称为____地址表。（MAC）
2. STP中端口角色包括根端口、____端口和阻塞端口。（指定）
3. 交换机对未知目的MAC的数据帧采用____方式处理。（泛洪）
