# 学术写作工作流

> 从研究想法到论文投稿的完整流程，适用于小龙虾网络所有节点。

---

## 阶段总览

```
P1 选题 → P2 文献调研 → P3 方法设计 → P4 实验 → P5 写作 → P6 修改 → P7 投稿
 (1周)    (1-2周)       (1周)       (1-2周)   (1-2周)   (1周)    (1天)
```

---

## P1: 选题（1 周）

### 选题评估清单

| 评估维度 | 检查问题 | 评分 |
|----------|---------|------|
| 新颖性 | 是否提出了新的方法/视角/问题？ | /10 |
| 可行性 | 现有资源能否完成？ | /10 |
| 影响力 | 能否发表在目标期刊/会议？ | /10 |
| 时效性 | 是否是当前热点方向？ | /10 |
| 团队匹配 | 是否与团队能力匹配？ | /10 |

**选题通过标准**: 总分 ≥ 35/50，且无单项 < 5。

### 选题报告模板

```
标题: [暂定论文标题]
问题: [要解决什么问题]
动机: [为什么这个问题重要]
方法: [计划用什么方法]
贡献: [预期贡献是什么]
风险: [主要风险和应对]
```

## P2: 文献调研（1-2 周）

### 文献检索策略

1. **种子论文**: 从已知的重要论文出发（3-5 篇）
2. **前向追踪**: 查看种子论文的参考文献
3. **后向追踪**: 查看引用种子论文的新论文
4. **关键词检索**: 在 Google Scholar / DBLP / arXiv 搜索
5. **顶会扫描**: 扫描目标会议近 3 年相关 session

### 文献分级

| 级别 | 定义 | 处理方式 |
|------|------|----------|
| A 级 | 直接相关，必须精读 | 使用精读模板完整填写 |
| B 级 | 间接相关，需要泛读 | 读摘要+方法+结论 |
| C 级 | 背景知识，了解即可 | 仅读摘要 |

### 文献综述结构

```
2.1 [方向1] 的现有工作
    - 方法A [1,2,3]: 核心思想 + 局限性
    - 方法B [4,5]: 核心思想 + 局限性
    - 小结: 当前不足 → 引出我们的方法

2.2 [方向2] 的现有工作
    - ...

2.3 本文的定位
    - 与已有方法的本质区别
    - 填补的研究空白
```

## P3: 方法设计（1 周）

### 方法描述模板

```
3.1 问题定义
    - 形式化描述（数学符号）
    - 输入/输出定义
    - 约束条件

3.2 整体框架
    - 架构图
    - 各模块功能概述
    - 模块间交互关系

3.3 核心算法/方法
    - 算法伪代码
    - 关键公式推导
    - 复杂度分析

3.4 实现细节
    - 关键数据结构
    - 优化策略
    - 工程实现要点
```

### 方法验证清单

- [ ] 能否用一段话清晰描述核心思想？
- [ ] 是否有形式化的问题定义？
- [ ] 是否有算法伪代码或流程图？
- [ ] 是否分析了时间/空间复杂度？
- [ ] 是否能解释为什么这个方法有效？

|----------|------|--------|----------|------|

## P5: 论文写作（1-2 周）

### 推荐写作顺序

1. **实验结果** — 先整理数据，确保故事有支撑
2. **方法** — 写清楚做了什么
3. **实验** — 描述设置和分析
4. **引言** — 倒推为什么做这个研究
5. **相关工作** — 定位自己的工作
6. **结论** — 总结和展望
7. **摘要** — 最后写，提炼全文精华

### 各章节字数参考（中文期刊）

| 章节 | 字数 | 占比 |
|------|------|------|
| 引言 | 1500-2000 | 15% |
| 相关工作 | 1500-2000 | 15% |
| 方法 | 3000-4000 | 30% |
| 实验 | 2500-3500 | 25% |
| 讨论 | 1000-1500 | 10% |
| 结论 | 500-800 | 5% |
| **合计** | 10000-13800 | 100% |

### 写作质量自检

- [ ] 每段有主题句
- [ ] 段与段之间有逻辑过渡
- [ ] 所有声明都有数据/引文支撑
- [ ] 无口语化表达
- [ ] 术语使用一致
- [ ] 中英文标点正确
- [ ] 图表有编号和说明

## P6: 修改与审稿（1 周）

### 三轮修改法

**第一轮：结构修改**
- 逻辑是否通贯？
- 各章节比例是否合理？
- 是否有冗余或缺失？

**第二轮：语言修改**
- 表达是否精确？
- 是否有歧义或模糊表述？
- 学术用语是否规范？

**第三轮：格式修改**
- 参考文献格式是否正确？
- 图表编号是否连续？
- 页面排版是否符合要求？

### 内部审稿流程

1. 作者完成三轮修改
2. 提交至 `student_data/{node_id}/drafts/`
3. Hermes 分配审稿人（另外两个节点之一）
4. 审稿人 48 小时内完成审稿
5. 作者根据审稿意见修改
6. Hermes 终审，决定是否可投稿
