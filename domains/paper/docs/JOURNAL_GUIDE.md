## 格式速查

### 中文期刊通用格式

```
字体: 中文宋体/黑体，英文 Times New Roman
字号: 正文五号(10.5pt)，标题小二号(18pt)
页面: A4，双栏（栏宽 8cm，间距 0.6cm）
参考文献: GB/T 7714-2015
摘要: 中文 150-200 字 + 英文 200+ 词
关键词: 3-5 个
```

### LaTeX 模板

```latex
% 中文期刊（ctexart）
\documentclass[a4paper,10pt,twocolumn]{ctexart}
\usepackage{times}
\usepackage{geometry}
\geometry{left=2cm, right=2cm, top=2.5cm, bottom=2.5cm}

% 国际会议（IEEEtran）
\documentclass[10pt,conference]{IEEEtran}
```

## 投稿决策树

```
研究完成度 > 80%?
├─ 否 → 继续实验/写作
└─ 是 → 创新性强?
    ├─ 强（新方法/新框架） → CCF-A 期刊/会议
    ├─ 中（改进/组合创新） → CCF-B/C 期刊
    └─ 弱（应用/验证） → 中文核心/CSCD
        └─ 时间紧? 
            ├─ 是 → 审稿快的期刊（电信科学/计算机应用）
            └─ 否 → 审稿慢但影响力大的期刊（计算机学报）
```
