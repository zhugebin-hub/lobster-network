## 一、新理念概述：代码即设计

### 1.1 核心理念

**"HTML+Playwright 视觉设计管线"** — 将所有视觉设计产出（海报、PPT、社交媒体图、证书等）通过以下管线生成：

```
需求分析 → ImageGen生成纯视觉插画 → HTML/CSS设计排版 → Base64嵌入资源 → Playwright 2x渲染截图
```

### 1.2 理念产生的背景

这个理念来自海报技能学习的实战过程：

| 版本 | 方案 | 结果 | 用户反馈 |
|------|------|------|---------|
| V1 | ImageGen + PIL合成 | AI中文乱码渗透 | — |
| V2 | 更暗遮罩 + 新AI背景 | 版面呆板 | "效果变差了" |
| V3 | HTML+CSS+Playwright | 中文完美，布局精美 | 效果大幅提升 |
| V4 | V3 + ImageGen插画嵌入 | 完整专业海报 | "效果挺好的" |

**关键洞察**: 浏览器天生就能完美渲染中文！用HTML/CSS做设计，Playwright截图即可。ImageGen只负责生成纯视觉插画（不含文字）。

### 1.3 理念的可迁移性

同一管线已成功迁移到PPT制作：每页PPT = 一个1280x720px的HTML页面 → Playwright渲染 → python-pptx组装。已生成完整的14页汇报PPT并验证。

## 二、四层互动学习闭环

### 2.1 闭环架构

```
第一层·秒级: 调度器V6自动出题 → 学员做题 → evaluator评分 → 错题入库
第二层·日级: 教练分析训练数据 → 发现短板 → 调整次日计划 → 更新技能文档
第三层·周级: 三人讨论局 → 内部对抗赛 → qoder技术助教讲解
第四层·任务级: 用户下达真实任务 → 学员实战 → 用户反馈 → 教练策略调整
```

### 2.2 闭环的关键价值

- 每一层反馈都会沉淀为技能文档更新
- "效果变差了"不是失败，而是发现根因的信号
- 真实任务驱动比模拟数据有效100倍
- 三方协作：AI生成 + 教练决策 + 用户验收
