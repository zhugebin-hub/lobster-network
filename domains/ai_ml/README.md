# 🤖 AI/机器学习学习模块

> AI基础概念、机器学习算法、深度学习、AI应用

## 课程概述

本模块涵盖AI基础概念、机器学习算法、深度学习、自然语言处理、计算机视觉等内容。

| 阶段 | 章节 | 主题 | 类型 |
|------|------|------|------|
| **基础篇** | 1 | AI概述 | 理论 |
| | 2 | 机器学习基础 | 理论+实战 |
| | 3 | 深度学习基础 | 理论+实战 |
| **进阶篇** | 4 | 自然语言处理 | 实战 |
| | 5 | 计算机视觉 | 实战 |

| | 8 | AI应用 | 实战 |
