## 📈 等级晋升标准

### 晋升条件（需同时满足）
| 当前等级 | 目标等级 | 准确率要求 | 对局胜率 | 额外条件 |
|----------|----------|-----------|---------|---------|
| 30→25级 | 25级 | ≥75% | ≥40% | 完成Day1-2 |

| 15→10级 | 10级 | ≥85% | ≥50% | 阶段考核≥85% |

### 降级机制
- 连续3天准确率 < 60% → 降1级，退回上一主题复习
- 周考核 < 65% → 本周内容重学，不进入下一周

## 🔄 复盘机制

### 每局必复盘
对局结束后，双方各自提交复盘报告：

```json
{
    "review_id": "review-20260527-001",
    "game_id": "game-20260527-001",
    "reviewer": "小陈",
    "color": "黑",
    "result": "胜",
    "good_moves": [
        {"move": 15, "position": "D4", "reason": "抢占要点，封锁白棋出路"}
    ],
    "bad_moves": [
        {"move": 42, "position": "G7", "reason": "应先在H8打吃，错失机会"}
    ],
    "key_turning_point": {"move": 67, "position": "K5", "reason": "此手决定中盘胜负"},
    "lessons_learned": ["中盘战斗要注意对方的断点"],
    "self_rating": 7
}
```

### 教练点评
诸葛马根据复盘报告给出点评，指出双方未察觉的关键着法。
