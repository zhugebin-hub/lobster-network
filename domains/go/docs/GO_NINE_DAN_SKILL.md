## 一、布局理论体系（Fuseki）

### 1.1 开局哲学

布局的本质是效率——用最少的棋子获取最大的实地与外势平衡。九段布局追求的不是定式的机械背诵，而是对每一手棋效率的深刻理解。

**核心原则**：
- 金角银边草肚皮：角部效率最高（2面围墙），边次之（1面），中腹最低
- 先大后小：优先抢占大场，不纠缠局部小利
- 先急后大：紧急处（死活、攻防）优先于普通大场
- 先手价值：保留先手权利比获取小利更重要

### 1.2 星位（Hoshi / 4-4）开局体系

星位是最具现代性的开局点位，兼顾角部和中腹，适合快节奏战斗。

#### 1.2.1 星位基本定式（6大核心）

**① 小飞挂角 → 小飞应（一间低夹的替代）**
```
  ● 黑棋小飞挂角（3-6），白棋小飞应（5-3）
  → 黑棋可拆边或转攻他角
  → 最平稳的下法，双方均可接受
  → 适合：稳健型选手，追求中盘实力决胜
```

**② 小飞挂角 → 一间低夹**
```
  ● 黑棋小飞挂角（3-6），白棋一间低夹（3-4方向第3线）
  → 引发复杂变化，黑棋有多种应对
  → 点三三：白棋挡，黑棋活角，白棋取外势
  → 跳出：正面战斗，双方均可战
  → 双飞燕：白棋另一侧挂角，形成夹击
  → 适合：攻击型选手，喜欢中盘战斗
```

**③ 小飞挂角 → 二间高夹**
```
  ● 白棋二间高夹，给黑棋更多空间但保持压力
  → 黑棋通常点三三转换
  → 白棋形成厚势，黑棋取角地
  → AI时代最常用的应对之一
```

**④ 点三三（San-San Invasion）**
```
  ● AI革命后最重要的定式变化
  → 直接点入3-3位，夺取角部实地
  → 星位方取外势，点三三方取角地
  → 关键变化：挡的方向决定外势走向
  → 先手/后手判断至关重要
```

**⑤ 大飞挂角**
```
  ● 距离较远的挂角方式，AI时代使用率上升
  → 避免近身战斗，追求全局平衡
  → 通常配合边上已有棋子使用
```

**⑥ 一间高挂**
```
  ● 从第4线挂角，追求速度
  → 不如小飞挂角紧凑
  → 特定局面下有效
```

#### 1.2.2 星位高级变化

**大斜定式（Large Slant）**：最复杂的星位定式之一，涉及30+手的变化树。关键要点：
- 第3手靠压是引发大斜的关键
- 黑棋取实地、白棋取外势（或反之）
- 需要精确计算，一步错全盘皆输
- AI时代重新评估了部分变化的优劣

**小雪崩定式（Small Avalanche）**：
- 局部战斗中最重要的定式之一
- 涉及角部死活、外势、劫争等多个维度
- 需要记住至少5个主要分支的变化

**芈氏飞刀（Mi Yuting Flying Knife）**：
- AI时代的新定式，由芈昱廷九段首创
- 星位定式中的新型攻击手段
- 变化极其复杂，职业棋手仍在研究

### 1.3 小目（Komoku / 3-4）开局体系

小目是最传统的开局点位，注重角部实地，变化丰富。

#### 1.3.1 小目基本定式（5大核心）

**① 小飞挂角 → 小飞应 → 拆三**
- 最经典的小目定式
- 黑棋取角地，白棋取边地
- 平和分投，双方满意

**② 小飞挂角 → 一间高夹**
- 激烈战斗型定式
- 黑棋可点角、跳出、或反夹
- AI倾向于点角转换

**③ 小飞挂角 → 二间高夹**
- 给黑棋较大活动空间
- 黑棋通常跳出或飞压
- 适合追求外势的一方

**④ 高挂（4-5位挂角）**
- 从高位挂小目，追求速度和轻灵
- 小目方通常飞应或夹击
- AI时代高挂使用率显著提升

**⑤ 大飞挂角**
- 较远的挂角方式
- 不如小飞挂角紧凑
- 特定全局配置下有效

#### 1.3.2 小目高级理论

**秀策流（Shusaku Opening）**：
- 1-3-5连续占据三个小目
- 传统围棋的经典开局
- 现代围棋中较少见，但理念仍有价值

**中国流（Chinese Opening）**：
- 星位 + 小目 + 边上第5线大飞
- 快速展开，形成大模样
- 适合擅长中腹战斗的棋手

**迷你中国流（Mini Chinese）**：
- 星位 + 小目 + 边上第3/4线
- 比中国流更注重实地
- AI时代的热门开局

### 1.4 三三（San-San / 3-3）开局

- 极端重视角部实地
- AI时代价值被重新发现
- AlphaGo/AlphaZero 频繁使用
- 缺点：外势较弱，需要后续补偿
- 适合：实地流选手，善于官子决胜

### 1.5 全局布局战略

**速度 vs 实利 vs 厚势三角平衡**：
- 速度型：快速展开抢占大场，牺牲局部利益
- 实利型：确保角部和边地，中盘通过治孤弥补
- 厚势型：构建强大外势，通过攻击获利

**AI布局启示**：
- 第1-10手：优先角部（4个角 > 4个边 > 中腹）
- 点三三时机：对方星位未完全巩固时
- 拆边优先级：拆三 > 拆四（安全性考虑）
- 先手价值：AI极度重视先手权利
- 避免低效：同一方向重复行棋是大忌

## 二、死活（Life & Death）

### 2.1 基础死活形状（必须秒判）

#### 活棋形状
| 形状 | 眼位空间 | 判断 |
|------|---------|------|
| 直四 | 4格直线 | 活（先手后手均活） |
| 曲四 | 4格弯曲 | 活（先手后手均活） |
| 板六 | 6格 | 活（先手后手均活） |
| 直三 | 3格直线 | 先手活，后手死 |
| 曲三 | 3格弯曲 | 先手活，后手死 |
| 丁四 | 4格T形 | 先手活，后手死 |
| 刀五 | 5格刀形 | 先手活，后手死 |
| 梅花五 | 5格十字 | 先手活，后手死 |

#### 死棋形状
| 形状 | 眼位空间 | 判断 |
|------|---------|------|
| 直二 | 2格 | 死（无法做两眼） |
| 方四 | 4格方形 | 死（无法做两眼） |
| 聚五 | 5格聚合 | 死（要点被占后） |

### 2.2 经典死活题型

**大猪嘴（O-Da-Butsu-Guchi）**：
- 形状：角部6目空间
- 结果：先手活，后手死
- 杀法：1扳、2点、3立
- 活法：1做眼关键点

**小猪嘴（Ko-Ma-Butsu-Guchi）**：
- 形状：角部5目空间变体
- 结果：劫活
- 关键：第一手的选择决定劫还是净死

**金鸡独立（Golden Rooster）**：
- 一线打吃造成对方无法连接
- 利用边线的特殊性
- 实战中非常常见

**倒脱靴（Under the Stones）**：
- 故意让对方提子后反杀
- 高级死活中的经典技巧
- 需要精确计算提子后的形状

**胀死牛（Oshitsubushi）**：
- 利用气紧的原理杀棋
- 先填满外气再点眼
- 实战中需要判断气的数量

**黄莺扑蝶**：
- 利用扑的手法制造眼杀
- 需要精确的顺序
- 职业对局中的经典手筋

### 2.3 高级死活技巧

**角的特殊性**：
- 角部只有2面围墙，空间受限
- 一线和二线是死活的关键线
- 角的死活比边和中腹更复杂
- 常见角部死活需要精确记忆

**劫争死活**：
- 劫活 vs 净活：劫活价值约为净活的2/3
- 先手劫 vs 后手劫：先手劫价值远高
- 万年劫：双方都不愿先开劫的局面
- 两手劫：需要连赢两个劫才能活/杀

**对杀（Semeai）**：
- 公气计算：公气偏向有眼一方
- 有眼杀无眼：有眼方在对杀中占优
- 大眼杀小眼：眼位大的一方在公气对杀中占优
- 长气杀短气：基本对杀原则

### 2.4 死活训练方法

**九段级死活训练标准**：
1. 基础形状秒判（3秒内）
2. 5步以内的死活100%正确率
3. 7步以内的死活90%以上正确率
4. 10步以上复杂死活70%以上正确率
5. 实战中能快速判断大龙死活
6. 能发现隐藏的妙手（一路妙手、角部妙手）

## 三、手筋（Tesuji）

### 3.1 基础手筋（25级应全部掌握）

**征子（Shicho / Ladder）**：
- 最基本的吃子手筋
- 阶梯形追杀，每步打吃
- 关键：征子方向不能有对方棋子（征子有利/不利）
- 征子不利时考虑枷吃

**枷吃（Geta / Net）**：
- 不通过连续打吃，而是用包围网捕获
- 比征子更可靠（不受征子方向影响）
- 常见形状：飞枷、尖枷

**倒扑（Uttegaeshi / Snapback）**：
- 先送一子让对方提，再反杀
- 利用对方提子后气紧的弱点
- 实战中出现频率极高

**双叫吃（Ryo-atari / Double Atari）**：
- 同时叫吃两块棋
- 对方只能救一边
- 制造双叫吃需要前期的准备工作

**接不归（Oi-otoshi / Connect and Die）**：
- 对方连接后反而被杀
- 利用气紧原理
- 需要精确计算气数

### 3.2 中级手筋（20级-15级）

**靠（Tsuke / Attachment）**：
- 紧贴对方棋子下子
- 目的是借力、腾挪或制造弱点
- "靠无好手"——被靠方通常有反击手段
- "靠单不靠双"——靠单个棋子有效，靠厚形无效

**扳（Hane / Turn）**：
- 在对方棋子旁边斜着下一子
- 压缩对方空间或扩展己方空间
- "扳二子头"是极具攻击性的手筋
- 角部的扳特别有力

**尖（Kosumi / Diagonal）**：
- 斜向移动一步
- 最坚实的连接方式（不可能被切断）
- 攻击时：尖顶压迫对方
- 防守时：尖连确保连接

**跨（Kosumi-tsuke / Diagonal Attachment）**：
- 比尖更进一步的攻击手段
- 切断对方连接或压缩空间

### 3.3 高级手筋（15级-段位级）

**腾挪（Sabaki / Light Play）**：
- 在对方势力范围内灵活处理弱棋
- 核心思想：弃子取势、借力打力
- "腾挪从靠开始"——靠是腾挪的第一步
- 成功的腾挪 = 牺牲少量棋子 + 获得外势或先手

**弃子战术（Sacrifice）**：
- 主动放弃部分棋子以获取更大利益
- 弃子取势：放弃角地获取外势
- 弃子争先：放弃局部获取先手
- 弃子整形：放弃几子使剩余棋子形状完整

**切断手筋（Cutting Tesuji）**：
- 楔（Wedge / Kiri-komi）：在对方连接处楔入一子
- 扭断：制造复杂的切断战斗
- 跨断：利用跨的方式切断
- 挖（Scoop / Eぐり）：在对方棋子中间挖入

**一路妙手**：
- 在边线（一线）上的精妙手段
- 一路扳：角部死活中常见
- 一路跳：逃跑或连接时的妙手
- 一路点：破坏眼位的关键手

### 3.4 手筋在实战中的应用

**攻击中的手筋**：
1. 先靠后扳：靠住对方再扳，压缩空间
2. 声东击西：攻击一边实则瞄准另一边
3. 缠绕攻击：同时威胁两块弱棋
4. 缓攻：不急于杀死，通过攻击获利

**防守中的手筋**：
1. 做活优先：确保死活是第一原则
2. 轻处理：不要过分执着于每一颗棋子
3. 弃子整形：牺牲部分棋子让整体变厚
4. 转换思维：此处损失要在别处补偿

## 四、中盘战略（Middle Game Strategy）

### 4.1 形势判断

**实地 vs 外势评估**：
- 精确计算双方目数差
- 外势价值评估：厚势能转化为多少实地？
- 先手权利的价值量化
- 弱棋负担的扣分

**厚薄判断**：
- 厚形特征：活棋、连接牢固、外势强大
- 薄形特征：弱棋多、断点、被攻击风险
- 厚势的利用方法：攻击、围空、切断
- 薄棋的处理方法：轻处理、腾挪、弃子

### 4.2 攻防策略

**攻击原则（九段级）**：
1. 攻击的目的不是杀死，而是通过攻击获利
2. 缠绕攻击 > 直接攻击（同时威胁两块）
3. 攻击方向：把对方赶向己方厚势
4. 保持距离：不要贴太紧（攻守兼备的距离感）
5. 利用攻击扩大己方领地或压缩对方领地

**防守原则（九段级）**：
1. 治孤优先于反击（先活再打）
2. 轻处理：不要所有棋子都要救
3. 利用对方攻击的漏洞进行反击
4. 转换思维：局部亏损要全局补偿
5. 保留变化：不要过早定型

### 4.3 大龙攻防

**攻龙策略**：
- 切断退路 → 包围 → 收紧 → 杀棋或获利
- 不要急于杀棋，通过威胁杀棋获取利益
- 注意自身弱点，防止对方反击
- 利用攻龙过程中围空或取外势

**治孤策略**：
- 寻找眼位 → 确保一只眼 → 利用对方弱点做第二只眼
- 逃跑路线：向开阔地带、对方薄处突破
- 弃子治孤：放弃部分棋子换取整体安全
- 劫争治孤：通过打劫获取活棋机会

### 4.4 中盘转换（Furikawari / Trade）

- 角地换外势：放弃角部获取强大外势
- 边地换先手：放弃边地获取先手权利
- 局部亏损全局获利：在某个局部让步，在另一处获利
- 判断转换得失的能力是区分段位的关键

## 五、官子（Endgame / Yose）

### 5.1 官子基础

**先手官子 vs 后手官子**：
- 先手官子：走完对方必须应，己方保持先手
- 后手官子：走完后对方可以脱先
- 先手官子价值 = 目数差 × 2（因为保留了先手权利）
- 收官顺序：先手官子优先 → 大后手官子 → 小后手官子

### 5.2 官子计算方法

**基本计算**：
1. 计算某处官子的双方得失（黑走得到多少 vs 白走得到多少）
2. 两者之和即为该官子的价值
3. 先手官子的价值需要额外加权

**常见官子大小参考**：
| 官子类型 | 大致价值 |
|---------|---------|
| 一路先手扳粘 | 约4-6目 |
| 二路先手扳粘 | 约6-8目 |
| 一路后手扳粘 | 约2-3目 |
| 角部二路大官子 | 约10-15目 |
| 边线拆二残留官子 | 约8-12目 |

### 5.3 高级官子技巧

**官子手筋**：
- 一路妙手：在一线上的精妙收官手段
- 二路夹：利用二线棋子进行收官
- 断点利用：利用对方断点威胁获取官子便宜
- 劫材利用：利用劫材压力迫使对方让步

**官子胜负判断**：
- 精确到半目的形势判断
- 贴目（Komi）的影响：黑棋贴6.5目或7.5目
- 半目胜负时的精确收官顺序
- 职业棋手的官子精度：1-2目以内

## 六、定式深度（Joseki Mastery）

### 6.1 星位定式深度变化

**点三三定式详解**（AI时代最重要定式）：

分支1：标准点三三
```
黑星位(4-4) → 白点三三(3-3)
→ 黑挡(方向决定外势走向)
→ 白爬二线 → 黑扳 → 白再爬 → 黑连扳或长
→ 白活角(约10目) → 黑取外势
→ 关键：挡的方向（向己方厚势方向挡）
```

分支2：点三三后反击
```
白点三三 → 黑从外侧挡
→ 白不活角而是切断反击
→ 形成复杂战斗
→ 需要精确的力量对比判断
```

分支3：AI新型点三三
```
白点三三 → 黑内侧挡
→ 白直接二线跳
→ 黑飞压或夹
→ 白活角 + 黑获更厚外势
→ AlphaGo Zero 首创的变化
```

### 6.2 小目定式深度变化

**小目高挂定式详解**：
```
黑小目(3-4) → 白高挂(4-5)
→ 黑飞应(5-3) → 白拆二或三间拆
→ 或黑夹击 → 白可点角转换
→ AI倾向：高挂后点角转换效率更高
```

**小目低挂 — 雪崩型**：
```
黑小目(3-4) → 白低挂(5-3) → 黑一间高夹
→ 白跳出 → 黑飞压
→ 白靠压 → 形成雪崩型
→ 小雪崩 vs 大雪崩（极其复杂）
→ 需要记忆大量变化分支
```

### 6.3 定式选择原则

1. 配合全局配置选择定式（不要机械套用）
2. 外势方向要配合己方已有棋子
3. 取角还是取势取决于全局实地平衡
4. 先手/后手的选择极其关键

## 七、AI围棋理论（AI-Era Go Theory）

### 7.1 AI对围棋的颠覆性认知

**AlphaGo/AlphaZero/Master的启示**：
- 点三三革命：星位被点三三后角地损失可控
- 早期侵入：AI倾向更早侵入对方势力范围
- 肩冲/碰：高位接触战的全新理解
- 先手执念：AI极度重视先手权利
- 厚势贬值：AI不像人类那样高估外势价值

### 7.2 AI定式新变化

**二间跳守角（AI新型）**：
- 替代传统小飞守角
- 更大空间但略薄
- 效率更高，AI时代流行

**肩冲消势**：
- 在对方势力第4线上方落子
- 压缩对方发展空间
- AI频繁使用，改变了中腹战斗方式

**早期点三三**：
- 开局阶段即点三三
- 快速获取角地实地
- 代价是让对方形成外势

### 7.3 AI vs 人类思维差异

## 八、教学方法论（Pedagogy）

### 8.1 分级教学体系

**入门期（30级-25级）**：
- 重点：规则、基本死活、基础手筋、简单定式
- 每日题量：20-30题
- 对局：9x9为主，偶尔13x13
- 关键能力：吃子技巧、两眼活棋、简单征子/枷吃

**初级（25级-20级）**：
- 重点：死活深化、手筋应用、星位/小目定式、布局原则
- 每日题量：30-50题
- 对局：19x19为主，9x9辅助
- 关键能力：金角银边草肚皮、基本定式、中盘攻防

**中级（20级-10级）**：
- 重点：复杂死活、高级手筋、定式变化、中盘战略、官子
- 每日题量：50-80题
- 对局：19x19慢棋为主
- 关键能力：形势判断、攻防转换、官子计算

**高级（10级-段位）**：
- 重点：职业棋谱研究、AI变化、全局战略、心理素质
- 每日题量：80-150题 + 棋谱研究
- 对局：19x19正式比赛节奏
- 关键能力：全局视野、精确计算、心理对抗

### 8.2 错题复习机制

**间隔重复法（Spaced Repetition）**：
- 第1次复习：做错后1天
- 第2次复习：3天后
- 第3次复习：7天后
- 第4次复习：14天后
- 连续4次做对 → 从错题本移除
- 做错 → 重置到第1次复习

**错题分类管理**：
- 死活错题：角部/边/中腹，按难度分级
- 手筋错题：按类型（征子/枷吃/靠/扳...）
- 布局错题：按开局类型（星位/小目/三三...）
- 官子错题：按大小（先手/后手，目数范围）

### 8.3 动态难度调整

```
IF 连续3天准确率 > 90%:
    → 升级难度（增加高级题比例20%）
    → 考虑升段评估
    
ELIF 连续2天准确率 < 70%:
    → 降级难度（增加基础题比例30%）
    → 插入专项复习日
    → 分析错题集中类型
    
ELSE:
    → 维持当前难度
    → 微调题目类型分布
```

### 8.4 差异化教学

**稳步型学员（如小陈）**：
- 注重基础扎实，不急于升级
- 错题本容量大（14题），需要更多复习
- 增加基础题重复练习
- 鼓励稳定发挥，减少失误
- 每日新题比例：60%新 + 40%复习

**加速型学员（如诸葛虾）**：
- 基础已扎实，可以加快进度
- 错题本小（6题），说明吸收能力强
- 增加高级题和挑战题比例
- 鼓励创新下法和复杂战斗
- 每日新题比例：80%新 + 20%复习

### 8.5 训练日程模板（九段级标准）

**每日训练（约3-4小时）**：
```
08:00-08:30  死活热身（15题，中等难度）
08:30-09:30  专项训练（当日主题：手筋/布局/官子）
09:30-10:00  休息 + 复盘上午内容
10:00-11:00  定式学习/复习
11:00-12:00  实战对局1盘（19x19，30分钟/方）
14:00-15:00  对局复盘 + AI分析
15:00-16:00  死活挑战（10题，高难度）
16:00-16:30  当日总结 + 错题录入
```

**每3天插入复习日**：
```
上午：错题本复习（重做所有错题）
下午：实战对局2盘 + 复盘
晚上：棋谱欣赏（职业棋手对局）
```

## 九、升段评估标准

### 9.1 各级升段条件

| 升级 | 准确率 | 胜率 | 周考 | 特殊要求 |
|------|--------|------|------|---------|
| 30k→25k | ≥80% | ≥60% | ≥75% | 完成基础死活100题 |
| 25k→20k | ≥80% | ≥45% | ≥80% | 星位+小目定式熟练 |
| 20k→15k | ≥75% | ≥50% | ≥80% | 复杂死活90%正确率 |
| 15k→10k | ≥75% | ≥50% | ≥85% | 中盘战斗力评估通过 |
| 10k→5k | ≥70% | ≥55% | ≥85% | 官子精度≤3目误差 |
| 5k→1d | ≥70% | ≥55% | ≥90% | 全局战略+AI变化掌握 |

### 9.2 降级条件

- 连续3天准确率 < 60% → 降1级
- 连续5场对局全败 → 降1级
- 周考 < 60% → 降1级 + 增加复习

### 9.3 25级→20级专项评估（当前目标）

**评估维度**：
1. 死活（30分）：10题，涵盖大猪嘴、小猪嘴、金鸡独立、角部复杂死活
2. 手筋（20分）：5题，涵盖征子、枷吃、倒扑、靠、扳
3. 布局（20分）：3题，星位/小目定式选择、大场判断
4. 官子（10分）：2题，先手/后手判断、目数计算
5. 实战（20分）：1盘9x9 + 1盘19x19

**通过标准**：总分 ≥ 75/100

## 十、心理素质与竞技策略

### 10.1 对局心理

- 开局：保持冷静，按计划布局
- 中盘：不因局部得失影响情绪
- 劣势时：寻找复杂化的机会（搅局）
- 优势时：简化局面，减少变数
- 官子：精确计算，不放松任何半目

### 10.2 时间管理

- 布局阶段：快速下子，节省时间
- 关键战斗：投入充足时间计算
- 官子阶段：预留足够时间精确收官
- 读秒技巧：利用对方思考时间计算

### 10.3 复盘方法

1. 全局回顾：标注关键转折点
2. AI对照：用AI分析每一步的评分
3. 找出3个最大失误（败着/缓着/过分手）
4. 找出3个最佳着手（妙手/好手）
5. 针对性训练：针对失误类型做专项练习
