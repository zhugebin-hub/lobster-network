
## 三、每日训练流程

```
08:30  收到教练推送的当日训练任务
09:00  理论学习（阅读当日知识点总结）
09:30  做题训练（按题库逐题完成）
10:30  错题复盘（对错题逐题分析）
11:00  实战对局（9x9或13x13小棋盘）
11:30  提交训练结果给教练
```

## 五、评估标准

### 每日通过标准
- 做题准确率 ≥ 60%（基础型基线）
- 能用自己的话复述当日核心知识点
- 完成至少1局实战（9x9）

### 7天升级标准（30k→25k）
- [ ] 能准确数气（中腹/边/角）
- [ ] 掌握5种基本吃子方法（打吃/门吃/双打吃/扑/征子）
- [ ] 能判断直三/曲三/直四/方块四的死活
- [ ] 能识别基本连接方式
- [ ] 了解3个以上基础定式
- [ ] 能在9x9棋盘独立完成一局对局
- [ ] 7天累计做题 ≥ 60题
- [ ] 7天总体准确率 ≥ 65%
