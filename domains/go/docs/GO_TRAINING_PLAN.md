# 围棋九段训练系统 - 完整方案

## 一、系统架构

```
诸葛马 (教练/Hermes)
    │
    ├──→ 小陈 inbox ← 小陈工作脚本 → 小陈 outbox ←─┐
    │                                                │
    └──→ 诸葛虾 inbox ← 诸葛虾工作脚本 → 诸葛虾 outbox ←─┘
         │
         └── 共享目录: /shared/messages/queue/
```

## 二、训练大纲（从入门到九段）

### 第一阶段：级位训练（30级→1级）约4周

| 周次 | 内容 | 目标 |
|------|------|------|
| 第1周 | 规则基础、吃子技巧、气的概念 | 达到20级 |
| 第2周 | 死活基础（直三、曲三、刀五等） | 达到15级 |
| 第3周 | 手筋基础（枷、征、扑、挖） | 达到10级 |
| 第4周 | 简单官子、布局入门 | 达到1级 |

### 第二阶段：初段→三段 约4周

| 周次 | 内容 | 目标 |
|------|------|------|
| 第5周 | 定式基础（星位、小目） | 初段 |
| 第6周 | 布局理论（中国流、小林流） | 初段 |
| 第7周 | 中盘战斗基础（攻击、防守） | 二段 |
| 第8周 | 死活进阶（大猪嘴、小猪嘴） | 三段 |

### 第三阶段：四段→六段 约6周

| 周次 | 内容 | 目标 |
|------|------|------|
| 第9-10周 | 高级定式变化 | 四段 |
| 第11-12周 | 中盘高级战术（弃子、转换） | 五段 |
| 第13-14周 | 官子计算（先手/后手官子） | 六段 |

### 第四阶段：七段→九段 约8周

| 周次 | 内容 | 目标 |
|------|------|------|
| 第15-16周 | 名局复盘（吴清源、李昌镐） | 七段 |
| 第17-18周 | AI时代布局（AlphaGo/ KataGo） | 八段 |
| 第19-20周 | 高级手筋、对杀计算 | 九段 |
| 第21-22周 | 自我对局+AI分析 | 稳定九段 |

## 五、对局系统

两个小龙虾互相下棋，教练裁判：

```
教练发送 → 对局指令 → 小陈执黑 / 诸葛虾执白
         ↓
    小陈落子 → 写入 go/move.json → 教练广播 → 诸葛虾收到
         ↓
    诸葛虾落子 → 写入 go/move.json → 教练广播 → 小陈收到
         ↓
    循环直到终局
```
