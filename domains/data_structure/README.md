# 📊 数据结构学习模块

> 数据结构基础、算法分析、常见数据结构实现

## 课程概述

本模块涵盖数据结构基础概念、数组、链表、栈、队列、树、图等常见数据结构的实现与应用。

## 课程结构

| 阶段 | 章节 | 主题 | 类型 |
|------|------|------|------|
| **基础篇** | 1 | 数据结构概述 | 理论 |
| | 2 | 线性结构 | 理论+实战 |
| | 3 | 树结构 | 理论+实战 |
| **进阶篇** | 4 | 图结构 | 理论+实战 |
| | 5 | 排序算法 | 实战 |
| | 6 | 搜索算法 | 实战 |
| **高级篇** | 7 | 高级数据结构 | 理论+实战 |
| | 8 | 算法设计 | 实战 |

## 快速开始

```bash
# 运行测试
cd docs/lobster-network
python -m pytest domains/data_structure/tests/ -v

python domains/data_structure/problems/problem_generator.py
```
