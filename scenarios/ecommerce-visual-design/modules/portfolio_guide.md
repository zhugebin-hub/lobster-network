## 一、作品集结构

### 1.1 必备模块

```
作品集/
├── 01_主图设计/          # 5-10 张
├── 02_详情页设计/        # 2-3 套完整作品
├── 03_海报设计/          # 3-5 张
├── 04_店铺装修/          # 1-2 套
├── 05_设计说明/          # 每个作品附说明
└── 06_个人简介/          # 联系方式 + 服务介绍
```

### 1.2 设计说明模板

```markdown
# 作品名称：XXX 品牌主图设计

## 项目背景
- 客户：XXX 品牌
- 产品：智能手表
- 目标客户：25-40 岁男性
- 设计需求：突出科技感、品质感

## 设计思路
1. 色彩：深蓝色背景 + 金色产品，营造高端感
2. 构图：45 度角展示产品，突出细节
3. 文字：简洁标题 + 卖点标注

## 技术实现
- AI 工具：Midjourney v6
- 提示词：/imagine prompt: luxury smartwatch, dark blue background, golden accents, 45 degree angle, professional photography --ar 1:1 --v 6
- 后期处理：Photoshop AI 修图

## 效果评估
- 点击率模拟：3.2%（目标>3%）
- 视觉冲击力：8.5/10
- 品牌一致性：9/10
```

## 二、作品展示技巧

### 2.1 主图设计展示

**对比展示法：**
```
Before → After
原始产品图 → AI 优化后主图
```

**多场景展示：**
```
场景 1：纯色背景
场景 2：使用场景
场景 3：细节特写
```

### 2.2 详情页设计展示

**长图滚动展示：**
```
首屏 → 卖点 1 → 卖点 2 → 细节 → 参数 → 评价 → 保障
```

**模块拆解展示：**
```
模块 1：首屏吸引（痛点/卖点）
模块 2：产品细节（多角度）
模块 3：技术参数（清晰表格）
模块 4：使用场景（生活化）
模块 5：客户评价（信任背书）
模块 6：售后保障（消除顾虑）
```

### 2.3 海报设计展示

**氛围对比：**
```
促销海报 → 品牌海报 → 活动海报
```

**尺寸适配：**
```
PC 端：1920×600
移动端：750×1000
朋友圈：1080×1080
```

## 三、作品集优化建议

### 3.1 质量优先

- ✅ 精选 10-15 张最佳作品
- ❌ 不要堆砌数量
- ✅ 每个作品附设计说明
- ❌ 不要只放图片

### 3.2 分类清晰

- ✅ 按类型分类（主图/详情页/海报）
- ✅ 按行业分类（服装/数码/食品）
- ❌ 不要混在一起

### 3.3 突出亮点

- ✅ 标注点击率/转化率数据
- ✅ 展示 AI 提示词模板
- ✅ 说明设计思路
- ❌ 不要只放最终效果
