## 🎯 学习路径

### Phase 1: 基础技能（Day 1-4）
- **目标**: 掌握 AI 设计工具 + 电商视觉规范
- **内容**: Midjourney/通义万相使用、尺寸规范、色彩理论、手机摄影、AI 修图
- **产出**: 20+ 基础作品、个人提示词模板库

### Phase 2: 专项训练（Day 5-10）
- **目标**: 掌握主图/详情页/海报/店铺装修设计
- **内容**: 点击率优化、转化率优化、氛围营造、品牌调性
- **产出**: 25+ 专项作品、达到商用级别

### Phase 3: 实战项目（Day 11-14）
- **目标**: 完成真实项目 + 淘宝开店 + 首单获取
- **内容**: 3 个真实店铺设计、淘宝开店流程、定价策略、客户沟通
- **产出**: 30+ 作品集、淘宝店铺、首单

## 💰 变现路径

### 淘宝开店步骤
1. 注册淘宝账号 → 实名认证 → 开通店铺
2. 选择类目：设计服务/虚拟商品
3. 发布服务商品（附作品集）
4. 设置定价与交付标准
5. 优化标题与关键词
6. 低价引流 → 好评积累 → 逐步提价

### 定价策略
| 服务类型 | 新手价 | 熟练价 | 专家价 |
|----------|--------|--------|--------|
| 主图设计 | 5 元/张 | 10 元/张 | 15 元/张 |
| 详情页 | 50 元/套 | 100 元/套 | 200 元/套 |
| 海报 | 10 元/张 | 20 元/张 | 30 元/张 |
| 店铺装修 | 200 元/套 | 350 元/套 | 500 元/套 |

### 预期收入
- 新手期（1-3 月）：500-2000 元/月
- 熟练期（3-6 月）：2000-5000 元/月
- 专家期（6 月+）：5000-15000 元/月
