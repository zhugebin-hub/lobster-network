# 浙江省小学体育与健康课程教案（4.0版本）

| 项目 | 内容 |
|------|------|
| **学段** | 小学水平三（5-6年级） |
| **教学内容** | 篮球：3对2战术配合 |
| **课时** | 第1课时（共3课时） |
| **授课教师** | |

---

## 一、教材分析

### 1. 内容定位
本课选自浙江省小学体育与健康课程水平三篮球模块，属于**战术配合**学习领域。3对2是篮球比赛中常见的以多打少战术情境，是培养学生团队意识和战术思维的重要载体。

### 2. 核心价值
- 发展学生快速决策能力和空间感知能力
- 培养团队协作意识和沟通配合能力
- 提升在动态情境中运用技战术的综合素养

### 3. 学情分析
水平三学生已具备基本的运球、传球、投篮技术，但战术意识较弱，需要创设真实情境引导学生在实战中理解和运用战术配合。

---

## 二、学习目标

### 1. 运动能力
- 85%的学生能在3对2情境中做出合理的传球或突破选择
- 70%的学生能运用"拉开空间—快速传导—创造机会"的战术思路
- 学生能在移动中完成至少3次连续传球后投篮

### 2. 健康行为
- 学生能主动与队友进行语言或非语言沟通
- 学生能在练习中注意保护自己和他人安全
- 学生能积极参与并坚持完成练习任务

### 3. 体育品德
- 培养学生团队合作意识和集体荣誉感
- 培养学生尊重对手、遵守规则的体育精神
- 培养学生在困境中积极思考、勇于尝试的品质

---

## 三、教学重难点

| 类型 | 内容 |
|------|------|
| **重点** | 以多打少时的空间利用和传球时机选择 |
| **难点** | 在快速移动中保持队形并做出合理决策 |

---

## 四、教学过程

### （一）开始部分（3分钟）

#### 1. 课堂常规
- 集合整队，师生问好
- 宣布本课内容和目标
- 检查服装，安排见习生

#### 2. 情境导入
> "同学们，在篮球比赛中，当我们形成3打2的局面时，应该如何利用人数优势得分呢？今天我们就来学习这个有趣的战术！"

**组织队形：**
```
    ××××××××
    ××××××××
    ××××××××
        ▲
       教师
```

---

### （二）准备部分（7分钟）

#### 1. 热身跑：蛇形跑 + 听信号变向（3分钟）
- 学生成一路纵队绕篮球场慢跑
- 教师吹哨，学生快速改变方向
- **要求：** 保持间距，注意观察

#### 2. 球性练习（4分钟）

| 练习内容 | 时间 | 组织形式 |
|----------|------|----------|
| 原地运球（高/低） | 30秒×2组 | 每人一球，散点站立 |
| 行进间运球 | 30秒×2组 | 往返篮球场 |
| 传球接力 | 2分钟 | 4人一组，围圈传球 |

**热身游戏："抢圈游戏"（2对1）**
- 3人一组，2人传球，1人中间抢断
- 目的：激活传球意识和快速反应

---

### （三）基本部分（25分钟）

#### 【环节一】战术讲解与示范（5分钟）

**1. 3对2战术核心原则：**
```
     进攻方(3人)          防守方(2人)
        ○                    △
       / \                  / \
      ○———○                △   △
    
    关键要点：
    ① 拉开空间——三人呈三角形站位
    ② 快速传导——球动人动，调动防守
    ③ 创造机会——形成空位投篮或上篮
```

**2. 教师示范：**
- 完整示范1次（3对2实战演示）
- 分解示范2次（重点展示传球路线和跑位）

**3. 学生观察任务：**
- 进攻方是如何站位的？
- 传球几次后形成投篮机会？
- 防守方是如何移动的？

---

#### 【环节二】分层练习（15分钟）

**练习1：无防守传跑练习（4分钟）**
- 3人一组，按战术路线传切配合
- 重点：传球后快速移动，保持三角形队形
- 轮换：每2分钟顺时针轮换位置

```
    路线示意：
       ①
      / \
     ②→③  (①传给②后向篮下切入)
```

**练习2：消极防守练习（5分钟）**
- 加入2名防守队员（只移动不抢断）
- 进攻方完成3次传球后投篮
- 要求：防守方模拟真实移动，进攻方观察空档

**练习3：积极对抗练习（6分钟）**
- 正常3对2对抗，进攻方10秒内必须投篮
- 得分规则：
  - 空位投篮命中得2分
  - 突破上篮命中得1分
  - 传球5次以上后得分得3分
- 轮换：每3分钟攻守交换

**组织形式：**
```
    场地划分：半个篮球场分为2个练习区
    
    练习区1        练习区2
    [3v2]          [3v2]
    [3v2]          [3v2]
    
    共4组同时进行，教师巡回指导
```

---

#### 【环节三】展示与评价（5分钟）

**1. 小组展示**
- 每组选派1组进行3对2展示
- 其他学生观察并记录亮点

**2. 师生共评**

| 评价维度 | 评价标准 | 自评 | 互评 |
|----------|----------|------|------|
| 空间利用 | 能否有效拉开防守 | ☆☆☆ | ☆☆☆ |
| 传球选择 | 传球时机是否合理 | ☆☆☆ | ☆☆☆ |
| 团队配合 | 是否有沟通配合 | ☆☆☆ | ☆☆☆ |
| 战术执行 | 是否按战术要求完成 | ☆☆☆ | ☆☆☆ |

**3. 教师点评**
- 肯定优点，指出共性问题
- 强调"球动人动"的核心理念

---

### （四）结束部分（5分钟）

#### 1. 放松活动
- 手臂拉伸（传球肌肉群）
- 腿部拉伸（跑动肌肉群）
- 深呼吸放松

#### 2. 课堂小结
**提问引导：**
- 今天我们学习了什么战术？
- 3打2时最重要的是什么？（空间、配合、决策）
- 你在练习中遇到了什么困难？如何解决的？

#### 3. 布置作业
- 课后观看1场篮球比赛，记录3打2的场景
- 思考：如果是4打3，战术应该如何调整？

#### 4. 回收器材，师生再见

## 六、安全措施

1. **场地检查：** 课前检查场地是否平整，清除杂物
2. **热身充分：** 确保学生关节活动充分，预防扭伤
3. **间隔距离：** 练习时保持安全距离，避免碰撞
4. **规则强调：** 强调不允许推人、拉人等危险动作
5. **见习安排：** 身体不适学生在场边观摩，协助记录
