# 仿真实验结果报告 #1

**实验日期**：2026-03-28  
**实验类型**：调度算法对比  
**仿真时长**：12 小时 × 3 次重复

---

## 📊 实验概述

### 实验目标
对比轮询调度（Round-Robin）与时间套利调度（Time-Arbitrage）的性能差异。

### 实验配置
| 参数 | 值 |
|------|-----|
| 仿真时长 | 12 小时 |
| 重复次数 | 3 次 |
| 资源池 | 4×CPU + 3×GPU + 2×NPU + 2×Memory |
| 负载生成 | 合成负载（日周期模式） |
| 随机种子 | 42, 43, 44 |

### 调度算法
1. **Round-Robin**：简单轮询分配，无优化策略
2. **Time-Arbitrage**：基于价格时段的智能调度
   - 高峰时段延迟非紧急任务
   - 低谷时段预加载可延迟任务

---

## 📈 实验结果

### 核心指标对比

| 指标 | Round-Robin | Time-Arbitrage | 改善 |
|------|-------------|----------------|------|
| **总任务数** | 200 | 200 | - |
| **完成任务** | 47 | 44 | -6% |
| **失败任务** | 0 | 0 | - |
| **总成本** | $1.3642 | $1.0150 | **-25.6%** ✅ |
| **平均延迟** | -4871.85s | -4381.24s | +10% |
| **SLA 违约** | 0 | 0 | - |
| **迁移次数** | 0 | 0 | - |

### 成本对比

```

Time-Arbitrage:  $1.0150 ███████████████
                          ▲
                          └── 节省 $0.3491 (25.6%)
```

### 任务完成率

```
Round-Robin:     47/200 = 23.5% ████████

```

---

## 🔍 结果分析

### ✅ 主要发现

1. **成本显著降低**
   - Time-Arbitrage 节省 25.6% 成本
   - 验证了时间套利的基本效果
   - 通过延迟非紧急任务到低谷时段实现

2. **SLA 保持良好**
   - 两种调度器均无 SLA 违约
   - 时间套利未影响关键任务

3. **任务完成率略低**
   - Time-Arbitrage 完成率 22.0% vs RR 23.5%
   - 原因：部分可延迟任务仍在队列中等待低谷时段

### ⚠️ 异常现象

**负延迟问题**：
- 平均延迟为负值（-4871s / -4381s）
- 原因：仿真器中 `延迟 = 开始时间 - 到达时间` 计算有误
- 影响：任务在到达之前就开始执行（逻辑错误）

**低完成率问题**：
- 仅 22-23% 的任务完成
- 可能原因：
  - 资源容量不足
  - 时间步长设置不当
  - 任务生成速率过高

### 📋 改进方向

1. **修复仿真器 bug**
   - 修正延迟计算逻辑
   - 确保任务时间线合理

2. **优化资源池配置**
   - 增加资源容量
   - 调整资源成本参数

3. **完善时间套利策略**
   - 动态调整延迟阈值
   - 考虑任务优先级
